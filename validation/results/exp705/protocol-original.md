# 实验705 固定名义键的全端口位置配对与路径交叉重放

2026-10-25，新增标签计算前登记。承接exp702的普通端口词误差与配对
覆盖缺口，检验两份报告共同关注的真实地图条件。理论依据为Vault
《固定名义键的位置差分与路径交叉重放》。exp704完整计时期间仅准备
本地代码；exact求解与正式程序计时串行。

## 假设与数据

固定完整pair和首Net对齐位移，真实位置仍会改变无Line最优路径的
合法性、终点或费用。空间配对可以消除同键共有的名义背景误差。
本轮只作机制诊断；路径oracle及新标签均不进入线上输入。

从旧exp535百万开发请求中，每个pair取原行序首条非空请求为锚点，
共59,904个pair。按固定seed 20261025705生成另外三个源坐标，
用实际首Net落点a和名义位移v构造目标t=a+d-v，保留相同完整pair
及有符号d。先检查源、首落点、目标有效及四位置互异，再读取标签。
最多4096轮候选位置；覆盖不足时停止，不按误差更换锚点。
每个pair四位置，总239,616行；原锚点59,904条D0复用exp553并复核。
新增位置最多179,712条D0。所有数据属于开发诊断，未声称目标分布
总体Acc；新端口对、跨架构外推另需验证。

## 方法与核验

复用exp552已核验的完整图exact求解器、父链恢复和exp553无Line架构。
私有派生tracer仅增加未知标签哨兵-2，已知锚点必须逐项一致。
每条最优词的独立重放须恢复准确D0、终点和全部费用守恒。
四位置的最优端口词作16向交叉重放，保留首个非法动作、出界、
缺格、最终落点偏差和Block费用差；合法同终点费用必须>=该位置D0。
对角项逐项等于D0。费用差统一扣除各自首Net非Line费。

报告同键D0-w的range与配对差分、全部pair/源族/方向/距离组、
首非法动作类别、合法同终点比例、移植损失及最优词tie的局限。
原始路径和交叉结果按行保存，任一身份或守恒失败立即停止解释。

## 决策与成本

若至少5%的pair在四位置有>=20ps的扣首费范围，继续寻找位置条件的
小状态表示；低于该门时降低此采样配置的研究优先级，回查共有偏置。
将从较低费用位置移向较高费用位置的词作为主要机制见证，按出界、
内部缺格、落点改变和费用变化统计；单类占比>=50%时优先研究该类。
此门只决定下一项机制实验，不代表线上Acc或CPU增益。

本轮不训练模型、不运行完整估计器、不发布制品。exact成本单列，
使用一个单线程离线求解进程，CPU上限1800秒、RSS上限3GB。
原始输入、路径与交叉矩阵预计小于100MB，不需要清理旧大文件。
exp704收益通过后，阶段接入与完整1B优先；本实验exact与其错开。
