# 实验715 完整端口多Net重复片段的执行复杂度

2026-10-25，在读取本轮重复片段统计前登记。正式阶段版exp708/M保持，
exp714已经完成100M并因实际收益门停止。接合报告第5.2、5.3、10.5节。
本轮复用exp705全部239616条真实D0最优词，不生成完整程序小规模测试。

## 假设与对象

exp392只合并同一个Z端口的连续重复；exp517只把至多两个重复self run
改为变量，固定连接词产生整数余类和非负次数缺口。本轮先检查另一条
必要机制，即完整端口的2至4个Net循环是否能显著降低真实词的执行长度。
沿用当前保存词，平局的其他最优词、非相邻循环重排和共享固定短连接
各自保留研究资格。

候选由literal单Net和完整重复单元组成。单元长度1至4，重复至少两次；
单元的Z代码序列逐字相同，包含全部lane。动态规划精确最小化宏调用数，
同数时按单元长度、覆盖长度作固定排序。对照只允许单元长度1的self表示。
每个重复边界必须具有完整端口Arc，终止Arc按原请求保留。

对重复单元u，内部Net位移之和为g，串接Arc闭合回到u首个Z；
它在名义平移图上重复n次的位移为ng。Arc费用由首接入、
单元内部、n-1次循环接续与最终接出分别计算。
真实图只接受按原顺序逐Net resolver重放的结果，Block与Line逐hop收费；
本轮没有把仿射名义费用当作真实费用或界。

## 检查和扩大门

全部原词重放、原Arc费用、D0、真实终点、名义位移与摘要逐条核对。
DP结果由独立Python解码、重新穷举递推和恢复字串核验。
另用固定短串穷举验证DP最少调用数与直接枚举切分一致。
汇报四方向、四角色、长短域和净跳格分组，及全部源目标覆盖。

固定机制扩大门同时要求候选相对self的平均宏调用数下降至少20%、
p90不超过4、p99不超过8。该门对应报告中少量宏替换背景的可用性；
宏自身守卫成本、全域编译、未知位移选择、真实Acc与CPU均另行验证。
记录全部单元字典、每条宏内容和索引字节，不用压缩率替代查询资产。
若机制门失败，结束当前保存词上的1至4Net相邻重复布局，
继续保留连接词共享、一般循环族与新选词的研究资格。
