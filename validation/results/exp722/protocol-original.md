# 实验722 T2D6阶段接入与完整1B

2026-10-25，在exp720完整100M配对结束前登记后续流程。
本轮以exp720的独立审计、所有预登记门通过为启动条件，

## 接入与测试

候选为exp720/T2D6，静态ELF93,360,152B。先在只含单ELF的空目录、
空环境执行完整新100M，核对输出与exp720候选预热输出的完整SHA，
复用该输出已通过的全部契约检查。通过后写入不可变阶段包，再刷新
根入口、latest及submission.zip。完整1B随后执行。

1B沿用全59,904角色端口对、十亿完整请求对非重复的既有输入。
固定CPU8，运行候选一次，完整CPU、wall、RSS、线程、查询分配和
输出契约单列。基线exp708的226.157413秒为历史同输入记录；
本轮一个候选运行只支持单次成绩，100M六对提供配对速度证据。

从该次十亿行完整输出抽取exp683原3,833,856个位置，与已核验exact
逐行配对。基线取exp688的原样本，完整输出SHA等于exp708。
评分复用exp683的有限总体分层方差和26源族组成敏感性区间。
两版本、输入、标签和抽样身份均明确记录。

质量复核沿用exp720的差值门，点值至少-0.03pp、保守97.5%下界
至少-0.05pp、distance/near_axis/direction各组至少-0.10pp。
若失败则保留失败证据并恢复exp708阶段指针；原不可变目录保持。
最终交付仍要求Acc严格大于99%，本轮研究门允许的有限退化单列。

## 边界与资源

1B输入和抽样已被历史研究观察，不再称为新盲测。100M新请求与
source-pin隔离证据来自exp720；角色域外官方覆盖、6242R及平台
性能仍为开放项。离线评分和归档成本不计入estimate CPU。

记录原路径及重建命令，确认当前实验消费者后再逐条删除。
