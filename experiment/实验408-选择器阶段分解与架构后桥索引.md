# 实验408 选择器阶段分解与架构后桥索引

2026-10-18，新结果前登记。正式exp354，CPU发布基准exp323。
上轮exp407为有效进展，77条开发中段选择器CPU继续降低，但每中段选择仍约2.15ms。
本轮先测索引准备、真实DAG与剩余选择CPU，检验两个由源码和原二进制支持的假设。
假设A是后桥分桶依赖架构和32个L目标端口，逐请求重建可提前共享。
假设B是跨度±10、±12的动态整数除法可以分离符号并交给常量除法。
竞争解释是准备成本较小、访存或剩余组合已占主要成本，新增分支抵消收益。

候选固定base、csr、stride、both四项，均使用同一冻结源码及ELF。
base复现exp407组界，csr仅新增全部目标后桥的稳定CSR索引，stride仅改跨度除法，
both组合两项。另保留原冻结exp407二进制old，核对新base的测量包装开销。
CSR按(targetCode,sourceCode,dx mod10,dy mod12)稳定分桶，122,880桶。
32位偏移、原桥id及五项组统计，逻辑容量3,447,684 B；
构建在读取请求前完成，所有桥id在桶内保持原顺序。
stride保持向零截断语义，对M∈{10,12}使用d/(sM)=s*(d/M)，s∈{−1,1}。
真实DAG、桥与候选顺序、稳定同费规则和组界保持。
理论见Obsidian《全目标后桥的稳定架构索引》《固定跨度除法的符号分离等价》。

全部122,880桶与独立逐目标扫描对照，核对桥id顺序、覆盖及五项组统计。
非空桶各16个余数一致位移、四种方向组合，核对新旧组界逐项相同。
除法自检遍历[-4096,4096]及INT_MIN、INT_MIN+1、INT_MAX−1、INT_MAX，
两跨度、正负步长共32,788项。普通与ASan/UBSan完整运行。
77条四项候选与old核对所有名义和实际费用、稳定词、组界和全部DAG工作计数；
sanitizer跑both前4条，逐项相同。标签与评分复用，不生成新exact。

另以profile-base、profile-both记录各行后桥准备CPU与进入DAG之后的CPU。
DAG scope只在既有费用筛选通过后开启，包含早退，避免逐候选读时钟。
用选择CPU减两项取得剩余循环与名义费用成本，报告计时探针开销和适用边界。
profile进程用于诊断，正式比较中关闭新增时钟读取。
保存原Xeon ELF的query静态idiv位置，不将静态指令数解释为动态耗时。

Xeon Gold6226R核3、通用O2、单线程串行。
五项各预热一次，三块顺序固定为
old/base/csr/stride/both，both/stride/csr/base/old，stride/old/both/base/csr。
每块每项各运行完整77条一次。主指标为both对old完整进程CPU配对差，
最小实际收益预定5%，三块t区间95%上界小于0则判主收益明确。
单项与组合对base的配对差作探索描述，不作多重显著性结论。
选择CPU、初始化、峰值RSS和不确定性分别报告；有选择收益的方法继续保留。
本机AMD用于语义与资源诊断，不据其时间弃用方向。
每进程CPU≤120秒、RSS≤2GB、单线程；sanitizer放开虚拟空间并核对RSS。
任何语义、顺序或资源失败保存并停止扩大。

完整估计器CPU、总体acc、新全图exact本轮均为0。
正式候选仍需新请求及完整1M、10M、100M阶梯验证，最终acc严格大于99%。
开工/dev/sdd可用385G，收尾记录清理清单。

## 结果与判定

本机与Xeon全部语义检查通过。122,880桶含63,696个非空桶，124,640个桥id的
覆盖、顺序与统计保持；4,076,544项新旧组界及32,788项整数除法相同。
普通及ASan/UBSan通过。77条全部费用、稳定词和工作计数保持，
其中2,952,734次组判断、2,852,131个跳过组、366,702次双核心求值和369次DAG保持。
CSR使用3,447,684 B；Xeon新增初始化均值0.002549 s。

远端Xeon核3，完整77条选择器进程的三块均值如下。
这里的完整进程包含初始化、文件读写与77条选择，属于开发选择器。

| 模式 | 选择CPU s | 完整选择器进程CPU s |
| --- | ---: | ---: |
| old，冻结exp407 | 0.165157000 | 0.670966667 |
| base，新ELF同逻辑控制 | 0.171934333 | 0.704508333 |
| csr，仅架构索引 | 0.142193667 | 0.682109333 |
| stride，仅常量跨度 | 0.164911000 | 0.703111667 |
| both，组合 | 0.131863667 | 0.668040667 |

主比较both相对old的选择CPU省20.158597%，差值−0.033293333 s，
三块配对t95%区间[−0.034521147,−0.032065520] s。
完整选择器进程仅省0.436087%，差值−0.002926 s，
区间[−0.019665370,+0.013813370] s。
因此预登记的完整进程5%收益及区间条件未通过，选择阶段的收益继续保留。

同ELF消融中，csr、stride、both对base的选择CPU差分别为
−0.029740667、−0.007023333、−0.040070667 s，各自区间全负。
这些属于探索描述。新base比冻结old的选择和初始化都慢；
旧table初始化均值0.315658 s，新base与both分别0.344530667、0.344448 s。
累计input_ready CPU从old的0.499297 s增至both的0.531921 s。
这组实测解释了选择收益与进程收益的差别，代码生成变化的具体原因尚未定位。
候选对照继续保留冻结old，后续复用本轮证据。

本轮确认索引准备可以共享，固定跨度改写也有选择阶段收益。
消除准备后，主成本仍是约295万次组判断及其外围组合。

直接跳过整段内桥循环，并保留原始几何见证和同费次序。

并更新索引及四条相关笔记的双向链接。固定次数域的uint32费用表为20,987,904 B，
忽略余数后下界的实际紧度、初始化成本和CPU收益均待原型验证。
