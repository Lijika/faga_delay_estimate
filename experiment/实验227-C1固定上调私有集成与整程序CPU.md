# 实验227 C1 固定上调私有集成与整程序 CPU

2026-10-12。正式入口 exp131 和交付包不变，私有完整程序对照为 exp220。
exp226 在未参与选型的同架构 6177 条请求上，固定 `(8,64)` 相对截断
预测增益 +0.035589 pp，七带配对 95% 区间 [+0.015375,+0.055587] pp。
本轮仅测试该规则的等价部署和整程序 CPU，不使用新标签调参。
开工 `/dev/sdd` 可用 465,074,757,632 B。

## 预注册

复制 exp220 冻结源码、对象和静态编译命令，仅在 `UpperTree::evaluate`
最终 `prediction` 生成后加入一条规则，当预测为正且 C4800 合法上界
与预测至少差 64 ps 时加 8 ps。上界已包含全部二十源八 cycle 的最短
合法路径。其他函数、模型、压缩资产及编译参数保持原样；源码和 ELF
身份记录到冻结清单，候选仅在 `build/exp227/`。

先按 exp226 已冻结逐行 CSV 检查全部 6177 条的旧、新预测，以及零值、
不可达和其他特殊值。另用 exp121 的 14 条边界请求核对端点和特殊值；
显式 `-bias-ps 0` 的非生产配置须与 exp220 逐字节相同。
静态 ELF <100 MB，单线程，RSS <=2,000,000,000 B，单次
CPU/wall <=3600 s。任一检查失败即停止计时并保留证据。

本地检查通过后，远程 `r9r4900:/home/lhj/lhjwork/eda2026`
通过 Herdr `w1:p2` 在 core3 串行运行。公开 1M、unique 1M 和
repeated 1M 分别预热 AB 一次，然后 BA/AB/BA 三对交错计时；
同机避开其他重负载。复用 exp205 的完整输出契约与线程、资源监测，
每臂同分布多次完整 SHA 一致，旧臂等于 exp220 冻结 SHA；
记录端点顺序、整数、精确 EOF、三字段、cache miss 和 CPU/wall/RSS。
公开 golden 在候选冻结后仅作独立描述，沿用 exp226 的新请求精度
增益和区间进行条件综合分判断。

三对 CPU 差取候选减 exp220，df2 双侧 95% t 区间。目标 1B 输入的
增量 CPU 暂按一次初始化、约 1M cache miss 和命中路径未变化，
以 unique 1M 的配对差条件外推；public 1M 作为另一组同量级 miss
核对，repeated 1M 单独检测命中和初始化行为。若两种 unique 输入的
条件综合分点值均 >=+0.01 且保守下界均 >0，并且 repeated 的 CPU
差区间下界 <=0（未检出额外增长），则通过本轮 CPU 筛选。使用
`0.8*accuracy增益pp - CPU差/120`，保守下界代入精度区间下界
和 CPU 区间上界。按 exp226 点值，实际收益门允许新增目标 1B
CPU <2.2166 s；精度区间下界为正的零收益门允许 CPU <1.4760 s。

本轮门槛仅比较 exp220 与加入本规则的程序。exp220 相对正式 exp131
的额外 CPU 很大，整体综合收益和架构可移植性仍需另行证明；
正式接入还需符合完整 1M 验收及打包规则，平台 1B 以实际评测为准。
