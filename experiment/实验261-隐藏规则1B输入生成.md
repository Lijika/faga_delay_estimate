本轮按 `/mnt/d/obsidian_work/竞赛/EDA2026/赛题测试集/1B本地测试集生成规则.md`
准备远程 CPU 优化输入。算法研究 goal 保持暂停。

## 预先固定的合同

- 官方五个 JSON 固定，坐标按 `(x,y)` 排序，端口按 JSON 顺序。
- U-output 使用 160 个 Z 源和 288 个 Output 目标。
  U-role 使用 208 个非 I 路径源和同样 288 个目标。各生成 1,000,000,000 行。
- 有效坐标和具体端口等概率随机提议；排除完整 pin 自查询和真实图不可达请求。
  完整有向点对精确去重，保留最先出现的合格请求。
- proposal seed 为 2026101201/2026101202，shuffle seed 为
  2026101301/2026101302，label sample seed 为 2026101401/2026101402，
  bootstrap seed 为 2026101501/2026101502。
- 按独立的 128 位 shuffle key 全局排序，平局按完整 pair key 排序并计数。
  CSV 使用 `From,To` 表头、两个字段、LF 和最终换行。
- 可达索引枚举原始逐格 resolver 的全部 Net 落点，对 Z 图运行非递归 Tarjan。
  逻辑源、终端逻辑目标和同 SRB 的直连 Arc 分别映射到原图。
  全域正反落点核对、独立 JSON 几何检查和既有 exact 抽查通过后才扩大规模。
- 完整 1M、10M 试生成后执行两份 1B。验收包含全 CSV 解析、角色、可达、
  自查询、精确重复检查、覆盖统计、最终 SHA-256 和文件大小。
- 生成器使用独立脚本和 `build/hidden-suite-v1/`，远程仅在
  `/home/lhj/lhjwork/eda2026` 执行。本轮保留现有源码和发布改动。

## 结果

全域Z图有9,632,000个状态、161,753,344条边。9,417,280个状态构成一个
强连通核心，其余214,720个是核心可到达的无出边单点。Tarjan、正反BFS和
9,417,280条有效Net的全域互逆检查通过，建立索引约4.44秒、峰值RSS约438 MB。
独立Python解释原始JSON的16个不同offset，全域前驱及核心成员资格保持。

冻结的780条样本覆盖全部208个源端口、288个目标端口和外边界、Line、Block、
同SRB直连与死端。exp203 exact与资格逐条一致，包含176条不可达和88条
无启发式参考求解器交叉检查。本轮仅查看可达性，精度标签用于后续实验时另行登记。

四次输入全量解析和精确桶排序去重通过，独立JSON端点资格通过。生成前后端口、
坐标、距离层、位移方向、Line与Block两侧计数与独立解析结果完全一致。
按10M外推，两份1B CSV合计约70.8 GB；另保留原提议序号、shuffle记录及检查桶。

抽样器按规则使用独立seed与分层reservoir，非零距离层各抽取4096或2048条，
零距离带合计最多1024条。只保存抽样输入，后续accuracy使用前还需核对已有标签交集。
1M抽样检查得到84,314条请求，55个非空层的实际配额、每条原始行号和pin均通过。
其中非零层按实际人数取配额与人数的较小值，1B时按相同算法抽取。

独立Python MT19937-64参考实现通过标准seed首值检查，复现1M试验的前10,000条
接受pair及提议序号、全部1,000,000组128位shuffle key，并把排序结果逐行核对
至CSV的精确EOF。验收程序针对重复、自查询、不可达、额外字段与缺少末尾LF
各返回失败，合法对照通过。manifest在完整1M证据上试写通过。

## 复现

远程源文件和架构固定在 `build/hidden-suite-v1/{scripts,src,validation,arch}`。
三个C++工具以 `g++ -O3 -std=c++17 -Wall -Wextra -Werror` 构建，
链接冻结的 `src/architecture.cpp`。索引及独立几何检查通过后，使用
`sh scripts/run_hidden_suite.sh` 串行生成两份1B、完整核对并冻结manifest。
远程系统Python缺少NumPy，独立JSON几何检查在本机NumPy 1.26.4完成，
其约60 MB资格文件传至远程，SHA身份进入manifest。

## 资料差异与边界

规则将特殊区域邻域半径固定为8，本轮按8执行。其“8取自当前最长名义Net跨度”
的说明与官方JSON有差异，`ZLN/ZLS` 的 `delta y` 为12，`ZLE/ZLW`
的 `delta x` 为10。完整输入由真实JSON几何判断可达，邻域统计使用固定半径8。
左下角半径8区域全部处于Block 0中，该角有效SRB数为0，角点统计按实际有效域解释。
