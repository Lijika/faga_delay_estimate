# 实验734 真实损失交叉与条件表达四格

2026-10-26 预登记。接续 exp728 解答第 1.3、2、3.3、4、9.1 节。
目的为判断是否有足够信号支持大规模条件距离表，先固定函数族和划分。

## 数据与主假设

损失审计复用发布包的 3833856 条 exact/prediction，采用每 pair 的
人口权重 N/64。事件、距离和近轴沿当前权威代码定义；实际端点位移、
对齐名义位移及模型近域分别保存。完整角色端口共 59904 对。

训练使用已核验百万行历史缓存及原 source-pin 三折。该缓存是开发集，
折外结果只支持配置筛选。当前曲线背景、首段和 mandatory 保持。
所有臂使用完整目标 `truth-base_curve-mandatory` 和 `1000/truth` 权重，
使四格只改变特征和函数容量。原 exp719 T2D6 及 exp726/J 作为额外对照。
V 事件统一沿用冻结折外 V8，ordinary 和 H 都纳入四格模型训练。

## 固定四格

| 臂 | 特征 | 模型 |
| --- | --- | --- |
| A | 当前 53 列 | 两棵 depth6，eta 0.7599，复用已验 exp726/J |
| B | 当前 53 列加廉价两端几何条件 | 同 A |
| C | 当前 53 列 | 64 棵 depth6，eta 0.1 |
| D | 与 B 相同 | 与 C 相同 |

新条件复用现有 18 列几何特征，再加入由当前坐标直接生成的两端
side 组合、百行带差、同带、两端中央带距离、外边界裁剪距离、
压缩位移差和首段实际/名义偏移差。所有特征逐列注明计算式；
标签和 exact 路径字段不作输入。保留完整 family/lane，pair 编号
只用于分层诊断，不把编号阈值当物理特征。

64 树固定使用 MAE、Exact leaf estimation、Plain boosting、No bootstrap、
border_count256、l2_leaf_reg1、random_strength0，其余复用当前参数。
训练种子沿用 seed20261023640，重采样 seed20261026734，
离线训练最多 8 线程。此项在开始训练和查看结果前固定，确保与 A
使用相同训练种子。每折每 route 独立训练，
逐叶编号、raw、两次整数化与原生预测相互核对。每行预测在其 source-pin
留出折生成，训练源 pin 与该折相交为零。不做后验超参数扫描。

## 主要指标与门

主要指标为最终整数 Acc，报告 A/B/C/D 与冻结 T2D6 的配对差、
source-family 重采样区间、三折结果、距离/近轴/方向/事件/源族分组。
同时报告训练分数以识别过拟合。

大资产构造门要求教师对冻结 T2D6 增益至少 0.20pp，三折均为正，
source-family 95%同时区间下界大于零；0.45pp 为有余量的研究目标。
新条件的独立贡献至少 0.02pp，方向、距离、近轴主分组下降不得
超过 0.05pp。教师无足够信号时停止扩大该条件目录，转向标签分解
和状态碰撞。门只限定本轮特征、教师容量、样本和固定参数。

损失交叉固定输出 ordinary∩[24,300)∩near_axis 及其互斥非近轴组，
再按完整 pair/lane、真实位置区和 exact 延迟拆分。报告总体损失贡献，
不同分组维度不相加。相同名义键重复数和每键样本数必须随冲突量给出。

## 产物与验证

复用 `build/exp728-consultation` 中的无损数据与训练帮助。
新增 `validation/exp734_condition_teacher.py`，目录 `build/exp734` 与
`validation/results/exp734`。理论依据写入 Obsidian。
本轮只做离线研究；新完整 100M/1B 由后续通过质量和部署门的候选触发。

## 结果

144个新模型全部完成源pin隔离、逐叶、raw与整数预测核对，V预测保持。
历史百万行折外Acc为冻结T2D6 98.639766895%、A 98.642067264%、
B 98.643482433%、C 98.679927225%、D 98.685365459%。
最强D对冻结版提高0.045598564pp，同时源族区间
[0.040839907,0.050755215]pp。B-A为0.001415168pp，D-C为
0.005438235pp。教师及条件价值均未过固定扩大门。

C/D训练评分约98.7038%/98.7187%，折外约98.6799%/98.6854%。
该结果未显示通过这组教师和条件即可补足0.355pp缺口的信号。
停止这组条件驱动的大目录构造，保留其他表示和监督来源的研究资格。
后续exp735用同名义键多位置补充状态冲突及完整费用证据。

3833856条分层exact审计重现当前1B的总体及既有分组损失。
G1普通中短距近轴占人口26.529634%，贡献0.491870992pp损失；
G2普通中短距非近轴占42.851933%，贡献0.469716334pp。
二者互斥，共贡献0.961587325pp，约占当前损失70.96%。
全量评分样本只有793个重复名义键，每键两条，共1586行，
不足以据此建立可靠的多位置条件冲突估计。

准备元数据导出对12521600个合法源端点组合核验首Net落点及费用，
全部通过。当前架构明确为19条Line、7个Block，旧文献转述计数不参与
构图。完整pair损失和各交叉分组保存在`validation/results/exp734`。
本轮新exact和完整estimate运行均为零，生产版保持exp728。
