# 实验240 A1 几何查表同ELF完整1M

2026-10-12。承接 exp191/192/197 的精确 68,160 B 几何表与上下文诊断，
将它接入 exp236 combined 的私有源码。上界、残差模型、缓存及所有预测
固定。本轮解决同一 ELF、同一对象控制下的完整程序成本问题。

## 预注册

三臂为 reference（exp236 combined ELF）、raw 和 table。后两臂使用同一
静态 ELF，每个进程只创建一个相同的 estimator 对象；raw 在架构加载后
关闭该对象的查表资格，table 保持原字节资格。试验开关只存在于私有
审计构建，环境变量 `EXP240_RAW` 只读取一次。实际架构 Net/Gap/Inst
身份不符时，沿用原 resolver。

复用 exp191 已核验的表和生成规则。生成后的 architecture.h/cpp 与
exp191 已认证文件逐字节相同才复用其全域证据；任何差异须停止并另查。
本地核对新候选 12,324 条 exp234 输出与 exp236 combined 完全一致，
raw/table 在单样本及边界分支上保持，三个几何文件的换行变体继续使用
原 resolver。通用 C++17/O2，静态 ELF 小于 100,000,000 B。

等待 exp236 完整计时、exp239 标签及证据传输完成后，再占用远程
`r9r4900:/home/lhj/lhjwork/eda2026` 的 Herdr `w1:p2`、core3。
public/unique/repeated 三种完整 1M，每种预热 reference/raw/table，
随后三轮逆序/正序/逆序，进程严格串行。每次检查完整输出契约、SHA、
单线程、RSS<=2 GB、CPU/wall<=3600 s；每臂另记实际 cache miss。

主工程门要求 table 对 reference 和 table 对 raw，在 public 与 unique
上都点节省至少 1%，配对 t(df=2) 95% 区间上界低于零。repeated 的
两项差值区间下界须不大于零。raw 对 reference 单独报告，衡量编译代码
和对象布局改变带来的影响。每项区间独立解释，跨比较共同覆盖另有限制。
输出任何差异立即停止；固定构造未过门则结束本轮，保留原精度候选。

完整运行计入初始化、资格比较、查表索引、预测、cache 和 I/O。
已核验代码与输入身份保持时复用全域等价证据；新测试用于核对接入与
