# 实验237 C1 选择历史残差模型容量消融

2026-10-12。exp234 的 32 维特征已通过新请求验证，exp236 正在验证部署。
本轮只研究既有 6,180 条 exp215 开发请求上的容量限制，复用
Obsidian《合法上界约束的带符号残差回归》的监督目标和上界条件。

## 预注册

全部使用 exp233 combined 的 32 维特征与相同空间五折。每折完整 pin
隔离训练、校准和测试；alpha 只从既有 `0/0.25/0.5/1` 中按校准分数选择。
保持 L1、权重、eta、min_child_weight、lambda、max_bin、随机种子和
单线程设置。四臂只改变树数和深度。

| 臂 | 树数 | 最大深度 | 用途 |
| --- | ---: | ---: | --- |
| reference | 32 | 3 | 逐行复现 exp233 combined |
| rounds | 128 | 3 | 树数单项 |
| depth | 32 | 5 | 深度单项 |
| combined | 128 | 5 | 唯一主候选 |

主假设为增加这两项容量能学习已有字段的剩余关系。主门固定为 combined
相对 reference 的总体加权增益至少 +0.05 pp，七带配对描述性 95% 区间
下界大于零，至少四个空间折为正。10,000 次 bootstrap，seed2026101215。
区间以已拟合折模型固定为前提，开发集选择后的泛化另用新请求验证。
rounds 和 depth 用于归因，本轮主候选失败后按冻结配置结束。

全部树独立遍历 JSON，核对 XGBoost raw float32、整数取整、P<=0 保持及
有限 U 截断。计时仅记录本地训练/验证资源，exp236 远程计时继续串行。
exp231/234 标签保留原验证用途，本轮训练与校准只使用 exp215。
通过后固定全量模型、alpha 和新请求窗口，再做 exact 新标签验证。

新增推理成本由后续 C++ 实测确定。精度达到门槛时继续研究可移植的
推理优化，并据完整 CPU 与综合分决定部署。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp237_residual_capacity.py freeze
# 提交冻结记录后
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp237_residual_capacity.py run
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp237_evidence_check.py
```

## 结果

主候选未达到预注册开发门，该固定配置结束。

| 臂 | accuracy | 相对 reference 增益 | 描述性 95% 区间 |
| --- | ---: | ---: | --- |
| reference | 97.378365% | 0 | 基准 |
| rounds | 97.394491% | +0.016126 pp | [-0.007065,0.039447] |
| depth | 97.400787% | +0.022421 pp | [0.004380,0.040603] |
| combined | 97.396060% | +0.017694 pp | [-0.014608,0.050272] |

combined 四折为正，五折增益依次为
`+0.063341/+0.004958/+0.007570/-0.035106/+0.052061 pp`。
reference 逐行复现 exp233 combined；rounds/combined 第三折的校准
alpha 为 0.5，其余为 1。depth 单项保持描述性结果，主候选继续按原门判断。

训练及运行检查 CPU 13.05 s、峰值 RSS 276,971,520 B；独立 checker
CPU 19.94 s、峰值 RSS 265,711,616 B，stderr 均为空。
20 个模型的独立 JSON 推理、校准 alpha、完整 pin 切分、树数/深度、
评分和 bootstrap 全部通过。证据见 `validation/results/exp237-report.json`、
`exp237-evidence-check.json`；模型和资源记录位于 `build/exp237/`。

现有 6,180 条开发数据下，增加两项容量的收益不足以进入新请求验证。
后续若研究训练样本量，需将其列为独立因素重新冻结匹配消融。
本轮可用空间从 462,396,170,240 B 变为 462,391,898,112 B，
减少 4,272,128 B，删除释放量为 0 B。
