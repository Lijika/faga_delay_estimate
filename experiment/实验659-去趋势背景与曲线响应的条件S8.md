# 实验659 去趋势背景与曲线响应的条件S8

2026-10-24，查看结果前登记。阶段exp655保持，测试阶梯仅100M、1B。
复用历史开发缓存进行离线训练，新增完整1M/10M及exact标签均为0。

## 主假设与候选

exp656匹配目标和exp658纯地图目标均失败，后者在精确名义背景上
小幅改善、实际曲线上下降，说明补偿关系值得显式表示。固定当前
曲线、匹配D0-B目标及S8预算，给原53列追加两个在线可得整数。

```text
dx = feature8 + feature6; dy = feature9 + feature7
H = 125*(abs(dx)//10) + (125 if dy<0 else 127)*(abs(dy)//12)
z0 = D64 - feature50 - H
z1 = curve_base - D64
```

z0保留第一次舍入及正cycle覆盖，z1只由冻结字节曲线产生。验证
B=z0+z1+fee+H、z1范围[-55,59]、近域z1=0及原53列逐值保持。
两列形成唯一候选C；A为当前曲线+原S8，M为exp656匹配S8。
主比较C-A，C-M隔离特征作用；保持CatBoost1.2.8、全部原参数、
seed20261023640、16路、depth4和固定前8树。16树仅训练/解码中间量。
不添加map新列、不改变路由、不据结果选择某一列或事后混合模型。

## 数据、核验和停止门

历史1,000,000条缓存、source-pin三折及59,904端口对沿用exp656。
每折及补集完整覆盖，权重1000/max(D0+F,128)。新目标不使用oracle。
全部叶编号、原生与JSON double raw、最终整数恢复逐行核对。

C-A点值>=0.02pp，C-A及C-M各用97.5%源族区间下界>0，以Bonferroni
覆盖两比较；26族、9999次、seed20261024659。C-A的distance及
near_axis各组>=-0.03pp。报告MAE、改变行、forced、cross、Line组及
两新特征在固定8树中的split使用量。离线累计CPU<=1200s、RSS<=8GiB、
持久增量<=1GiB。任一质量或数值门失败，停止本固定两列S8组合。

通过后另登静态CLI及新100M联合门，点值>=0.005、保守95%下界>0，
满足资源与契约后阶段接入并完整全端口非重复1B。背景在finish596
才计算，新增特征将改变树的执行依赖；这项成本必须实测，当前不作
CPU相同假设。当前ELF93,398,296B，静态余量6,601,704B。
