# 调研建议与实验结论

本表对应 Obsidian 中《EDA2026-FPGA布线延迟估算两轮调研汇总》的算法建议，列出已做的尝试、采用情况和证据范围。生产结构由实测收益决定，论文的完整布局布线指标单独保留。

## 逐项对应

| 调研方向 | 实际尝试与证据 | 当前决定 |
|---|---|---|
| 真实图语义与 exact reference | 实验1、4、5、7核对八条公开路径、独立显式小图、Block/Line/边界与终点启发式 | Architecture 统一解释真实 Net；Router 提供 exact 标签 |
| 有向端点与 lane 身份 | 实验6、8、13、15比较 Source、Target、Both 及选择性端点；实验24补 I 目标反例 | 默认 source-short 150，保留完整端口身份 |
| Block skip、跨越费用、绕行 | 实验12比较四种几何修正；+110/带在公开集有收益，在独立 skip 见证上明显退化 | 使用真实端点 Net；全局固定 Block 加项不进入默认 |
| ALT | 实验7、10、18与 plain 或基准搜索配对，检查终点下界并记录展开 | 保留在 exact Router，标签模式结合 PDB |

| Karp 与 De Schutter 周期诊断 | 实验26计算精确分数环均值、全 160×160 连续幂恒等式和位移丢失反例 | 保留理论探针，二维位移查询继续使用 residue |
| min-plus 与固定 Net 消元 | 实验17利用唯一 Net 复用源构表、派生 I 目标列，mult2 全表 316,538,880 项零差异 | 采用等价压缩，存储 288 列，保留完整 448 种目标查询 |
| PDB 下界 | 实验9逐边审计；实验10、18测 Router 组合；实验14测输出地板 | 用于 exact 标签加速；输出地板在公开集零改进且增加成本，默认关闭 |
| 两级 CRP/MLD | 实验11修接口计费，实验20A构建两级 overlay，在三个真实窗口及人工有向图与 plain 对照 | 局部正确性成立，较大窗口扫描成本高；保持研究探针 |
| 标准 CCH | 实验20B采用 METIS nested dissection、拓扑补边及双向 customization，115 项检查通过 | 8×8 fill 比 13.455，查询慢于 plain；保持局部原型 |
| 区域骨架 CCH、TNR、HL | 实验20C检查全部 67,108,864 个真实接口对；三种索引另与窗口 plain 对照 | HL 局部查询快，索引规模和跨窗口收益尚未证实；保留探针 |
| AIR/VPR lookahead | 实验22按 20 个 wire family、5 个采样点执行 100 次真实 flood，生成独立二维 map | holdout accuracy 75.156、CPU 327.65 s，弱于 residue；保留对照 |
| 常数与分带残差 | 实验2、3、13做全局/分带中位及空间、端口留出；实验19C同冻结树模型对比 | 作为消融参照，默认无 bias |
| 非线性残差学习 | 实验19A/B做六种留出及特征消融；19C核对 Python/C++；24做独立架构留出；28扩容量并补43/44特征的直接预测对照 | 默认冻结64树 xgb；扩容量两种外层条件退化，直接预测六折均弱于现有残差；保留显式 off及零负结果 |

| 合法上下界与模型截断 | 实验30核对13,230条已见样本及129个见证；实验31生产核对、新架构3,105条、公开1M及十轮100M输出与资源检查通过 | L与复用U1保持显式候选、默认关闭；公开增益仅允许0.152338秒CPU，计时波动更大，保留实验29；独立U2成本超过该批收益允许值 |
| 有限缓存、流式 CSV 与确定性 | 实验8、17、23测重复及混合请求；实验25测1B输入；实验29完成100M消融与1B五次验证；实验49/50补测容量和全独特规模 | 固定64 MiB缓存，采用字段视图和标准库整数转换；1B repeated 平均CPU 464.056秒，五次完整输出一致；实验50中 10M/100M unique 均为 0 命中、单线程、RSS 合规且输出契约通过，100M wall 2182–2183秒 |

实验20中的局部图使用完整 port 状态和真实 Net，独立 plain 直接查询指定目标。早期 `plan_probe` 的 `ZGraph::terminalCost` 曾使用错误的 Z 终点语义，实验2中的 CCH/PDB 旧查询数字已标记失效；实验20采用独立实现。

## 理论建议与实现取舍

周期图论文为线性势函数加 residue 的结构提供依据。实验26用四条轴向自环给出必要边界，再用四角 Bellman-Ford 和凸性证明当前名义商图的可行斜率区域恰为矩形。该架构的完整斜率边界已有验证，新增通用 facet 枚举没有生产收益。实验17和21分别验证压缩与格点容量；实验26的费用预算搜索验证了 `L≤R1≤R2≤exact`，finite-prefix/sector-period 的一般公式及全位移误差上界仍未建立。真实 Block 图上的 residue 高估反例继续适用。

实验26实现了 Karp 精确分数环均值和 De Schutter 的有限矩阵幂诊断。原始权重满足 `M61=M60+49`，四角约化权重也分别达到周期 1；完整矩阵恒等式可向后归纳。两步路径反例展示了相同端口对包含不同净位移，矩阵元素只保留最低费用。生产查询使用二维端点位移，边数周期公式需要额外的位移状态；探针结果支持保留现有 residue。

`L <= exact <= U` 的认证记录与 witness 重放保存在实验4、5、30。最终近似器只返回估计值，可采纳下界保留在搜索接口；生产结果未附逐条误差证书。实验27以模型修正幅度作为不确定度代理，测试固定阈值的 exact 回退。实际 CPU 和公开目标覆盖支持保持默认关闭。实验31完成L和U1生产融合两阶段验证，xgb组合在新架构样本与公开1M的accuracy分别提高0.003129和0.001587个百分点。公开收益允许每1B增加0.152338秒CPU，十轮100M中同一实验29的两轮CPU相差68.95秒，稳定综合收益尚未确立。正式交付继续使用实验29，候选五次1B留待收益证据充分后进行。

原调研中的 StateCodec、NeighborIterator 和 QueryPlanner 职责由现有 Architecture、Router 与 ResidueEstimator 承担。运行时没有通用模型加载器，冻结树数据直接编译进程序。未获收益的索引留在测试目录，具备既有调用方式的诊断选项保持显式开启。

## 比较范围

当前可核验的整体收益是公开 1M 的 accuracy 从原始实现 91.621 提高到 96.116，以及独立架构分布上从关闭残差时的 93.578 提高到 95.376。最终时间与一致性由同一 binary 的 1B 实测给出。

AIR-style map、Port/Lane residue、真实端点修正与残差模型已经在本架构上比较。CRP/CCH/TNR/HL 的查询结果仍限于局部窗口，整图资源与精度收益未验证。DREAMPlaceFPGA、TD-Placer 等完整布局流程，以及 WP532 的 Versal 指标，使用的器件、任务和指标各异，属于外部参考。

实验28以同一约10K条训练标签及相同九项网格，比较直接延时预测与结构残差。独立架构加权 accuracy 为现有64树残差95.376、扩大残差95.420、43特征直接预测87.238、44特征直接预测94.911。六种外层留出中，现有残差均优于两个直接预测对照；扩大容量有两折退化。结构估计与残差目标的贡献已有同条件证据，WP532 的数千万训练标签和器件条件仍超出本轮复现范围。

实验29采用解析与输出优化，两组相反顺序的100M消融中，平均CPU从111.750秒降到96.905秒，所有输出逐字节一致。正式1B五次平均CPU从实验25的679.322秒降到464.056秒，减少31.69%，完整输出与旧版相同。公开accuracy保持96.116008，本机综合分从91.231790升到93.025673；repeated输入包含1M个不同请求。

实验50补齐了全独特请求的规模边界。10M 四轮和 100M 两轮均通过退出码、单线程、RSS、wall、行序、端点原文、整数 delay 与精确 EOF 检查；cache=0/64 的命中数均为 0，10M 与 100M 的同规模输出 SHA 分别完全相同。100M 实测 wall 2182.34–2183.44秒，按预注册的一点线性外推全独特 1B 为 21,574.3秒，超过 3,600秒上限，因此不启动 1B。该结论只描述全独特上界负载，不改公开 repeated 分布下的正式缓存判断，也不外推隐藏集成绩。

原调研的第一阶段目标为 accuracy ≥98、MAPE ≤0.5% 和 1B CPU ≤300 s，研究目标进一步提高到 ≥99、≤0.2% 和 ≤180 s。已测公开 accuracy 与 MAPE 尚未达到第一阶段目标。现有结果支持相对本仓库基线和已测候选的提升，对全面超过学术 SOTA 的主张仍缺同条件证据。
