# 实验147：C1 稠密状态启发式缓存与配对计时结果

生产 Router、正式估算器、根入口和交付包保持 exp131。

## 结果

92行冻结样本的答案、exact 标签、plain 对照、重复运行结果均匹配；safe bound 搜索无 unknown
或不完整项。safe A* 每轮扩张11,463,114个状态，span A* 扩张130,490,437个，差异约91.2%。
五轮固定交错计时结果如下，CPU配对差定义为 `safe - span`：

| 配对差 (s/92行) | 均值 | 样本标准差 | 95% t区间 (df=4) |
| --- | ---: | ---: | ---: |
| `safe - span` | -60.444 | 1.763 | [-62.633, -58.255] |

safe CPU 均值22.187秒，span为82.631秒。该配对结果支持 safe 启发式配置在此样本上比
span A* 更快；计时对比同时改变了启发式配置，不能把差异归因于缓存表示。exp146 的 map
缓存 safe CPU 单次为41.578秒，和本轮dense结果属于非配对参考。

dense 数组包含10,560,000个完整网格状态，两个32位数组合计84,480,000 B。峰值RSS为
671,804 KiB，较exp146 map版本的971,568 KiB低299,764 KiB（292.738 MiB）。本轮数组容量
比预登记的9,632,000状态、77,056,000 B估算高7,424,000 B（9.635%）；实际字节数与完整网格
状态数乘每状态8字节完全相等。总进程CPU657.94秒、wall658.94秒、单线程。provider累计
217,273,145次调用，命中148,281,790次，计算68,991,355个状态界。

输出CSV共92行，SHA-256
`3cafd6751991627d1bc150c92ee6d8f48b70ea9ba6413b5ee5742635e0644350`，与首轮留存文件及
exp146逐行输出完全一致。正式exp131二进制SHA仍为
`aed8b929957a14cd5a2ae73bf94fedfd0cfaa86732ff79a7ee08a9e7afca064c`。

## 判定与边界

- 正确性、逐行输出、单线程、RSS上限、相对exp146的RSS下降、预登记配对顺序及数组字节计算通过。
- 验证脚本因 `cache_bytes_expected` 未满足而以状态码1结束；唯一为假的gate是77,056,000 B容量估算。该估算与全网格稠密数组的实际分配不同，报告保留该偏差。
- 本轮配对CPU比较是safe与span启发式之差；dense与unordered_map的CPU差异仍待同轮交错实验测量。
- 结果支持继续优化和隔离测量该组件，尚未建立完整1M端到端收益或精度收益。正式路径继续使用exp131。
