# 实验437 末段证书的非重复100M规模验证

2026-10-18预登记。exp435在八源独特10M上，exp431与exp434的
完整程序CPU均值为13.660和8.605秒，输出保持，达到预登记扩大条件。
本轮主假设是末段证书减少名义距离读取的收益在100M保持，
同时测量该八源分布能否达到100秒。全160源表示继续独立研究。

固定A为exp431原字段模型，B为exp434末段证书模型，全部沿用冻结ELF。
生成新的100M请求，均匀不放回抽取八源合法首Net位置到160种Z目标，
排除exp419、420、425、429、432请求。种子20261018437，
独立40k标签抽样种子20261018438。样本用于本轮验收，不调模型或阈值。
源端点成组bootstrap 2000次给出acc区间，并记录端口、距离分组误差。

Xeon core3，20k预热，完整A/B/B/A，单线程、RSS<=2GB、每次<=3600秒。
每次CPU包含初始化、解析和输出，架构预计算、生成、契约检查与exact成本单列。
四份完整输出SHA须相同，逐行核对端点顺序、3字段、整数、行数及EOF。
相同SHA复用首份完整输出契约；每份输出仍计算完整SHA并核对大小。
40k新exact必须关联同次完整运行提取的预测，不另跑估计器取得评分。

主指标为CPU和总体acc。CPU少15%作为扩大研究的实际收益参考，
acc严格>99%，争取95%区间下界>99.1%。两对计时报告原始值、
配对差及小样本t区间，避免将其当作跨机器稳定性证据。
100M<100秒只记录八源分布的实测；全源、其他端点、1B及平台继续待验。
相对exp323的发布基准比较复用exp429同分布完整1M，
本轮不重复约万秒的100M发布基准。exp431为本轮等价性能对照。

运行：

```sh
python3 validation/exp437_witness_100m.py prepare
python3 build/exp437/code/validation/exp437_witness_100m.py remote
python3 validation/exp437_witness_100m.py analyze
```

83.87、134.46秒。均值134.43降至83.81秒，减少37.655285%；
两对CPU差为-50.60与-50.64秒，小样本t95区间
[-50.874124,-50.365876]秒。候选两次均低于100秒。

`f0405d6d047656e8b161f886277a6b3e23f5d0314d22068988ba6e46dab4ab05`，
首份全量核验100,000,000行的端点原序、三字段、整数、EOF，
其余输出核对完整SHA和字节数。单线程，最大RSS1,666,093,056字节，

候选每请求2.414938次；Block下界工作保持。完整输出等价，变化行数0。
