## 预注册

exp239 的 32 维加 exp242 九个获胜路径字段。128 树 depth5、eta、
权重、正则和随机种子固定，alpha=1，与 exp242 五折校准一致。
JSON 保存、重载和独立逐树 float32 核对后提交模型。

主门要求相对冻结 exp239 模型的 accuracy 增量至少 +0.05 pp，
七带配对 95% 区间下界大于零，同时相对 P 至少 +0.30 pp。
10,000 次 bootstrap，seed2026101222。新样本只验证固定候选，失败
结束本配置。字段、容量、alpha 和阈值保持冻结。

窗口固定 `[66M,68M)`，每带至多 2,048 条，seed2026101221。
排除 exp174/203/215/226/228/231/234 已查看完整 pin，并排除 exp239
已经登记的样本端点。生成器核对 100,000 条，基础训练请求重叠必须为零。
样本、权重和人口先提交，随后才运行经核验 exact，八条 plain/span 交叉核验。

路径 exporter 复用 exp242 的冻结源码，仅将固定行数检查改为正行数。
导出旧 26 维、gain、selected、P/U 和九项路径摘要；前述旧值与冻结
selector、二十源 C4800、正式预测逐行对齐，费用项加和等于合法 U。
两模型独立 JSON 推理、整数修正和 bootstrap 复算；C++ 部署另验。
