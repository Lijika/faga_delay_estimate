# 实验419 首尾真实事件之间的名义距离

2026-10-18预登记。exp417两源开发子集的首段接合acc 98.828638%。
本轮固定假设为目标端最后一次Net的实际前驱、收费和端口Arc可解释部分剩余误差。

源p唯一首Net落点a、费用w，名义位移v。目标q的每个入Arc来自I_r，
真实Net前驱为b、费用u、Arc费用c。两次及以上Net路径的混合候选为
`w + Dplus_p,r(b-a+v) + Line(a,b) + u + c`，遍历真实合法入边取最小。
另单独考虑同pin零路径、首Net直接落到目标后接Arc的单Net路径。
只保留首尾真实事件，中段仍是近似名义距离。

Dplus在零位移同端口处使用正长度最短环，按目标入边Bellman式从原场计算；
其余位置等于D。每个中段查询检查窗口证书，候选缺失认证的行回到exp417 C
并计数。无可达候选的开发行同样回C。正式不可达逻辑仍独立检查。

固定复用exp417全部15,477条开发请求。主门为总体acc至少99.1%、
两源各自acc严格超过99%，相对C配对增益的源pin分组bootstrap
95%下界大于0，种子20261018419、2000次。
原名义图的末Net Bellman回代须与D逐项相等，真实特殊路径单独自检。
近轴、规则代理、Block矩形及边界分别报告。

先测局部表示质量及候选数，预期完整查询显著变快且全源容量可行后
进入完整1M，再10M。若本轮门未过，保存高损失实例并检查路径内部事件，
暂停增加首尾层数。首尾探针单次CPU不当作完整1M成绩。
本轮只新增实验文件；生产入口exp354及exp323比较基准保持。

LE为99.133329%，规则代理99.647542%，Block矩形相交98.313598%。

[0.193220,0.255717]个百分点。553条变化全部改善，11,597条精确、
3,880条低估，未观察到高估。总体99.1%及SEA单源门未过，
按协议暂停继续增加首尾层数，保留内部几何为下一项误差来源。
该观察不构成真实图下界证明。
