# 实验93：当前 gamma=1 模型的 depth-10 独立验证预注册

日期：2026-09-27。承接实验92 的正收益，验证一个只改变树深度的高容量候选；本轮先做离线精度筛选，不修改正式入口。

## 冻结对象

- control：实验92 gamma1 模型，47维 base 特征，46,505 行可达 exact 训练池，128 棵树、`max_depth=8`、`reg:absoluteerror`、`gamma=1.0`、`eta=0.1`、seed `20260919`、hist、CPU、单线程。
- candidate：完全相同的训练池、特征、目标、权重、树数和 gamma，只把 `max_depth` 改为10。
- 当前 gamma1 模型 JSON：`build/exp92/model-gamma1.json`，SHA-256 `92a3c09217e7881fc07704159f4ba7d123f233bcb21dab5f78a2a8fc61c015cc`。
- 统一生产输出固定为 `-3 ps`；候选不读取 golden，不改变 residue、端点配置或输出契约。

## 独立数据与判决

- 新窗口固定为 affine unique `[38M,40M)`，切片2,000,000行；排除公开输入、训练池、实验91窗口、实验92窗口和全部历史已登记端点。
- 每个距离带最多1,024条 exact 标签，由冻结 `build/query_profile_exp18b --pdb-only --dedup-endpoints --landmarks 8` 产生；七带缺失、排除集命中或端点冲突即停止，不替换样本。
- 主指标为新窗口原始距离带份额加权 accuracy；辅以 MAPE、逐带结果、false finite 和 reachable false unreachable。
- 使用七带 paired bootstrap 10,000次、seed `20260925`。candidate 相对 control 必须同时满足：点增益至少 `+0.03 pp`、95% 下界为正、两类可达性误判不增加。失败即关闭 depth-10，不做部署和性能测量。
- 通过精度 gate 后才做静态导出、逐行 C++ 对照和最多3对1M unique性能测量；本轮不运行完整1B。

## 复现入口

```sh
build/venv-ml/bin/python validation/exp93_p1_depth10.py --stage requests
build/venv-ml/bin/python validation/exp93_p1_depth10.py --stage sample
build/venv-ml/bin/python validation/exp93_p1_depth10.py --stage score
```

请求生成、样本、预测和报告写入 `build/exp93/` 与 `validation/results/exp93-*`。开工前 `/dev/sdd` 可用约481G；收尾记录释放量和可重建大文件身份。
