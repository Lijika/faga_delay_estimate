# 实验57 P0 固定 -3 ps 新窗口验证

日期：2026-09-25。固定比较基线为实验29 `./estimate`，SHA-256
`db2cca1eb976df543b2b7281326402fd77fc7b58bf1492d530535903df88ba35`。
正式入口和 `build/submission/estimate` 在本轮保持不变。

## 冻结协议

候选只在实验29的整数输出后减去 3 ps，命令使用现有 `-bias-ps -3`，不重训模型、
不读取 golden 选择参数、不扫描其它偏移。验证窗口固定为确定性 affine unique 请求的
`[14,000,000,16,000,000)` 行；实验56使用的 `[12M,14M)`、公开输入、训练池、
实验24/31/40/41/43/46/48/51/52 的完整端点键全部排除，命中不替换抽样。

每个距离带最多 1024 条，exact 标签来自 SHA 固定的
`build/query_profile_exp18b --pdb-only --dedup-endpoints --landmarks 8`，采样和标签在
候选预测前完成。主指标是按原始请求带份额加权的 accuracy；同时报告 MAPE、分带结果、
负 exact 可达性和逐行改变数。配对 bootstrap 固定 10,000 次、seed `20260925`，band 0
全量保留。

通过条件预先固定为：相对实验29 accuracy 点增益至少 `+0.01 pp`，95% bootstrap 下界
大于 0，综合收益点估计至少 `+0.01`；候选只允许发生预期的整数减法和零钳位，负 exact
不得变为有限值。候选新增 CPU 用同一进程 200k unique 交错测量，预算为
`96 × accuracy_gain` 秒/1M unique。任一条件失败，关闭 P0，不启动五次 1B 验收。

## 结果

`[14M,16M)` 请求生成后，历史 `[0,10M)` 前缀逐字节一致，固定排除集命中 0。探针保留
6176 行，七带覆盖为 `32/1024/1024/1024/1024/1024/1024`，negative exact 93 行。
实验29基线与候选的输出身份、端点顺序和整数契约均通过；候选只把有限 delay 减 3 并在
零处钳位，982415/1000000 行发生变化，negative exact 始终为 `-1`。

新窗口按请求带份额加权的 accuracy 从 `95.7750783` 提高到 `95.7965678`，增益
`+0.0214895 pp`；七带 paired bootstrap（10000 次，seed 20260925）的 95% 区间为
`[+0.0036572,+0.0399000]`，满足预注册精度门槛。MAPE 从 `1.0746425%` 降到
`1.0702999%`。点综合收益在 CPU 未计入时为 `+0.0171916`。

私有二进制 `build/exp57/estimate-minus3` 只放宽了 bias 与 residual xgb 的组合保护，
其输出与基线结果后处理逐字节一致。固定 warmup 后在同一 1M unique 输入、CPU 3 上交错
运行 10 对，候选减基线 CPU 差为 `-4.206 s`，样本标准差 `0.8697 s`，正态诊断区间
`[-4.745,-3.667] s`；两侧峰值 RSS 约 `904 MiB`，输出行数和 EOF 检查通过。允许预算
为 `96×0.0214895=2.063 s`，组件成本通过。

本轮只完成筛选和组件成本验证，未运行 1B；五次 1B 验收须在确认后按交错顺序执行。
证据：`validation/results/exp57-score.json`、`validation/results/exp57-timing.json`、
`validation/results/exp57-stage-requests.json`、`validation/results/exp57-stage-sample.json`。
