# 实验77：base-d8 固定 128 树新窗口验证预注册

日期：2026-09-26。当前正式模型以实验63/exp71 交付版本为基准；性能比较固定为 3 对交错运行。

## 冻结协议

- 训练池固定为实验63的来源和规则：`exact >= 0` 的 34,352 行，47 维 base 特征，六个屏蔽槽，距离带权重，目标 `exact - fast`，`reg:absoluteerror`，`max_depth=8`，`eta=0.1`，`seed=20260919`，单线程。
- 只比较树数这一变量：64 树控制组与 128 树候选。控制组需复现实验63模型 SHA；候选模型在生成新请求前冻结 SHA。
- 新验证窗口固定为 affine unique `[28M,30M)`，七带各至多 1024 条 exact。排除公开 1M、训练池、历史独立窗口和 exp76 `[26M,28M)` 样本；命中即停止且不补样。
- 主指标为按新窗口距离带份额加权 pooled accuracy。配对 bootstrap 10,000 次、seed `20260925`。候选需达到 `+0.03 pp`、95% CI 下界大于 0，且 false finite 与 reachable false unreachable 不增加。
- 精度通过后才构建私有 C++ 候选并做同一 1M unique 输入上的 3 对 CPU 交错测试；检查完整输出 SHA、端点顺序、整数 delay、EOF、单线程、RSS≤2 GB、wall≤3600 秒。精度失败则不做性能测量、不改正式入口。

## 结果

训练、请求、抽样、exact 评分和原始身份写入 `validation/results/exp77-*`，中间文件在 `build/exp77/`。结论只支持同架构新窗口，隐藏分布和平台 1B 结果以实际评测为准。

## 结果

- `[28M,30M)` 生成 2,000,000 行，抽取 6,177 行，七带完整，历史排除命中 0。
- 64 树控制模型 SHA 为 `79e705e78d3680e9528f479dd2b6722ef6dc06ba0272c0ff0e8823385a256fe0`，与实验63一致；128 树模型 SHA 为 `28445cb3bcd08dfc6838984f2e5a1a4491656919208215ffbabfa655757e3774`。
- 正式控制输出 pooled accuracy `96.354256%`，128 树输出 `96.380741%`，增益 `+0.026485 pp`；配对 95% CI `[+0.005821,+0.047546] pp`。两类可达性误判均为 0。
- 点增益未达到 `+0.03 pp`，精度门禁失败；按协议不做性能测量、不改正式入口。由于区间仍稳定为正，128 树模型保留到 exp78 的事前固定复核，不根据 exp78 结果回调树数或参数。

开工空间读取漏记，收尾 `/dev/sdd` 可用487G，未删除文件，释放量0；本轮中间文件保留用于复现。
