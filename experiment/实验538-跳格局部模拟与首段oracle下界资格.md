# 实验538 跳格局部模拟与首段oracle下界资格

2026-10-20，查看本轮数值结果前登记。exp536完整1M零高估是开发观察，
本轮检查能推出全真实walk下界的有限充分条件。exp537固定秩比较保持
独立，本轮新增训练、真实exact和请求评分均为0。

## 固定命题与数据

沿用vault《跳格宏边的名义模拟与全路径下界》。对每个真实水平
`Z_p --Net_p--> I_p --Arc(c)--> q`检查
`Dplus_p,q(δ_p+14*sign(δ_px)*e_x) <= c+292`。
全部通过则逐宏边walk替换和Line三角不等式赋予exp536精确oracle
全路径下界资格；失败时只结束当前充分证书，整体资格保持未证。
本命题范围为208源及固定288个Z/logic目标，I目标保留独立语义。
原始同pin和真实不可达继续按原生产契约处理。

全部208份exp499认证字段、全部官方Net、Arc、Gap与端口mapping参与。
完整208×288端口对分别查询零位移、源名义首Net位移，以及增加同向
14列的水平位移；logic源及竖直源第三臂沿用第二臂。
160个非空cycle使用exp536原值，独立直接宏边回放必须满足名义值≤原Arc。
每份压缩、原始SHA及完整端口头核对；保存全部179,712个整数值、
全部直接宏边、全部水平跳格宏边和源族计数。每对至少3次查询。

主判据固定为所有水平宏边通过，记录所需统一Block费Bstar最大值、
失败数量及最大违例。任何原直接宏边或身份检查失败都停止本轮，
不得以条件失败代替实现错误。无需bootstrap，这是一组完整有限资格条件。
本轮没有真实acc、生产CPU或最终平台资格结论。
