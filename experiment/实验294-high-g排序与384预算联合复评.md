# 实验294 high-g 排序与 384 预算联合复评

## 预注册

2026-10-16。exp292 完整 1M 与 CLI 修复通过，独特 CPU 均值
139.37 s，提交 `dd55beb`；exp293 全序编码在三个 Xeon 样本均变慢，
采用 exp292 fixed 继续研究。开工 `/dev/sdd` 可用约 410 GiB。

复评 exp253 的同 f 较大 g 优先排序。旧开发 oracle 增加
0.042754497 pp、加权展开减少 4.159020%，原 0.05 pp/10% 门结束扩大。
本轮保留旧结论，按 acc >99% 及同分布 CPU–acc 前沿重新判定。
主假设为 high-g 提高固定预算完成率并减少完整查询 CPU；与 384 预算
组合有机会保留总体 acc 门槛。假设和推导见 Obsidian
`agent-theory/同键较大g优先的预算前缀与路径合法性.md`。

四臂为 baseline（exp292 fixed，512）、highg512、raw384、
highg384。候选复制私有源码；排序改变只修改 search_queue.h，
小桶使用 `(g降序,id升序)`，大 key 四叉堆先比较 key 再使用同一规则。
384 臂仅另改主程序预算说明和 residue 调用预算。默认 Both、模型、
bias、上下界、Net/Arc 和数据布局保持。通用 O2/C++17 静态构建，
源码与编译命令冻结，不添加架构专属指令或依赖。

先以实际候选头文件运行普通及 ASan/UBSan 队列差分夹具，使用标准库
独立三元组比较器覆盖负 id、g 极值、重复项、非单调 key、65536 边界、
大 key 与 clear。high-g 搜索探针对同一 12,150 条开发请求运行
256/384/512 三个预算，256 逐字段与路径对照 exp253 的历史 highg256。
所有有限结果经原始 JSON 独立重放并检查 U>=exact；小预算完成时，
较大预算的结果及路径应相同。六条内置边界及完整程序七行边界另核对。
探针查询 CPU 仅计实验成本，正式性能取完整程序。

主性能沿用三个已查看 exact 样本 U-output、U-role、exp258；按每组
四臂预热，再正序/逆序/正序三轮，Xeon core 3 同机串行。固定样本与
权重，同次完整运行联合记录 acc、配对差、分组误差、变化行、CPU、
RSS、线程和完整输出契约。同臂 SHA 多次一致，baseline 与 exp287
search512-both 冻结输出一致。复用标签，新增评分和探针成本单列。
配对 acc 分层 bootstrap 10,000 次，seed 20261016294；CPU 使用
三对 df2 Student-t 95% 区间，两端加 0.02 s 舍入，0.5% 仅作效应
描述。区间按单比较报告，多候选探索的结论需新请求验证。

逐分布列 acc>99% 的点前沿；CPU 或 acc 区间不足以区分时保留待定。
选择三个分布总体 acc 均>99%、保留在点前沿或有比较不确定性的最快
候选进入另行冻结的新请求与完整 1M。若没有符合条件的新候选，保留
原始数据并结束这一固定组合的扩大。旧候选不会因 AMD 本地计时退出。
任一路径合法性、历史复现或输出契约失败先停止性能测量并记录原因。
本轮不作独特完整 1M、100M/1B、跨架构或官方平台的收益外推。

## 准备记录

三个候选均完成通用静态编译，各 ELF 为 94,083,728 B。highg512、
raw384、highg384 编译 CPU 分别约 18.013/18.071/17.916 s，搜索
探针约 15.146 s。普通及 ASan/UBSan 队列夹具各通过 395,400 次
push、242,496 次 pop 与 75 次 clear。

冻结保存三臂 111 个源码文件和 137 项输入。逐文件核对后，
highg512 仅修改队列头文件，raw384 仅修改两处预算，highg384 仅
组合这两项。完整程序沿用 exp292 的显式端点模式语义。复现命令为
`python3 validation/exp294_high_g.py prepare`、`audit`、远端
`run` 和收回原始证据后的 `check`。现有输出独占创建，复核可复用
冻结身份；重新生成需另用私有目录。

冻结提交 `c2e14da`。三个预算共 36,450 条搜索记录通过核验，
27,882 条有限结果与 294,483 条路径边经原始 JSON 独立重放通过。
highg256 的 12,150 条历史记录（查询 CPU 除外）及 88,085 条路径边
完全复现；18,139 组小预算已完成请求在较大预算下保持字段与路径。
探针 CPU 为 12.064159 s，Python 重放及字段核验 CPU 为 6.538590 s，
均单列为验证成本。
