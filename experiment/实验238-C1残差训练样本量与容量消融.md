# 实验238 C1 残差训练样本量与容量消融

2026-10-12。exp237 在 6,180 条数据上的容量增量较小。本轮将训练样本量
作为独立因素，与同一容量改动做匹配消融。exp236 的部署验证继续使用
冻结模型。exp231/234 从本轮起进入新方向的开发池，原冻结比较仍保留。

## 预注册

开发池固定为 exp215 的 6,180 条、exp231 的 12,322 条和 exp234 的
12,324 条，共 30,826 条。每窗保留原总体抽样权重，汇总指标对应三个
约 2M 窗口的混合总体。各窗标签均由已核验 exact 生成，与基础训练请求
重叠为零；三窗之间完整 pin 互斥，组合后继续按目标 y 的五空间折切分，
排除测试/校准完整 pin。

exp231 缺少的历史特征由 exp234 冻结 exporter 导出。逐行核对原 selector、
P 和 U，统一 32 维特征。四臂采用相同测试行和原 exp230 的 L1 参数。

| 臂 | 训练与校准数据 | 树数 | depth |
| --- | --- | ---: | ---: |
| reference | exp215 | 32 | 3 |
| capacity | exp215 | 128 | 5 |
| data | 三窗池 | 32 | 3 |
| combined | 三窗池 | 128 | 5 |

reference/capacity 复用 exp237 保存的五折模型与校准 alpha，并核对训练、
校准索引和原 exp215 预测。data/combined 重新训练，alpha 继续只在
`0/0.25/0.5/1` 上按对应校准集评分选择。训练、校准、测试按完整 pin
隔离。在线特征、权重定义、seed、eta、min_child_weight、lambda、
max_bin 和截断规则保持固定。

唯一主候选为 combined。开发门要求相对 reference 至少 +0.08 pp、
相对 data 至少 +0.03 pp，两项描述性配对 95% 区间下界均大于零，
且各至少四个空间折为正。每窗七带内分层重采样，保持窗和带的总体权重；
10,000 次 bootstrap，seed2026101216。
单项用于解释收益来源。主门失败后结束该组合，本轮不切换单项或搜索参数。

独立 JSON 树遍历、alpha、逐行整数、有限 U、特殊值、样本来源、折划分
和指标全部核对。区间按拟合折模型固定解释，样本选择及训练不确定性
需要新的冻结模型和新请求验证。公开 golden 保留给部署评分。

本地执行并记录训练 CPU/RSS；远程 exp236 计时保持独占。若开发门通过，
再冻结全量模型及 alpha，然后选择尚未使用的新窗口生成标签。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp238_residual_data.py freeze
# 提交冻结记录后
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp238_residual_data.py run
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp238_evidence_check.py
```

## 结果

主候选通过两项开发门，支持继续冻结模型做新请求验证。

| 臂 | accuracy | 相对 reference 增益 | 描述性 95% 区间 |
| --- | ---: | ---: | --- |
| reference | 97.401377% | 0 | 基准 |
| capacity | 97.420129% | +0.018752 pp | [0.003747,0.034062] |
| data | 97.422804% | +0.021427 pp | [0.011793,0.030661] |
| combined | 97.548241% | +0.146864 pp | [0.124946,0.168777] |

combined 相对 data 增加 0.125437 pp，95% 区间为 [0.104452,0.146120] pp。
两项主比较五折均正，combined 的五折 alpha 全为 1。
主候选相对 P 增加 0.313072 pp；相对 reference 的 101～300 带贡献
0.087663 pp，51～100 带贡献 0.030183 pp，301+ 贡献 0.012243 pp。
数据和容量单项增量较小，二者共同增加后出现较大收益；这是本轮固定
模型、固定开发池上的交互观察，机制和新请求泛化仍待验证。

reference/capacity 在 exp215 子集逐行复现 exp237。独立 checker
重新生成全部特征，核对三窗 pin 隔离、空间折划分、保存的树、alpha、
整数输出、总体/分带/分折指标和按窗按带 bootstrap，全项通过。
训练及运行核查 CPU 60.14 s，峰值 RSS 461,561,856 B；独立检查
CPU 90.24 s，峰值 RSS 482,222,080 B。stderr 均为空。
证据见 `validation/results/exp238-report.json`、`exp238-evidence-check.json`，
模型、特征和资源记录位于 `build/exp238/`。

可用空间从 462,379,323,392 B 变为 462,373,117,952 B，减少 6,205,440 B。
本轮保留原始数据，删除释放量为 0 B。
