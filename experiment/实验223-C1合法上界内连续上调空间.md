## 预注册

对每行固定exp214/215的截断预测P、C4800最小合法上界U与exact G。
只在P>0、U>P时允许输出区间[P,U]中的整数；其余保持P。
逐行oracle为`P if G<=P else G`，仅对符合条件的行执行。
上界合法保证G<=U。报告每组整体与七带的eligible、能精确上调行数、
原accuracy、区间oracle增量、相对exp222两端点oracle额外增量、
总oracle accuracy；核对所有行的索引、权重、合法U、截断关系，
按同一权重重新计算exp222的二选一oracle作为独立对照。

主假设是允许输出区间内整数可补回二选一错过的中长距离收益。
筛选门为两组**各自**相对exp222额外oracle增量至少+0.10 pp；
未过门则停止这个固定区间插值方向；过门才考虑低成本可部署估计器。
同时报告固定候选族距离99%的剩余百分点。已查看标签仅用于离线容量描述；
训练、门限和CPU需要单独实验，全新请求验证不能复用这两组标签。
在计算区间oracle前冻结脚本、输入、判据和协议并提交。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 validation/exp223_interval_headroom.py freeze
# 提交冻结清单后
PYTHONDONTWRITEBYTECODE=1 python3 validation/exp223_interval_headroom.py analyze
```
