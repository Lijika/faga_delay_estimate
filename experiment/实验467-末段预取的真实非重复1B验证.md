# 实验467 末段预取的真实非重复1B验证

2026-10-18预登记。exp466的t在完整100M上达到预先固定的扩大条件后，
使用原ELF在exp462已有的十亿个不同请求上运行一次。请求唯一性、
原完整输出契约与40k exact评分已有证据；本轮继续核实输入和完整输出SHA。
主指标为完整程序user+system CPU，同时记录wall、RSS、线程和非时间计数。
CPU <=300秒记录为八源范围内的1B时间目标通过，实际精度须严格大于99%。

先运行20k预热，再在Xeon core3串行完成1B。固定预测规则、模型、
请求顺序和输出格式，全部非时间计数与exp462/f相同，变化0行。
完整输出SHA相同时复用exp462同次输出新40k exact评分及分组结果，
acc99.1635384648%，95%区间[99.1283602333,99.2001114870]%。
该工程等价验证新增exact与评分CPU均为0。

本轮只运行t一次，exp462/f的343.20秒保留历史同输入参照，
两者的差没有同期配对区间。CPU发布基准仍为exp323，复用exp429同分布
1M的101.535秒，同规模1B发布对照未跑。完整160源、逻辑/I端点、
100MB静态交付、其他架构、官方平台和隐藏集分别待验。

每次运行单线程，RSS<=2,000,000,000 B，CPU与wall<=3600秒。
新输出约41.58GB，开跑前可用空间至少47GB；先清理已核验的重复100M/10M
输出并保留一份同SHA结果。本轮完成后将新1B结果与exp462/f比较头尾各64MiB，
确认完整SHA、可重建命令和按名输入消费者后逐名清理，保留exp462/f。
