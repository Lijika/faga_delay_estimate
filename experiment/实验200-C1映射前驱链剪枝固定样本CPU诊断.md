# 实验200 C1 映射前驱链剪枝固定样本CPU诊断

2026-10-10。承接实验199的逐行等价检查。本轮比较：

- control：实验198未剪枝程序（8个映射，含重复xor4）；
- candidate：实验199程序（7个cycle映射、query级端点、Arc-only剪枝）。

两者使用相同架构、6176条exp174请求、40棵树和manifest，输出写入
`/dev/null`。每个进程包含加载、树恢复、查询、重放和输出调用，采用
`taskset -c 3` 与 `/usr/bin/time` 记录CPU/RSS/wall。

## 协议

- 每臂一次非计时预热；
- 10对配对进程，偶数对 control→candidate，奇数对 candidate→control；
- 不使用新的exact标签，不改变正式源码、二进制、统计门或交付包；
- 计算 `candidate - control` 的配对CPU均值和df=9的95% t区间；
- 本轮是固定6176行组件/初始化诊断，不外推完整1M或平台1B。

## 预注册解释

若candidate的CPU差点估计为负且区间上界小于0，记录工程收益并进入同一
输入的更大计时设计；区间跨零只记录工作量与未定CPU效应。无论结果如何，
精度沿用实验199逐行等价证据，不把本轮写成生产验收。
