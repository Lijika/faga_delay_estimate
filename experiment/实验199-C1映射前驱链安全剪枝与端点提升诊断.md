# 实验199 C1 映射前驱链安全剪枝与端点提升诊断

2026-10-10。承接实验198的固定映射真实重放和 DeepSeek 只读审查。
本轮验证三个工程改动的逐行等价性与工作量：

1. `endpoints(arch, query)` 从 `mode × tree × query` 内层提升到每个 query
   一次；
2. 只使用非负费用推出的 Arc-only 下界，在真实重放前剪枝；
3. 删除与 cycle4 完全相同的 xor4。

## 安全定义

对模式`m`和一条完整父链，令`seed_m`为真实 source Arc，`A_m`为映射
Arc费用和，`a_t`为终端 Arc费用。真实重放费用满足：

```text
U_m = seed_m + A_m + nonnegative_geometry + a_t
    >= seed_m + A_m + a_t = LB_m
```

当`LB_m >= baseline`时，跳过重放不会改变`min(baseline,U_m)`。首轮
不使用尚未单独证明的剩余Line项，避免把剪枝安全性与Line证书混合。

## 固定输入与门

- exp198冻结的40棵树、6176条exp174请求和8个完整映射；
- exp199只运行cycle1--cycle7，xor4由exp198证据证明逐行重复；
- 逐行 `prediction` 必须与未剪枝exp198完全相同；
- 所有实际重放得到的U仍满足`U >= exact`，不可达行不得产生finite；
- 输出保留每模式链尝试、完整链、LB拒绝和resolver计数；
- 本轮不接生产，不修改正式源码、统计门或accuracy候选。

本轮只作安全工作量诊断，CPU计时另行预注册；若逐行等价失败，停止
该剪枝实现并回退到仅提升端点的版本。
