# 实验90：四象限连续表值读取

## 假设

`tableValue` 的四个象限槽在表中连续。请求阶段先计算一次行地址并读取四个相邻值，可减少四次函数调用和重复地址计算，保持 Z 源平移、零位移直达路径和输出不变。

## 方法与固定身份

- 基线：`subm/versions/exp87-more-labels-54e0202/bin-estimate`，SHA-256 `2813881c1a22fca79c47752d71784a120e5000fec282d86be94bfa47332bf043`。
- 候选：`build/exp90-estimate-row-load`，SHA-256 `cb3e7a5d88b4120999059bd747e41216f4c3b971e5c51d7099df48e70e2efca1`。
- 输入：`build/exp57/timing-1m-unique.csv`，SHA-256 `2cf587f1b27ccc5699040e64ea3efc6eb68c100cfd72a36cad383383a018d7bd`。
- 固定核 3，预热 1 次，随后按基线、候选、候选、基线、基线、候选交错 3 对；候选显式使用生产的 `xgb-base47-d8` 与 `-3 ps`。

## 结果

- 候选一次完整 1M 运行及三对正式运行均通过输出契约。两侧每轮输出 SHA-256 均为 `2fabc5f89059bcd15d16735e5579ec7e472a92706ef1e749c01b5209e999ee0d`，1,000,000 行，负值 17,585 行，负值位置 SHA-256 为 `6c9e67fb737c58a52edc1db23a805285bc26118600da3aca8cc1db85c7d242a6`。
- 候选减基线 CPU 差 `[-0.48, -0.73, -0.59] s`，均值 `-0.600 s`，95% 区间 `[-0.911, -0.289] s`。
- 最大 RSS `572,133,376 B`，每轮单线程，最大 wall `26.58 s`。
- 原始计时和完整契约记录：`validation/results/exp90-timing-1m-unique.json`。

## 综合判定

exp87 独立窗口精度增益为 `+0.065892722 pp`，95% 下界 `+0.023182937 pp`。与本轮等价优化合并后，综合点收益为 `+0.057714`，95% 保守下界为 `+0.020953`；新增 CPU 预算为 `6.3257 s`，本轮均值减少 `0.600 s`。候选达到本地接入门槛，进入正式源码重建和完整 1M 静态包验收；本轮未运行 1B。
