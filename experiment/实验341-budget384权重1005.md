# 实验341 budget384 / weight1005

2026-10-17。起点 ba4a6b0，基线为当前 exp335/exp334 `estimate`。本轮只把真实
路径修正查询的预算从 480 降为 384，并把加权键从 1.010 改为 1.005；目标批次、
搜索队列、模型、cache0、输出顺序和其他预测逻辑保持。

历史 exp303 在独立窗口和公开 1M 上记录了 `weight1005/384` 的公开 accuracy
99.0208067288%，当前实验仍需核对源文件和输出身份，不能直接把历史成绩当作本轮
结果。该候选若通过公开 accuracy 严格大于 99 且 Xeon CPU 前沿，再进入完整 1M
资源与输出验收。

## 验证与停止

普通和 ASan/UBSan 队列夹具、搜索字段、路径、exact、边界、CLI、特殊 CSV、
诊断和写出失败审计必须通过。Xeon 核 3 串行，20k/100k 各预热一对并做三对
AB、BA、AB，区间包含 0.02 秒计时舍入。100k 区间上界小于 0 才扩展完整 1M；
区间跨零则保留待定，下界大于 0 则结束该实现。

若扩展完整 1M，公开输出的 accuracy 必须严格大于 99；100M 与 1B 阶段成绩仍只
认非重复、事先未知请求的对应规模完整程序实测。
