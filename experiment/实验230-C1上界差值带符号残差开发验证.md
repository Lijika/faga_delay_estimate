# 实验230 C1 上界差值带符号残差开发验证

2026-10-12。正式入口 exp131、私有 exp220、exp227 和 exp229 保持原样。
exp223 的固定 [P,U] 区间 oracle 仍低于 99%，exp226/228 的固定小步规则
约增加 0.03 pp。本轮检验上界差值是否包含小模型可用的带符号误差信息。
理论见 Obsidian `合法上界约束的带符号残差回归.md`。

## 预注册

仅使用 exp215 的 6180 条已查看请求，其基础预测固定为 exp220 等价的
selector+C4800 截断值 P。复核 exp215 样本、exact、权重和合法上界身份，
复用已核验的基础训练请求零重叠，重新检查与 exp174/203 完整 pin 无交集。
exp226/228 留作其原规则的验证证据，本轮不读取它们的逐行标签用于训练或选型。

五折按目标 y 坐标 `ty//110` 划分，每折留下一带测试、下一带校准，其余训练。
复用 exp202 的完整 pin 排除，训练与校准/测试、校准与测试均无完整 pin 交集。
只训练 P>0 的行，监督值固定为 `exact-P`，权重为
`population_weight/max(exact,1)` 并归一化为训练均值 1。

固定 XGBoost `reg:absoluteerror`、32 棵 depth3、eta 0.1、min_child_weight 10、
lambda 10、hist/max_bin64、base_score0、seed2026101207、单线程。
两臂的模型参数、切分与预测约束相同，geometry 为消融对照，upper 为唯一主候选。

- geometry 使用 P、dx/dy、绝对位移、Manhattan 距离、四个坐标、源目标端口 ID、
  两个 lane 和两端边界距离，共 16 个特征。
- upper 增加合法上界存在标记、U-P、(U-P)/max(P,1)，缺失差值为 -1，共 19 个特征。

每折在校准集选择缩放 `alpha in {0,0.25,0.5,1}`，相同评分优先较小 alpha。
输出先把 `alpha*residual` 按绝对值四舍五入、恢复符号，再加到 P 并截到至少 1；
有合法 U 时截到 U。P<=0 保持原值。高估行的负残差完整参与训练。
选择与评价使用项目 `point_of` 的实际评分。

按七带总体权重报告折外 accuracy、对 P 和固定 `(8,64)` 的配对差、分带贡献、
改写/改善/恶化数量，以及 upper 相对 geometry 的差。seed2026101208 的
10000 次七带配对 bootstrap 只描述已查看开发窗口的折外波动；训练集互相
重叠产生的模型不确定性及多轮历史选择不由该区间覆盖。

主候选推进门为相对 P 至少 +0.10 pp、相对固定 `(8,64)` 至少 +0.05 pp、
对 P 的描述性 95% 区间下界高于零且五个空间折至少四折为正。未过即停止该
固定小模型，本轮不增加树数、深度、参数网格或数据。通过后先冻结全量模型，
再用未参与选择的新请求验证，完整 CPU 与部署成本另验。

本机只做开发训练与评分，远程 exp229 继续独占计时。文件在 `build/exp230/`
和 `validation/results/exp230-*`，不修改生产算法、模型或交付包。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp230_upper_residual.py freeze
# 提交冻结协议后执行
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp230_upper_residual.py run
```
