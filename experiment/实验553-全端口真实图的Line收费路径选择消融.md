## 推导、对象与固定量

理论笔记为Vault的《移除Line收费的真实距离与路径选择余量》。
记原真实距离D、无Line真实距离D0、exp536首Net对齐名义值O。
同pin空路径令F=0；其余Z源令F=首Net的Line费+Line(首Net落点,目标)，
logic源令F=Line(源,目标)。所有原合法路径的Line费用至少F。

```text
L=D0+F <= D
C=D-L >= 0
G=D-O=(L-O)+C
X=原最优路径的Arc+Block费用-D0 >= 0
ell=原最优路径的Line费用-F >= 0
C=X+ell
```

C只依赖两个最短距离和端点，与路径tie无关。X和ell沿用exp552已选路径，
分别衡量Line存在时所选路径的非Line费用增加及Line回跨，仍有tie边界。
无Line所选路径在原图的总费用U0必须满足D<=U0，且C<=U0-L。
O的全图下界资格继续开放，L-O可有符号，所有整数恒等式逐行检查。

## 固定指标、机制门与停止条件

主指标为官方acc，配套记录SSE、MAE、逐行变化、208源、288目标、端口类型、

相对O的配对差按完整源pin簇bootstrap2000次，seed`20261020553`，报告95%区间。

- H_line为本轮主要假设。`O+C`相对O增益至少0.05pp、95%下界>0，且
  C>0覆盖S>0行的比例至少20%，全部满足才保留Line路径选择为主要词误差来源。
- H_kernel为独立表示方向门。L的acc至少99.5%，相对O增益至少0.30pp、
  95%下界>0，全部满足才保留无Line真实核加端点Line的质量方向。
- X、ell及两者交叉能量分别记录；它们不产生额外选型门。
- 任一架构变化超出Line delay、输入身份、全端口覆盖、路径合法性、整数恒等式、
  非负性或安全上下界失败，停止机制解释并保存全部失败证据。
- 任一单线程求解任务CPU超过7200s、RSS超过3GB或wall超过10800s即结束该次任务；
  总新增资产<=1GB，并发RSS保守和<=12GB。本轮为离线预算，生产2GB约束另验。
- H_line失败后结束这一固定收费假设，返回真实几何限制及端口词表示研究；
