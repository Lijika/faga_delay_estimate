# 实验241 C1 残差回归加入结构估计中间值

2026-10-12。exp238 表明扩大训练数据与容量后有增量。本轮检验基础预测
已经计算的 residue 原估计与 endpoint 细化值，是否能解释 32 维历史特征
之外的残差。路线依据外部建议筛选文档第 4.2 节的模型修正量。

## 预注册

数据、五空间折、完整 pin 排除、权重和 128 树 depth5 均沿用 exp238。
reference 复用 exp238 combined 的五折模型与 alpha。唯一候选保留原
32 维，增加六个字段。

```text
base
endpoint
base - endpoint
original - endpoint
(base - endpoint) / max(endpoint,1)
(original - endpoint) / max(endpoint,1)
```

base 为 exp236 私有源码 estimateBase 的整数结果，endpoint 为默认
SourceShort 细化后、基础残差模型前的整数结果。original 为 exp131
最终校准输出，与 selector 历史特征中的 original 对齐。两项比例以
double 计算后转 float32，特殊分支保存实际 0/-1 语义。

只使用既有 friend 测试接口从同一 estimator 导出，按源码相同分支重算
基础残差后的结果，并与 `estimate` 以及三窗原 formal 输出逐行核对。
导出器关闭 upper 模块，结构与 endpoint 参数保持正式默认值。
这些字段的生产路径已计算，后续部署需要传递值；本轮先检验信息增量。

候选沿用全部 XGBoost 参数与 alpha 校准集合。开发门为相对 reference
加权增益至少 +0.05 pp，按窗和带 10,000 次 bootstrap 的描述性 95%
下界大于零，至少四个空间折正；seed2026101219。未过则结束这组特征。
通过后仍需冻结单模型并用新请求验证，exp239 的新标签保持独立。

核对 exporter、原 formal、输入顺序、float32 特征、保存树、alpha、
特殊值和上界截断；训练测试继续完整 pin 隔离。记录本地 CPU/RSS，
远程既有实验按串行顺序运行。结论限定已查看三窗的开发比较。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp241_base_history.py freeze
# 冻结提交后
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp241_base_history.py run

```

## 结果

0.027544 pp，按窗按带 95% 描述区间为 [0.014815,0.040028] pp。
五折均为正，增益依次为
`0.066660/0.000597/0.023386/0.030297/0.020939 pp`，两臂 alpha 全为 1。
点增益低于预注册 0.05 pp 门，该组特征本轮结束。

新增收益主要来自 101～300 和 301+，分别贡献 0.015264/0.009562 pp。
exporter 的 30,826 条结构分支与 formal 整数全部一致；reference 逐行
复现 exp238 combined。全部特征、JSON 推理、alpha、空间 pin 隔离、
分折/分带/总体评分和 bootstrap 复算通过。

CPU 161.03 s、峰值 RSS 483,520,512 B，stderr 均为空。
