# 实验427 直接距离模型高损失真实路径分解

2026-10-18预登记。exp426表明两源开发误差全部欠估，跨Block区域贡献
主要损失。本轮恢复真实exact路径，区分中段Arc差、Line绕行、
内部Block收费及目标后缀选择差，给下一模型提供路径证据。

数据固定使用exp420已查看的20k exact开发样本，选官方损失最高的128条，
再为每条选择同源端口、Manhattan距离最接近且损失≤0.01个百分点的
未用控制请求128条。并列按原样本序号。描述性配对不作为独立精度验证。
复用经核验的exp207 exact_paths二进制与orbit资产，固定256条输入，
逐边重放并检查费用总和等于已保存的exact标签。

对真实路径选定的末Net，计算exp420相应候选M_e以及全部候选最小值M。
对至少两Net的路径，严格检查

```text
exact - M =
  (真实中段Arc和 - 名义中段距离)
  + (真实中段Line和 - Line(首Net落点,末Net前驱))
  + 真实内部Block费用
  + (M_e - M)
```

首末Net的Gap费和末Arc费在两边精确抵消。名义中段包含首Arc，
正长度环保持exp419语义。单Net请求另列，零值和不可达不在选取样本中。
Line差和后缀选择差必须非负；有内部跳格时Arc差可为负，
不得把各项自动解释为全图非负下界。

报告两组每项和、分位数、真实跳格次数、路径包围盒以及高损失实例。
本轮只定位模型缺项，不增加首尾层数，不拟合偏置，不修改正式入口。
复现、输入、二进制和原始路径身份写入validation/results/exp427。

## 结果

256条真实路径逐边重放及费用核对通过，256条分解恒等式成立。
高损失128条的欠估合计17,540 ps，四项总和如下。

| 分量 | 合计ps |
| --- | ---: |
| 中段Arc差 | -11,119 |
| Line额外绕行 | 32 |
| 内部Block费用 | 24,236 |
| 末端候选选择差 | 4,391 |

83条路径包含内部跳格，每次跳过14列并增加292 ps；这83条的Arc差为负。
因此Block费用与名义位移变化必须同时处理。128条控制路径的四项全部为0。
上述结果来自按误差选择的开发样本及每条请求的一条最优路径，
不能解释为总体损失份额或所有最优路径共同的分解。
后续exp428采用绕行与跳格路径类的析取下界验证这一机制。
