## 对象与恒等式

对固定exact求解器返回的一条真实最优路径，A为全部Arc费用，n为全部Net
名义位移之和。Z源先消费唯一Net，落点a、名义位移v、费用w；logic源取
a=s、v=0、w=0。N_g为exp536对齐名义响应，N_w为原源到目标在n上的名义
响应。Z源非平凡请求保持Dplus的强制非空Net，源目标同Z且净名义位移为0
时恢复exp536已保存的正cycle。相同pin的空路径单列，全部分量置0。

定义B为消费首Net后的实际Block费用，ell为剩余实际Net的Line费用减
Line(a,t)。同样从首Net后取O=w+N_g+Line(a,t)，沿用exp550的O。

```text
G = exact - O
S = A - N_w >= 0
T = N_w - N_g
G = S + T + B + ell
B >= 0, ell >= 0
```

S描述固定真实端口词相对相同净名义位移的费用余量，T描述重登记名义位移
后的距离变化。T带符号；Block费用与T保留交叉项。路径tie由原求解器决定，
分量支持这条最优路径的解释。全体最优路径的因果份额与真实下界资格另验。
理论笔记位于vault《真实最短路的净名义位移与事件费用分解》。

## 固定指标、假设与停止条件

主指标为全量G与四项的整数和、平方和、4×4 Gram矩阵、非零行数和评分。
统计分区沿用exp549，并增加源/目标端口、首后skip数(0/1/2+)、Net数
(0/1/2–8/9–32/33+)、S符号和T符号。各分区穷尽且和为全量。

只评估固定标签诊断O、O+B+ell、O+S、O+T+B+ell及exact，不选择系数、
阈值或新组合。全部评分使用同一整数值，非负截断另报。配对单位为完整源pin，
2000次有放回bootstrap，seed=20261020552，报告95%百分位区间、变化行数。

- H_fee，费用诊断O+B+ell相对O改善≥0.10pp，配对95%下界>0，残差平方和
  ≤原G平方和的50%。满足时继续研究显式事件费用的信息表达。
- H_word，O+S达到99.1%，相对O改善≥0.10pp且配对95%下界>0。
  满足时优先研究保持同净名义位移的端口词费用余量。
- H_event，O+T+B+ell达到99.1%，相对O改善≥0.10pp且配对95%下界>0。
  满足时优先研究联合位移与事件响应。两个门均过时保留两通道。
- H_coupling，T与B均非零的行数≥G非零行数的20%，且
  `sum((T+B)^2) <= 0.25*(sum(T^2)+sum(B^2))`，且`sum(T*B)<0`。
  满足时后续表示需共同保存位移与收费；本轮不宣称在线方法收益。

固定门失败后结束对应固定假设，原始关联统计仍保留。未参与选择的新请求、
生产CPU、容量与新ELF分别验证；本轮结果不足以扩大到10M。

### 固定门与误差机制

- H_word与H_event通过，保留端口词余量与联合事件响应两个研究方向。
