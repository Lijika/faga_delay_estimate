# 实验431 八源Block模型的Bellman免枚举

2026-10-18预登记。exp429完整新八源1M的Block候选平均CPU2.255秒，
40k新exact抽样acc99.194730%，95%区间[99.160173,99.230154]%。
每请求原模型平均查询16.784672次，Block修正额外查询1.604534次，
实际下界调用率3.4044%。本轮首先减少仍占主要工作量的目标枚举。

固定将exp421的目标几何证书和exp424的无末端跳格模型下界提前结束，
推广到exp429的8源原始场；字段值、正长度环、首尾模型和Block修正保持。
每个提前返回都经过相同几何过滤及max(M,L)。继续复用原首Net准备。
所有候选值与lower的比较保持断言，有限域身份保持exp429检查。
不改源文件中的正式实现，不扩大场资产，不读取请求答案缓存。

先在exp429的20k开发及20k八源预热输入核对逐字节输出。
预登记名义查询数减少至少25%后进入完整1M。
完整输入及40k标签复用exp429，等价优化按完整SHA复用同次输出评分，
没有新增标签成本。Xeon core3、O2、20k预热，A/B/B/A，
A为exp429 bound，B为本候选，完整解析、初始化及输出均计CPU。
报告CPU配对差、单线程、RSS和契约；同一输入SHA必须相等。
完整CPU至少减少15%作为此次扩大10M的优先条件，较小收益仍按现行规则保留。
100M及1B阶段、全源静态容量仍需各自验收。

平均2.255降至1.595秒，减少29.2683%。

`a34c3f9d5bbe0b673a7548d0e4edc6ee49f91e7ce33ca9e06a8fb909f094af1d`，

[99.160173,99.230154]%，相对A变化行数0，新增exact成本0。

名义查询16,784,672降至7,493,361，几何证书直接结束229,247条，
模型下界求值696,637条，其中683,443条候选取等后结束。
Block调用34,044次及其1,604,534次认证查询保持。
