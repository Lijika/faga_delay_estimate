# 实验291 短预算双端点独立验证

## 预注册

2026-10-16，exp290 已提交 `e65cb69`。本轮固定 exp287 的
search512-both ELF，对照 exp281 combined，二者大小均
94,083,728 B。实验身份沿用各自源和冻结对象，不重新编译，
也不修改正式入口、构建脚本和交付包。search768 在 exp288 新请求与
完整 1M 的原始结果继续保留，本轮新请求将其既有窗口列为开发集，
不重复把其已查看标签当成独立验证。

主假设为历史 search512-both 在另一段未参与选择的同架构请求上
总体加权 acc 严格 >99%，且完整独特 1M Xeon CPU 低于 exp281。
目标仍为独特 1M <100 s、100M <100 s、1B 100-300 s。
最低实际 CPU 收益固定 0.5%，只用于描述效应；
相同分布、硬件、规模和计时方式下的 CPU-acc 帕累托前沿决定保留。
候选同现有 search768 的 CPU 比较只在相同批次、协议与分布上解释；
历史候选不因本轮单一分布被删除。

从既有 affine unique 生成器取 [76M,78M)，固定 seed=20261016291。
排除 exp284/exp288 冻结的已查看和训练 pin，再加入 exp288 新样本；
另排除公开完整 1M、独特完整 1M 和 repeated 1M 的完整 pin。
非零六带各取至多 2048，零距离带全部保留，
按排除后人口计算权重；生成和抽样均不读取新标签或预测。
先冻结协议、脚本、ELF、输入身份及新样本，再生成新 exact 标签。
标签由现有已核验 exact 求解器和 `orbit.i16` 给出，
四个中短距离带各取前两条由 plain Router 交叉核对，
标签生成 CPU、RSS 和 wall 单列。

新请求样本先两臂预热一次，再 AB/BA/AB 三对；
A 为 exp281 baseline，B 为 shortboth。
Xeon `r9r4900` core 3 串行，用完整进程 user+sys（含初始化和 I/O）。
同次估计输出联合用于 CPU、acc、SHA、契约和多次一致性。
分层配对 bootstrap 10,000 次，seed=20261016291；
CPU 差用三对 df2 Student-t 95% 区间、两端各加 0.02 s 舍入。
报告七带 acc、相对误差、配对差、变化/改善/恶化行数、
零及不可达行。若总体 acc 未严格超过99%，保存数据并停止扩大；
若 acc 通过且样本 CPU 区间下端 <=0，则继续完整 1M。
区间仅逐项解释，三对时间不能确证差值正态，
请求同家族相关性限制 bootstrap 泛化。

完整阶段在现有独特 U-output 1M 上用两臂 20k 前缀预热，
再 AB/BA 两对；使用完整 SHA、多次一致性和 df1 CPU 区间。
shortboth 在公开 golden 1M 连续运行两次并直接评分，
baseline 输出和 acc 按冻结输入与完整 SHA 复用；
两臂公开 CPU 仅保留跨批描述。repeated 1M 各预热一次，
再 AB/BA/AB 三对，并单列 cache hit/miss 诊断成本。
每次估计校验端点原序、恰好三字段、整数 delay、精确 EOF、
单线程、RSS≤2,000,000,000 B、CPU/wall≤3600 s。
独特 1M 缺少全量 exact，不把新样本或公开 acc 转赋给它。
七行边界与 CLI 特殊输出复用同 ELF 的 exp287 原始证据。

原始运行存于 `validation/results/exp291/`，生成输入存
`build/exp291/`。评分、bootstrap、exact、估计 CPU 分列，
正式结果独占创建。开工 `df -h /dev/sdd` 约 411 GiB，
收尾复查，不清理未经核验的历史和按名引用数据。
新请求只验证同架构泛化；100M/1B、跨架构及官方平台成绩待验。

## 完整 1M 结果

16 次计时及两次 cache 诊断完成，`check-full` 通过。独特 U-output
1M 两对 AB/BA 中，baseline 为 192.74/193.47 s，shortboth 为
143.45/142.90 s，均值分别 193.105/143.175 s。配对差为
-49.29/-50.57 s，平均节省 49.93 s，即 25.8564%；df1 的 95%
区间含舍入为 [-58.081971,-41.778029] s。0.5% 最小效应达到，
第一阶段的独特 1M <100 s 指标仍待达到。两对结果支持本次 CPU 收益，
差值正态性与更长时间尺度的稳定性仍有采样限制。

公开完整 1M 同次输出的 acc 为 99.0626964394%，baseline 冻结输出
为 99.2763801451%，配对差 -0.2136837057 pp。候选总体 acc 条件通过，
距 99% 约 0.062696 pp；公开 1M 的 CPU 为 168.00/167.94 s。
baseline 公开 CPU 属于另一批次，不能将其和独特 1M 时间拼成一个前沿点。

## 接入限制与收尾

Both，覆盖显式 `-endpoint-mode off`；与同预算 search512 参考相比改变
9 行，日志仍打印 off。证据保存在 `validation/results/exp292/repro.json`。
本轮默认路径的证据有效；正式接入前另建候选修复显式参数与诊断信息，
冻结源码和 ELF 保持。本轮正式入口、构建脚本及交付包保持原状。

100M/1B、独特 1M 全量 exact、跨架构与官方隐藏集待验证，
