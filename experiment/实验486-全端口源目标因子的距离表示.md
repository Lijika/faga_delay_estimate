# 实验486 全端口源目标因子的距离表示

2026-10-18，查看新结果前登记。主假设为全部端口距离曲面的源维和目标维
具有可共享的数值响应，少量独立源、目标因子可减少逐端口对的存储。
本轮固定8、16、32三个对称rank，只评价完整有限域误差、容量与解码。

## 数据、表示与固定训练

复用exp483全部208源、288目标、四方向、两余类及552点，
以及exp485共同rank128基、全部偏移和系数。资产完整身份保持。
每臂覆盖全部208×288端口，不使用端口子集。已有字段属于开发域，
全部余类和真实请求分别待验。

把exp485的加权常数向量加入原128个空间基，通过QR得到129个正交列。
将偏移和空间系数共同变换至该基，以保持原浮点空间函数。
构造208×288×8×129的系数张量，从源展开和目标展开各自的Gram矩阵
取得前32个特征向量，符号固定为最大绝对值项取正。
8/16/32候选分别截取相应列并投影核心，源和目标因子独立保存。
全部端口参与两个展开矩阵与投影。该数值分解不包含实际路径资格。

对每个候选，把核心的129个空间系数提前展开为552点几何表。
每个源因子与目标因子组合，共rank平方条核心几何曲线。
每条曲线的量化尺度固定为覆盖所有8上下文最大绝对值的最小2次幂，
使整数值绝对值不超过32767。保存float32两端因子、float32尺度及
int16核心表，核心先按几何点做int16模差分以供Zstd19压缩，
启动恢复后逐点查询。头、全部端口ID、因子、尺度与表均计入资产。

实际解码从float32因子求积，用float64按源因子、目标因子依次累加
rank平方项，加入原趋势，半值远离零并限制为非负整数。
同源同目标零位移空路径显式为0。量化前核心解码也单列评分。
本轮Python/BLAS的矩阵乘评价与独立标量解码共同核对；
将来完整C++程序须另验其固定累加与舍入。

## 指标与门槛

复用exp485完整评价器，报告三臂各264,536,064值的完整有限域区间、
去重复零轴的评分、近轴/内部、每源/每目标、类型、方向与余类误差。
保存后独立解码全部域，核对实际误差两端和完整输出SHA；
每个源目标及上下文另取一个固定几何点核对标量求和。
本轮新增129空间基参照完整评价，标记与exp485的float32系数变换影响。

实际压缩并回读完整两余类资产，条件全余类静态为共同头与因子一次、
核心表压缩60倍。此投影假定其余余类保持相同核心复杂度和压缩率。
运行时另计全部120余类核心、全部源目标预求积的float64系数表及共享头，
使用预求积时每请求为rank平方项内积，其真实CPU必须独立测量。
逐片误差两端保存为离线研究证据，用作在线界时容量和几何前提另验。

任一臂总体名义至少99.97%、近轴至少99.9%、条件压缩不超过80MB、
条件运行时主体不超过1.5GB，才扩大至全余类编译。
任一端口覆盖、整数范围、解码、SHA或有限域区间失败停止并保存。
全部三臂未达到联合门则结束本固定源目标投影配置扩大。
未量化核心分用于区分源目标表示误差与整数表误差。

## 实测结果

全部源和目标参与拟合、编码及评价。四组各检查264,536,064个有限域值，
去重零轴后评分值数为257,647,104。三份候选资产全部保存回读，
共793,608,192个值再次解码，另1,437,696次独立标量求和覆盖全部
源目标与上下文。整数范围、实际误差区间和输出SHA核对通过。

129维参照与exp485的rank128输出SHA完全相同，总体名义99.993639%、
近轴99.994540%，本次常数项合并及QR没有改变最终整数输出。
