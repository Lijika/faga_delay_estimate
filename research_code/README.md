# exp707 至 exp732 研究源码

`validation/` 与 `tests/` 保存本轮相关实验的生成、拟合、测量和审计源码，逐文件身份见 `manifest.json`。对应假设与结果在根目录的 `experiment/` 和 `validation/results/`。正式可独立构建的查询程序位于 `source/`。

| 主题 | 重点文件编号 |
| --- | --- |
| 准备编译、流程成本、端口及 CSV | exp707、709、723 |
| 全词支持、函数共享、平局与局部支持 | exp710、711、712、713 |
| 宏、片段及执行器 | exp715、717、718 |
| 完整 Line 和有限词周期核 | exp721、729 |
| 少树深层残差与部署 | exp719、720、727、730 |
| 条件码本、监督、次优词与认证下界 | exp724、726、731、732 |
| CPU ISA 原型 | exp716 |

这些原始脚本保留了当时的兄弟实验路径、主机约束和预算检查。它们适合检查实现和提取构造过程，原命令需要恢复相应历史工作目录及大型中间资产。本轮没有把全部历史运行器改造成独立工具。

可直接使用的入口是 `source/build.py`、`accuracy/check_records.py`、`training/retrain_residual.py` 和 `dataset_protocol/` 中的适配程序。路径见证重放沿用 `path_witness/` 的独立入口。旧组件所依赖的更早研究脚本位于 `training/original/`；未归档的大型名义场及中间资产保留重建代码和身份。

本轮复制原始研究代码时保留文件内容。新适配入口的核验与原实验的已通过证据分别记录，不能把源码可阅读解释为全部原型已在此目录重新运行。
