# exp610 外部 AI 咨询材料发送说明

建议一并提供以下材料。

1. `docs/exp610/exp610-历史实验与理论摘要.md`，解释已有表示方法、失败条件、理论规律和版本演进。
2. `docs/exp610/exp610-外部AI参考材料.zip`，含实验原文、精选理论笔记、训练审查脚本和数值报告，供外部 AI 按需回查。

```sh
cd source
python3 build.py
```
