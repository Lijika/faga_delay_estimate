## 赛题简述

赛题来自 2026 中国研究生创芯大赛 EDA 精英挑战赛赛题一，题目为面向超大规模 FPGA 的布局布线延时估算。给定固定 FPGA 互连架构，以及两个完整 pin 名称，程序要估计从起点到终点的最短路径延时，单位为 ps。

FPGA 上有一个 120×550 的 SRB 阵列，实际有效 SRB 为 60,200 个。SRB 是互连交换块，每格复用同一套端口和内部连接模板。五个官方 JSON 分别描述 SRB 实例、端口、内部 Arc、跨格 Net，以及 Line Gap 和 Block Gap。该架构有 496 种端口、8,192 条 Arc 模板、160 条 Net 模板。

这是带端口状态和方向的加权有向图。完整状态需要保留坐标与端口身份。路径经过同格 Arc 和跨格 Net，并累计相应费用；不同 lane 的可达关系和费用会影响最优路径。规则区具有大量平移重复，真实地图还包含边界、缺失格点和特殊跨越行为。

运行输入只包含 `From,To`。例如，一个端点可以写成 `SRB_90_463/ZLE[0]`。程序输出同样的端点原文，并增加一个整数 `delay`。比赛允许估计误差，并按连续评分函数计分，因此我们同时研究精确结构、近似表示和学习修正。

### 精度和时间怎样计分

对于真值 $g_i>0$ 的请求，单点得分和总体 Acc 为

$$
s_i=1-\tanh\!\left(4\frac{|\widehat d_i-g_i|}{g_i}\right),
\qquad
\mathrm{Acc}=100\cdot\frac{1}{N}\sum_{i=1}^{N}s_i.
$$

这里 Acc 是平均连续得分。精确命中比例、误差不超过 5% 的比例、MAPE、MAE、MSE 都有各自的含义。请明确每个指标的定义，最终以官方 Acc 评价改进。

本地评分器对 $g_i=0$ 采用预测恰为 0 得 1 分、其余得 0 分的规则；负值预测等特殊状态另行统计。PDF 中的正真值公式与本地特殊值约定分别记录，涉及特殊值的平台行为需要回查官方实现或回传证据。

官方总分和时间项为

$$
\mathrm{Score}=0.8\,\mathrm{Acc}+0.15\,\mathrm{TimeScore}
                 +0.05\,\mathrm{ConsistencyScore},
$$

$$
\mathrm{TimeScore}=\max\!\left(0,1-\frac{\mathrm{avgCPU}}{1800}\right)\cdot100.
$$

当时间项大于 0 且一致性相同时，项目采用以下成本换算。Acc 差以百分点计，CPU 差以一次完整 1B 的秒数计

```text
ΔScore = 0.8 × ΔAcc - ΔCPU / 120
允许增加的 CPU 秒数 = 96 × ΔAcc
```

例如，提高 0.1 个百分点对应约 9.6 秒的 1B CPU 预算。小规模倍乘属于成本估算，阶段成绩依赖对应规模的完整实测。

### 真实地图中容易误解的规则

Line Gap 位于相邻行或列之间，跨越时收费，SRB 坐标保持原定义。Block Gap 占据一块矩形，内部格点缺失，并且按方向决定 Net 的真实落点。

沿可穿越方向，Block 内部位置跳过 SRB 步数计数，跨过 Block 还要收费。因此一条名义水平位移可能产生更长的真实坐标位移。沿不可穿越方向，Net 保持名义位移；若落点在缺失格中，连接失效；跨度较大的 Net 仍可能落到 Block 另一侧。请用题目和 `source/src/architecture.cpp` 中的 `resolveNet` 复核具体语义。

源端若为 Z 互连输出，离开该 pin 的第一条 Net 已由端口身份确定。首 Net 可能跨越端点包围矩形外的 Line，后续路径也可能回跨。单纯按起终点矩形加收费会遗漏这类费用。

## 项目术语和源码地图

| 术语 | 在本项目中的含义 |
| --- | --- |
| pin | 坐标与端口名称的组合，例如 `SRB_x_y/ZSEA[0]`。单个端口类型在不同坐标对应不同 pin。 |

### 背景重建与真实事件

程序先解析两端 pin、检查端口映射和格点，再处理源端的强制首 Net。若首 Net 存在，得到真实落点 $(a_x,a_y)$、名义位移 $(n_x,n_y)$ 和首段费用。对于没有首 Net 的逻辑源，落点保持源坐标，名义首位移为 0。

背景使用的位移键是

```text
Δx = tx - ax + nx
Δy = ty - ay + ny
qx = abs(Δx) / 10
qy = abs(Δy) / 12
direction = 2 * (Δx < 0) + (Δy < 0)
context = (direction * 10 + abs(Δx) % 10) * 12 + abs(Δy) % 12
```

其中整除采用非负整数商。近域由 `qx+qy<=3` 定义，使用 rank 512；其余远域使用方向专属 rank 64。两个因子均为 INT8，每 64 分量保存一个 float32 尺度。点积先做整数乘加，再按固定顺序转 double 乘尺度、累加。

名义距离的主体恢复为

```text
value = response * (128 + 125*qx + 125*qy)
        + center[pair]
        + 125*qx + (Δy < 0 ? 125 : 127)*qy
nominal = int(max(0, value) + 0.5)
base = nominal + fee
answer = int(max(0, double(base) + double(raw)) + 0.5) + mandatory
```

`response` 是量化因子点积，`center` 是端口对固定中心项，`raw` 是所属 R8 模型的 float32 输出。完整同 pin 返回 0；部分相同 Z 身份、名义零位移状态有独立的非空循环费用处理。无合法映射或无有效候选时保持相应负值状态。

**请核查两处位移定义。背景索引和专家组使用 `Δx,Δy`；大部分树的相对位置特征使用 `x=tx-ax,y=ty-ay`。源首段的名义位移通过独立特征进入树。**
