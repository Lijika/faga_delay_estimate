# exp610 历史实验与理论摘要

这份摘要为 [[exp610-外部AI提问书]] 补充研究经过，范围截至 exp610。它保留重要机制、反例和资源障碍，便于外部 AI 理解已有探索。源码基线位于 [Lijika/faga_delay_estimate](https://github.com/Lijika/faga_delay_estimate) 的 `source/`。精选原文见仓库 `docs/exp610/exp610-外部AI参考材料.zip` 的 `experiment/` 成员，相关短篇推导见同一参考包的 `agent-theory/` 成员。部分实验编号在同一轮登记后并行推进，依赖关系以实验内容为准。

文中的名义分是把近似表示与认证名义距离比较得到的分数，真实 Acc 是对真实图 exact 或公开 golden 计算的分数。各自采用的采样、全域和输入分布均需保留。历史实验中的 80 MB、95 MB 等是当轮组件预算，最终静态 ELF 的硬限制始终为 100,000,000 B。

## 历史记录中的其他术语

| 术语 | 本文使用的含义 |
| --- | --- |
| 宏边 / quotient graph | 将一段固定 Net 加后续 Arc 合并为一次转移；商图按端口保留重复模板，位移作为边的属性。 |
| 势函数 / reduced cost | 给状态赋一个值，并用势差重写边费，在保持相应路径关系时得到更易搜索或分析的非负费用。涉及真实图时要重新检查每条边。 |
| A* / Dijkstra | 最短路搜索。A* 利用到目标的下界排序；Dijkstra 按已知起点距离推进。近似排序和安全下界需要分别说明。 |
| CCH | Customizable Contraction Hierarchies，一类按消元顺序增加 shortcut 的距离索引；消元产生的额外边称为填边。 |
| Hub Labeling | 每个节点保存中间枢纽及其距离，通过两端标签交集回答距离查询。标签总字节和扫描量是主要成本。 |
| min-plus | 用最小值选择替代普通加法，用路径费用相加替代普通乘法。常用来表达最短路和“若干段路径中的最低费用”。 |
| TT / tensor train | 将多维距离数组拆成一串较小张量核。变量顺序和链中间的截断会影响所需维度及误差。 |
| SVD / 低秩空间 | 用少量向量乘积近似距离矩阵。普通截断主要面向平方误差，官方相对误差分需要另验。 |
| Huber | 小误差区近似平方、大误差区近似绝对值的一类损失，历史中用于调节拟合目标。 |
| Gram | 向量之间的内积矩阵，历史中用于汇总投影和量化扰动的平方成本。 |
| 仿射尾 / 常数尾 | 在声明的有限网格末端，距离或去趋势残量满足固定线性增量或常数的区域。其覆盖范围经过逐值检查。 |
| 连接词 / cycle | 词表示一串带端口身份的路径动作；cycle 表示回到相同端口身份的一段循环，仍可具有非零空间位移。 |
| 路径支持 | 某个循环或短连接能否在给定起终端口、位移和真实位置条件下接入整条路径。 |
| Bellman 关系 | 当前距离等于合法第一步费用加最优后续距离的最小值。用于恢复动作、验证距离和构造停止证书。 |
| 许可 / 决策图 | 许可为某个值或动作在误差预算内允许采用的集合；决策图通过条件分支与共享子结构保存整张函数。 |
| certificate / 证书 | 可由独立检查重算的见证，例如逐边不等式、完整路径、有限窗口出界界或资产完整恢复。具体检查决定其有效范围。 |

## 从周期图与精确路径开始

### 周期商图、势函数和 residue

早期方案把名义 Net 与后续 Arc 合并成有位移的宏边，以 160 个 Z/lane 为商图状态。忽略真实 Gap 后，端口与 Arc 模板在无限格点上重复。选择线性趋势和端口势函数，将约化边费变为非负，再在有限 residue 图上求最短距离，可以得到紧凑的周期性背景。

exp26 核查了这个名义商图的 160 点、2,752 边。东西两个长线自环的位移为 ±10、费用 125 ps；南北长线的位移为 ±12，费用分别为 125、127 ps。在当轮缩放及环不等式条件下，四个角已经覆盖该商图的全部可行线性斜率。继续增加线性方向的收益受这个具体结论限制。

有限 min-plus 矩阵幂可以描述固定边数的最低费用，但只保存端口对时会合并净位移不同的路径。exp26 给出同源同目标、两条边、不同位移与费用的见证。二维位移信息需要额外状态保留。

mult2 的大 residue 表采用 20×24 模数，历史完整恢复表约为 438.8 MiB。exp118 至 131 逐步检查窄整数、公因子、按象限拆分、沿余类轴的模差分和字节平面，并使用 Zstandard。exp129 的完整压缩流约为 58.02 MB，exp131 静态包约 68.20 MB，完整恢复值与旧表一致。

这些无损编码证明了固定背景表可以合规嵌入。真实地图的 Block 会改变落点，旧纯 residue 输出曾高于真实单 Net 费用，因此将它用于真实图的安全 A* 剪枝还需要独立前提。历史 exact 标签工具使用经过核验的下界或 Dijkstra 参照。

### 精确场、父链与有预算真实搜索

exp112 至 219 探索若干源端口的精确距离场、平移模板、父链和预算闭包。固定模板源可以复用大量路径，但全部源、目标和几何的容量与覆盖需要共同衡量。路径重放到真实地图时还须确认每条 Net 的真实落点和可达性。

exp250 至 258 将已有结构估计用于真实路径搜索的排序，并保留完整可重放路径费用。exp258 的固定 1,024 扩张预算方案通过当轮新请求的 99% 精度门。相关排序函数属于近似优先级，合法路径费用具有上界身份；精确最短路保证仍依赖相应停止条件。

exp323、exp354 等版本沿这条路线继续优化。在后来全端口非重复 1M 基准中，exp482 测得旧高精度路径约为 101 至 114 秒/1M，40,000 行 exact 样本 Acc 约为 99.0907%。完整独特输入上的计算成本促使后续研究转向直接距离函数。这个样本精度与 exp610 独立完整 1M 的评价范围各自保留。

exp383 还试过在保留 160 个 Z 状态的真实局部窗口上构建 CCH 和 Hub Labeling。4×4 窗口已产生较多填边和标签，8×8 在预算内未完成拓扑，终止原因未细分。该结果限制当轮无剪枝格式的扩大，其他索引结构仍需要各自证据。

## 精确背景的空间结构与容量

### lane 状态与二维耦合

exp391 针对相同 Net 几何的 I→Z 转移矩阵，检查“只差常数”的行与精确 min-plus 因子。16 个几何组的构造上界与独立不相容见证下界相同，合计为 160。这个固定精确单步因子化无法缩减当前全部 lane 状态；多步摘要、近似合并与区域状态有各自的研究范围。

exp413 认证两个源的名义距离场后，用小尺度差分外推仿射尾部，名义诊断分只有约 94.5% 至 96.5%。具体反例中连续 24 行的费用增量先为 88 ps，后为 254 ps，前缀阶段的接入变化会影响远处外推。

exp414 保留全部斜率变化，两源约 183.55 万条曲线包含 684,124 种差分形状。当前字典格式按两源作全源条件估算约需 2.94 GB。exp415 的后缀共享和 exp430 的“residue 下界 + 精确残差曲线”继续检查重复，残差虽小，形状仍多；exp430 两源有 885,465 种残差曲线。

exp418 使用保留余类的二维可分表。两个源的较强版本名义分约 99.34% 和 99.39%，接入当轮真实请求后约为 97.79%。近轴区域保留显著的 x/y 耦合。exp445 在固定仿射面集合上做 min/max 表示，完整精确网格仅约占 5%，固定面集合的选择能力不足。

### 尾部、生成元与连接词

exp450 的两轴有限基、exp452 的首 Net 对齐距离差有限基可以精确恢复已测域，当前逐源格式仍超过静态和内存预算。它们反映了有限基密度与跨源重复不足这两类成本。

exp453 将路径中的长线自环分离，固定 16 边连接词覆盖不足。exp454 保留端口支持的二维循环，发现 147 种规范 cycle，样本远区 16 边连接词覆盖上升至约 97.2% 至 99.1%，仍有更长连接词。cycle 字典估计约 2.9 KB，完整选择目录、连接词和支持资格另占容量。

exp475 至 481 继续研究自环归一化、双生成元程序、零次数支持补全和按字节选择公式。局部切片可以精确恢复，但当轮格式的全源条件压缩估算仍在数百 MB。小程序主体与完整寻址和条件目录需要一起计量。

exp504 至 508 对全部端口、全部方向余类的有限网格检查精确常数尾。共享矩形约覆盖 21% 至 22%；逐行尾覆盖达到 68.470140%，原静态资产约为 187.22 MB。exp508 沿行轴做模差分降至约 129.78 MB，仍超过当轮组件预算和单 ELF 可用空间。

exp511 放宽成逐行仿射尾，完整物理域覆盖约为 76.657485%，同向 long-lane 增量约覆盖 76.655943%。稳定增量存在，但进入稳定区之前的切换及未覆盖部分仍须存储。

## 从全端口标签到有损双表

### min-plus、张量链和不同查询展开

exp479 的两源共享线性基说明低秩可以获得很高的局部名义精度，但当轮逐源条件部署格式容量较大。后续转向一次覆盖全部端口的表示。

exp482 建立 208 源、288 目标的全端口基准。exp485/486 尝试乘积量化及源目标分解；exp487/488 的三组 min-plus 模型在持续训练后，所测余类名义分约为 97.72%。exp492 扩大整数 min-plus 因子到 128/256，名义分约为 98.24%/98.50%，条件全余类资产和近轴质量仍有限制。

exp489 至 493 的交错位张量链、常数分离、八 context 共享和 residue 分离，测试了不同分解次序。部分八 context 模型名义分达到 99.67% 左右。完整矩阵包含哪些变量，以及查询切口两侧分别存什么，直接影响所需维度。

exp494/495 对查询切口做直接矩阵分解，并采用逐分量尺度，降低张量链额外截断和统一尺度量化带来的损失。exp496 把完整几何移到同一侧。exp497 按条件查询组使用短点积，所测八 context 的 rank64 名义分约为 99.965%；exp498 的 Huber 投影把两个固定配置提高到约 99.972%。

这些早期高名义分有各自的余类覆盖范围。全余类扩展后，精度和容量都需要重新实测。

### 全部认证名义域与自然双表

exp499 完成全部 208 个源、288 个目标、480 个方向余类、12×46 个商网格位置的认证标签，矩形域共 15,872,163,840 个距离值。去除重复负零轴和超过芯片合法位移的填充后，物理位移域为 15,734,444,544 个值。

这些是名义图距离标签。真实地图查询还带绝对位置，因此它们构成可复用背景。

exp500 用分组受限投影，在完整物理名义域量化后约得 99.376727%。exp510 将完整端口对放左侧、全部几何放右侧，形成 59,904×264,960 的矩阵，一次查询读取两条向量并点积。rank64/96 的完整名义分约为 98.387665%/98.569098%，压缩静态约 25.46/38.76 MB。该布局简洁且容量明显改善，质量门仍需后续工作。

exp530 尝试混合位宽和误差反馈，静态约 64 至 68 MB，完整名义分下降至约 97.26% 至 97.29%。exp531/532 尝试共享公共行列空间，exp532 的 384 维公共空间量化后约为 98.987144%；主要损失来自空间投影。exp533 的端口族条件共享减少部分系数，当前固定收益门未过。exp534 验证某套资产可静态、单线程启动恢复；恢复资源通过与完整预测质量分别评价。

这一阶段的共同观察是，矩阵展开、条件分组和损失设计对表示能力的影响较大。相同 rank 或相同静态字节的不同结构，需要使用同域误差和完整程序成本比较。

## 精确策略与压缩决策图

exp512 检查逐行压缩坐标与真实 Block 事件，确认压缩坐标需要保留跨区域的转移语义。

exp513/514 研究短桥基与首次长线紧边，当前全域精确删桥收益有限，短线连接有较深的端口依赖。exp515 对短线拓扑及费用最优路径的 lane 绕行做独立动态规划。exp516 在全部端口对及 41 个位移上发现，约 41.19% 的根在所有最优路径中都需要反向 Arc，单向 lane 推进模型覆盖不足。

exp517 将共享策略和二维循环编译为参数化词，在构造的 41 点恢复 100%；迁移到另外 16 点时，有限覆盖约为 52.70%。exp518 定位了策略访问未认证后继状态的代价，说明局部动作与后继闭包需要共同保证。

exp519 构建全端口联合费用决策图，完整原始模型约 19.25 GB，XZ 静态约 3.17 GB。exp520/523 的动作重命名与输入平移使查询资产约为 1.12 至 1.15 GB，但静态仍约为 279 至 286 MB。

exp521 在约 101.84 万条新名义请求中，理想语义片段平均约 3.61 个，99 分位 5 个。已访问内容字典压缩约 9.06 MB，实际完整出口选择继续依赖原目录。这个内容字典只覆盖登记请求，完整随机访问的容量需要原目录支持。

exp522 的参数化出口模型在完整目标集合构造结束前触发 8 GB 停止。exp524 的近优动作许可任务触发 CPU 上限，完整恢复验证缺 15 个目标。两项都保存了部分证据和未完成范围。

exp525 至 529 放宽为一次预算量化、区间许可、直线段和自由偏移共享。代表性的完整恢复结果如下。

| 实验与固定表示 | 查询资产 | 静态资产 | 已测性质 |
| --- | --- | --- | --- |
| exp525 一次预算量化 | 约 13.46 GB | 约 2.22 GB | 完整名义分约 99.4111% |
| exp526 完整后续区间共享 | 约 16.00 GB | 约 2.31 GB | 完整名义分约 99.8044%，平均约 6 次访问 |
| exp527 整数许可直线段 | 约 2.63 GB | 约 994.93 MB | 完整名义分约 99.4334% |
| exp528 自由偏移父目录 | 约 2.62 GB | 约 993.94 MB | 全域恢复通过，目录减少很小 |
| exp529 二进制内部共享 | 约 3.40 GB | 约 1.46 GB | 与 exp527 原函数等价，平均访问约 25.11 次 |

这些实验建立了具体格式的恢复、误差许可和容量证据。当前主要障碍包括完整条件目录、变量展开顺序、支持关系和随机访问。其他图结构、变量次序或编码方式仍须独立核算。

## 将名义表示误差和真实地图误差分开

### 强制首 Net 与剩余几何

exp416 的具体请求 `SRB_90_463/ZLE[0]` 到 `SRB_92_469/ZSEA[2]`，golden 为 991 ps，名义距离 441 ps，端点 Line 项为 0。首 Net 必须先到 x100，跨两条 Line 收费 275 ps，再回到 x92 至少再付 275 ps。这个例子完整解释了 550 ps 的差异。

exp535 在完整开发 1M 上测得，精确原位移名义背景加端点 Line 的真实 Acc 约为 97.014014%。exp536 强制首 Net 对齐后，oracle 提升至约 98.995487%，几何平方误差大幅减少。相同近似背景的真实 Acc 从约 96.011289% 提高到 97.913976%。

exp537 改变物理窗传播响应的对齐方式，名义与真实评分都有改善，固定 rank96 的真实 Acc 仍约为 97.751379%。exp539 加入净跳格及强制绕行，精确场诊断达到约 99.112111%；与旧高精度输出的组合约为 99.432639%。这些依赖 exact 场的诊断指出了误差来源，紧凑部署成本另验。

### 势函数与空间商图

exp541 至 548 研究真实可行势、边界波前、端口余类剩余距离和空间条件商图。部分组合是经过逐边认证的真实图下界，不能由任意近似值直接替代。

exp543 发现某个余类剩余表约 99.52% 的元素为 0；仿射投影增加的评分很小。exp544 给出空间投影词的不可共同实现反例。exp545 研究零剩余循环流，保留“边或环分别可行”和“同一真实路径可实现”之间的条件。exp546 先组合真实落点再投影，原组合评分基本保持。

exp547 的空间分桶恢复了部分零费用可达约束，exp548 值函数最终对旧组合的 Acc 增益仍很小。当前固定商图和费用投影仍遗漏了影响全路径的空间与端口连接信息。

### 真实无 Line 核与小残差

exp550 的反事实分解表明，几何误差与名义表示误差都影响精度。只把其中一项设为完美，当前固定表示的其他误差仍会限制目标。

exp552 用真实最优路径逐边重放，分开净名义位移、跳格和收费等事件。使用 oracle 的词项或联合事件可以将诊断分提高到约 99.59% 或 99.41%，简单费用相加的方案却可能下降。

exp553 将真实图的全部 Line 收费置零，再求 exact 距离 D0，保持真实落点、Block 和边界。`D0+mandatory` 在开发 1M 上达到 99.909873713%，其中 972,812 行恰等于 truth。这给出一个有价值的分工方向，即较准确背景承载端口和位移，较小函数学习真实地图余量。

exp554 直接学习无 Line 距离的紧凑函数存在明显拟合不足。使用精确名义背景再学习小修正，small Q 折外 Acc 约为 99.333115%，模型约 15,700 B；较大 Q 约为 99.406689%。这两个分数依赖精确背景诊断条件。

exp556 增加物理趋势和双通道残差，直接学习约为 96.75%，量化背景加修正约为 98.08%。背景质量和地图修正需要共同改进。

## N512、D64、R8 与工程优化的汇合

### 条件空间和小模型

exp557 比较共同几何、方向条件几何和其他条件划分。32 树修正后的三个固定背景 Acc 约为 97.88%、98.03%、97.96%。exp564 的端口 phase 主效应分离、exp567/568 的共享叶字典及重编码、exp569/570 的连续几何与加性码字均获得各自机制证据，固定精度门仍未通过。

exp570 的完整归一化平方残量降低约 15.19%，真实 Acc 却下降。exp590 按逐行官方分重算，发现大量原低误差与精确行恶化。平方误差下降、归一化 L1 和官方分之间需要使用独立指标判断。

exp571/573 继续调整局部空间和稳健目标。exp575 改用距离分区，近域 rank128/192、远域 rank96，近域资源分配带来明确收益。exp576 在 N192 上比较全局小修正与 16 路 R8。R8 折外约 98.060711882%，每次只执行一组 8 棵 depth4。

这些模型未达到当时某些更高精度扩大门。exp579 按用户当轮 >98% 和 CPU 100 至 300 秒目标，选择已有 N192+R8 构建自包含程序。独立 1M Acc 为 98.070968152%，完整程序约 0.63 秒/1M，静态 ELF 约 93.65 MB，逐位和资源检查通过。它成为后续规模测试的基础。

### 量化与容量分配

exp582 改为每 64 或 32 分量共享尺度的 INT8 因子，质量和速度对照后保留 B64。exp586 利用容量增加近域 rank，N512/N768 分别提高约 0.09/0.12 pp，N512 的联合成本收益更好。

exp587 为新近域背景重新训练修正，最佳改善很小。exp589 保持 N512 近域，将远域由一个共享 rank96 改为四个方向分别拟合 rank64/rank96。

### 已有树推理研究

早期 exp111 的阈值秩二分、部分交错和树布局优化做过逐行等价检查，收益依赖模型规模和完整程序。

针对微型模型，exp558 至 561 研究位并行、原生推理、特征复用、阈值秩编码、按层交错和依赖链延迟。exp561 的 O8-L 组件平均约 70.8 ns，质量约 99.33% 的条件依赖精确背景。特征生成、背景与 CSV 成本需要另外计入。

exp565/566/572 研究直接叶值表及寄存器字节查表。部分实现保持输出等价，但表准备、栈访存或加载时机抵消了新增速度收益。当前 R8 采用的按层交错和直接叶值索引，是这些探索之后的具体选择。

exp592 系统检查了标签、三折 source pin 隔离、叶支持、特征职责、原生树、导出、舍入和背景迁移。它发现小修正确实会使一部分原精确行变差，同时整体约增加 0.41 pp；已核查的重复学习率、遗漏截距等问题没有证据支持。叶支持较少和几何特征主导是后续实验的依据。

### 完整程序与最终冻结

exp580 先发布 N192+R8 的完整程序，1B CPU 为 472.881246 秒。平台该版本两次平均 CPU 为 564.0315 秒，Acc 为 97.911209517%，其硬件和输入身份继续未知。

exp581 将背景预取与树计算调度重叠。exp594 压缩树节点并直接写原始行，exp595 固定 INT8 点积长度，exp596 使用批 8 的稳定行视图与预取。exp597 再增大批次未获得通过门的收益。

exp598 冻结 D64+R8 批 8，完整 1B CPU 为 303.716262 秒。exp601 的短坐标解析与中心项预取组合进入 exp602，1B CPU 为 276.287395 秒。两者完整输出相同。

exp607 至 609 比较通用、SSE4.1、AVX2 和自动选择的整查询路径。exp608 原型的 AVX2 worker 存在 `main` 检测前全局构造使用 AVX 的可移植性问题，因此停止该原型发布。exp609 将唯一架构实例放到 generic 入口，检查扩展 worker 没有动态全局初始化，再完成新的数值与规模验证。

完整 10M 六轮比较中，F 比原基线节省 0.240692 秒，AUTO 比 F 多约 0.018253 秒。选择固定 F/SSE2 后，100M CPU 为 24.728427 秒，1B CPU 为 251.136671 秒。1B 完整输出 SHA 与 exp598、exp602 相同。

exp610 封装上述冻结 F，静态 ELF 为 76,907,800 B。源码包在独立目录重建，六份目标文件和最终 ELF 与原发布逐字节一致。当前交付固定 N512 近域、方向 D64 远域、旧 R8 修正、批 8 流式查询及通用 SSE2。

## 已有规律怎样使用

以下是历史证据支持的工作判断，各自范围写在相关实验和理论笔记中。

- 端口状态和二维位移都携带不可随意丢弃的信息。单步 lane 因子下界、边数 min-plus 反例及反向 Arc 证据限制了若干简单模型。
- 固定名义图具有可压缩结构。接入前缀、近轴耦合、连接词支持和真实地图响应使完整表示更加复杂。
- 精确程序的主体可能很小，完整条件目录和寻址可能成为主要资产。小字典、少量理想片段与完整随机访问成本需要分别统计。
- 压缩无损、名义图精确、真实图精确和在线预测误差具有独立含义。每个迁移步骤都需要相应证据。
- 当前质量同时受表示和真实几何影响。首 Net 对齐、D0 诊断和条件小修正的增益为这项分工提供了实测支持。
- 容量分配、因子条件化与查询切口会改变收益。近域高秩和远域方向短点积形成了 exp610 的取舍。
- 官方评分更关注逐行相对绝对误差，尤其低误差和原精确行。平方损失降低可以伴随总体降分。
- 组件吞吐、单次依赖链延迟、完整程序 CPU、不同规模和未知硬件是不同的观察对象。正式判断需保留对应条件。

这些规律供外部 AI 检查和延伸。exp610 后续研究的最终目标仍为真实未知分布 Acc 严格大于 99%，并保留已有速度优势。
