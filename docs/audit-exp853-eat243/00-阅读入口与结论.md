## 已建立的判断

- **精度存在可观察的信息损失。** EAT162 对 CURRENT117 的完整开发 1M 做 exact-nominal 干预后，Acc 从 98.8573470845321% 提高至 99.36993263558435%。这是携带额外教师信息的离线干预，部署成本尚未得到验证。它支持继续研究名义表示的信息损失；它没有给出固定资源下的可达上限。
- **当前 ELF 和 RSS 均有剩余容量。** 1B CPU 超过用户目标 25.208939 s。容量、精度、访存依赖和完整程序成本共同限制下一次改动。exp816 使用 1,496,072,192 B RSS 仍使 100M CPU 增加 2.574855667 s，说明填满 RSS 不自动改善性能。
- **“lossless”限定于资产恢复。** EAT243 无损恢复目录字段和码本；目录所指向的 A/B 曲面及历史残差构成近似预测，当前真实延时 Acc 为 98.85534283747039%。
- **历史测试对象发生过改变。** 早期重复 1M 扩到 1B 的缓存成绩、8 源分布、496×496 扩展命名域，以及后来的 208×288 主角色域须分别比较。exp758 的 +62.700666262 pp 已撤回比赛主分布收益依据。
- **源码身份与正式 ELF 身份已经分离。** 当前 `./estimate` 与正式 EAT243 ELF 的 SHA 相同。正式源码来自不可变版本的 `source/`；普通根源码和 `scripts/build.sh` 有各自历史身份。

## 证据使用方式

本包完整收录当前 `experiment/` 的 **1,018 篇 Markdown**，共 **4,892,638 B**，涉及 **845 个独立主实验编号**。原文在 `evidence/experiment/`；[逐篇索引](index/experiments.csv)包含文件名、标题、字节数、SHA-256、文本首个日期和自动主题标签。[全文 ZIP](index/experiment-corpus.zip)包含同一批原文。自动标签用于检索，不能作为成功或失败判定。

本包另附全部可见 Git 历史、工作区状态，以及 `validation/results/` **53,253 文件**和 EAT `results/` **47,069 文件**的路径、大小、mtime 库存。两处结果目录合计 **100,322 文件**。逐文件库存覆盖了可见文件；语义复核集中于主干、关键失败和当前正式证据。本次没有逐项重新计算这 100,322 个文件的全部数值。

数字旁的“日志记录”表示历史实验自述；“原始收据复核”表示本次读取了对应 JSON 或源码；“推导”表示给定前提下的代数结果；“未验证”表示没有足以支持该结论的当前证据。缺失的 Acc、ELF、RSS 或 CPU 保留为“未测/未取得”，不按相邻版本补齐。

本次新增文件只属于审计文档、证据副本和检查工具。算法源码、正式版本包、既有研究进程和原始实验记录均保持原状态。
