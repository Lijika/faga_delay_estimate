# 实验327 单槽缓存对象布局控制

## 条件预注册

2026-10-16。正式基线exp323保持，复用exp326冻结ELF与输出证据。
本机开工`df -h /dev/sdd`约400GiB可用。源码候选使用独立私有目录。

exp326初始结构探针测得baseline缓存56字节，direct缓存48字节。
该探针省略了正式构建的UPPER_TREE宏，ResidueEstimator的绝对
大小和成员偏移需用完整宏重新测量。本轮以正式构建的LEGAL_PATH
和UPPER_TREE宏核对布局，性能归因继续待验。

主假设是恢复原有对象布局可以改善direct完整程序的CPU。
固定三臂baseline、direct、layout；layout在direct中恢复原来的
maxLoad_字段与初始化赋值，lookup与insert继续使用单槽覆盖。
原来的停插条件保持在baseline中。当前控制可辨别恢复字段后
完整实现的效应，生成代码和函数地址变化仍可能参与性能差。
测试覆盖ResidueEstimator、Router和HybridEstimator的共同缓存。

先核对三臂sizeof与关键成员偏移，layout应与baseline相同。
复用缓存随机自检，layout普通和ASan/UBSan各运行1,000,000次；
四套开发样本共48,184行、四组CLI和258行消费者样本须与exp326
基线完整SHA相同。算法和搜索头保持，复用原路径证据。
新增exact和评分预算为0。

Xeon Gold 6226R核3空闲时，同机串行执行。短规模分布为unique
20k、100k及repeated 1M，各先baseline/direct/layout预热，
再正序、反序、正序三组。随后固定执行unique完整1M，
先20k三臂预热，再正序、反序、正序三组；另对direct、layout
各执行公开完整1M两次，复用对应SHA的评分。
完整1M用于区分初始化影响与规模变化，也完成exp326保留的验证。
预计完整1M计时约900至1000 CPU秒。

主比较为layout减direct，baseline比较同时报告。三次配对t区间
计入0.02秒舍入；0.5%最低实际节省只作效应描述，区间跨零保留
待定。各分布分别报告CPU–acc前沿、RSS、单线程、行序和输出SHA。
每次完整CSV核验行数、端点、3字段、整数delay、EOF和换行，
上限保持2GB与3600秒。精度使用同次输出SHA复用。
正确性或资源检查失败即停止后续运行；固定协议完成后记录结果。

若layout相对direct的CPU差区间明确为负，支持恢复布局的实现
有收益；若区间跨零，保留不确定性；若明确为正，结束该固定控制
的扩大。正式接入须相对exp323进入对应分布CPU–acc前沿。
完整算法100M/1B、跨架构和平台表现继续待验。
