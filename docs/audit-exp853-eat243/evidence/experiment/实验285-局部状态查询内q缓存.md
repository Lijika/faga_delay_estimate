# 实验285：局部状态查询内 q 缓存

## 预注册

- 日期为 2026-10-16，基线为 exp281 combined，提交 `505dbd9`。候选只在私有 `build/exp285/qcache/src/legal_path_search.{h,cpp}` 增加局部 q 缓存；正式入口、用户构建脚本及交付包保持。
本查询内同一状态的 q 由固定架构、目标和状态决定。假设首次成功 relax 后缓存 q 可以保持完整搜索及输出，同时节省重复 q 求值。exp256 的 1.760429% Xeon 节省为历史组件证据，旧 3% 门保留在原记录。

- 影响范围为局部标签分配、strict relax 和诊断 evaluations。distance、parent、全局 id、heap key、预算、权重、邻接顺序及 finish 保持；evaluations 只由诊断探针消费。缓存与 distance 同步扩容，新查询首次有限标签覆盖旧 q，读取条件由本查询 distance 有限建立。

- 先复用 exp281 源码、模型、架构及已通过的路径证据。开发 12,150 条、U-output 9,472 条、U-role 14,080 条逐行核对所有搜索字段，允许 cpu_s 和 evaluations 改变；候选 evaluations 必须等于 states 且不超过基线。完整路径字节相同；caps 768 组、weights 80 组、Arc 变体 128 条以及探针内边界检查覆盖连续查询、提前返回与扩容。任何语义差异停止性能测量并修正。

- 完整程序联合测量使用已查看的 output、role、exp258 exact 样本，分别为 9,472、14,080、12,320 行；复用原标签、分层权重与数据次序。每个分布先预热 AB，再固定 AB/BA/AB 三对；A 为 exp281，B 为 qcache。同一估计进程输出用于 CPU、acc、完整 SHA 和输出契约检查。七行边界及 bias0/off/source CLI 输出与冻结参考比较。

- 主要计时在 r9r4900 的 `/home/lhj/lhjwork/eda2026` 内串行执行，绑定 core 3，采用完整进程 user+sys。每次检查线程、峰值 RSS、wall、端点次序、三字段整数 delay 和精确 EOF。AMD 只做参考与语义检查，其计时不参与放弃判定。

- CPU 使用配对差均值和三对 Student-t 95% 区间，额外向两端扩 0.02 s 表示 time 输出舍入。最小实际收益预设为 0.5%，仅用于效应描述；候选规则保持总体 acc >99% 与 CPU–acc 帕累托前沿。逐行等价时配对 acc 差及其区间为 0；记录全部分组误差和变化行数。相同输入、标签和输出身份可以复用历史评分与绝对 acc 区间。

- 若至少一个 Xeon 分布仍存在 CPU 改善可能，即差区间下端 <=0，则继续完整 1M；若三个样本均为明确 CPU 退化，保存该固定候选作为当前实现的负证据。通过语义检查的候选始终保留，历史优化方向按新规则继续追踪。

- 完整阶段先用 U-output 原序 20k 预热两臂，再运行独特 U-output 1M 的 AB/BA/AB 三对；qcache 公开 golden 1M 两次；repeated 1M 预热 AB 和 AB/BA/AB 三对。公开 acc 从这些计时输出评分或按完整 SHA 复用 exp281 分数，完整独特 1M 的 exact 缺失单列。repeated 的 cache 统计及初始化另做诊断，成本独列。

- 阶段指标保持独特 1M <100 s、100M <100 s、1B 100–300 s。本轮只验证完整 1M，跨架构和平台隐藏集待验；通用静态编译保持原参数，不使用本机专用 ISA。

- 证据存入 `validation/results/exp285/`，冻结源码、ELF、输入、标签、协议、runner、编译命令和历史参考；评分、诊断、编译与估计成本分别记录。开工 `df -h /dev/sdd` 可用约 412 GiB，收尾复查；删除按文件核验后执行。

## 结果

### 实现与等价检查

候选 ELF 为 `build/exp285/qcache/estimate`，大小 94,083,728 B，SHA-256 为
`a7cc354bc27c0626eb137401c0ce6f927076416ca10877f6b391746517afc769`。
私有源码只改 `legal_path_search.h` 与 `legal_path_search.cpp`。原 rank、模型、预算和队列保持，补丁见 `validation/results/exp285/candidate.patch`。

36,678 组搜索检查及 360,978 条路径边通过。三套主要请求共 35,702 条，q 求值从 109,505,958 次降到 96,674,699 次，减少 11.717407%。每行 evaluations=states，除该计数与 cpu_s 外的字段相同，路径完整 SHA 相同。caps、weights、Arc 变体、连续查询、无效坐标、same-pin、零延迟与不可达检查通过。caps 实际扩容到 327,680 槽，新增 q 数组占 1,310,720 B；三套主要请求最大为 163,840 槽。

Xeon Gold 6226R，core 3，完整进程 user+sys，串行 AB/BA/AB。差值均为 qcache 减 baseline，区间含两端各 0.02 s 的计时舍入。

独特 1M 原始 CPU 为 baseline 193.15/191.97/193.49 s、qcache 198.64/198.56/198.18 s；三个配对均变慢，平均增加 5.59 s。独特请求继续采用 exp281。repeated 的两臂均记录 cache hit/miss=999000/1000，初始化诊断均约 2.7 s。该诊断进程独立于主计时。独特输入确有 1,000,000 个不同请求，原行序及输出 SHA 保持；本轮复用既有缓存实现，独特 cache miss 未另开插桩运行。

公开 golden 1M 两次候选 CPU 为 214.53/214.62 s，acc 为 99.2763801451%，全部 1,000,000 行输出与 exp281 相同。该公开负载只运行候选，历史基线 CPU 为跨批描述。三个 exact 样本和公开负载的配对 acc 差、各距离组差、变化/改善/恶化行数全部为 0。分组 MRE 和绝对 acc 区间见 `sample-report.json` 与 `full-report.json`，绝对样本区间按相同输入、权重、标签和输出 SHA 复用 exp283。公开评分按相同身份复用 exp281。计时输出直接用于这些判定，新增评分和 exact 求解 CPU 均为 0。

42 次计时估计运行的输出契约、端点顺序、精确 EOF、完整 SHA、多次一致性和资源检查通过。最大 RSS 为 baseline 1,713,086,464 B、qcache 1,713,713,152 B，最大 wall 为 214.64 s，均为单线程。exp258 的 180 条不可达与公开唯一零标签正确。完整独特 1M 达到资源与输出验收要求，阶段一 <100 s 继续待达成。

### 解释、成本与局限

当前组合减少 q 求值，同时增加 q 数组读写及分支。完整独特 1M 的 CPU 增加已有配对证据，具体硬件开销来源尚未插桩归因。exp256 的 1.760429% 旧组件节省和本轮 repeated 节省均保留；当前固定 qcache 实现保留为分布相关候选，独特主线维持 exp281。no-tree 的完整独特收益仍待定，exp271 列证书以及历史 tree-mode0、endpoint-source/both、search2048 继续保留在待复评清单。

计时只含三对，Student-t 区间依赖配对差有代表性及独立性的假设，正态性未由三对数据确认。统计解释检查覆盖 11 项常见问题，保留全部分布、分组权重、原始运行与固定停止条件；区间跨零的样本保留待定。区间为逐项区间，未作多重比较校正；完整 1M 和 repeated 结论分别限定到当前机器与输入。完整独特 acc、100M/1B、跨架构和平台隐藏集待验，未外推综合分或平台速度。

编译 CPU 为 53.8172 s，本机搜索与 CLI 检查为 56.9254 s，42 次 Xeon 估计为 1747.66 s，两个诊断进程为 6.6298 s，最终补充检查为 11.2408 s。本机仅用于构建与语义核验。

补充检查曾因跨环境重算区间的浮点严格相等而失败，最大差为 1.39e-17 s。原记录保存在 `evidence-check-failure-01.json`；检查器改用绝对 1e-12 s 容差，通过已知舍入差与 1e-6 s 错误区间的测试后，42 次原始证据核对全部通过。估计程序、冻结 runner、输入与计时结果保持，修正后只重跑证据检查。

开工与收尾 `df -h /dev/sdd` 均显示约 412 GiB 可用。冻结时可用 441,857,695,744 B，收尾检查为约 441,624,629,248 B，期间增加约 0.217 GiB 产物。删除 0 文件，主动释放 0 B；本轮未产生超过 10 GB 的文件，原始 CSV 与私有构建保留，本地和远端均可复查。正式入口和交付包身份保持。
