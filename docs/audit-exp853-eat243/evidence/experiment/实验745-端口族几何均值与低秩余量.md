# 实验745 端口族几何均值与低秩余量

2026-10-27预登记。exp744的精确背景匹配教师为99.402233%，对普通
人口贡献0.718635pp；横向差分的收益主要集中于H。本轮继续路线B，
先判断一个可同时改变精度和计算量的背景表示。

## 固定假设

沿用exp589 mapping中的source_families/target_families，共26乘36个
族对，各族含8个lane。布线端口按去除方括号编号的名字归族，逻辑端口
按A/S与Q0/Q1/Y或0/1/2/3/4/5/D/M归族，完整成员保存于freeze。
对每个族对、方向、phase和商点，存64个完整pair的精确名义剩余均值。
剩余沿exp689定义，已扣解析趋势和当前pair中心。族均值保留完整几何
变化；每个完整pair与该均值的差再由rank16、32或64点积表达。
完整pair身份由左因子继续保留。新表示拟替代远域D64与字节曲线，
近域N512、首段、mandatory、端点检查和残差匹配流程继续沿用。

本轮复用已核验的方向0、phase(0,0)/(5,6)、全部59904 pair及542个
远域商点。三个旧数组的完整SHA按exp689提取记录检查。这是固定图
结构数据上的表示检查，全部点参与拟合并评价编码误差。全部phase、
真实请求Acc、未知位置泛化及完整程序CPU均在后续单独验证。

## 构造与核验

族均值使用整数和除64，保存Q6整数，检验完整pair回填后的组内余量
精确均值为0。保存均值的最小有符号int16或int32格式由实际范围确定。
使用Zstd level9比较直接小端字节和逐曲线int32一阶差分加字节平面，
完整解压、逆变换和SHA必须一致。两phase压缩长度乘240只用于初筛，
全方向资产实际长度仍待测。

归一化余量为R=(values-family_mean)/(128+125*(qx+qy))。
对两phase合并的1084列计算R转置乘R，取最大64个特征向量。
固定评估rank16、32、64的浮点重建与逐行INT8量化。左右各一float32
scale，每行最大绝对值映射到127，零行scale取1；使用floor(v/scale+0.5)
及[-127,127]裁剪，报告量化前后误差。整数点积另用标量int64抽查。
实际背景先恢复趋势与中心，再进行一次原规则整数化。

这项族均值投影在相同几何权重下可以降低同秩最佳平方误差，
当前D64加曲线的最终整数评分需实测。归一化SSE、最终名义tanh、
相对加权L1、phase、qx短域和qy短域分别记录，禁止以SSE替代Acc。

## 门与资源

INT8臂的全部两phase名义评分至少提高0.20pp、加权L1比不高于0.70，
两phase均提高、qx_short和qy_short均下降最多0.03pp，才扩大完整
方向和phase。容量投影须低于100MB，并分别计入近域、全部方向的
左右系数和scale、族均值、现有非资产部分、1MB新代码预留及4KB元数据。
更小rank的通过臂优先。所有臂失败时，结束本固定族划分、均值、
归一化和rank预算；保留其他结构共享与有向费用表示的研究资格。

即使本轮过门，也须完成完整背景、匹配残差、新100M联合收益门，
之后阶段接入并运行全端口非重复1B。当前均值表的展开和点积长度只
支持成本规划，生产RSS、初始化和随机行序性能均待验。

全部算法计算在r9执行，离线CPU预算1200秒、wall1800秒、RSS8GB，
新增磁盘预算2GB。源码和证据分别位于validation/exp745_family_mean.py
及validation/results/exp745，私有目录build/exp745。开工本地约273GiB，
r9约35GiB；原始输入、正式二进制和用户改动保持。

### 执行前索引核对

预登记初稿把相邻8个索引等同于8个lane。源逻辑端口实际按lane后接
Q0/Q1/Y排序，目标逻辑端口实际按lane后接0至5/D/M排序。本轮尚未
开始算法计算时，按已存在的mapping族名修正分组，并加入完整成员
计数与逻辑端口自检。主指标、rank、资源门和候选数保持原登记。

首次启动在压缩自检前发现r9缺少`/usr/include/zstd.h`。保存该次日志，
改为随输入冻结本机已核对的公开C API头文件，实际仍调用r9系统库，
记录运行库版本并核对压缩回读。该次没有拟合和评分结果。
