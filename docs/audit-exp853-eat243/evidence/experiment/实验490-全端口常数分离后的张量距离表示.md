# 实验490 全端口常数分离后的张量距离表示

2026-10-18，查看本轮结果前登记。exp489的A排序优于相同rank的B排序，
两种原始拟合均未通过质量门。新假设为逐端口对常数占用了TT端口切口
的表示容量，独立保存常数后，小rank链能更好地拟合几何残差。
理论见Obsidian《逐端口对常数分离与张量残差》。

保留全部208合法源、288 Output目标、552点、(+,+)/(0,0)一个context。

exp489两臂和rank128参照按文件身份复用，全部标签属于已查看的开发域。

重新核对其定义，先确认int16范围。训练对象改为`Z=w*(D-trend-c)`，
最终输出恢复`trend+c+Zhat/w`，随后执行原整数后处理。
常数表随float资产、int16核心资产和float32查询表一起保存，回读逐值核对。
完整保存、解码、区间、SHA和59,904次独立标量查询保持每臂执行。

由冻结exp489脚本生成私有驱动，仅修改常数分离、资产携带、A两臂和容量
计算，记录生成源及替换次数；exp489代码和原结果保持。每阶段继续报告
所有端口、类型、族、lane和近轴误差。最终输出与同rank exp489按逐行身份
配对比较，记录评分差、变化行、改善/恶化行，完整程序CPU仍另验。

压缩体积为固定序列化布局的条件外推，其余context须实际编译验证。
