# 实验832 全局主曲面与源族残量共享

2026-10-29，结果前登记。exp831将A/B全部按源族分开，方向0判别
L1恶化65.492731%。本轮保留exp820全局2048个A，单独检验源族是否
适合作为残量B的条件。研究重点是一次目录、两次码本读取下的信息分配。

26族各64个B，四方向正文16,392,192B；偏置10bit、A11bit、B6bit，
共27bit。sf已在当前Prepared输入中出现，在线采用其完整对应关系
还需组件核对。当前实验只验证方向0，静态压缩及完整CPU另验。

数据沿exp820的119,808构造曲面与8,320判别曲面，认证mapping逐源
取族编号。全局A固定；每族先分配旧A/B，按构造曲面的B使用数选择
63个非零B初值，次数相同时选小代码，另保留零号。四轮只更新B中心，
并交替更新A/B选择及受限偏置。A中心保持原整数。

判别从当前exp820 C-words的A和偏置开始，先选B，再两轮交替编码。
R为原A/B的同流程重新编码，C为原A及族条件B。所有训练先于判别，
训练不读取判别标签。主门为C相对当前L1改善≥8%，相对R改善≥5%，
近轴与远域各自退化≤0.5%。通过才扩大四方向与最终评分四格。
失败只限定本分组、64个残量、初始化与四轮更新，按门停止扩大。

每次native分配抽一条穷举所有中心，核对损失与并列规则。
全部判别结果从字段独立恢复并核对分族损失；另32行逐格标量验证。
R每曲面目标不增，全局A逐整数保持。CPU≤1200s、wall≤900s、
RSS≤4GiB、新增资产≤32MB。种子20261029832仅用于独立核验抽样。
