# 实验339 桶内手写上滤：结果

2026-10-17。基线为 exp335/exp334 `estimate`，候选只把已建堆桶追加路径中的
`std::push_heap` 改为显式下标上滤。目标分组、搜索参数、模型、cache0、批次大小
和输出顺序保持。有效阶段成绩仍只认非重复 100M 与 1B 的完整程序实测，本轮没有
接入正式版本，也没有产生阶段成绩。

## 等价与资源

- `queue-test-normal` 与 ASan/UBSan 夹具通过：395,400 pushes、242,496 pops、75 clears。
- 搜索审计保持 12,150 条字段和 126,462 条路径边。
- exp333 的 exact、边界、CLI、特殊 CSV、诊断和写出失败审计全部通过。
- 20k/100k 输出 SHA 与基线一致，单线程，峰值 RSS 约 1.67 GB，候选 ELF 94,087,824 字节。
