# 实验762 冻结端口空间的全角色相对L1几何拟合

2026-10-27预登记。阶段基线为exp728，目标按用户goal为未知、非重复、
有效端口全覆盖1B完整CPU约100秒且越快越好，Acc严格大于99%并有余量。
exp744的精确名义背景支持主要精度缺口；本轮检验现有64维端口空间内，
冻结当前256曲线后按相对L1重算几何系数能追回多少质量。

exp752只改左系数，且每phase只有16个训练几何点；exp756改变左空间，
采用平方目标和有限训练列。本轮保持当前全部INT8左系数及尺度，仅
改变所选几何列的右系数和其float32尺度，每列拟合使用全部59,904角色对。
完整近域、中心、趋势、曲线和真实地图残差均保持。

## 数据与固定对照

复用exp755认证的方向0、59,904×3,840去趋势名义值及完整输入SHA。
全部数据属于同架构开发数据。seed为20261027762，先在每个phase的
32个已有几何列中均匀选择1列，得到120列主评分域；再从剩余列中
分别为qx=0、qx=1、qy=0、qy=1、双轴至少2且qsum<=15、双轴至少2且
qsum>15各无放回选20列。共240列、14,376,960个名义值。
两个分母及所选列在读取值和拟合前冻结，辅助列只用于分组诊断。

每个列的全部角色标签都参与拟合和重建评分。这检验已知有限名义场的
压缩能力；没有把这些分数称为未见请求精度。其他几何列、其余方向、
真实地图匹配残差及未知请求分别验证。

对照W使用相对平方损失的一次加权最小二乘。候选R从当前右系数开始，
使用平滑相对L1的IRLS，平滑宽度依次为1、0.25、0.0625ps，每段固定
4轮，共12轮。QR只对冻结左空间做可逆预条件；不增加秩或偏置。
每步核对加权线性方程残差及同一平滑宽度下目标不增，不根据评分调轮数。
每臂分别记录浮点系数和原行尺度INT8导出的结果，保持现有两次整数恢复
及非负截断顺序。记录末段目标下降幅度，有限迭代不宣称全局L1最优。

## 继续条件与成本

R浮点在主120列的名义Acc须提高至少0.05pp，相对L1比例至多0.92；
R的INT8导出须提高至少0.03pp，相对L1比例至多0.95。两者均须在qx短轴、
qy短轴、中距、长距、核心端口和逻辑端口组退化至多0.03pp。
主域至少90个phase的INT8评分提高。W用于解释目标作用，不作为后验候选。

通过后按同一固定算法登记完整几何构造，测真实压缩容量、匹配T2D6
背景/残差四格和完整程序成本，再及时推进新100M、1B。保持完整覆盖，
禁止只把当前240列当作可交付覆盖。浮点通过而INT8失败支持检查量化；
浮点失败只停止当前冻结左空间、曲线、有限迭代和所选列组合。

主过程预算CPU2400秒、wall900秒、RSS4GB、离线BLAS8线程；独立审核
CPU120秒、wall180秒、BLAS1线程。预计新增磁盘小于250MB，完整estimate
和新exact均为0次。新代码只增加实验驱动、独立审核、记录与理论笔记，
复用既有认证读取、量化、评分和身份工具，生产源码与包指针保持。

自检覆盖已知精确线性解、带异常值的稳健位置、零/正负量化以及整数
点积范围。审核从保存因子独立重算INT32点积、恢复顺序、全部评分和
门判断，并检查原始目标与最终拟合记录。全部算法在r9执行。

实验位于r9的research/exp745，新增build/exp762和validation/results/exp762。
