# 实验171 多源前驱树可变盒抽样

2026-10-10，分支`research/exp171-source-specific-tree-sample`，起点`446239f`。
正式exp131与exp169保持，开工`/dev/sdd`可用454G。

## 主假设与对象

不同源的名义预算盒由角势各自导出，exp170固定公共盒前提已经失败。
本轮保持20个端口族各取lane0、lane4共40源，C1200，最小索引最优parent。
逐源记录实际盒和槽位数，按[z,y,x]保存字节；根254，unknown255。
先构造完整预算树并检查每个有限状态的严格下降等式，再压缩。
exp169同源流须逐字节相等，其他源完整unknown/range/root/count独立复核。

固定名义路径语义及单parent局限沿用Obsidian
`单源最优前驱字节树的证书与平移边界.md`。本轮只判断容量与共享空间。

## 表示与门

40个独立流分别用既有Zstandard19单线程、checksum、content-size和完整EOF压缩，
随后按冻结源顺序串联原流，用同一工具压缩。每次全字节往返核验。
不同盒的lane对仅比较共同完整位移区域，相同字节统计保留unknown比例局限。

扩大全160源门为
`68,201,104 + 1,000,000 + 4 × min(独立40流合计, 串联40流字节) < 100,000,000`，
并要求所有证书、编码、资源通过。这里假设另外6个lane容量与所选2个lane相同；
串联上下文的比例推广也属于假设，完整160源容量须另测。
单流与主探针各timeout900 s、峰值RSS≤2,000,000,000 B、CPU3单线程。
未通过仅停止当前固定扩展；其他源选择、delta、字典和事件标签保持开放。
