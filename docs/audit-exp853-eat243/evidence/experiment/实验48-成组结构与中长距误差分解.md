# 实验48 成组结构变体与中长距误差分解（预注册）

日期 2026-09-24。起点提交 `b051392`（工作树只有用户未跟踪 `blobs/` 与用户改动的 `AGENTS.md`，
保持不动）。开工 `df -h /dev/sdd`：1007G 总 / 574G 用 / 382G 可用。

本协议先于任何变体生成、exact 标签、生产预测或分析产生，单独提交。本轮不训练模型、不改
`./estimate` 与 `build/submission/`、不读公开 golden、不跑 1B 计时、不删大文件。

## 假设

- **H1 平移稳定性**：固定端口对与完整位移、只整体平移端点位置时，残差 `d−B0` 与 `d−E` 的
  组内离散明显小于跨族离散；组内中位数修正在同族留出位置上优于 `E`。
- **H2 周期扩展**：固定端口、位移符号与余数、按 20/24 格扩展位移时，`Δd` 与残差在短前缀后趋稳。
- **H3 Line/Block/边界**：只改变 Line 跨越数、Block 跨越或边界距离时，残差出现与这些条件相关的
  系统差。
- **H4 中长距分解**：距离 ≥25 的评分损失集中在特定（距离带 × 端点类 × 几何标签 × 高估/低估）
  单元；现有 44 维特征不含路径级位移匹配、中段 Block/边界约束、象限主导与端点候选分散等信息。

前三条来自三份调研文档的 P1（成组变体识别可复用结构），第四条来自 P2（中长距损失分解）。
三份文档一致指出：现有 10,024 条标签没有重复的“端口对＋完整位移”组，直接查表缺覆盖；中长距
（≥25）贡献公开集约 90.7% 的剩余损失。

## 变体生成规则（128 族 × 8 个有效变体 = 1,024 条请求）

族种子取自 `exp18b-labels.csv`，按 (band, x1, y1, p1, x2, y2, p2) 排序后按固定步长确定性选取。

| 族类型 | 固定 | 主动改变 | 族数 | 带分布 |
|---|---|---|---:|---|
| `translation` | 端口对、完整位移 (dx,dy) | 整体平移 (s,t)，两端点都必须落在有效 SRB | 64 | 32 长（≥25）/ 32 短 |
| `periodic` | 端口对、sign(dx)、sign(dy)、`dx%20`、`dy%24` | 沿 x 加 20k 或沿 y 加 24k（k=0..7） | 24 | 长 |
| `line` | 端口对、完整位移 | 放置位置使水平/垂直 Line 跨越数不同（0..3） | 16 | 长 |
| `block` | 端口对、完整位移 | 可跨 Block 横跨 / 不可跨 Block 纵跨 / 端点洞 / 内部 | 16 | 长 |
| `boundary` | 端口对、完整位移 | 边缘距离 <12 与内部（≥12）交替 | 8 | 长 |

合计 96 族长距、32 族短距（满足“至少一半来自 ≥25”）。

可放置性规则（预先固定）：

1. 两端点坐标必须在 `SRB_Inst.json` 的有效 SRB 集合内；否则该位移候选丢弃并计数。
2. 变体的完整位移必须严格等于族定义（`translation` 保持 (dx,dy)；`periodic` 保持符号与余数）。
3. 族内 8 个变体互不相同，且不含族种子端点。
4. 一个族凑不满 8 个有效变体时，记录 `short_family`，不补造不合规则的变体；分析按实际变体数
   做族内留出（至少 4 个变体才进入统计）。
5. Line/Block/边界族按同一谓词（与 `tests/query_profile.cpp` 的 tag 规则一致）筛选候选位置，
   由脚本在 Python 侧复算并在标签里交叉核对。

## 主指标、统计与对照

- 每行参考 = `exact`；accuracy 用竞赛点公式 `1−tanh(4|pred−exact|/exact)`（正参考）代理。
- 残差三个：`d−B0`（`--endpoint-mode off`）、`d−E`（`--endpoint-mode source-short 150`，
  即标签 `fast` 列）、`d−xgb`（生产二进制）。报告每族/每类/每带的中位数、MAD、最大值。
- **组内留出**：每族 8 变体按序号奇偶分 4 拟合 / 4 留出；修正 `c_f = median(d−E)`（拟合半）；
  在留出半比较 `E`、`E+c_f`、生产 `xgb`。
- **新族留出**：族在 (type,band) 内按 id 奇偶对半；修正只用训练族拟合：全局中位数、
  距离带中位数、(带,几何 tag) 中位数；在留出族上比较。
- 统计：按族重采样的配对 bootstrap（10,000 次，seed 20260924），报告 accuracy 差的点估计与
  95% 区间；同时报 `组内 MAD / 跨族 MAD` 比值。
- 可达性：`exact<0` 与预测 `-1` 的混淆矩阵（false_reachable、reachable_false_unreachable）。

## 门槛与停止条件

- **判正条件**（两条都要）：组内中位数修正在同族留出上的 paired 95% 下界 > 0（对 `E`），
  **且** > 0（对生产 `xgb`）。
- **稳定性证据**（即使判负也报）：`组内 MAD / 跨族 MAD < 0.5` 记为“存在组内结构”，
  但不足以接入；`≥0.5` 记为“无稳定组内结构”。
- 任一条件不满足：保留负结果，不改模型、不改生产二进制、不接入。
- 若出现正信号：先做单项离线消融（新族留出上的固定 64 树 + 单项修正），通过后才讨论下一轮，
  仍不改正式入口。
- 可达性退化（`false_reachable` 或 `reachable_false_unreachable` 增加）即判负。

## 预算

1,024 条变体 × 2 次探针（`off` 与 `source-short`，各自 exact 搜索一次）+ 1 次生产预测。
按实验18B 标签的 `us_pdb` 分布（10,024 条共 25.7 s，301+ 中位数 2.5 ms）估计 exact 成本
远小于 1 分钟；先用 8 族试点测量真实成本再放大，若超预算则缩小到能判别假设的最小规模并说明。

## 中长距误差分解（P2，独立于变体选型）

数据：`exp18b-labels.csv`（10,024，训练池，只作诊断）、`validation/results/exp24-holdout-samples.csv`
+ `exp24-holdout-predictions.csv`（3,107）、`build/exp43/fresh-samples.csv` + `pred-baseline.csv`（6,180）、
`build/exp46/fresh-samples.csv` + `pred-baseline.csv`（6,177）。

按 25-50、51-100、101-300、301+ 四带，交叉记录：端点类（Z*/I*/logic）、方向（dx/dy 符号）、
几何 tag（可跨 Block、不可跨 Block、端点洞、近边界）、Line 跨越数、高估/低估，输出每单元
的样本份额与 accuracy 损失贡献（`n_cell/N × (100−A_cell)`）。

同时列出**已有信号**（现有 44 维特征覆盖：完整位移、余数、端点坐标、边界距离、Line 费用、
Block 标签、端口类型/ID、Net 方向、lane）与**缺失信号**（路径级完整位移匹配、中段 Block/边界
约束、象限主导值与端点候选分散、`U1−L` 区间、真实路径绕行）。诊断数据不用于本轮任何选型。

### 结论与重启条件

1. **组内结构成立**：固定端口与完整位移时，`d−E` 的位置稳定性很强（MAD 中位数 0），组内常数
   在留出位置上接近精确（98.63 vs xgb 90.62）。这解释了 NeuralTalk 文章中"seen 组"机制为何有效。
2. **不可接入**：可复用键覆盖 0.00131%（公开 13/989,976），新族修正劣于现有模型；即使接入，
   期望综合收益 0.000084 ≪ 0.01。P3 查表三个条件不齐。
3. **周期扩展不成立**：每周期增量在族内跨度中位数 268.5 ps，不能当常数用。
4. **中长距分解给出方向而非候选**：Line 跨越与可跨 Block 条件下 `xgb` 的 accuracy 低 3–6 点，
   但这些量已在特征里；需要的是能解释"为何模型没有用足它们"的新信号（路径级位移匹配、中段
   几何），而不是再加同一批几何量。
5. 重启条件：若未来标签池能覆盖同一 (端口对, 完整位移) 键的未见请求（例如按该键定向采样到
   至少 10% 公开剩余请求量级），或出现新的中段/路径级信号在独立留出上超过 `xgb` 的配对下界，
   再考虑结构查表或新特征；本轮不训练模型、不改 `./estimate`。

- 变体是人工构造成组样本，不是生产请求分布；128 族的规模只够判别"组内是否稳定"，不足以估计
  生产收益。
- 精度一律以 Router exact 为参考的竞赛点代理；未读公开 golden，也未做端到端 1B 计时。

  但同一族的 8 个变体仍共享端口与位移。

  3.5242 点损失一起报告，但不构成新盲测。
