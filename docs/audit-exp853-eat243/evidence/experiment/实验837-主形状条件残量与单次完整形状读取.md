# 实验837 主形状条件残量与单次完整形状读取

2026-10-29，结果前登记。上一轮exp836属于有效进展，固定函数
归因显示恢复普通背景可提高0.476821pp，单轴自由偏置分别只回收
19.26%和16.17%。本轮检验完整二维形状的条件共享，目标仍为
未知非重复全角色1B约100秒、Acc严格大于99.1%并留余量。

## 最高杠杆假设

当前C+A[a,q]+B[b,q]中的B在全部A之间共用。exp831/832的条件
来自源端口族；本轮条件来自已经离线保存的主形状码A。相近完整
曲面的剩余形状可能有更集中的变化，允许每个A使用独立的16个
残量，而查询时直接读取预合成S[a,b,q]=A[a,q]+B_a[b,q]。

每键保存10位C+67和15位合并形状码，共25位，仍使用uint32目录。
四方向完整S正文为4×2048×16×552×2=144,703,488B，
目录115,015,680B。旧四方向A/B正文10,174,464B。
查询由原目录读取C与合并码，再读一项S，省去一次码本读取及
A/B相加；原解析、首段、Line、残差与输出保持。
较大工作集可能抵消这些节省，完整CPU必须实测。
本轮先做方向0原型，交付候选必须扩大全部方向与全部键。

## 数据和唯一配置

复用exp820的全59904角色对各两个phase，共119808条构造曲面；
8320条开发曲面与构造键不交叉。当前主码和基线来自exp822方向0，
开发原word须逐项等于exp820 C-words。
复用exp744生产字段及exp822百万折外开发数据，在同一8251条
ordinary请求上计算当前、候选、精确背景的最终整数评分。
数据已观察，统计只作开发诊断，不声明独立确认。

先使用当前码本和同一既有两轮编码器取得构造集主码，主码随后固定。
每个A的局部B保留零号恒零；其余15个中心由该组最常用的旧B号初始化，
数量不足时按全构造集的旧B频率补齐，并列取编号小者。
四轮执行局部加权中位数、精确16码重选和原10位偏置重估。
每步代理L1不得增加，未出现的A保持确定的初始化。
开发编码固定原A，按同一局部码本执行两轮取码与偏置更新。
全流程不使用真实标签选择中心、偏置或主码。

## 最终评分与扩大

基线必须逐行复现exp822所选B1R0在匹配请求上的整数输出，
精确背景必须复现exp836对应oracle。记录完整代理L1、实际查询点
误差、最终Acc以及距离、近轴、qx、源族和fold分组。
名义L1没有进入本轮最终质量门。

若候选最终Acc高于基线，且近轴、距离、方向、fold的最低组差
不低于-0.05pp，立即扩大其余方向，并完成完整静态容量与新100M
联合验证。完整联合收益通过后及时1B及阶段接入。
若未通过，则本轮高保真替换假设缺少支持，停止该固定16码、
主码分组与四轮配置的扩大；其速度交换价值继续标为未测，
不据此否定所有条件码本。

本轮另记当前编码的条件组支持数，避免将训练不足与表示族等同。
静态压缩仅记录方向0资产，四方向投影标明假设，完整目录未构造时
不宣称ELF合格。线上成本的最终结论只由完整程序给出。

−0.018980023pp；精确名义背景参考为99.509075122%。

四轮结束为10,234,100,446,844，相对原编码改善32.315561%。

恶化4.875610%。2048个条件组有1个空组，115组少于16条，

当前证据尚未分别确定样本支持、码量约束和训练目标的因果贡献。
