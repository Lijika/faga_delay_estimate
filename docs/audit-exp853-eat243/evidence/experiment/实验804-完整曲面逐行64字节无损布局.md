# 实验804 完整曲面逐行64字节无损布局

2026-10-29，预登记。正式阶段版为exp780，最终目标保持全角色未知非重复
1B完整CPU约100秒、Acc严格大于99.1%并留余量。

## 全局判断与唯一假设

exp801的三个端点加性基底和exp803的两个完整键轴加性式丢失必要交互。
本轮保留exp781的完整预测函数、目录、码号、模型和静态压缩资产，
只改变初始化后的码本表示。exp781已在独立100M上提高0.074890107pp，
CPU增加1.677024秒/100M；exp783的LLC缺失增加支持热集假设。
exp782只检查跨代码的逐列跨度。本轮检查每个代码内部的46格行跨度。

适用对象为所有208非I源、288目标、59904角色对及全部有效商格。
主请求规则复用赛题测试集中的补充信息、qa和生成规则；用户最新100M→1B
测试阶梯优先。已看过的数据用于无损等价部署验证，精度直接复用相同输出的
既有独立标签；本轮不能把旧输入称为新的未知确认集。

## 冻结格式与停止条件

每个direction×code×qx记录固定64B、64B对齐，保存int16行最小值、
46个uint8低位以及两个uint64高位掩码。查询恢复
`base + low[qy] + (((high8 >> qy) & 1) << 8) + (((high9 >> qy) & 1) << 9)`。
记录内所有读取都在同一行内；新增指令与初始化成本完整计时。

1. 全部A8192/B256码本行跨度必须≤1023；任何一行超界就停止这个固定格式。
2. Python全码本往返与C++全码本往返逐整数一致，合成边界覆盖int16两端、
   高位255/256/511/512/1023、qy0/45，超界1024必须拒绝。
3. 原压缩资产恢复仍保留原始scratch容量，delta跨qx连续、每552格重置。
   原目录和最终数值链保持。ELF静态且<100000000B，单线程、RSS≤2GB。
4. 全部检查通过后直接完整100M；本轮不新增1M/10M完整程序运行。

码本运行正文预算为4×(8192+256)×12×64=25952256B，
原正文37306368B，减少30.434783%。此计数只给出容量差。

## 完整100M协议

r9 Xeon Gold6226R，绑CPU8，同机串行并检查其他重负载。
A为exp780，B为原exp781，C为本轮布局。先各预热一次，随后六组交错
`ABC, BCA, CAB, ACB, CBA, BAC`。全组执行完毕再判定，不追加顺序择优。
每次完整输出记录SHA、行数计数、线程、RSS、user+sys和wall。
相同输入及完整输出SHA允许复用逐行CSV契约和评分。

输入为exp781保留的非重复全角色100M，SHA
`b26b7e7942dadcc21f58251758fd60da3d0222f8a80bcefd9d86703ddbad7bea`。
B/C输出必须为4013573040B、SHA
`0b244862fb19602f4db2d872c7a597ea0170b325f6e7db60a753d417f68403fd`。
A输出必须为4013572706B、SHA
`d69146449c13321f6acc1ae665e169b54be75aa41214f3783fd31a95771dbe75`。

主比较为C对A。沿用既有精度配对差与97.5%保守区间
[0.07067264860669065,0.07952989962153707]pp。
六组配对CPU节省使用df5双侧97.5% t区间，系数3.163381449748624。
阶段接入要求按1B线性成本诊断的综合分点估计≥0.02，且
`0.8×精度差下界 + (10×CPU节省下界)/120 > 0`。
次比较C对B解释无损布局效果，报告配对均值与95%区间。
这是阶段联合收益门，最终99.1%与100s继续单列。

通过后尽快完整1B及阶段接入；1B按实际CPU和同次输出评分报告，
不把上述线性诊断称作1B成绩。失败仅限定本64B固定格式。

## 完成结果

全部393216个A行与12288个B行的最大跨度分别为482和265，固定1023
范围门通过。Python与C++逐项恢复18653184个码本整数，C++另核对
28753920个目录整数；合成int16边界、qy边界与1024拒绝均通过。
静态ELF为94400536B，SHA
`c28709859c396243688ded87a0515d1178bca1a45a777138b0e0c80cd2040f44`。

完成21次全角色非重复100M。六组正式均值A/B/C分别为
15.994338833、17.677926000、19.017755167秒。
C较同函数B增加1.339829167秒，配对95%增加区间
[1.283782224,1.395876109]秒；相对正式A增加3.023416333秒。
精度按相同完整输入、输出SHA复用原1916928条exact，
C为98.902636046%，A为98.827745939%。
1B线性成本诊断综合分-0.192039275，联合下界-0.200117263，阶段门失败。

所有完整输出身份与原合同一致，单线程、峰值RSS328417280B，
最长wall19.061785秒。逐次回执、冻结身份、输出SHA及独立重算均通过。
按协议停止本64B格式的1B和正式接入；没有修改正式入口或交付包。

这次结果明确区分运行正文和查询工作量。码本少30.43%仍增加CPU，
所以后续优先检验整批请求的读取依赖和计算顺序。它保留全部预测值，
也保留了exp781的质量信号；其他无损布局仍需独立评估。

冻结二进制、输入与命令重建。原输入、候选与正式二进制继续保留。
