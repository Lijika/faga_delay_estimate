# 实验428 Block绕行析取的真实下界修正

2026-10-18预登记。exp427在128条高损失路径中发现83条中段跳格，
每条内部Block费用292 ps、Arc差通常为负。单独增加Block费会误算位移。
本轮实现vault `Block绕行析取与名义跳格类的真实下界` 的诊断原型。

固定比较exp420预测M与max(M,L)。L枚举无跳格、非空净零跳格和
非零净跳格类，使用已认证完整名义距离与全局势界；无跳格类在
端点被同一个Block分隔时加入上绕/下绕必要条件。
全部整数跳格类采用费用尾部停止，不预设±1完备。
真实首末费用及原坐标Line单列，保留正长度环和单Net分支。

先用exp427的256条已恢复路径与exp420的20k开发exact逐行核对L≤exact，
修正后的绝对误差不得增加。开发acc增加至少0.03个百分点且没有违例
才进入新的完整请求实验。记录分组增益、域外势界回退、名义查询数、
计时和峰值内存，成本只作诊断；部署前继续研究查询次数与共享表示。
运行时资源、全源容量和新请求精度均需另验。

原型只读既有字段和架构，程序不读取请求答案表。exact仅供离线验证。
架构中的可跨越Block必须具有相同水平宽度、相同收费且无竖直跳格，
当前从数据核对14和292；不满足时显式停止此研究原型。
该前提的泛化属于后续算法工作，本轮不据此宣称跨架构完成。

## 结果

已查看的20k开发样本中，acc从99.079815%升至99.213105%，
增加0.133291个百分点，157条输出改变且全部改善，L>exact为0。
SEA组从99.005299%升至99.176405%，LE组从99.161532%升至99.253353%。
256条路径样本属于这20k的子集，全部包含在此次逐行检查中。
同pin为0、无效首Net为-1和991ps回归均通过。

本机全量调用的查询CPU为0.215557秒，认证名义查询849,624次，
移位查询513,755次，barrier候选5,794个，域外势界回退0，
峰值RSS453,058,560 B。这些组件成本用于诊断，主要CPU由远端完整运行判定。
开发增益通过预登记0.03个百分点条件，exp429冻结8源新1M验证。

首次构建因共享lookup419未使用的警告被严格构建检查拒绝，没有执行查询。
修订仅改为复用该共享查询函数；原code-v1、freeze-v1及编译错误保留。
exp429进一步验证几何过滤与这20k输出逐行一致，并完成ASan/UBSan检查。
