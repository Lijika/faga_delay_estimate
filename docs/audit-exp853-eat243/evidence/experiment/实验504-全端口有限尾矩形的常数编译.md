# 实验504 全端口有限尾矩形的常数编译

2026-10-19，在查看本轮覆盖率与容量前登记。exp503继续原评价。
本轮检查完整有限网格中可由一个常数和两个阈值恢复的区域，
正式入口继续exp354，CPU发布比较基准继续exp323。

## 假设与固定表示

使用exp499已认证的208源、288目标、四方向、120余类、
12乘46几何的15,872,163,840个值。全部标签属于开发域。
每片固定残差常数C为去趋势矩阵的右上角(i=11,j=45)值。
每个i先计算本行末尾连续等于C的起始j，再沿i逆序取最大值，
得到每个起始a对应的最小b，使整个矩形i>=a、j>=b均等于C。

在a=0..11的候选中选择合法物理域覆盖值数最多者，同分选择最小a。
全部候选覆盖为0时仍保存第一个候选；b=46表示空矩形。
每片记录C为int16、a和b各uint8，共4字节。
固定208乘288乘480片，原始记录主体115,015,680B。
有序记录用XZ preset6压缩，完整头和端口身份另计。

查询在矩形内返回trend+C，矩形外返回未覆盖。
这份表示用于精确覆盖证据，尚未定义完整估计器。
有限域标签已经认证；当前判据只承诺枚举矩形内的名义值保持。
真实Block、Gap、边界、首尾路径及域外外推分别另验。

## 计算与核验

l7只执行固定常数和阈值的离线编译，逐份验证标签身份，
完整保存全部端口记录和编译成本。模型编译完传入r9并逐份核对SHA。
r9等待exp503完整评价结束后进行全部值检查，独立构造每个矩形，
核对全部覆盖值等于标签，且a、b符合完整行列范围。

r9同时用独立行扫描重建每个a的可行b与物理覆盖数，核对确定性的
最大覆盖选择。覆盖率按全部合法物理域15,734,444,544值计算，
报告208源、288目标、四方向、120余类和近轴/内部。
完整模型恢复、精确EOF、原始流SHA及覆盖输出流SHA一并检查。
任一身份、覆盖、整数或独立实现检查失败，停止并保留现场。

## 固定机制门

合法物理域精确覆盖>=50%，完整静态资产<=40,000,000B，
所有恢复与独立检查通过时，保留为与其他完整模型组合的候选组件。
这两个条件只决定后续组合研究价值，实际完整CPU与真实acc另验。
任一门失败，结束当前固定角点与单矩形格式的扩大。

旧exp413固定仿射外推、exp418三表可分近似、exp490加权常数与TT
均保留原失败结论。本轮使用完整认证有限网格上的精确等值矩形，
新判据不推断有限域以外的仿射性质。新增exact标签0，
exp501新1M继续保留。模型质量与算法测试只在r9执行。
