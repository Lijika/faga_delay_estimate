# 实验384 逐行极差的单槽排序证书先导

2026-10-17，在新测量前登记。CPU固定基准为exp323发布版，当前对照为
exp354。正式源码和入口保持。exp381显示exp354约有330MB名义余量，
本轮使用其中约44.24MB，给每个目标列、residue、源Z的四槽行存uint16极差。

主假设是行级极差明显小于全域最大值，能减少四槽求值。
竞争解释是剩余请求靠近坐标轴，行级证书也难覆盖；另一竞争解释是额外
访存与分支抵消省下的加法。exp271逐列证书只增0.72/0.39个百分点，
本轮新增的信息粒度固定为实际四槽行，容量与访问成本分别记录。
