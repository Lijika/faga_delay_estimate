# 实验246 C1 获胜路径真实几何摘要

2026-10-12。exp243 的九项获胜路径费用摘要通过新请求门。本轮在旧开发集
增加真实落点信息，检验费用相近的候选路径是否仍有可识别差异。

## 预注册

固定 reference 为 exp242 的 41 维、128 树 depth5 五折模型，
candidate 加十项几何字段，形成 51 维；树数、深度、训练权重、
eta、正则、随机种子和校准 alpha 集合保持原样。数据只用
exp215/231/234 三窗 30,826 条，exp239/243 标签保持验证用途。

十项字段为真实两轴绕行量、相对起点的 x/y 最小最大坐标、
正费用 Net 数、最大 Net 费用、方向变化数、实际位移偏离名义位移的
Net 数。完整路径含终端 Net。只在严格改善 expandedUpper 时保存，
等费保持首次路径，缺失 U 时全部为 -1。

新增观察使用既有 resolver 返回值。所有旧 audit 字段须逐行保持。
两轴绕行量非负且为偶数，极值包含起终点，计数不超过完整 Net 数，
费用满足已有 replayGap 加 terminalGap 的求和界。
理论与边界记录在 Obsidian 的“获胜真实路径几何摘要的可检验不变量”。

使用同一五空间折、完整 pin 排除和每窗人口权重。主门为 candidate
相对 reference 增加至少 +0.05 pp、窗和带内 10,000 次配对 bootstrap
95% 下界大于零且至少四折为正，seed2026101225。未过门则结束
本固定十字段组。reference 复用未改变的 exp242 模型和校准证据。
新模型独立 JSON 推理、校准、逐行预测、分组、指标和 bootstrap 必须通过。

本地执行，每阶段上限 1,200 秒。达到开发门后再冻结全量模型并登记新请求；
C++ 完整程序与 CPU 单独测量。平台 1B、隐藏集和跨架构继续待验。
