# 实验563 整数几何点积的尺度分组与SIMD

2026-10-21，exp557质量结果查看前登记。继续完整全端口紧凑背景主线，
本轮只研究已有int16因子的精确查询实现。正式exp354、CPU基准exp323、
exp557模型和其评分协议保持冻结。该实验独立于exp557质量门，速度结果
仅为组件证据，完整CLI及未知1B另验。

## 假设与实现范围

exp557的完整整数绝对和证书通过时，任意分组float64累加保持精确值。
比较原分量顺序S、四路float64累加A、共同列指数分组的整数SSE2点积I。
I只置换已有因子列；每组使用PMADDWD，先把int32对积符号扩展至int64，
两路int64向量独立累加，余项用标量int64。按共同指数恢复至一个int64
总和，最后仅转换一次double并乘公共二进制尺度。全部整数绝对值≤32767、
公共尺度整数界≤2^53、指数跨度≤31以及正常有限缩放为I的充分资格。
SSE2属于x86-64通用目标；无AVX2、AVX-512、VNNI或SSSE3依赖。

作用范围为私有解码源码、实验驱动、完整模型列置换和证据，复用exp557
已冻结解码器，不修改生产或exp557文件。理论见Vault《共同尺度分组的
整数SIMD点积》。PSHUFB、INT8-MLP和对称树模型转换保留待定，当前先
测量几何查询中可认证的整数算术与ILP组合。

## 数据、指标与停止条件

仅在r9固定目录运行。复用exp557完整非重复1M，208源、288目标、59904
端口对全部覆盖。G/F/T分别独立取得完整资产SHA、指数分布和整数证书；
资格失败的模型结束该实现。各模型的独立S输出已与Python逐位核验，
A/I的完整1M结果须与该输出逐位相同，输入与资产身份保持。

先每臂完整1M预热一次，再固定六轮循环，顺序依次为S/A/I、A/I/S、
I/S/A，重复两次。同机串行，无其他算法计时任务。每次均解码全部1M，
保持原CSV对应的随机行序；输出全量SHA与基准相同后删除可重建副本，
记录路径、字节数、SHA和重建命令。单线程、静态通用构建、零查询分配。
计时使用原解码器CPU边界，包含映射后的查询与结果数组写入，不含输入
解析、背景恢复、特征、残差、CSV输出或初始化。

主效应为S减A、S减I的六个配对CPU差，报告均值与双侧95% t区间；
平均查询CPU降低至少10%且差值区间下界>0时保留速度组合。质量由
exp557及新请求另验，本轮不重新选择树、rank、阈值或训练参数。
任一数值、线程、退出、文件身份检查失败即结束对应路径并保存现场。
预算CPU360秒、新增私有资产300MB；结果副本逐份核对后删除。
