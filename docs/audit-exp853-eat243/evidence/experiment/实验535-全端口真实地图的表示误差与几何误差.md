# 实验535 全端口真实地图的表示误差与几何误差

2026-10-20，查看本轮结果前登记。目标是确定下一轮架构的主要误差来源。
复用exp501完整非重复1M真实exact开发集，覆盖208源、288目标、
59,904端口对；复用exp499全部208张完整名义认证字段及exp534恢复表。
本轮没有训练、阈值选择或正式版本更新。

## 固定对象与假设

四臂为原位移名义oracle、压缩坐标名义oracle、原位移共享表、
压缩坐标共享表。四臂均加真实坐标的强制Line前缀。
oracle直接提取exp499认证字段，模型固定exp532的int16恢复表，
后者与exp534的36表SHA完全相同。原exp532名义整数评分保持独立；
本轮属于真实误差诊断，允许记录未通过名义质量门的模型。
正式输出exp354和CPU基准exp323复用exp502同身份输出、完整CPU及exp506评分。

压缩坐标固定使用exp512已认证的
`X=x-14*(y%100<50)*(x>=90)`，Y=y。
该变换仍有竖直行带事件、Block费用和实际Line费用。
本轮检验把变换后的端点直接代入名义场的效果，全部剩余事件误差保留。
同端点同端口的空路径继续为0。

对每一臂逐行检查
`exact-model=(exact-oracle)+(oracle-model)`，
记录几何残差、表示残差及二者交叉项。符号残差描述这两个固定函数之差；
其数值没有自动获得真实图下界或单一Block归因资格。

H1为真实几何影响主导。判据固定为原位移oracle真实acc<99.25%，
且几何残差平方和至少为表示残差平方和的两倍。
H2为仅改变坐标已产生足够收益。判据为几何残差平方和至少减少20%、
oracle配对acc增加至少0.05pp，按完整源pin重采样的95%区间下界>0。
H2失败则结束单独坐标替换方向，后续显式事件表示另登记。
两条假设均使用完整1M判定，条件组用于解释。

## 检查与成本

输入、exact、发布输出、全部208张字段和恢复表先核对完整SHA。
逐字段回读认证头、目标身份、完整解压SHA，提取两种位移的全部1M值。
C++单线程对每条请求计算两种128项点积；Python按同一累加顺序
复核全部1M两臂，覆盖所有端口对。保存整数预测、名义oracle与完整行序身份。
两种坐标的混合基数映射分别核对逆映射，检查全部源族、目标族与方向。

报告总体与source family、target family、role、direction、近轴、距离、
端点边界距离、Block条带两侧和行带相位、Line费用组。分组按输入端点固定，
各分割的行数与损失贡献需完整求和。配对区间使用完整源pin、2000次、
seed20261020535；本开发集的统计区间用于诊断，独立请求泛化另验。

仅在r9r4900的`/home/lhj/lhjwork/eda2026/research/exp535`执行，
CPU上限7200s、AS16GB，离线主体单线程，新资产≤500MB。
完整字段逐源流式解压，复用现有字段与查询表，避免再生成稠密全域。
C++加载、查询及写出成本分别记录；并行离线任务会影响组件计时，
本轮CPU属于诊断成本，完整生产请求CPU另验。
任何身份、完整覆盖、逐行一致、分解或资源检查失败即保存失败并停止。
本机开工`/dev/sdd`可用361GiB，计划删除0项，正式文件保持。
