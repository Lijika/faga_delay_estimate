# 实验459 小批次距离场预取的非重复1M消融

2026-10-18预登记。exp455逐指令采样中，main内约61.92%的周期样本
位于三处距离场读取之后；exp457普通页p在完整10M用4.256667秒。
主假设为独立请求的随机读等待可以通过提前读取重叠。

固定候选为p（exp456普通页解析）、ph（解析加大页）、b（p加32行批次）、
f（b加主距离地址及目标几何摘要预取）、fh（f加大页）。
首Net落点按真实resolveNet获得，坐标按tx-a.x+n.dx、ty-a.y+n.dy计算，
先检查有效性与域内地址。批次保持输入顺序、原估计过程和原输出文本。
预取调用GCC __builtin_prefetch，通用C++17/O2构建；没有新ISA要求。
接口语义来源为GCC官方Other Builtins，通过Defuddle读取并保存原文。

仅更改私有源码副本与实验测试。局部先检查空输入、1/31/32/33/65行、
CRLF、无末尾换行、非法端点、特殊请求及普通/ASan/UBSan的逐字节输出、
非时间计数和错误状态。完整输入固定exp442非重复1M。
所有候选均真实写完整输出；SHA等于exp444后复用完整契约和
exp442同次输出acc99.1617735414%、95%区间[99.1249889788,99.1974752644]%。
新exact与评分成本均为0，已查看输入属于等价部署开发集。

远端Xeon core3串行。每臂20k预热，固定p/ph/b/f/fh、反序、正序三对，
主指标为完整程序CPU，配对t95、df2，加0.02秒计时舍入。
记录RSS<=2GB、单线程、cache_hits=0、输出SHA及所有非时间计数。
f对b区分预取收益，fh对ph检验大页条件下的组合收益。

1M无资源或语义失败的固定五臂均进入10M，防止初始化掩盖规模收益。
10M相对对应标量p或ph节省>=5%且差区间上界<0的预取臂扩大100M，
否则停止该固定配置。100M通过后再规划真实1B诊断。
全160源、逻辑/I端点、静态100MB容量与跨架构分别待验。

## 结果

完整1M三次CPU均值为p 0.626667秒、ph 0.890000秒、b 0.630000秒、
f 0.573333秒、fh 0.816667秒。f相对p节省8.5106%，配对差95%区间
[-0.087676,-0.018991]秒；f相对b节省8.9947%，区间
[-0.091009,-0.022324]秒。批次单项b与p的差区间跨零。
fh相对ph节省8.2397%，相对f增加0.243333秒。

全部输出SHA为
`3c96dcb8d71591fc4f79cfe08c61341b8ddc6842cac0400459a1fb27ba928b7a`，
变化0行，所有非时间计数保持。复用同次输出acc99.1617735414%及
95%区间[99.1249889788,99.1974752644]%；新增exact及评分CPU均为0。
单线程，最高RSS1,755,291,648字节。全部五臂按预登记进入10M。
原始证据在validation/results/exp459。
