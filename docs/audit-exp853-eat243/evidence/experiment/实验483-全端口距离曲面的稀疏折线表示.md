# 实验483 全端口距离曲面的稀疏折线表示

2026-10-18，查看新结果前登记。主假设为带可选转折位置的共享折线
函数能够以较少系数表示名义距离曲面。每份数据及每臂评价均覆盖
全部208个合法非I源和288个Output目标，包含全部逻辑端口。

## 固定有限域与标签

每片固定源、目标、方向及余类。方向为四象限；
余类固定为(0,0)、(5,6)，商格为i=0..11、j=0..45，
位移为sx*(rx+10*i)、sy*(ry+12*j)。
共479,232片、264,536,064个含零轴重复的值。
零轴重复在总体评分时去除；逐片误差区间保留完整552点。
这是全端口开发名义网格，实际请求acc另由完整程序输出验证。

复用exp413的正权Dijkstra、二进制堆参考实现和窗口逃逸证书。
Z源直接使用对应初态；逻辑源从同格出Arc初始化Z状态；
逻辑目标枚举最后Net与终止Arc，同格直达Arc单列。
源包含全208端口，目标包含全288端口，任何缺失立即停止。
有限窗口先固定rx=160、ry=608；所有被引用的末段值均须通过
exp413原窗口证书。认证失败保留反例并停止当前配置。
离线编译最多8个独立单线程源任务，成本与完整估计程序分开记录。
按旧22秒/源测量，208源原型预计约6,000至8,000 CPU秒；
保存选定切片约1.06GB，完整中间距离场只存进程内存。

## 固定候选与编码

共同趋势为125*i+(正y时127，否则125)*j，另拟合仿射项。
共享函数为max(0,a*i+b*j-t)，方向固定
(1,0)、(0,1)、(1,1)、(1,-1)、(1,2)、(2,1)、(1,-2)、(2,-1)；
t枚举域内整数转折点，去除零函数与仿射退化项。
加权最小二乘权重的平方根为1/(128+125*i+125*j)。
在消除仿射项后的标准化字典上按最大残差相关依次选择，
每次对已选项联合最小二乘重拟合。
固定比较K=0、4、8、16，K为逐片折线项数。

全部系数以1/16ps单位量化，截距int32、两条斜率int16，
折线索引uint16、系数int16。每片保存实际解码误差的最小/最大值，
两端各int16；任何溢出立即停止并记录。整数解码固定为最近整数，
半值远离零，完整资产回读后重新评价。固定长度片通过乘法定位；
所有头、字典、系数、误差记录均计入容量，Zstd19实际压缩并回读核对。

## 指标与停止条件

逐片恢复检查数量、完整有限域误差区间、整数与浮点模型的评分差、
名义评分、平均绝对误差、最大误差、变化值数。
分别列源/目标类型、每个源、每个目标、四方向、近轴与内部区域。
全部有限网格穷举结果属于确定性数据，统计置信区间留给真实新请求。

进入全部余类编译须满足全部端口总体名义评分至少99.97%，
近轴至少99.9%，按相同切片成本推算的全余类运行时主体不超过1.5GB，
实际Zstd压缩的全余类条件投影不超过80MB。
此条件为筛选，全部余类实际容量仍需完整编译。
如全部候选未满足联合门，保留质量与容量曲线，结束本配置扩大。
CPU仅记录离线成本；本机计时不承担候选性能淘汰。

通过后还需编译可处理未知全端口请求的完整算法，按新的非重复
1M、10M、100M顺序验证。exp323保持CPU发布基准。
全端口100M及1B目标、真实acc和平台可移植性各自保留待验身份。
