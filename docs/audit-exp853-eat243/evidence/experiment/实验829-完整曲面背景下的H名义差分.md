# 实验829 完整曲面背景下的H名义差分

2026-10-29，查看新结果前登记。exp825的100M独立审核已通过，
完整1B验收继续。本轮使用本机历史开发缓存，r9保持串行完整计时。

## 全局判断与假设

exp827/828的固定四形状配置在开发近轴损失上未达门，停止扩大。
exp750曾在新100M中验证H名义差分提高0.045032946pp，但完整CPU
增加0.944147333秒，联合门失败。当前背景已经改为完整目录及双码本，
其查询工作与旧N512/D64背景不同。当前差分的信息增益及实际成本
重新验证；历史模型和速度结论各自保留适用范围。

冻结exp822/825的B1R0为基线，ordinary与V输出保持。
对H人口比较两个同容量、匹配当前背景的8棵depth6模型。
C8使用exp744的89列控制特征；P8增加当前曲面横向±14的绝对与
相对名义差分，共93列。原位移背景复用，变体保留pair、方向翻转、
合法性、cycle与首段费用语义。差分加292仅作特征。

两个模型均使用exp749固定参数，learning_rate=0.3、原随机种子、
MAE、Exact叶估计及无bootstrap；本机thread_count=1。
数据为既有1M缓存中的18,064条H，沿原三折source-pin划分。
当前背景在全部1M行须与exp822的base1逐整数相同。
该数据已经参与历史选型，只支持开发机制判断。

## 质量门与下一步

分别比较C8和P8相对B1R0，以及P8相对C8。使用26个源族重采样
9,999次，统计seed20261029829；三项比较使用Bonferroni同时95%
区间，每项分位点0.05/6与1-0.05/6。
候选整体增益至少0.02pp且区间下界为正，各折增益为正，
direction、distance、near_axis任一组变化至少−0.03pp。
非H全部整数保持。

P8还须较C8提高至少0.01pp且配对区间下界为正。
满足时优先P8，否则选择通过主门的C8；两者均失败则停止当前
特征和容量配置。通过后以全部H训练单个final模型，核验native、
JSON叶编号、raw与最终整数，随即研究静态接入和完整100M→1B。
100M与1B联合精度、CPU、资源门另在部署前登记。

本轮使用既有标签，新exact与完整estimate次数为0。
CPU≤300秒、wall≤600秒、RSS≤2GiB；新开发产物≤100MB。
复用exp748训练与exp734评分、分组方法，独立标量核对名义变体
与重新计算三组配对结果。实现及证据分别位于
`validation/exp829_surface_h.py`和`validation/results/exp829/`。
本地/dev/sdd开工可用265GiB。
