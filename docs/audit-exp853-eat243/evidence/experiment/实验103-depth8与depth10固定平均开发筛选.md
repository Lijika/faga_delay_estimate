# 实验103：depth 8/10 固定平均开发筛选

日期：2026-09-27。开工 `/dev/sdd` 可用约 479G。

## 预注册

假设：实验93的 depth 8 与 depth 10 在同一47维特征上的逐行误差有互补性，简单平均可超过两者，并足以支付双模型在线推理。冻结输入为 `validation/results/exp93-p1-predictions.csv`，SHA-256 `0910ac7cb245de0f45d3b62c57a534fda15867d986bbeae23959448158b7fca9`；数据为实验93的 `[38M,40M)` exact 窗口，6,178行，已多次参与选型，只能作开发筛选。七带份额和计数固定复用 `validation/results/exp93-p1-score.json`，SHA-256 `0baa25fbf5fd95f37a99650c1b53c65eca30a4b5d58a192831634740f3149a7d`。生产基线仍为47维、depth 8、128树、gamma 1、统一 -3 ps。

唯一候选对双方非负的最终整数预测计算 `(depth8 + depth10 + 1) // 2`；任一负值时沿用 depth 8。固定权重1:1，不扫描其他权重、分带条件或阈值。主指标为原语料带份额加权 accuracy；辅以 MAPE、逐带结果和两类可达性误判。按实验93七带配对 bootstrap，10,000次、seed 20260925。

开发门槛：相对 depth 8 的点增益至少 `+0.06 pp` 且95%区间下界大于0；相对 depth 10 的点增益至少 `+0.01 pp`；两类可达性误判不增加。失败就关闭这个固定平均候选，不生成新标签、不做在线实现。通过后先在全新 exact 窗口独立验证，再对双模型推理做 profiling、三对1M unique计时和综合收益检验。正式接入仍须满足独立精度与CPU联合门槛、完整1M输出和资源检查。

复现命令为 `build/venv-ml/bin/python validation/exp103_depth_ensemble_screen.py`。原始结果写入 `validation/results/exp103-depth-ensemble-screen.json`。本轮不运行1B，不修改正式包。

## 结果

对照指标逐项重现实验93，6,178行和七带计数一致。固定平均相对depth 8增加 `+0.043844 pp`，七带配对95%区间 `[+0.023292,+0.064868] pp`；相对depth 10仅增加 `+0.003717 pp`。两类可达性误判均为0。相对depth 10的预设 `+0.01 pp` 门槛未过，关闭这一固定平均候选；其额外一套推理的CPU预算只有约 `96×0.003717=0.357 s/1B`，缺少继续实现的价值。

收尾 `/dev/sdd` 可用约479G，释放量0。没有新增大文件，也没有清理文件。开发窗口已参与选型，本结果不作独立泛化证据。
