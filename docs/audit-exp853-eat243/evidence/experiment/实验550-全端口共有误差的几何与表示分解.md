# 实验550 全端口共有误差的几何与表示分解

2026-10-20，查看新增统计前登记。exp549结束固定输出组合，并测得较好
三模型误差相关0.882至0.917。本轮确定这些共有误差中，各固定函数差值
承担的部分，为新的统一表示选择研究对象。正式exp354、CPU基准exp323保持。

## 数据与精确分解

完整exp501非重复1M开发请求，208源、288目标、59,904端口对，每对至少一行。
标签、exp354与exp536/537/549冻结预测全部核对SHA及原统计。训练0、exact0、
估计程序运行0。所有新数值计算仅在r9的私有exp550目录进行。

三个模型沿用M1=exp536 aligned、M2=exp537 original、M3=exp537 aligned。
O为exp536精确名义场首Net对齐并恢复真实首段费与Line后的预测。
逐行定义g=O-exact、c_i=M_i-O、e_i=M_i-exact，则e_i=g+c_i。
g是两个固定距离函数的差，包含内部几何及名义图语义影响；本轮保持这一
操作性定义，具体Block或路径切换归因仍需另外的路径见证。

对每对模型记录精确整数恒等式
`<e_i,e_j>=<g,g>+<g,c_i+c_j>+<c_i,c_j>`，中心协方差另用整数和校正。
分别记录去除g前后的相关系数。对三个误差通道用共同均值与差异能量分解，
核对`3*sum||e_i||²=||sum e_i||²+sum_{i<j}||e_i-e_j||²`，c通道同样核对。
交叉项保留符号，相关性与差值分解分别报告。

## 固定反事实、分组与判断

固定几何修复oracle为`max(0,M_i-g)`，同时报告负值截断行数及截断前能量。
它使用标签，旨在隔离表示误差的质量影响。固定表示精确化oracle为O。
它们均用于诊断，不作为可部署规则，也不据此推断新请求效果。
三个修复oracle相对对应原模型，以及O相对M1，按完整源pin成簇配对
bootstrap2000次，seed20261020550。既有开发请求继续属于开发集。

固定判断如下，失败后不追加阈值搜索。

- H1，共有压缩结构显著。三个模型对去除g后相关均≥0.75，且各对中心
  协方差的c-c项均至少为原e-e项的50%；这一判断仅选择表示研究优先级。
- H2，几何与压缩均限制99.1%目标。O和M1几何修复oracle的acc均<99.1%。
  通过时后续表示同时处理这两个通道；任一通道通过也保留其查询与容量成本。
- H3，近轴结构集中。首Net对齐位移满足abs(x)<20或abs(y)<24的组，
  共同压缩误差`(c1+c2+c3)`平方和占比≥50%，且达到该组行占比的两倍。
  通过只授权有近轴机制的表示原型，具体方向由证据限定。

沿用exp549十类端点与地图事件分组，新增全部源端口、目标端口、对齐近轴、
对齐方向、g符号、三模型同号及四模型区间内外组。各分割完整行数、g/c/e
能量、交叉项与误差和均须恢复总体；分组为解释性统计，不据其选择新规则。
保存四个原始整数误差通道，便于后续复用，不重新求标签。
