# 实验744 精确与生产名义差分的教师对照

2026-10-27预登记，主线为postexp728深化报告第6.2、6.3、6.5与11.3节。
exp733至743使用的是较早的审查报告。exp734只测试廉价几何条件，
exp659只测试本点背景和曲线响应，本轮加入同完整端口对的位移响应。

## 假设与数据

冻结exp728，ELF SHA为
`9c05eb2ce01450f58ffa6d2adaa6793f307f44d8962a66e5d36453be32c5c68f`。
使用百万历史开发缓存及原source-pin三折，完整费用truth作为监督。
复用已核验exp499全端口名义场和exp536首Net对齐标签。
所有计算在r9r4900执行，正式入口和交付包保持。

同一原始完整pair采用首Net对齐位移d=(tx-ax+ndx,ty-ay+ndy)。
分别查询d、d-(14,0)、d+(14,0)。越出既有名义场的变体标为无效，
差分置0并附有效位。合法名义域、方向变换、近远域和正cycle逐条处理。
三次响应的非Line首段费用相同，在差分中消去；mandatory保持原查询值。
加292的两个候选差分表示一次中央穿越的响应特征，合法路径资格另验。

Pexact使用精确名义距离，Pprod使用当前N512/D64加曲线的整数结果。
每臂加入两个有向差分及其除以max(B-fee,128)的相对值。
共同控制输入为exp734的83列，加两变体的有效、方向改变与近域标记。
共同输入已含首段实际与名义位移差，特征覆盖首段已跳格的区别。
精确差分只作结构信息诊断，其在线实现成本和静态容量尚未通过。

## 固定比较与验证

- C使用共同输入和旧背景B。
- Pprod使用共同输入及生产差分，背景为B。
- Pexact使用共同输入及精确差分，背景为B。
- E使用共同输入，背景换成精确名义N加首段fee，匹配重训。
- EP使用共同输入及精确差分，背景与E相同。

五臂均为16路、64棵depth6、eta0.1，继承exp734其余固定参数。
目标为truth-background-mandatory，权重1000/truth，V行最终预测保持
冻结T2D6/V8结果；训练人口与exp734一致。另保留B+R_C、N+R_C、
B+R_E、N+R_E四格，区分背景替换与残差适配。所有模型选型留在开发集。

先核对百万查询身份、原53列、pair/位移、旧名义标签与生产背景。
逐源解压只保留当前152.6MB场，核验完整SHA、表头及端口顺序。
新位移值采用向量和独立标量地址重算，正cycle由完整Arc/Net再求最小值。
训练验证source-pin隔离、原生和JSON叶编号、double原序累加及最终整数。
报告实际位移距离、近轴、方向、事件、源族、折与改变行数。
差分误差及相关性只作描述，最终判断采用同一行完整truth的评分差。

Pprod-C至少提高0.03pp、ordinary组至少提高0.02pp、三折正，
源族9999次重采样同时95%下界为正，距离/近轴/方向组下降最多0.05pp，
才进入低成本差分表示与小学生研究。Pexact-C的0.05pp作为精确信息门，
EP-E同时报告。E达到99.1%只支持精确背景信息目标，完整部署另验。
上述四个差分比较使用Bonferroni区间，seed20261027744。

若精确差分有效而生产差分无效，研究直接差分编码；两者均无足够信号，
结束本轮固定±14、输入和教师配置。新背景的适配价值单独保留。
有效学生需新请求100M联合CPU、Acc和资源验证，再接入阶段版并完整1B。
本轮离线组件与历史缓存训练均不计作完整estimate规模测试。

离线CPU预算2400秒、wall1800秒、RSS8GiB、持久新增2GiB。
开工本地约273GiB，r9约36GiB可用。复用既有资产与标签，不产生大CSV。
数据身份、模型、逐行结果和审计保存在私有build/exp744及
validation/results/exp744。理论笔记保存到Obsidian。

## 结果

208个名义场的SHA和端口顺序全部通过，百万原位移名义值与exp536逐行
一致，生产背景与冻结缓存逐行一致。变体有224022次方向改变、61747次
近远域改变、13672次超域，正cycle独立复算通过。原背景MAE为5.394332ps，
两差分MAE为7.591887ps。输入唯一、实际source-pin隔离、59904 pair覆盖
及每折完整pair覆盖均通过独立审核。
