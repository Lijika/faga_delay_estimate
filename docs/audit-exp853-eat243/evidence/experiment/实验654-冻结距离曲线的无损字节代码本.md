# 实验654 冻结距离曲线的无损字节代码本

2026-10-24，查看本轮曲线数值范围及新计时前登记。exp652已经完成，
共享二维曲线在新100M提高0.191319140pp，当前int16读取布局新增
CPU1.794343秒，质量门通过而联合门失败。阶段版保持exp644。

## 假设与范围门

最高杠杆仍为D64点积加共享二维残量函数。本轮只改变代码本的整数
表示，冻结全部曲线、单元码、D64恢复、S8、特征、批次、预取及舍入。
若555,008个int16值的全局最大值减最小值不超过255，则取全局最小值
为固定origin，保存uint8(value-origin)。在线读字节并加编译期origin。
全码本恢复须逐值相同，单元码字节保持；范围超限则停止此固定配置，
保留原始范围证据。完整程序运行、裁剪值、重新拟合均不能越过范围门。

范围门通过后，代码本由1,110,016B降为555,008B。改善CPU属于待验
假设，字节加origin的成本与缓存影响由完整程序共同测量。用完整
码本回读及原C的完整100M输出SHA检验等价，复用exp652同次输出
精度及239,616条exact评分，不新增训练、exact或评分选型。

## 构建与完整100M

A为exp640冻结S8，与当前阶段版相同；C为exp652原int16曲线；
B为同一程序的字节代码本。实际静态ELF须小于100,000,000B，
保留通用x86-64/SSE2，线上单线程、RSS不超过2GB。
源码仅替换曲线header及资产对象，原始worker、D64压缩资产和其余
对象均核对冻结身份。全部构建、算法及计时只在r9指定目录执行。

纯等价改动复用exp652已独立核验的完整非重复100M及exact。输入
覆盖59,904端口对；该输入已被查看，保留开发性能基准身份。每臂先
完整预热一次，之后六个完整100M块按以下顺序串行运行。

```text
warmup A C B
1 A C B
2 C B A
3 B A C
4 B C A
5 C A B
6 A B C
```

每臂在三个位置各两次。记录完整CPU、wall、RSS、线程数、计数器
及完整SHA；A须等于exp652/A，B和C须等于exp652/C的完整输出。
相同完整输入与输出复用已通过的全量CSV契约。每次运行CPU<100秒、
wall<=3600秒、单线程、RSS<=2,000,000,000B，完整运行共21次。
开始前核对负载，保持同机串行；编译和离线数值审计先完成。

## 统计、停止与扩大

主比较B减A的Acc差及保守97.5%精度区间固定复用exp652结果。
六块A减B的CPU差取97.5%配对t区间，按exp652公式报告联合分，
点值>=0.005且保守95%下界>0才通过。精度质量门沿用原门。
同时B相对C须平均节省至少0.05秒/100M，95%配对区间下界>0；
该比较只核验纯部署改动的工程收益，不重新选码或修改质量结论。

任何身份、回读、SHA或资源错误即停止。固定B未过联合门则停止
本字节布局的接入与1B扩大，保留曲线质量及其他读取资源配置。
通过后另行登记同一B的清洁目录完整100M、及时接入阶段版和完整
全端口非重复1B。最终Acc>99%、官方平台和其他CPU继续另验。

私有目录为research/exp654，源码为validation/exp654_curve_bytes.py、
tests/exp654_distance_curve_bytes.h。原始证据存validation/results/exp654。

重建命令和引用情况后删除，同族原始输出继续保留。
