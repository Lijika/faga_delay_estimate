# 实验293 桶内二元组无损整数编码

## 预注册

2026-10-16，exp292 CLI 修复与 18 项回归已提交 `2443476`，完整默认路径
核验正在 Xeon 串行执行。本轮从 `build/exp292/fixed/src/` 复制私有源码，
仅改变 `search_queue.h` 的桶内元素表示。主假设为 uint64 比较减少二元组
比较成本，同时保持每次出队三元组、搜索路径与最终预测。

原桶内 `(int id,uint32 g)` 占八字节。新表示令 id 加上 2^31 后占高
32 位，g 占低 32 位，解码在 int64 中减去偏移后回到 int。32 位 int
前提由编译期断言检查；大 key 四叉堆、位图、延迟建堆和全部搜索算术保持。
推导见 Obsidian `agent-theory/桶内二元组的无损整数全序编码.md`。
不增加依赖、CPU 特定指令或编译架构参数。

先复用 exp277 队列夹具，改为包含实际候选头文件，分别用 O2 和
ASan/UBSan 检查每次出队。夹具包括正负 id 极值、g 极值、重复项、非单调
key、65536 边界、大 key、全桶清空及多次 clear。再复用 exp281 的搜索、
768 组 cap、80 组 weight 和费用变体探针，逐字段核对原始记录与路径 SHA。
边界、零 bias、显式 off/source 的 CLI 输出沿用已验证参考。

Xeon 主性能先测三个已查看 exact 样本 U-output、U-role、exp258，
每组两臂预热一次，再 AB/BA/AB 三对，core 3 同机串行。
A 为 exp292 fixed，B 为 packed。两臂同次计时输出须与 exp287
search512-both 对应原输出完整 SHA 相同，复用原标签、权重和评分，
新增 exact 与评分成本为零。完整进程 CPU 包含初始化及 I/O。
报告 paired acc、分组误差、变化行数、CPU 效应和 df2 Student-t 95%
区间，两端加 0.02 s 舍入；0.5% 最小效应仅作描述。AMD 只作参考。

三个样本若全部 CPU 差区间下端大于零，保留固定实现与证据，结束扩大。
存在区间跨零或明确收益时保留候选，另冻结完整 1M 测量。
本轮先导 CPU 不直接转赋给完整 1M，沿用总体 acc >99% 的逐分布前沿条件。
纯等价改动的预计精度差为零；任一行或路径差异停止性能测量。

正式入口、src、构建脚本、交付包和其他用户改动保持。开工磁盘约
410 GiB 可用；完整 100M/1B、跨架构和官方平台另验。
