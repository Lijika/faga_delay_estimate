## 假设与候选

主假设 H1：对同一完整请求，基础 residue 查询的四个有限象限候选中，
最大值与第二大值之差、最大值与最小值之差、主导象限编号，能够解释现有44维特征
未解释的 `exact - xgb` 误差；效果主要出现在距离25以上的请求。
这是经验假设，象限差值不是路径证书，也不用于精确界或剪枝。

唯一首轮候选是冻结64树残差训练配置加上述三个 `B0` 象限特征。
对 I 目标保留 `estimateBase()` 现有位移与 residue 折叠语义；无有限象限、零延迟和
不可达行单列记录且保持原输出。原始整数候选的差值先除以现有 `scale_`，
不引入任何拟合阈值。对照为同样训练数据、权重、树数和训练参数的44维模型，
以及冻结 `B_perf` 输出；训练和评估均按完整端点键连接，禁止按行号拼接特征。

3. 在训练池拟合对照与唯一候选；在实验24、43、46数据上报告全体和25–50、
   51–100、101–300、301+四带的配对 accuracy、MAPE、误差符号与可达性。
   三个已见来源中至少两个的请求加权 accuracy 差为正，且合并点估计不少于
   +0.03 个百分点，才冻结候选进入独立验证。否则停止本候选。
4. 冻结模型和阈值之后，使用现有 `scripts/make_scale_requests.py` 的 unique
   生成规则取序号 `[10M,12M)`，沿用 `query_profile_exp18b` 的七带、每带最多
   1,024 条、固定 seed 20260919 抽样规则。排除公开请求及实验18B、24、31、

主指标是按该留出请求来源各带份额加权的竞赛 accuracy 差。
区间用七带内配对 bootstrap，10,000次，seed 20260925；全量抽取的零距离带不重采。
要求 accuracy 差的95%下界大于0，可达性无新增错误，且所有零/负参考按既有规则单列。
开发集选择后的公开1M仅用于公开评分，不充当独立证据。

## 成本与采纳

若独立验证通过，先在候选私有构建目录检查导出模型与 Python 逐行等价，
再与 `B_perf` 同机串行交错测 repeated、10% unique 后缀和 full-unique 的
cache miss、初始化、CPU、wall、RSS、线程、输出契约；full-unique 先测小规模并按
实验50规则决定是否扩大。正式 repeated 1B 的配对 CPU 差与独立 accuracy 差共同形成
`Δ综合分 = 0.8 × Δaccuracy - ΔCPU / 120`（accuracy 为百分点，CPU 为秒）。
综合收益95%下界须大于0、点估计至少+0.01；通过后才运行五次1B正式验收，
每次单线程、RSS不超过2,000,000,000字节、wall不超过3,600秒，五次完整输出一致。

本轮先做特征可用性和旧数据筛选，不改正式 `./estimate`、`build/submission/`
或平台交付包。原始证据放 `validation/results/exp51-*`，私有中间产物放
`build/exp51/`。无信号时记录该特征的负结果；该结果不否定其他路径级或中段几何方向。

## 第一阶段结果：只读四象限探针（已完成）

日期 2026-09-25，起点提交 `0e2dd26`。本轮只量特征并检查语义：未训练模型、未读公开

实现：`ResidueEstimator::quadrantDiagnostics()` 成为纯 residue 查表的唯一实现，
`estimateBase()` 只从它取出 `value/unreachable/fallback`，所以探针与生产不可能走不同数值

逐行输出完整端点键、四个象限 slot 与候选原始值（无穷记 `INF`）、B0、最大−次大、最大−最小、
主导编号、有限象限数与折叠/Line 状态；有限象限少于 2 时区间字段写 `NA` 并单列计数。

构建与运行（`validation/exp51_quadrants.py` 复现全部命令与哈希）：

```text

    tests/exp51_quadrant_probe.cpp src/architecture.cpp src/residue_estimator.cpp
g++ -std=c++17 -O2 -Wall -Wextra -Wno-unused-parameter -o build/exp51/estimate-src \
    src/main.cpp src/architecture.cpp src/router.cpp src/residue_estimator.cpp
python3 validation/exp51_quadrants.py --public-rows 10000 --with-asan
```

估计器身份：m=2 时商图 20×24、S=120、480 个余数类，368 源 / 448 目标，斜率四象限
`(1500,1270) (1500,-1250) (-1500,1270) (-1500,-1250)`，表 813,957,120 字节，建表 27.2 s。

### 覆盖限制与异常

- 未观测到：`fallback`（四象限全无穷的直线回退）与 `clamped`（含 Line 后为负再钳零）在
  本轮 21,137 行中均为 0 行；这两支的复算逻辑已实现但本轮无实例，不能算已验证。
- SRB 网格有 5,800 个空洞（如 `(0,0)`–`(0,4)`），"无路"类是真实类别而非构造。
- 实现期发现并修复一处自引入缺陷：最初的折叠把 Line 费用提到 `exists()` 之前计算，对
  `SRB_99999_0` 一类"解析成功但网格外"的坐标会越界索引 Line 前缀数组。改为 `exists()`
  之后计算，探针边界集合与 ASan/UBSan 运行确认无越界，生产输出不受影响。
- 同 pin / 无效端点 / 网格外端点的语义只在 14 条生成用例与 1 条已见同 pin 上行验证，
  规模小但覆盖了每类分支。
