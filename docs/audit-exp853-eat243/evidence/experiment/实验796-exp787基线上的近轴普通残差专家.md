# 实验796 exp787基线上的近轴普通残差专家

2026-10-28预登记。exp795在历史开发集相对exp787提高0.044661990pp，
但其支持域专家仍使用exp793中按exp791背景训练的模型。当前问题是
近轴专家在exp787背景上重训后能否独立保留增益。

## Altitude：固定背景，判别条件残差价值

报告路线B要求把背景替换、匹配残差和新增信息分别对照。exp792的
全域B1024匹配残差相对exp787下降0.001718pp；exp793近轴普通组
取得正向分组收益、qx≥2退化；exp795再把预测回退到exp787后通过
开发门。上述结果说明近轴修正有候选价值，也留下背景身份与专家
函数的混杂。本轮只重训支持域近轴残差，背景、特征、路由与训练
配置均固定到exp787。

## 固定对象与方法

- 基线背景、普通/H/V预测、残差目标、特征、三折source-pin划分、
  CatBoost配置及解码规则均取exp787。
- 支持route从exp795冻结为`[0,1,4,5,8,9,12,13]`；不重选路由。
- 对每个支持route和fold，仅用该route、ordinary且`qx<=1`的其余两折
  训练匹配残差专家，并预测留出fold。qx定义为`floor(abs(dx)/10)`。
- 仅对`ordinary && qx<=1 && route in supported_routes`替换exp787预测；
  其他请求逐行沿用exp787。H/V及qx≥2须逐行相同。
- 不增加exact标签、不调参、不生成新请求、不改背景或模型特征。
  这是复用历史百万开发集的机制复核，不是独立泛化确认。

## 预登记门与停止条件

相对exp787基线的总体Acc提高至少0.02个百分点；qx=0、qx=1分组
均不退化；四方向最低分组差不低于-0.05个百分点；H/V逐行不变。
离线CPU≤2000秒、wall≤1200秒、RSS≤8GiB，source-pin训练/留出簇
无交叉，整数解码与预测行数完整。

通过后，在固定的现成非重复100M请求和exact抽样上构建单线程静态
候选，记录完整输出契约、SHA、CPU、RSS及同次Acc；达到预登记联合
门后再进行完整1B。门失败则停止本次固定路由与exp787匹配残差配置，
不通过增加route或反复调参挽救。

## Depth：解释边界

该折分只能降低单个模型的source-pin泄漏风险。支持route、qx边界与
实验方向已经参考exp788–795及同一百万开发集选择，因此当前分数
不能解释成未见总体上的独立95%证据。报告关于“完整选择管线需位于
外层隔离中”的提醒继续有效。若本轮通过，100M只提供固定历史输入
身份下的完整程序联合证据；官方未知1B泛化仍需实际比赛或新独立请求
验证。
