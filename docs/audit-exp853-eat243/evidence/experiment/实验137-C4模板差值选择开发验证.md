# 实验137 C4模板差值选择开发验证

2026-10-09，Asia/Shanghai。分支`research/exp137-template-gap-selection`，起点`9172038`。正式基线exp131为68,201,104 B，SHA `aed8b929957a14cd5a2ae73bf94fedfd0cfaa86732ff79a7ee08a9e7afca064c`。开工`/dev/sdd`可用461G。

## 问题与固定范围

exp136十二场较小值方案改变247行，203行改善、44行恶化，总体accuracy差-0.006428 pp。少量恶化行的加权损失抵消了多数改善行；本轮检验模板与当前预测的相对差值能否作为低成本选择信号。选择C4与C2，复用十二场、真实端点解析和无损压缩，不增加回归模型容量。

固定使用93、105、136三个已查看窗口的完整exact、现有请求与七带权重。136由独立验证转为本轮开发数据。旧窗口重新运行exp131及冻结十二场探针，核对当前预测与exp127记录相同、十场raw与exp127命中输出相同。十二场相对十场的同规则对照用于说明新增5.27MB的作用。全部新输出放`build/exp137/`，生产源码、根入口、模型和正式包保持原身份。

## 候选族与选择

预测时输入为当前带bias预测`base`、十二场原始模板值`raw`、源端口类别。`base<=0`、`raw<0`或源类别不符时保持base。其余行须满足以下整数条件才使用raw。

```text
abs(raw - base) * 10000 <= cap_bps * base
```

固定上限为50、100、200、500、1000 bps，即0.5%、1%、2%、5%、10%。源类别固定all、arc、direct-Z三种；direct-Z按源端口以Z开头识别，arc为其余有效源。方向固定lower-only与either，lower-only额外要求`raw<base`，either允许双向替换。共30个候选，全部计算后固定选择，不增补阈值和特征。

主选择按三个开发窗口的最小accuracy差最大排序，然后按均值差最大、改变行更少、候选名称字典序排序。每次留一窗口时仅在其余两个窗口选择，训练最小收益不为正时选择原基线；报告三折留出差、均值、变更行和最终规则。全部数据此前已被查看，留窗结果只描述开发稳定性。

固定对照包括基线、十二场无门控raw覆写、十二场无门控较小值、十场同一最终规则。另报在base与十二场raw之间逐行按exact选较高评分的oracle上界，用于判断选择信号尚余空间。oracle只参与诊断，不进入候选预测。

## 指标、成本与停止

各窗口按原七带总体权重评分。三个窗口的主均值等权，分别报告各窗收益、直接Z/Arc分组、改变/改善/恶化行、false-finite、false-unreachable和zero-mismatch。自检覆盖相对差阈值恰好相等与越界、双向选择、模板缺失、基线零/负值与源类别。

下一轮独立验证的开发条件固定为最终规则三个窗口收益均大于0、平均至少+0.03 pp、三折留出均值至少+0.02 pp，且可达性及零延迟错配不高于基线。条件未过时结束本轮候选扩大，保留所有规则、原始数据与明确的单项收益，C4/C2方向继续保留。

精度明确提升而CPU增加的候选保留为后续优化对象；CPU明确下降而精度降低时保留加速部分并继续修复精度。当前分离探针的CPU只用于成本诊断。生产组合、精确输出等价的CPU优化、实际ELF及完整1M须单独预注册和验证。
