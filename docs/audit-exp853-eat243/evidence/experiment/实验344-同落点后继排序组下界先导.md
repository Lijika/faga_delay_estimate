# 实验344 同落点后继排序组下界先导

2026-10-17。基线为 exp335/exp334 冻结源码。仅构建观察探针，原搜索、
strict relax、出队、预算、parent、路径和默认程序保持。正式入口保持 exp335。

## 主假设与范围

同一 Net 落点的后继共享坐标、Line 与基础费用。若能用一个便宜的组排序
下界推迟整组的 q 和入队，可能省下终止前没有使用的工作。先统计该固定下界
能覆盖的保守省略量，再决定是否实现调度。理论推导保存于 Obsidian
`同落点后继的加权排序组下界.md`。

设当前落点的 residue 排序值为 H，后继 Arc 费用为 a，后继排序值为 h，
前提为 H <= a+h，h >= 0。权重 w 非负，原键为 g+a+floor(w*h/1000)。
取 A 为 w>=1000 时的最大 Arc，否则取最小 Arc。组下界为
g+max(minArc, floor(max(0,w*H-(w-1000)*A)/1000))。
这条关系用于包住当前排序键，其前提须由实际表与特例核验。

## 预先固定的先导

- 数据为已有 12,150 条带 exact 标签的搜索审计请求，以及 U-output 原序
  非重复 20k 前缀。两套都属于开发数据，前缀临时文本的第三列为 0，
  只用于复用路径探针的输入格式。
- 保留原始全部排序键。每个组核对下界不超过该组实际生成的最小键。
  整个查询结束后，以原队列所有 pop 的最大键 K 为观察阈值。
- 若组下界严格大于 K，该组的全部 q 与 push 计入保守省略量；另记录
  真实组最小键大于 K 的理想组省略量，以及组下界与真实最小键的间隔。
  stale pop 同样进入 K，避免把原物理队列的清空语义省略。
- 主指标为非重复 20k 上的保守省略 q/push 比例。至少 10% 且全部排序
  包含关系、搜索字段和路径检查通过，才为本固定下界实现整组延迟调度；
  低于 10% 时结束本构造扩大，保留其他后继表示方向。
- 每次探针单线程、RSS<=2,000,000,000 B、CPU及墙钟<=3600秒。带插桩
  时间只记录研究成本。100M与1B阶段成绩等待对应完整程序实测。

## 验证与证据

先运行整数关系 self-check，随后冻结源码、探针、输入、编译命令与基线。
12,150 条请求核对所有非 CPU 字段与原路径 SHA；20k 核对输出行数、
原序和路径费用下界。两套均核对完整文件身份、单线程、资源和分组计数。
这里的观察阈值不能直接作为在线停止条件；未来调度仍需单独证明父链、
stale 与 empty/budget 语义并做无插桩 Xeon 配对计时。

```sh
python3 validation/exp344_group_bound.py self-check
python3 validation/exp344_group_bound.py prepare
python3 validation/exp344_group_bound.py run
python3 validation/exp344_group_bound.py check
```

原始证据位于 `validation/results/exp344/`，私有源码和探针位于
`build/exp344/`。本轮开工 `/dev/sdd` 可用约395GiB，结束时补记，
清理按逐文件身份、可重建性和按名引用三项执行。
