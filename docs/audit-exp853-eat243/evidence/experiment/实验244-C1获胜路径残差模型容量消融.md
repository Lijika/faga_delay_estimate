# 实验244 C1 获胜路径残差模型容量消融

2026-10-12。exp242 的 41 维路径特征通过旧开发集五空间折验证。
本轮检验同一批数据与特征下，树数和深度能否继续改善折外预测。
exp239、exp243 的独立请求保持各自冻结协议，本轮使用 exp215/231/234
三窗 30,826 条已查看数据。

## 预注册

四臂固定为 128 树 depth5 的 reference、512 树 depth5 的 rounds、
128 树 depth7 的 depth，以及 512 树 depth7 的 combined。
reference 直接复用 exp242 已核验的五折模型及预测。其余臂保持相同
41 维、eta=0.1、max_bin=64、min_child_weight=10、lambda=10、
加权 L1 和随机种子，训练仍只用 P>0 行。

沿用五空间折、完整 pin 排除与校准 alpha 集合。每窗保留原人口权重，
配对 bootstrap 在窗和距离带内进行，10,000 次，seed2026101223。
唯一主候选为 combined，要求相对 reference 至少 +0.08 pp，
95% 区间下界大于零，且至少四折为正。两项单因素只用于解释增益。
任何单项结果均按原样记录，主候选未过门则结束本固定容量构造。

先核对 reference 的模型、alpha、逐行整数和分数。新模型导出 JSON，
独立逐树 float32 推理、分组、校准、评分和 bootstrap 复算必须通过。
本地使用既有 ML 环境与单线程 XGBoost，训练和 checker 各设 1,200 秒
执行上限。该轮只筛选精度潜力，新增容量的 C++ 推理、完整程序 CPU、
文件大小及全新请求单独验证。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp244_path_capacity.py freeze
# 冻结提交后
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp244_path_capacity.py run
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp244_evidence_check.py
```

## 结果

冻结提交 `f3b7db5`。全部臂五折校准 alpha 均为 1，reference 的逐行
预测与 exp242 保持相同。

| 臂 | accuracy | 对reference增益，pp | 95%区间，pp | 正收益折数 |
| --- | ---: | ---: | --- | ---: |
| 128 树 depth5 | 97.656548250% | 0 | 基准 | 基准 |
| 512 树 depth5 | 97.665018762% | +0.008470511 | [-0.001076070,0.018098976] | 4 |
| 128 树 depth7 | 97.672618254% | +0.016070004 | [0.006482388,0.025470261] | 5 |
| 512 树 depth7 | 97.668115688% | +0.011567438 | [-0.002265014,0.025294845] | 4 |

主候选低于 +0.08 pp 门，区间跨零，固定容量构造结束。depth 单项的
描述增益仍低于主门量级。后续继续采用已通过新请求门的 128 树 depth5，
把新增信息作为下一项研究变量。

训练与原始位核对 CPU 278.70 s、RSS 561,876,992 B；checker CPU
474.87 s、RSS 594,681,856 B，stderr 均为空。新模型逐树 JSON、
alpha、空间与 pin 划分、指标、窗与带内 bootstrap 独立复算通过。
未改变的 reference 复用 exp242 已通过证据。

统计解释检查覆盖 11/11 项，全部冻结臂及低收益项保留。区间以固定折模型
为条件，属于已查看数据的开发描述，后续未扩大到新请求和完整 CPU。
证据为 `validation/results/exp244-report.json`、`exp244-evidence-check.json`、
`exp244-predictions.csv` 及 `build/exp244/`。冻结时可用 461,200,998,400 B，
收尾为 460,526,964,736 B，`df -h /dev/sdd` 约 429 GiB。当前模型和
原始结果仍供复现，删除释放量 0 B。
