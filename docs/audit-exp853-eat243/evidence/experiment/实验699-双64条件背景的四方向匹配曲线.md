# 实验699 双64条件背景的四方向匹配曲线

2026-10-25，在exp698结果前条件登记，仅当其质量、容量、资源和
独立审计通过才执行。方向0沿用exp697的全部资产与证据，其余方向
保持exp698最终选择的每域64维因子，固定同一qsum分界和恢复顺序。

## 固定构造与指标

复用exp651方向1至3的构造单元、原D64残量T/V和构造542点缓存，
以旧整数背景减新整数背景更新残量，保留完整输入身份。每方向以
生产exp654的256曲线初始化，固定16常函数，仅240条更新六轮；
训练点44、留出商点49与56个留出源保持。此V已参与历史探索，
本轮属于开发诊断，新请求验证留待完整100M。

每方向比较A=原D64与生产曲线、Q=新背景与原曲线、C=新背景与匹配
曲线。方向0仅汇入exp697已有A/C统计，其Q来自当时exp694初始化，
不合并为统一四方向Q。保留矩形/物理域、近轴、内部、rx与源分组。
物理域在负方向排除零位移对应的重复符号槽。

四方向留出源物理域总体C/A归一化L1<=0.98，名义分提高>=0.01pp；
每方向总体、qx/qy近轴及每个rx组L1比<=1.02；全部源物理域总体
不退化。报告26源族bootstrap敏感性区间。通过名义门后仍须真实
地图冻结/匹配残差四格，保持S8/V8预算与监督隔离，再决定100M。

## 资产与容量

目录为pair-major的59904×480个uint8码。四向码本int16保持精确，
若全局max-min<=255，则按exp654方式无损恢复为uint8加共同origin；
两个格式表示同一函数，只采用较小的精确格式。Zstd-9实际压缩、
完整恢复SHA、逐方向回读与合并布局核验。容量使用四向实际因子、
本轮完整曲线压缩量、冻结近域和非资产字节以及1MB预留，严格<100MB。
实际静态ELF与在线工作集在后续部署验收，不能用预算值替代。

## 成本与停止条件

方向1至3串行，复用旧T/V真值来源，新增每方向T/V残量约1.337GB；
评分时由原D64加原残量重建truth，避免再保存两份大缓存。单线程
赋码、BLAS8线程背景计算。CPU<=3600秒、wall<=1800秒、
峰值进程RSS<=4GiB、AS<=8GiB、实际新增<=5GB。

检查全域原缓存身份、构造单元T/V一致、每轮目标非增、64条独立
赋码、标量整数背景、所有资产完整恢复及四向统计。质量、容量
或资源门失败停止本固定组合，分别记录其否定范围。
没有新增exact或完整估计程序运行；后续完整测试继续仅100M、1B。

本地/dev/sdd开工294GiB；远端启动需至少6GB可用。exp698正在运行，
本轮仅准备接续，不提前查看或选择其他方向的曲线结果。

独立审核由`validation/exp699_close_audit.py`执行。方向0复用exp697
已通过的完整评分；方向1至3重新从原D64整数背景、原残量标签和
序列化曲线计算全部V的三臂统计，核对物理/矩形域、近轴、rx、
源族区间和联合门。另做192条独立整数点积、合并资产回读与全部
冻结输入身份检查。训练损失复用已有逐轮及64条独立赋码证据，
完整估计程序运行次数保持零。
