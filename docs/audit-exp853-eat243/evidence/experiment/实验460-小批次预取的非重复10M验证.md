# 实验460 小批次预取的非重复10M验证

2026-10-18预登记。exp459固定五臂通过完整1M等价与资源检查。
本轮保持相同代码、32行批次和预取位置，全部五臂进入10M，
检验初始化摊销后的随机访存重叠收益。p/ph为普通页与大页标量，
b为普通页批次，f/fh为普通页与大页预取。f对b解释预取增益。

固定复用exp443非重复10M及exp457完整输出SHA、契约与同次输出
40k exact抽样，acc99.1523260694%，95%区间
[99.1140868108,99.1877221737]%。输出保持时新增exact与评分成本为0。
这些输入已查看，属于等价部署开发集。每次真实写出全部请求，
核实完整SHA、所有非时间计数、cache_hits=0、单线程与RSS<=2GB。

远端Xeon core3串行。各臂20k预热，顺序固定p/ph/b/f/fh、反序、正序，
三对完整程序CPU，配对t95、df2并加0.02秒舍入。相对对应标量p或ph
节省>=5%、CPU差95%区间上界<0的批次或预取臂进入100M。
其余固定配置保留证据并结束扩大。条件外推只作成本分析。
同架构八源之外的160源容量、逻辑/I端点、静态交付和1B另验。

复用exp459测量与分析脚本，新增文件只负责固定本轮数据和已编译二进制。
正式入口保持exp354，固定发布CPU基准保持exp323。本机/dev/sdd可用375GiB。

## 结果

完整10M三次CPU均值为p 4.240000秒、ph 4.490000秒、b 4.196667秒、
f 3.630000秒、fh 3.963333秒。f相对p节省14.3868%，配对差95%区间
[-0.630000,-0.590000]秒；f相对b节省13.5028%，区间
[-0.601009,-0.532324]秒。b单项节省1.0220%，fh相对ph的差区间跨零，
按本轮扩大条件保留f进入100M。

全部完整输出SHA为
`bc5f2e8844ffd78e2a242f246d145bd797cb17bef2e2851ea90d7329623739a5`，
变化0行，非时间计数保持，cache_hits=0。单线程，最高RSS
1,755,291,648字节，复用acc99.1523260694%及95%区间
[99.1140868108,99.1877221737]%。新增exact与评分CPU均为0。
已验证重复副本的清理释放49,897,500,672字节，逐项身份与重建命令见
validation/results/exp460/cleanup.json。原始计时和评分证据保留。
