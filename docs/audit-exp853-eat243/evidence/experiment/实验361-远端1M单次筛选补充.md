# 实验361 远端1M单次筛选补充

2026-10-17，在读取该候选Xeon计时前登记。20,000组随机夹具与sanitizer
通过，实际架构88,473,600个策略掩码逐项等价。正式源码保持exp354。

复用exp360的公开完整唯一1M、golden及combined输出身份。等待exp360全部
运行及检查结束后，固定核3串行运行候选20k预热一次、完整1M一次。
完整输出必须等于combined的已评分SHA，acc沿用99.0903196569%。
资源上限为单线程、2GB、3600秒，完整CPU计入初始化。

本次是低成本筛选，exp360三次均值作为同期参照，单次候选没有配对区间，
不宣称确认CPU收益。若完整CPU低于exp323三次均值，且初始化成本下降，
后续另登记配对复测；否则优先继续分析本项构造与搜索成本，暂缓10M。
本次最多两次估计器运行，契约或资源失败即停止。原始证据保存于
validation/results/exp361/xeon，数据输出保存于build/exp361/xeon。
