# 实验394 任意长线换向的整体距离表先导

2026-10-18，在查看新统计前登记。exp393的共享短连接约1.99MB，
显式展开约120.05GB。本轮改为检查整体长线距离查询，接续exp258建议中的
路径距离索引及真实费用摘要。正式入口为exp354，固定CPU基准为exp323。

主假设是L-only图的名义位移格`(10u,12v)`可以显著减少距离表的状态数，
把多次L换向和lane选择合成一次距离查询。它与exp392的同Z重复段不同，
允许骨干内任意L到L转接；固定端口状态仍完整保留。
名义图费用为真实Arc费，Gap暂为零。

固定两个有限域为`u=-14..14,v=-48..48`和
`u=-16..16,v=-50..50`，各从32个L源的原点求最短路径。
主报告域为`u=-12..12,v=-46..46`。
比较两域在报告域内的所有费用；相等仅支持有限域稳定性。
每个记录保存费用、父端口、跳数、方向掩码及prefix包围盒。
费用和父指针使用显式小端二进制，保留恢复真实路径的能力。

当候选路径的整个平移包围盒均为真实SRB、x与y各自单调时，
每一步落点与步行区间都有效，Gap Line沿轴相加后等于两端前缀差，
无Block费用。因此可以通过表费用、包围盒资格和两次Line前缀差求整段费用。
该资格只证明所存路径的真实费用；总体exact、完整查询组合与泛化另验。
缺格前缀和用于检查完整矩形，避免漏掉Inst中的其他缺格。

复用exp207同SHA的256条定向开发exact路径。
提取所有连续的`L源Net + Arc到L源`段，保存端点、原始费用、
名义位移和原始跳数。用名义最短候选逐跳真实重放，报告端点/费用、
原路径覆盖、整段求值资格与费用相等比例。
独立核验Arc费用、全部表记录的父指针递推和元数据，
用两个固定L源的Python Dijkstra复算小域完整费用。
普通及ASan/UBSan小域Dijkstra与Bellman-Ford交叉验证，
破坏父费用和方向掩码的负对照应失败。

固定主指标为两域记录数、表尺寸、有限费用范围、报告域稳定行数、
真实子路径匹配与费用、免逐跳求值资格和跳数。
共享核心距离及父链格式在总文件<=100MB、两域报告费用全部相同、
原子路径全部重放通过、且有效同端点的整段资格至少占核心段一半时，
保留目标导向组合原型资格。门未过只调整这一表示及资格条件，
已有明确收益方法继续保留。

单次原型CPU<=120秒、地址空间<=2GB，普通及sanitizer的小域单列。
局部耗时用于资源诊断，完整未知请求CPU尚无新成绩。
本轮不生成全图exact标签，不训练模型，不执行估计程序1M。
若前提通过，下一项才冻结首尾短接入、内部短桥和核心查询的选择规则。
证据放validation/results/exp394，私有产物放build/exp394。
开工/dev/sdd约386GiB可用，收尾报告清理量。

小域的两个完整源Python Dijkstra通过，父费用及方向修改负对照均被拒绝。
报告域2,380,800条费用全部相同，有限域稳定性通过。
