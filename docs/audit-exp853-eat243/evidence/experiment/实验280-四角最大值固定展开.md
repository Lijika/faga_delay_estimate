# 实验280 四角最大值固定展开

2026-10-16。性能基线为exp277冻结私有ELF，精度基准为exp258。
本轮使用私有构建目录，先完成局部原型与资源测量。

## 预注册

主假设是窄表四角分支中的循环、have更新与数据相关分支存在可消除成本。
原O2汇编仍有0至4的循环和INF、have、大小比较分支。本轮仅将该分支
展开为四个有限值和两层std::max，缺席角映射INT64_MIN。单槽证书、
宽表分支、fallback、整数舍入、Line、非负截断、队列与搜索预算保持。
当前四角为固定格式，有限值严格大于INT64_MIN，证明见vault的
四角有限最大值的缺席哨兵展开笔记。实现采用标准C++17，编译参数沿用
exp277，不添加CPU专属指令。

独立算术自检覆盖全部6^4槽组合的8组线性项与100,000组固定种子请求，
另运行ASan与UBSan。生产局部检查复用固定128条开发请求、原夹具六个
边界自检、768组cap和80组weight，要求搜索字段及完整路径保持；
weight含负值、0、10、17和INT_MAX。随后配对12,320条exact开发请求，
要求总体与七组acc、平均相对误差及逐条整数输出相同，变化、改善、
变差行数均为0。任何差异结束性能验证。

局部与精度通过后，在Xeon core3同机串行测两种原序20k；
每臂预热一次，AB/BA/AB三对，CPU为user+sys。统计采用df2配对95% t
区间并加入±0.02秒舍入界。两分布点省至少1%，且舍入后区间上界小于0
时扩大。固定三对结束测量，跨零记待定，明确变慢记退化。

扩大时完成35,702条搜索审计、109,505,958次原成功relax求值、
七组CLI和128条Arc费用变体；同一ELF在AMD执行相同20k三对。
在Xeon运行两次完整独特U-output 1M、一次公开golden完整1M配对acc、
repeated 1M三对。逐行检查端点原序、三字段、规范整数delay、精确EOF、
完整SHA及多次一致；资源要求单线程、RSS≤2,000,000,000字节、
每次≤3600秒、ELF<100,000,000字节。

已查看样本属于开发集，纯等价修改复用原exact标签。其他FPGA架构、
隐藏集及完整独特100M/1B另验。远程仅在~/lhjwork/eda2026内操作。
开工本地可用414GiB，收尾记录两机空间与实际清理量。

## 结果

已完成预注册的算术、局部路径、exact 和 Xeon 20k 检查。候选 ELF
大小为 94,083,728 字节，SHA-256 为
`4e06f004dbc20b56c21ec6eecd054fde02f2902ce40222fa7ec6f82bb2836b86`；
exp277 基线 SHA-256 为
`1fa6c6acde6c0acd478f3fe82ce60db1a9771ca18f0b88381f789c3203627752`。
算术普通版与 ASan/UBSan 各通过 110,368 个组合。局部 128、caps 768、
weights 80 的字段和完整路径均相同。

exact 共 12,320 条。总体 baseline/candidate acc 均为
99.30225286909072%，平均相对误差均为 0.0017840440564241811；
`changed_rows`、`improved_rows`、`worsened_rows` 均为 0。七个距离组
（0、1-12、13-24、25-50、51-100、101-300、301+）的 acc、平均相对
误差和逐条整数输出全部保持，acc 退化未发现。独立 evidence checker
还拒绝了对 `changed_rows`、`worsened_rows`、`candidate_accuracy_pp`
的篡改。

Xeon core3 同机串行，warm-up 一次后按 AB/BA/AB 完成三对。所有 16 次
输出行数、端点顺序、整数 delay、EOF 和 SHA 均通过，单线程，最大 RSS
为 1,699,676,160 字节。

- `output`：baseline 均值 6.9333333333 秒，candidate 均值 7.0200000000
  秒，配对差 `[0.09, 0.08, 0.09]`，均值 `+0.0866666667` 秒；
 95% 区间 `[+0.0723244909,+0.1010088424]`，加入时间舍入后为
  `[+0.0523244909,+0.1210088424]`，saved fraction `-1.25%`。
- `role`：baseline 均值 7.1866666667 秒，candidate 均值 7.2600000000
  秒，配对差 `[0.07, 0.08, 0.07]`，均值 `+0.0733333333` 秒；
  95% 区间 `[+0.0589911576,+0.0876755091]`，加入时间舍入后为
  `[+0.0389911576,+0.1076755091]`，saved fraction `-1.0204%`。

两个 profile 的上界均为正，扩大门槛为 false，未运行扩大审计、AMD
和完整 1M。候选保留为负性能证据，不进入正式 `src/`、`./estimate`
或 `subm/`。复核文件为 `validation/results/exp280/evidence-check.json`。

空间记录：本地冻结时可用 443,690,467,328 字节，收尾为
443,573,043,200 字节；远端 timing 开始为 205,076,910,080 字节，
收尾为 205,073,436,672 字节。exp280 证据和约 199 MB 构建产物继续
保留，按三条件核对后本轮清理 0 字节。

局限：仅测 exp258 两类原序 20k，exact 属于开发集；官方隐藏集、其他
FPGA 架构、完整独特 100M/1B 未验证。后续候选必须重新预注册，并在
先导阶段再次检查总体及七组 acc。
