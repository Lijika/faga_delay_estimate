# 实验167 名义显式最优路径目录

2026-10-10，分支`research/exp167-explicit-path-directory`，起点`cd9bb34`。
正式exp131和exp161精确组件保持。开工`/dev/sdd`可用454G。

## 假设与范围

exp166固定四跳宏结构门未过；本轮转向首步目录的显式路径基线。
复用exp26商图、四角势和费用预算Dijkstra，在名义无Gap无限图中，
固定`ZSEA[0]→ZSEA[0]`、dy0、dx=-97..97、C1200。
完整性盒沿用[-97,97]×[-116,116]，2752折叠Arc最小48 ps。
预算缺项记unknown，每个有限根保存一条完整最优路径。

按原距离标签反向选择最小Z索引的最优前驱，正费用使预算内≤25跳。
逐步核对source-prefix距离、Arc费用、二维位移、终点与剩余费用。
记录选中后缀键、first-step run数，统计限所选路径。
后继全集、首步集合RLE优化与Pareto包络留给独立窄候选。

## 编码与主门

prototype在当前little-endian平台采用16 B头、195条16 B根记录及uint16动作码。
根含dx、cost、offset、length与四个int16 bbox界；cost65535为预算unknown。
动作码为`p*160+q`，≤25599。实际字节数与完整恢复逐项核验。
总目录与路径证书≤128 KiB、全部声明有限根及恢复零不一致，才扩大此表示。
只测单端口195根，31,798,896 B余量能容纳的全端口规模另测。

## 真实几何诊断

固定sx∈{30,60,72,74,90}、sy∈{48,49,50,260,268,300}，共5850平移项。
记录预算缺项、端点不存在、无效Net、完整重放但终点偏离、合法吻合。
逐hop使用真实resolver，Block变位允许重放，最后须回到请求真实终点。
完整合法且终点吻合的费用给U。

固定dx∈{-60,-40,-20,-10,-2,-1,0,1,2,10,20,40,60}的可用真实端点，
使用既有span exact Router，无landmark/cache。核对U≥exact、报告U-exact。
选择提前固定，该几何网格作开发诊断；其U=exact比例保留描述范围。
本轮没有生产trigger、精度改动或配对CPU结论；离线生成与重放成本单列。
