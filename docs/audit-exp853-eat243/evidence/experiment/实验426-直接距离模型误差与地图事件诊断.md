# 实验426 直接距离模型误差与地图事件诊断

2026-10-18预登记。exp420至424的两源预测保持，已有20k exact评分
约99.08%，SEA分组余量很小。本轮用已查看的exp420开发样本分析误差
与地图关系，决定下一类精度工作。该数据明确归入开发集。

不训练或选择修正参数。固定按源端口、Manhattan距离≤32/33至100/
101至300/>300、横跨Block列带、端点靠近Block竖边和横边各统计
样本数、官方评分损失份额、欠估比例和平均绝对误差。
列带来自实际Block矩形，横跨要求端点位于左右两侧；
近边定义端点与Block边界的距离≤12且另一轴在扩张12的矩形范围内。
分别给出重叠条件与互斥源/距离分组，不能把重叠组的份额相加。

逐行对照exp323与当前模型，保留损失最大的前20条和已知开发反例。
总体误差份额只作下一研究方向的排序证据。单纯空间相关性不足以
确认因果，内部Block或Line的因果解释仍需具体真实路径证据。
本轮没有新的性能或独立精度成绩。

## 结果

20k样本当前模型acc 99.079815%，MAE 5.24025 ps，全部评分损失来自
欠估。此观察支持单侧误差归因，尚不证明模型是全图下界。

| 预定分组 | 行数 | 当前acc | exp323 acc | 总损失份额 |
| --- | ---: | ---: | ---: | ---: |
| 距离≤32 | 605 | 98.191290% | 99.168867% | 5.95% |
| 距离33至100 | 3,667 | 97.516760% | 99.193673% | 49.48% |
| 距离101至300 | 10,341 | 99.373798% | 99.198119% | 35.19% |
| 距离>300 | 5,387 | 99.679256% | 98.981650% | 9.39% |
| 横跨Block列带 | 6,735 | 98.255260% | 98.878450% | 63.85% |
| 端点靠近Block竖边 | 7,146 | 98.308779% | 98.896399% | 65.67% |
| 端点靠近Block横边 | 5,119 | 98.380267% | 98.886567% | 45.05% |
| 上述三个地图事件之外 | 8,902 | 99.784747% | 99.376041% | 10.41% |

距离组互斥，三个地图事件组允许重叠。距离33至100的18.335%样本
贡献约一半损失；单看最短距离会遗漏主要损失区域。
地图事件外的44.51%样本MAE仅1.09863 ps。
这为研究内部Block事件算子提供排序依据，完整名义距离在远距离
和低事件区域已表现较好。下一项需要对高损失行恢复真实路径，
区分Block跨越、绕行及Line重复收费，才能构造有因果依据的修正。

没有拟合补偿量或用本分组筛选正式候选。前20条大误差与逐组统计
保留在`validation/results/exp426/report.json`。
