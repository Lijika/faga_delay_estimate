# 实验636 端点相位条件主效应的近轴残量消融

Gemini4第6.3节启发先分离低成本主效应，再看剩余耦合；exp634方向0的
pair×轴态×距离桶项在分离网格下降1.402028%，exp635在qx短轴上下降

## 假设与表示

固定方向0、D64、Q4、全有向pair、近轴远域`qx∈{0,1}, qy≥4`和三个
长轴桶`[4,16),[16,32),[32,46)`。每cell先拟合pair×cell的int8加权
L1中位数，再分别拟合source×phase×cell、target×phase×cell残量主效应；
另测source后接target的一次顺序坐标更新。Q4及完整端点pair保持，其他
域和forced样本不在本轮建模。

相较全局`phase×cell`，端点相位表把共享效应拆到source或target身份。
方向0的source/target数分别208/288；pair顺序固定为
`pair=source*288+target`。每方向pair表为359,424B，端点表合计357,120B；
四方向全表上限2,866,176B，低于exp622/T记录的8,952,808B余量。在线
查询预计只在覆盖域多读1–2项；本实验不推断其CPU收益。

## 固定数据与门槛

训练qy固定为`{9,13,18,25,34,43}`，分离验证qy为
`{11,15,22,29,37,45}`；两组均对qx=0/1完整配对。每桶各有两个训练和
两个验证商点。核对exp633–635协议后，这些商点均未被前轮使用。数据仍是
同一208源认证名义场的商网格分离，不是新请求或跨架构验证。

保留权重`1/(128+125*qx+125*qy)`。先以pair×cell加权中位数建立共同底项，
在扣除底项后拟合source项、target项；组合臂固定为source再target。
所有表值裁剪至int8，组合以int16计。报告未修正、pair-only、source-only、
target-only和组合臂的训练/验证总L1、六cell损失、饱和值、表大小及CPU/
wall/RSS；随机小矩阵枚举检查加权中位数与索引。

任一端点臂继续的质量门：训练L1不增、验证总L1相对未修正至少下降2%、
相对pair-only再下降至少0.5%、任何验证cell退化不超过1%，且无int8饱和。
若均不通过，不扩到其他方向、不评分完整1M、不接入部署。通过仅允许另行
预登记完整1M精度/CPU检验，不能直接接入。测试未参与本轮拟合的商点，
但完整认证场有历史使用，因此不称新请求验证。

全部拟合仅在r9 `research/exp636`运行；CPU预算500秒、wall预算700秒、
地址空间8GiB、BLAS四线程，新增持久结果小于32MB。启动时远端可用空间
约17GB；不生成1B输出。
