## 完整域与唯一候选

复用exp499/500认证字段，208源、288目标、59,904端口对、
264,960几何槽，共15,872,163,840个整数残差R。
原残差范围[-67,944]与原趋势H逐点保持；D=H+R>=0。
固定q=200，允许`q*abs(P-D)<=D`，D=0保持P=0。
所有原字段、端口双射、长度、原始与压缩SHA先核对。

变量次序为`direction,target_family,rx,qx,ry,(qy,target_lane)`，
分支数4、36、10、12、12、368。把最后两个轴作为一个完整
后续向量，按qy优先、lane次序排列。每条向量提出原第0项
a=R(qy=0,lane=0)，第0分支固定为0，其他367项保留整数许可。

```text
delta_i = R_i - a
b_i = floor((H_i + R_i)/200)
low_i  = delta_i - b_i
high_i = delta_i + b_i
```

若全部许可含0，直接用常数a。否则在固定候选索引中查找已有
完整向量组。候选组保留所有已加入上下文的逐项low最大值和
high最小值，全部交集非空才允许加入。加入后把原代表逐项夹到
新交集，组编号和第0分支保持。已有父引用继续有效；父基值差
始终取原锚点的精确值。保存模型只保留最终代表，许可用于离线。

固定搜索规则如下。取向量位置1、7、32、360，扣a后分别用
宽32、32、64、64分桶，先统一加2048，四个签名相位依次为
0、8、16、24。每桶只保留最近新建的8组；合并不刷新桶。
按相位、桶内新到旧顺序选择首个完整兼容组，每向量最多32次
兼容尝试，重复候选照常计数。无候选则新建组。
先检查8个固定坐标再检查全部367项，精确兼容条件保持。
本轮结果返回后不改变相位、位宽、顺序或池大小。

前五层复用exp519精确基值规范化和共享实现，末层记录为736B，
存367个int16及2B零填充。uint32引用仍使用高3位保存层号加一，
低29位保存编号加一；根8B。末层布局、维数和magic写入独立模型。
完整计入根、节点、偏移、mapping和压缩资产，离线索引及许可
内存单列。新原型无生产源码调用者。
