# 实验716 共享资产的整查询EVEX与VNNI

2026-10-25，在读取新ISA候选性能前登记。基线为完成1B的exp708/M。
接合报告第9章，exp714的固定三阶段布局继续停止，原批8和56B保持。
exp715的相邻重复机制门失败，独立字串与DP审计先完成再启动本轮。

## 作用与范围

本轮属于次级支撑，检验整条worker的代码生成与VNNI是否取得明确CPU收益。
exp703旧版本点积采样约3.58%，因此单个点积的提速不足以解释100秒目标；
结构主模型和固定连接片段共享继续保持研究优先级。

固定V256与V512两臂。signed点积使用a XOR 0x80，
再减128乘右侧块之和。右侧近远共298560个64维块，int16和表597120B，
启动生成。每块原double乘左右尺度、八块顺序、两次舍入和树累加保持。
compile分别使用最小AVX2、AVX512F/BW/VL/VNNI开关与256/512宽度偏好，
继续generic tune、关闭fast-math/FMA/LTO。

三条worker共享单个恢复缓冲与右块和表，嵌入资产和Architecture只链接
一次。入口以x86-64编译，在main内检查全部所需能力后选择固定候选；
能力不足时走SSE2。实验入口报告实际路径，CLI仍为-in/-out。
worker对象不得含.init_array、.ctors或动态全局初始化符号。
SSE2入口与构造路径检查、弱CPU特征屏蔽分别记录；静态检查不能代替仿真。
本轮机器为6226R，6242R专用性能仍需该实机验收。

## 组件与完整程序验收

先验证165600组整数极值与非对齐案例、全部298560个真实右因子块，
以及239616见证的四折逐字段和浮点位模式，补99200个边界案例。
组件在审计宏下运行，正式性能binary保持生产宏。
数字核、准备状态、分派前启动及最终文件各自核验。

完整性能复用exp685全端口非重复100M与冻结输出身份。
固定CPU8、同机串行，A/V256/V512各一次完整100M预热；
随后六轮，顺序AVW、WVA、VAW、WAV、AWV、VWA，其中V/W为两候选。
逐轮配对A减候选，六对t区间乘3.163381449748624，
两比较共同95%覆盖。每个候选需均值节省至少0.5秒/100M、
区间下界大于0；通过者取平均CPU最小的一臂。

全部输出SHA等于已保留参考，精度复用1916928条exact，新增标签0。
资源门为单线程、查询分配0、RSS不超过300000000B、CPU小于100秒、
wall不超过3600秒、静态自包含单ELF严格小于100000000B。
过门后及时形成阶段版并完整非重复全端口1B，复用相同输出的3833856
条exact评分。未过门停止当前编译配置、块和布局与ISA组合，保留数学等价。

所有新增二进制与对象处于`research/exp716`，exp715结束后串行构建、
组件与完整计时。每份重复输出在完整SHA相同后逐项删除并记录重建。
本机开工`/dev/sdd`可用278GiB，远端空间由freeze与report记录。

## 结果

极值165600组、真实因子块298560组、239616条见证的四折trace和99200
边界案例全部相同。三worker共享69303616B恢复数组与597120B块和。
三个静态ELF均为93673048B，对象启动段与动态初始化符号检查通过。

完成21次完整100M，六轮正式均值如下。区间为两比较共同95%区间，
节省按同轮A减候选计算。

| worker | CPU均值秒 | 节省秒 | 节省区间秒 |
| --- | ---: | ---: | --- |
| A，exp708/M | 21.716685333 | 0 | 基线 |
| V，EVEX256 | 21.353928500 | 0.362756833 | [0.309236160, 0.416277507] |
| W，VNNI512 | 24.091149833 | -2.374464500 | [-2.481197234, -2.267731766] |

V的区间为正、点估计低于0.5秒门；W变慢。保持A，当前固定ISA配置
结束扩大，完整1B新增0次。数学等价、其他布局及目标6242R仍分别保留
研究资格。整worker代码生成和宽度同时改变，本轮没有单独归因频率。

21份输出均为4013564765B，SHA等于冻结参考
`96879a84252afb9cf6c9d27b88d7a6987d197dfda6cf825142868c79aadc2553`。
单线程、不可达0、查询分配0；A/V/W峰值RSS分别为206450688、
207691776、207429632B。复用1916928条exact，Acc变化0、新增标签0。
100M输入与既有输出身份保持，本轮支持数值等价和该机器性能结论。

`python3 validation/exp716_audit.py`从逐次run、输出身份、cleanup记录
独立重算全部统计和门。报告SHA为
`8dcb2e81b647de40ffb326e09d2a80b71ab57c551567b84a291ee36906ac231f`。
审计复用删除前的完整SHA记录，已删除输出没有二次重新读取。
generic入口完整反汇编、弱CPU特征屏蔽和6242R实机尚未完成，本轮
候选未进入发布，相关安全检查仍是未来发布的必要条件。
