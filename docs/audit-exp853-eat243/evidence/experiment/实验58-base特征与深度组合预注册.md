# 实验58 base 特征与模型深度组合预注册

日期：2026-09-25。固定基线为实验29 `./estimate`，正式入口和交付包保持不变。
本轮承接实验56的 d6/d8 结论，验证实验41的 `base` 三列与容量轴是否可加。

## 冻结候选

训练池、标签目标、语料带权重、seed `20260919`、`reg:absoluteerror`、`tree_method=hist`、
64 棵树和单线程均固定。输入特征为实验41的 44 个生产特征加上架构可直接计算的
`base`、`base-fast`、`base/max(fast,1)` 三列；候选只改变 `max_depth`：

- `base-d4`：47 维、depth 4，重训 control；
- `base-d6`：47 维、depth 6、64 棵树；
- `base-d8`：47 维、depth 8、64 棵树。

实验56的 d6/d8 结果只作单项参考，不在本轮新窗口上调深度、树数、阈值或偏移。

## 新数据与标签

使用同一确定性 affine unique 生成器的 `[16M,18M)` 窗口，排除公开输入、训练池、实验24、
31、40、41、43、46、48、51、52、56、57的完整端点键；固定排除集命中即停止且不替换。
每个距离带最多 1024 行，exact 标签来自身份固定的 `query_profile_exp18b --pdb-only`，
候选预测不参与抽样。`base` 值由实验41私有 `estimate-base` 只读计算，`fast` 由实验29
`-residual off` 重新计算并逐行对齐。

## 指标与门槛

主指标为按新窗口原始距离带份额加权 accuracy，辅以 MAPE、分带、可达性和输出契约。
使用七带 paired bootstrap 10000 次、seed `20260925`。每个候选相对实验29须有点增益至少
`+0.03 pp`、95% 区间下界大于 0、false finite 不增加；同时报告相对 `base-d4` 的区间。
若组合收益不足两项单独收益之和的 70%，保留更简单候选并关闭组合叙事。

精度通过后先测 10 对同一 1M unique 输入的单进程 CPU/RSS，新增 CPU 预算为
`96×accuracy_gain` 秒。未获得用户确认前不做五次 1B 验收。

## 复现与停止

请求阶段和采样阶段先写入 `validation/results/exp58-*`，模型、预测和原始标签放在
`build/exp58/`。新切片下 pooled 下界不为正、组合非加性、负 exact 可达性恶化或资源
超预算时关闭本方向，实验29继续作为正式版本。
