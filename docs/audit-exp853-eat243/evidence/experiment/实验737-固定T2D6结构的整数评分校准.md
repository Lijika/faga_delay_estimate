# 实验737 固定T2D6结构的整数评分校准

2026-10-26预登记，接续报告4.1、4.2节。复用exp719的48个source-pin
折外模型、原百万开发缓存和当前曲线背景，V8保持。检验固定树结构能否
通过真实整数评分校准增加精度，在线树数、特征和叶读取数保持。

固定两轮坐标更新，每轮依次校准两棵树。每叶在外层训练集支持至少64行
时，从整数偏移[-8,8]枚举完整部署输出的官方评分；选择训练损失最小者，
平局优先0、再较小绝对值、再负值。每次更新将整数偏移加入原叶值。
训练人口按当前缓存等权，官方损失内已有相对分母，不另乘1/g。
V请求不参与校准，模型结构和任何阈值均不改变。

严格复用source-pin三折，校准只用训练折。两轮数、支持数、范围预先固定，
不根据测试折选择。所有训练更新须不降低该训练叶的最终整数评分，
导出模型重算raw及整数链；与冻结折外预测在非V区域先逐行核对。
保存各叶支持数、所选偏移及训练损失变化。

主门为折外Acc提高至少0.02pp、源族95%区间下界>0、三折均正，
方向/距离/近轴组下降不超过0.05pp。通过后才重训最终叶值并安排新100M；
失败限定这组支持数、±8两轮加性校准和T2D6结构。更换表示后可独立重开。
本轮没有完整estimate规模运行和新增exact，历史开发集不作最终未知分布证明。

## 结果

48个模型的两轮叶值更新完成训练折隔离、导出raw与整数重算。
历史折外Acc为98.649029680860%，比冻结T2D6提高0.009262785553pp，
源族95%区间[0.008614464857787064, 0.009883970044046831]pp，改变247956行。
低于0.02pp预登记门，停止该两轮±8配置；线上实现、新请求和完整CPU未触发。
该证据保留真实评分校准的小幅收益，未否定新表示后的校准。
