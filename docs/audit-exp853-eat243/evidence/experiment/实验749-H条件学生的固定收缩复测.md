# 实验749 H条件学生的固定收缩复测

2026-10-27预登记。exp748的C8/P8整体分别下降0.100480369和
0.099954311pp，训练H精度约88.2%。该配置采用8棵depth6与学习率0.1，
exp719已经验证的少树尺度对应8棵学习率0.3。本轮固定改为0.3，
复用exp748的全部数据、source-pin三折、seed20261027748、权重、
树深、特征、直接替换目标及开发门，检验欠拟合解释。

常量残差被每步精确拟合且初始预测为零时，剩余比例为
`(1-eta)**T`。8棵0.1和0.3分别得到0.43046721和0.05764801。
该特例仅用于预设尺度，实际MAE贪心训练结果由折外评分决定。
理论依据复用Obsidian《同叶值预算的对称树深度与收缩边界》。

本轮只进行一次固定修正。开发总体增益至少0.02pp、三折各自正收益、
两比较同时源族95%下界为正，距离、方向、近轴组下降至多0.03pp；
P8相对C8整体至少提高0.01pp才承担三次背景求值。原生叶编号、
JSON原序raw、最终整数逐行一致，非H输出保持冻结T2D6/V8。
成功后立即拟合最终模型、构建完整候选并进入新非重复100M；
完整规模协议沿用exp748，100M联合门通过后及时阶段接入并测完整1B。
完整结果满足最终Acc>99%及赛题约束后才形成最终交付结论。

计算仍在r9的research/exp744私有目录，产物使用build/exp749与
validation/results/exp749。离线CPU/wall各300秒、地址空间8GB。
复用exp748驱动，仅把学习率提为常量，原驱动保存在
validation/results/exp748/driver-original.py。复用exp719保存的
CatBoost1.2.8接口帮助；新驱动自身与依赖一并登记身份。
本地开始可用273GiB，远端35.44GB。本轮未生成大体积完整输出。
