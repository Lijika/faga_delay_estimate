## 预注册

四臂固定为 formal（正式 exp131）、reference（exp232 的 19 维模型）、
history（exp234 的 32 维模型）和 combined（history 加 exp235 缓存）。
复用 exp234 的 12,324 条标签；模型、alpha、上界生成器和缓存容量全部固定。
32 维输入复用 selector 已计算的 float32 字段，新增比例仍按 double
计算后转 float32。树阈值用精确十六进制 float，逐树 float 累加和整数
修正规则沿用 exp232。零与不可达保持已有输出语义。

本地先验证两候选完整程序与 exp234 离线整数逐字节等价；逐位核对
32 维特征拼接、树输出、全部分裂阈值及相邻 float32、半整数取整。
14 条边界输入、bias0、endpoint off/source、修改架构和静态 ELF 分别检查。
combined 与 history 的全部检查输出必须相同，任何差异即停止。
通用 C++17/O2，最终 ELF 小于 100,000,000 B。

完整 1M 使用 public、unique、repeated 三种既有输入。每种先按四臂顺序
各预热一次，随后固定三轮逆序/正序/逆序；每臂每轮各运行一次，成组配对。
远程为 `r9r4900:/home/lhj/lhjwork/eda2026`，Herdr `w1:p2`、core3，
所有计时串行，传输在计时外进行。每次核对端点顺序、行数、恰好三字段、
整数 delay、精确 EOF、完整 SHA 和多次一致性。单线程、RSS<=2 GB、
CPU/wall<=3600 s。每臂各做一次 cache miss 诊断，记录初始化敏感的 repeated。

预先固定三项比较。

- history 对 reference 使用 exp234 的配对精度增量和区间。
- combined 对 history 要求预测逐字节相同；public 和 unique 的完整 CPU
  点节省至少 1%，配对 t(df=2) 95% 区间上界低于零。
- combined 对 formal 使用同一 exp234 样本重算整套精度增量，七带
  10,000 次配对 bootstrap，seed2026101214。全部标签和输出已查看，
  本次固定候选的配对复算承担组合评估；本轮继续冻结模型。

精度比较的综合门为点值至少 +0.01，保守下界大于零，public/unique 均须
通过；repeated 的 CPU 差区间下界须不大于零。下界使用精度区间下端点与
CPU 区间上端点，继承各单侧 2.5% 与并集界的条件解释。对 formal 的组合
增量另有边界检查，较大的初始化和未命中计算量可能使整套综合门失败，
届时保留单项进展并按实测成本继续研究。

综合换算限于时间分大于零、1B 约 1M cache miss、命中热路径增量可忽略
且精度可迁移的情形。各比较区间对应单项检验；本轮和历史自适应研究的
所有结论联合覆盖率另有多重选择问题。平台 1B、隐藏集和跨架构继续待验。
本轮通过完整 1M 后再决定正式接入，不据组件节省比例外推平台成本。
