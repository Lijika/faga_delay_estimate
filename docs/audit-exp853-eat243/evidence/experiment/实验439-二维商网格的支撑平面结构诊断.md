# 实验439 二维商网格的支撑平面结构诊断

2026-10-18预登记。exp436精确恢复全部两源距离，固定横纵分区产生
2,919,218个共享节点，条件全源RAM约3.04GB，容量条件未通过。
本轮先检查斜向分界是否适合更少的仿射函数，暂不构造新的查询器。

固定SEA0、LE0原场及exp436的象限、10x12余数和完整窗口。
每个目标端口得到最多15x49的二维商网格。逐个2x2小格检查混合差为零，
将其仿射面去重。每个候选平面在整张有限网格逐项比较，
分别保留处处不超过原距离的下支撑面与处处不小于原距离的上支撑面。
下支撑面的max及上支撑面的min分别给出有限网格包络，
统计取等覆盖、完整恢复的网格数、面数和混合差非零比例。

主假设是正交分区节点较多主要来自少量斜向面边界。
若至少90%的全部值由一种全局包络精确覆盖，并且平均所需面数<=8，
再研究包络加有限例外的表示。未达到时保留结构结果，
区域门控的XADD与其他表示仍可独立判断。
先做仿射、max两平面、min两平面及混合差的可执行自检；
实际原场的每个支撑断言和覆盖均逐值核对。

这项诊断不产生完整请求精度或CPU成绩，不把名义支撑面当成真实图下界。
构造及穷尽检查的CPU、RSS单列。原场和正式算法保持。

## 结果

每源76,800张网格、53,545,600个含零轴重复的值全部检查。
SEA/LE的混合差非零比例为6.35370%/6.07567%，候选平面平均10.4877/10.4430个。
全域下支撑覆盖25.37261%/31.67540%，上支撑覆盖1.01456%/2.57064%。
全局包络扩大条件未通过。两源分析CPU1.768499和1.794331秒，峰值RSS216,973,312 B。

追加独立曲率检查显示，SEA/LE分别有73,802/72,569张完整网格同时存在
正负轴向二阶差分。因此对这些网格，任何全局max仿射表示和全局min仿射表示
均有反例；这一结论不依赖本轮候选平面是否完备。反例三点保存于curvature.json。
区域门控及加法子程序仍有研究空间，exp440进一步测仿射归一化共享。
