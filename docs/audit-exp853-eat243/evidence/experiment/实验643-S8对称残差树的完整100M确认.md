# 实验643 S8对称残差树的完整100M确认

2026-10-24，在查看本轮100M输出与计时前登记。冻结exp640/S8，
A为exp641正式阶段版对应的exp622/T。本轮保持模型和全部推理路径。

## 假设与扩大理由

exp642全新源pin隔离10M通过完整输入、输出、标签及联合门。
A/S8平均CPU为2.576440083/2.290061083秒，配对节省0.286379秒，
97.5%区间为[0.278387442,0.294370558]。分层Acc差为-0.019438498pp，
联合分筛选点值0.223098368、保守95%下界0.214363292。
这些数据支持扩大规模，最终Acc严格大于99%的目标仍未达到。

主要机制是用固定层比较取代树内逐层地址依赖。解析、背景点积、访存与
输出仍占完整程序成本，S8没有改变这些部分。10M差乘10预测100M约节省
2.86秒，仅作成本假设；完整运行含一次初始化，实际规模收益需本轮验证。

## 输入、日程与判定

复用exp580完整非重复100M及239,616条分层exact标签，覆盖59,904端口对。
这批规模样本已参与历史比较；独立泛化证据来自exp642新10M。
核对完整输入SHA、已验证唯一性报告、标签身份及各pair人口数。
所有CPU和精度使用同次完整程序输出；相同SHA的重复输出复用评分。

A/S8各预热一次，随后固定6轮AB/BA交错，共14次完整100M，串行执行。
预热输出逐行检查原文端点、顺序、3字段、整数delay、行数与精确EOF，
各臂其余六次完整SHA必须一致。A的SHA另须等于exp622/T既有100M证据。
静态ELF身份沿用exp642，运行要求单线程、RSS≤2GB、CPU≤3600秒、
零查询分配。训练和标签计算已经完成，计时期间停止其他重负载。

精度沿用exp642的pair人口加权、26源族bootstrap和分层SRS方差区间外包，
seed=20261024643，9,999次bootstrap，报告97.5%区间。
CPU使用6个配对差的97.5%双侧t区间。联合点值与保守95%下界分别为
`0.8*Acc差+CPU节省*10/120`与两个分量下界的同式相加。
要求点值≥0.005且下界>0。质量门保持Acc差≥-0.05pp、
精度区间下界≥-0.08pp、distance与near_axis各组≥-0.15pp。
同时报告绝对Acc、变化行、加权MAE、方向与源族。

候选和阈值固定。通过后及时接入S8阶段版，完整实测全端口非重复1B；
1B必须记录CPU、资源、完整输出契约、SHA及同次样本精度。
最终交付资格继续要求Acc严格大于99%，平台及其他CPU表现另列待测。
未通过时停止当前S8配置扩大，保留对称树的其他容量和训练配置资格。
