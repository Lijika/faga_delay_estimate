# 实验100：depth10与新增exact标签组合开发筛选

日期：2026-09-27。开工 `/dev/sdd` 可用约479G。

## 冻结协议

实验93的 depth10 相对 depth8 在独立窗口提升 `+0.040127 pp`，实验97增加12,162条 exact 标签在 depth8 的开发窗口提升 `+0.021143 pp` 且区间跨零。两者交互未测。本轮固定47维特征、`gamma=1`、128树、`reg:absoluteerror`、`eta=0.1`、单线程、`-3 ps`，只在 depth10 上增加实验91/92两窗标签。control 模型必须重现实验93 SHA `9e0989b5b0f38e272a3e481498ea7042b69fd9b2d8d87bbf78adb04e21ea58cf`，control 逐行预测必须重现实验93 `depth10` 列；样本、模型、特征输出的身份与端点隔离沿用实验97核验。

开发窗口复用已查看的 `[38M,40M)` 6,178条样本，只作候选筛选，不作独立泛化结论。沿用原窗口七带权重、10,000次七带配对bootstrap与seed `20260925`。候选相对 depth10 control 的accuracy点增益至少 `+0.03 pp`、95%下界大于0、两类可达性误判均不增加，才进入未参与选型的 `[40M,42M)` 新请求及exact标签验证；失败即关闭本组合。新窗口须再检查相对正式 depth8 的精度、联合CPU收益和输出契约，才能考虑接入。公开 golden 不用于训练与开发筛选。

```sh
build/venv-ml/bin/python validation/exp100_depth10_more_labels.py
```

结果写入 `validation/results/exp100-depth10-more-labels.json`，模型和逐行预测保留在 `build/exp100-screen/`。本轮不改正式源码或交付包。

## 结果

control重训SHA与实验93一致，6,178条开发样本的预测逐行重现实验93 `depth10` 列；来源大小和SHA、训练/开发端点隔离均通过。候选58,667条训练行，模型SHA `040160fa58abe7a51f43514895b623825139574d48da20f484de7e93203c0d21`。

相对depth10 control，accuracy差 `-0.001568 pp`，七带配对bootstrap 95%区间 `[-0.047116,+0.044683] pp`；可达性误判均未增加。预设开发门槛未通过，关闭此标签组合，不生成 `[40M,42M)` 标签、不修改正式模型。开发窗口曾用于实验93选型，本差值不代表独立泛化；它足以按预注册规则停止该候选。
