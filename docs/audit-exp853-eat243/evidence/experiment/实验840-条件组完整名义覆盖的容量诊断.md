# 实验840 条件组完整名义覆盖的容量诊断

2026-10-29，新结果前登记。正式入口保持exp825，最终目标为完整
非重复全角色1B约100秒、Acc严格大于99.1%并留余量。
本轮复用exp838的主码、16局部码和训练方法，只改变条件组构造支持。

## 主假设

exp838每个方向仅用完整名义曲面的1/60构造，条件组中位数53条。
固定架构提供全部认证名义场，可以检验完整支持下的表示质量。
预期完整支持能改善当前16码模型在真实历史开发请求上的评分。
精确名义背景提供参考收益，RSS展开提供减少在线读取的实现机会。
二者分别核验。

## 冻结选择与三臂

方向0共有2048个主码。只依据exp824全目录的人口排序，主码打破并列，
每连续16组组成一层。seed 20261029840在每层均匀选1组，共128组。
选组、中心构造和编码均不使用真实请求标签或评分。
读取全部208个认证源场，为所选组提取完整288目标、120phase、
每曲面552点的数据。所选组的全部名义键进入构造。

- current沿exp824目录与原A2048/B256。
- R沿exp838已训练的条件形状，在完整所选键上重新执行两轮编码。
- D使用全部所选名义曲面重新训练。各组初始化次码沿exp838记录，
  16码、零残量、四轮中心更新和偏置优化均保持，随后同样两轮编码。
- exact用认证名义值替换背景，真实残差函数及整数解码保持。

R和D从同一exp824偏置开始编码。训练、编码逐组进行，避免将全部
曲面的权重与临时数组同时常驻。两臂保存目录word、最终取码时偏置、
完整形状和逐组损失。检查展开前后整数恒等，零码和偏置范围保持。

## 评分与停止条件

使用已有百万开发集中direction0、ordinary、主码属于所选组的全部
请求。沿原same_port、cycle、强制首段和最终整数语义。当前与精确
背景分别对照既有base1、exact和当前预测，逐行相同才评分。
名义场已完整参与构造，名义重建属于训练内证据；真实评分属于历史
开发诊断。新增真实标签和新请求均为0。

预登记质量门同时要求D相对current至少提高0.02pp，D相对R为正，
回收至少40%的exact背景参考增益，near_axis、distance、direction、
fold各非空分组相对current最低差不低于−0.05pp。
按26个source_family成组重采样9999次，seed 20261029840，
D-current与D-R使用两比较同时95%区间，分位点0.0125和0.9875，
两个下界均须为正。区间仅描述当前开发集，不能证明隐藏分布收益。

质量门通过后才扩大至全部条件组与四方向，检查实际压缩ELF、展开峰值，
并及时进入新100M，联合收益成立后完成1B与接入。
质量门失败时停止这组主码、16码、四轮、全组覆盖配置的扩大。
构造L1改善单列，表示容量、优化方法及最终评分目标的范围分别记录。
128组仅为机制原型，交付须使用全角色全方向方案。

## 资源与核验

只写exp840的私有构建、脚本和结果。复用冻结输入与assign.so，
逐源核对压缩SHA、原始SHA、头部、端口顺序和完整认证标志。
逐源用两套索引提取相同整数，并对照原8320条开发曲面。
独立枚举两臂全部最终16码选择，核对偏置加权中位数条件，
独立指数公式复算最终评分。

离线提取CPU≤900秒、wall≤1200秒、RSS≤2GiB；训练与编码
CPU≤1800秒、wall≤1200秒、RSS≤4GiB；新曲面资产≤1.2GB。
离线assign显式8线程；比赛执行仍须单线程、RSS≤2,000,000,000B、
静态自包含ELF严格小于100,000,000B，完整CPU计入初始化。
研究资源门与比赛运行门分别记录。

开工本地/dev/sdd可用259GiB，r9根盘2.9GiB，tmpfs14GiB。
原始证据保存validation/results/exp840，构造原始曲面可按冻结命令重建。
本轮不修改正式入口，新增完整100M与1B均待质量门。

## 完整覆盖结果

选定128组，共449,350条曲面、496,082,400B整数资产。
所选组的稀疏样本中位数52.5，完整支持中位数3243.5，
最小59条、最大11917条。全部208源场通过完整身份、认证标志、
双索引及原8320曲面的4,592,640个整数对照。

同一14,731条ordinary开发请求涉及14,482个名义键。

| 表示 | Acc | 相对current |
| --- | --- | --- |
| current | 98.993412704% | 0 |
| 稀疏R | 98.945020765% | −0.048391939pp |
| 完整D | 99.010604021% | +0.017191317pp |
| exact背景参考 | 99.486113550% | +0.492700846pp |

D相对R提高0.065583256pp，同时95%源族区间为
[0.035896442,0.093593350]pp。D相对current的区间为
[−0.021203082,0.052367706]pp，参考收益回收3.489200%。
最短距离304行下降0.154626425pp。原端点方向2的8行下降
1.389015965pp，构成预登记主分组的最低值；该8行对总体差的
贡献为−0.000754336pp，须与大样本距离组分别解释。
质量门失败，结束该16码、四轮、完整组支持配置的扩大。

完整所选名义域的L1由current的60,134,348,509,233，
变为R的62,146,928,150,807及D的54,942,527,787,582。
D改善8.633702%，R恶化3.346805%。真实请求背景MAE由
2.576200ps降至2.367524ps，但最终Acc增益仍较小。
数据支持不足具有受控证据，完整覆盖单独仍未达到本轮质量要求。
此结果没有给条件表示容量建立数学下界。

独立审核复算全部449,350曲面的两臂码号、偏置和损失，共
14,379,200个候选枚举及496,082,400个重建整数。
全目录人口、分层选择、完整键集合、每源整数指纹均通过。
当前背景、精确背景及最终整数输出沿原语义对照通过。

提取CPU225.031679秒、wall228.268917秒、RSS528,977,920B；
训练编码CPU257.393812秒、wall136.777523秒、RSS1,130,672,128B；
全曲面审核CPU38.949113秒，评分CPU1.386890秒。
这些均为离线研究成本。
