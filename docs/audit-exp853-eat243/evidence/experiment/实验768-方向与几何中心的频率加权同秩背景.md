# 实验768 方向与几何中心的频率加权同秩背景

2026-10-27预登记。exp766小残差已能支持精确背景99.3639%的开发精度；
exp767在2GB预算内，10bit完整三角形仅98.9495%，按当前标签选48个
最优商格为99.0138%。本轮转向跨全域共享信息，检验用户建议中的
方向center、几何gcenter与请求频率加权是否能改善同rank64的表示。

## 固定对象与四格

先在方向0筛选。复用exp755已认证的全部59904角色对、120phase、
3840个构造几何列，以及exp763的240个额外几何列；这些数据已有
历史查看，全部仍属开发诊断。后240列只隔离左空间拟合，右因子与
几何中心可以由完整名义字段求得，不能称为未知名义字段预测。
保持当前近域N512、字节曲线、解析趋势与rank64，新增完整程序运行0次。

U为原center、均匀几何权重的同rank重拟合控制。
C在U上加入方向pair中心与每几何列中心。
W在U上改用当前百万训练请求的名义几何频率。
CW同时采用中心项与频率。四臂固定同一种带旧左空间的随机投影、
两轮幂迭代、种子和INT8行尺度，分别报告浮点和整数合成评分。

频率从exp744已审核production的首Net对齐dx/dy计算，方向、phase、
商格必须与当前名义地址相同。每个完整方向0远域几何列的计数加1，
在构造列归一化至均值1，保证全域正权重。它是历史请求的列边际，
不假设未知分布相同，也不代表端口对与几何独立性已被证明。

设扣除原center、趋势及冻结曲线后的物理残量为V，d=128+125*qsum。
方向中心偏移取构造列上的sum(w*V/d²)/sum(w/d²)，存为float32绝对
center；gcenter取扣除该偏移后的逐列均值，也存为float32。
余量除以d，再乘sqrt(w)拟合；右因子投影后除回sqrt(w)。
完整预测按原舍入、再加原整数曲线并截零。固定中心后的rank近似
与最终tanh分数均需实测，平方误差优化不构成质量保证。

## 选择与检查

主指标为前120个逐phase列、全59904角色对的频率加权名义Acc差与
相对L1比，另保留均匀评分。固定C、W、CW中通过者要求INT8主差
至少+0.05pp、相对L1比<=0.92、均匀主差>=-0.03pp；qx短轴、
qy短轴、中域、长域、core与logic组均匀分差至少-0.03pp。
浮点与量化损失、C-U、W-U、CW-C、CW-W分别记录；候选相对U的
频率加权差须为正，避免把公共重拟合收益算给中心或权重。

四方向容量按实测左表压缩量的四倍投影，右表按完整未压缩量计入，
中心项另加4*(59904+65040)*4B，保留近域原center。投影严格小于
100000000B才允许扩大；其他方向和真实ELF仍待实测。
通过者按主分差最高选择一个，随后核验其余方向、完整字段和匹配
残差的真实请求收益。失败仅限制当前方向、中心定义、权重与曲线。

小数组核对双中心的加权零均值、权重还原、完全低秩重建和量化边界；
实际数据核对旧背景、整数点积、全部保存预测、输入与资产身份。
主实验预算CPU2400秒、wall1200秒、离线RSS16GB、新资产500MB，
在r9私有research/exp768执行。离线拟合资源与最终程序2GB分别记录。
复用已有NumPy、量化、投影与压缩帮助，不增加依赖。
本地/dev/sdd开工约272GiB，理论笔记与原始结果分别保存。
