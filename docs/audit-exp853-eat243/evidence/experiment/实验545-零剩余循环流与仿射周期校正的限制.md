# 实验545 零剩余循环流与仿射周期校正的限制

2026-10-20，在查看零边图的流量解前登记。exp544固定二宏步实例全0，
其搜索已结束。本实验判断一种表示类的能力，不继续枚举长词。

固定exp542八波前与全部60,200位置、496端口，扫描全部原Arc/Net。
保留每个0重加权Arc，以及每个按精确(dx,dy,Block费)分型的0 Net，
每型保存一个真实位置见证并重放。费用为exp543相同的scale12、去Line费用。
抽象类型继续允许复制到全部源余类；原图与此松弛分别记录。

对每图四个固定方向(+1,0)、(-1,0)、(0,+1)、(0,-1)，求非负平衡
循环流，目标为总流量最小，累计位移固定为相应单位向量。浮点LP仅用于
发现候选；每个非零系数固定以最大分母1,000,000恢复有理数，清除分母、
除公因子后逐项用整数核对496端口流量平衡和精确轴向位移。恢复失败即停。
LP报告不可行只记录求解器状态；不将该状态当作精确数学不可行证明。

对任意可行仿射校正λ·(x,y)+ψ(port)，每个0边要求λ·delta+ψ(to)-ψ(from)≤0。
将其按非负平衡流求和可得λ·总位移≤0。四个轴向证书同时存在就强制λ=0。
对任意有限周期ψ，把平衡流复制到全部余类后仍平衡，因此相同斜率约束成立。
非连通循环流足以约束所有边势，不能据此宣称存在同一真实路径。
当λ=0且exp543对应120余类表全0时，该固定周期的剩余势差已被全0最短路限制。

主假设为至少七个波前取得全部四方向的精确整数证书。任一完整域核验或
整数证书失败保存证据后停止；固定32次LP完成后结束，不补方向、模数或词长。
本轮无新标签、训练或质量比较，不宣称生产acc与CPU收益。
