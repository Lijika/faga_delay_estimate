# 实验755 相对lane均值与完整端口剩余的双低秩背景

2026-10-27预登记，查看新分数前冻结。exp754排除了当前端点势无损归约，
本轮沿路线B检验统计表示。生产基线为exp728，完整角色域59904pairs；
角色域外端点覆盖继续作为独立未验项。

按完整源族、目标族、目标lane减源lane模8建立7488组，每组8pairs。
逻辑端口用实际A-H字母确定lane；此处仅构造统计分组。去趋势与原pair
中心后的结构响应分成组均值M和完整pair剩余E，分别拟合低秩子空间。
固定候选为(M32,E32)、(M64,E16)、(M96,E16)，部署各需64/80/112项乘积、
两次尺度还原。候选整体替换远域D64与旧曲线，近域与真实残差保持现有入口，
实际残差匹配须在背景门通过后做四格。

方向0、全部120phase，每phase固定随机24个训练商点、8个留出商点，
均满足真实位移上界119/549。种子20261027755，全部59904pairs参与，
合计2880/960列。训练列学习左空间，宽度为最大rank加16、两遍幂迭代。
左空间冻结后，各列右系数由认证结构标签投影求得；留出列可以拟合自身
右系数，不能影响左空间。这检验固定端口空间的表示能力，未宣称未知请求
精度。所有field重新核对已有认证SHA；完整truth加回解析趋势。

左右因子按行INT8量化，报告浮点与整数结果；保留精确组均值加E32诊断，
区分均值压缩误差与完整lane剩余误差。基线为当前D64加完整旧曲线。
报告留出官方名义分差、相对L1、短轴/中程/长程、核心对与逻辑端口组，
另报120phase结果。训练域单列，已看过的两phase作地址回归检查。

整数留出名义提高至少0.10pp、相对L1比例至多0.85，各距离组与端口组
退化至多0.03pp，至少100/120phase提高，且容量预算低于100MB，才扩大
全方向和完整几何列。容量使用已有近域压缩32771541B、非资产7585312B、
exp728差额43776B、额外代码1000000B与头部4096B；新因子按未压缩字节
计入，目录包含在代码预留内。实际ELF、启动、完整CPU另验。

最多CPU1800秒、wall900秒、RSS12GB，离线BLAS8线程，所有计算在r9。
没有候选过门即停止本配置扩大；通过后完成全方向整数资产、实际请求
背景/残差四格，并尽快新100M、1B。完整程序阶段遵守单线程与2GB约束。
本轮不生成新exact，不运行完整estimate，不修改正式产物。

## 结果

三个整数候选均未过质量门，停止当前配置扩大。留出共57,507,840个
结构值，覆盖全部120phase、59904pairs；所有phase均退化。

三项对应浮点名义差为-0.555610903/-0.562982167/-0.513449350pp。
量化前已存在主要质量缺口。精确均值诊断的核心对/含逻辑端口分别
下降0.149860598/0.360685320pp，qy短轴下降0.926244579pp，
当前E32全相位共享剩余仍丢失较多信息。结果限定本次投影、秩和
去趋势规范；相对lane的其他表示仍需独立验证。

映射均通过。浮点剩余左因子的组内和通过数值检查。

120phase评分和门判断重算一致。
