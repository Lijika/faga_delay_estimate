# 实验403 真实端点生成零次与一次跳格位移类

2026-10-18，新结果前登记。正式exp354，CPU发布基准exp323。
exp402的双核心改善了费用，真实恢复仍受水平±14格影响。
本轮主假设是从官方Block与实际端点生成名义位移类，可改善规范词的同端点覆盖。
竞争解释是最小费用词的转向位置仍非法，或者短桥与非单调族缺失仍主导质量。

控制为exp402中单核心与双核心的两个规范胜者，按真实同端点费用取最小，
77条开发中段有37条满足exact的101%费用。新增候选从实际端点差生成
零次跳格与一次同向水平跳格两个名义位移类。官方水平可跨Block宽度须相同，
读取宽度w；第二类dx=(tx-sx)-sign(tx-sx)*w，dy=ty-sy。
此类只保留与实际水平位移同向且|dx|≥52、|dy|≥56的内部域，
其余保留控制并记录未覆盖数量。生成过程只读实际端点与架构，
exact费用和原路径词仅用于事后质量核对。

复用exp402已通过的私有普通与sanitizer ELF，B4、B1与全部选择规则保持。
旧零跳格类输出与既有输入身份相同，复用费用与路径。新增一跳格类
全量运行，前4项sanitizer核对；次数域仍由原ELF断言，复用exp401/402
全量边界与独立DAG证据，新增规范词逐项独立重放名义与真实图。
按真实合法且同端点的费用从最多四个胜者中取最小，费用相同优先控制，
候选选择全程使用实际路径费用。此选择只比较有限规范胜者，
未覆盖各位移族中的其他几何词。

主指标为全部77条上真实同端点且费用≤exact的101%的数量。
相对37条至少增加5条则继续几何与共享选择研究；90%作为完整恢复的扩大参考。
同时报告真实有效、端点匹配、exact相同数量、改善与保持行数、费用下降幅度，
按象限分组。开发集固定，统计采用确定性配对描述，
本轮没有总体acc或新请求泛化结论。
所有真实匹配候选必须≥已有exact费用；名义费用和位移逐项保持，
费用加1和位移加1负对照须拒绝。任何语义或资源失败保留原始证据并停止扩大。

先count全体新类桥候选，500,000,000项预算；普通进程CPU≤120秒、
RSS≤2GB，单线程；sanitizer放开虚拟空间并检查RSS。
完整架构初始化、输入解析、选择CPU与完整进程分列，全部为本机诊断成本。
冻结协议、脚本、原ELF、B1/B4、实际端点与已有原始结果后运行。
本轮不新增核心选择实现、全图exact、完整估计器运行与总体acc。
