# 实验613 D96背景在通用整查询路径的成本

2026-10-22，在编译及新性能结果查看前登记。exp611/612近域更短
表示均未过全域质量门，固定配置结束。正式exp610为D64＋R8，
完整1B251.136671秒。当前目标继续提高Acc余量及性能可移植性。

## 已知事实与本轮假设

exp589 D96在两套已用完整全端口1M比D64高0.121955/0.123978pp。
exp603在exp601执行路径中观测额外约13至14ms/1M，联合门失败。
exp609之后通用整查询代码组织改变，D64完整1B节省25.150724秒；
模型宽度增加的边际成本需要在当前路径重新测量，不能直接复用旧成本。
这轮只移植既有冻结D96，原特征、R8、舍入及其全部数值保持。

A为冻结exp609/F，H为相同通用worker搭配exp589 D96资产，近域
512维保持。远域采用一块64加一块32的SSE2整数点积，恢复顺序与
exp603 D96逐位相同。只链接本轮通用worker，启动架构仍由generic
入口唯一构造；不引入扩展指令要求、搜索、缓存或新的模型训练。
静态ELF预计小于95MB，实际严格检查100000000B。

## 验证、指标与停止条件

所有算法测试、数值审计、评分及计时仅r9指定工作目录。先执行完整
全端口1M trace与exp603 D96核对全部字段，输入唯一、59904端口对。
原完整D96 CSV与新输出SHA相同后复用精度；全部输出契约、查询分配0、
线程1、RSS<=2GB、3600秒、静态和容量门均检查。

开发exp501、已用稳健性exp562各完整唯一1M。A/H各预热一次，再六轮
正逆配对；同机串行、避开重负载，完整CPU含初始化。复用exp603
10000次26源族/计时bootstrap、seed20261022603，97.5%同时区间。
质量门为增益>=0.02pp且同时下界>0、各distance/近轴下降<=0.03pp。
联合分为0.8×Acc差pp-1000×新增CPU秒/120，点值>=0.01且同时下界>0。
两份均通过才选H。未过联合门保留精度/CPU帕累托证据，停止该移植扩大。

通过后冻结模型，在一份新完整全端口唯一1M上验证Acc及95%下界>98.2%，
配对质量门保持；随后完整10M六对、100M与可选完整1B依次验证。
任何规模扩大先解释初始化与新增32维成本，1B成绩依完整程序实测。
完整10M联合分95%下界>0且点值>=0.01才扩大100M，CPU外推倍数改100。
