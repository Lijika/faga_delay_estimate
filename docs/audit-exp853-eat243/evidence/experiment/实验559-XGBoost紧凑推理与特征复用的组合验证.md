# 实验559 XGBoost紧凑推理与特征复用的组合验证

2026-10-21，结果查看前登记。用户要求叠加多个推理优化。沿用exp558
固定R32，逐请求普通G、原生N、逐次原位NI、紧凑按层L为同轮对照。
exp558已通过完整1M等价与N/L收益门；NF单独收益门失败。

## 假设与组合

节点表示、指令独立性、特征重复计算与模型局部性作用于不同成本。
NC保留N分支代码，将仅使用的36项特征以固定生成代码计算一次，存入
请求的int16栈空间；它与NI比较特征复用，与N比较特征算术成本。
LI组合该一次计算及L紧凑按层交错，仍每请求处理32棵树。
B在相同有限整数模型上按64条请求分块，将节点转为逐树连续布局，
块内各行的同一棵树共同推进；特征按列存入固定栈区，模型复用与多个
独立请求的依赖链共同参与。BI将B的特征输入改为认证请求/首Net事件，
只计算模型实际使用的特征一次，并直接写入块内特征位置。

固定八臂G/N/NI/L/NC/LI/B/BI。比较NC-NI、LI-NC、B-L、BI-LI识别组合
贡献；N/G/L同轮重复作环境对照。B/BI仍按每行原树序逐次float32累加，
保留输出行序。块内按三折模型分组只服务本次折外评价，同一正式模型
可直接处理整个块。全部请求仍唯一，所有59,904端口对均参与；分块与
分组均不使用完整请求命中缓存。

原生预测。每折完整覆盖59,904端口对。标签和旧评分直接复用，当前精度
97.915560541%，本轮无模型质量变动。全部算法与数值检查只在r9r4900，
路径`/home/lhj/lhjwork/eda2026/research/exp559`。

复用exp558模型生成器、数据检查和执行器；生成私有C++变体与B布局。
单个完整层节点用uint8特征、int16阈值，叶号uint8；树序、叶值与分裂
语义保持。模型嵌入静态ELF，查询栈与固定BSS，无堆分配；输入只读mmap。
原位事件仍为已认证预生成输入，真实首Net生成与CSV成本另验。

全部臂在完整1M逐位核对原始float32与整数恢复，check阶段保存每行32个
uint8退出叶，进行完整逐字节比较并保存SHA，替代exp558的64位指纹。
53M项原位特征逐项核对，全部节点、逐树布局转置与范围检查通过后计时。
所有臂先各做一次完整1M check及一次预热，再按正序、反序、正序测三轮。
同机串行、单线程、通用x86-64，沿用O3、无异常/RTTI、严格浮点参数。

配对差用三轮df2的95%t区间，最小实际收益为相应对照CPU减少10%且区间
