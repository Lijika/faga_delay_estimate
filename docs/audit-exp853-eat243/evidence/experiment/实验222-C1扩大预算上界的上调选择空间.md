2026-10-12。正式入口exp131，私有精度对照为exp220，

## 预注册

固定每行原规则截断后预测P和已核验真实合法路径最小上界U。
在P>0、U有效且U>P时，计算
`d=point_of(exact,U)-point_of(exact,P)`。
该行实际规则只能选P或U，逐行oracle增益为`max(d,0)`；
其余请求保留P。两组分别按已有权重还原总体，
报告候选资格、改善/恶化行、oracle总增量、分带贡献与负收益量。
逐行核对索引、权重、exact、合法U>=exact、原规则截断关系；
核对聚合accuracy与exp214、exp215已提交报告相符。

主假设是扩大预算后的同一条路径上界仍能为低估请求提供有用的
上调候选。筛选门预先定为两组**各自**的oracle增量至少+0.10pp。
未过门则停止此固定两候选方向，转向新增独立路径信号或精确搜索；
过门也仅说明候选存在可选空间，需隔离训练/校准后用全新标签验证
线上可得特征的选择能力、整体CPU及跨架构行为。

两组标签与输出都已查看，用于描述固定候选空间，不能充作新请求验证。
oracle使用exact逐行选优，仅做离线上限；实际选择器可能出现恶化。
完整输入、脚本及判据在读取oracle结果前冻结并提交。

```bash
PYTHONDONTWRITEBYTECODE=1 python3 validation/exp222_new_upper_headroom.py freeze
# 提交冻结清单后
PYTHONDONTWRITEBYTECODE=1 python3 validation/exp222_new_upper_headroom.py analyze
```
