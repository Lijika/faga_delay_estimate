# 实验60 预注册：P0 -3 ps 固定偏移的纯等价快路（uniform bias fast path）

日期：2026-09-26。开工 `df -h /dev/sdd`：`1007G` 总、`573G` 已用、`384G` 可用（60%）。
本实验只做工程等价优化，不改变研究方向、不重训、不调参、不换窗口。

## 主假设

旧 P0 候选（`build/exp57/estimate-minus3`）在 `answer()` 里对**每一个** `value >= 0` 且
bias 启用的输出行调用 `arch.parsePin` 两次并求 Manhattan 距离，仅为选择 band；
`build/exp57/private-src/main.cpp` 的这段代码在 1B repeated（999M 次 query-cache 命中、
偏移与 distance 无关）上支付了约 `+89.7 s` 的纯开销。
若 7 个 `BiasTable.offsets` 全相等，则 `offsets[bandOf(d)] == offsets[0]` 对任意
`d >= 0` 成立，band 选择不可能改变结果。据此可把该行的一次性 uniform 判定提前到参数解析后，
`value >= 0` 时直接 `bias.apply(value, 0)`，只对非 uniform 表保留原双 `parsePin`/Manhattan 路径。

等价性论证（须逐字节验证）：
- `apply(value, d) = clamp0(value + offsets[bandOf(d)])`；uniform 时
  `offsets[bandOf(d)] == offsets[0]`，与 `apply(value, 0)` 完全相同（含零钳位）。
- `value < 0`、`options.exact`、未启用 bias 的行完全走原分支，不进入快路。
- 三个求值入口对不可解析端点都返回负值（`ResidueEstimator::estimateText` →
  `-1`；`Router::queryText` → `kUnreachable`；`HybridEstimator::estimateText` →
  回退 residue 并返回 `-1`），所以 `value >= 0` 蕴含两端点可解析，原路径与快路都不会
  跳过/多执行偏移。
- 非 uniform 表（`-bias-band`）继续原路径，行为与原二进制逐字节相同。

## 计时协议

1. **10M repeated 试点**（先做，小规模）：输入 `build/exp60/requests-10m-repeated.csv`
   = `timing-1m-unique.csv` 的 1M 行块确定性重复 10 次（9M 次 cache 命中），
   `taskset -c 3`、单线程、`timeout -k 30 3600`、无竞争，old/fast 各 2 轮交错，
   记录 CPU/wall/RSS/线程与输出 SHA；同时验证 fast 与 old 输出逐字节相同。
2. **1M unique 十对**：三标签 `baseline=./estimate`、`old=build/exp57/estimate-minus3`、
   `fast=build/exp60/estimate-minus3-fast`，各一次预热，10 轮轮换、同机串行、
   `taskset -c 3`、`timeout -k 30 3600`、每 5 s 竞争检测；主指标 `fast − baseline`，
   次指标 `fast − old`（纯工程收益）与 `old − baseline`（对照）。
   配对 t 区间，n=10、df=9、`t₀.₉₇₅=2.262157`。
3. 每轮完整核对 1M 输出的行数、端点顺序、恰好 3 字段、整数 delay、精确 EOF、
   negative 位置集合与各轮 SHA 稳定；RSS `×1024 ≤ 2,000,000,000 B`、线程 `1`、wall ≤ 3600 s。

## 停止条件

- 任一等价性检查失败（1M `cmp`、6176 行探针、零/负、非法端点、非 uniform band）→ 立即停止，
  保留旧候选与证据，不接入。
- 资源或契约失败、出现其他 `estimate*` 竞争 → 立即停止后续轮次并保留原始证据。
- 试点若无收益（`fast − old` 的配对均值不为负或不显著），停止，不跑十对，不讨论 1B。

### 语义边界（保持冻结）

默认与显式 uniform -3 走已验收 P0；显式 bias 为 0、其他 uniform 值或非 uniform 表时残差保持
off；`-residue-mult 1`、`-exact`、`-short-exact`、其他 endpoint/threshold、`-pdb-floor`、
`-bounds` 与接入前逐字节相同（矩阵覆盖）；`-residual xgb` 仅允许无 bias 或 uniform -3；
`-bounds` 仍只允许无 bias。uniform 判定只做一次，`value < 0`、`-exact`、非法端点不进入快路。
