# 实验336 当前非重复请求热点采样结果

2026-10-17。当前exp335的主要开销仍在搜索。两套非重复完整1M中，
SearchQueue::push分别占26.34%和22.91%，桶内比较与维护适合作为
下一项等价优化原型。采样支持热点定位，性能收益由新候选配对测量。

## 身份和检查

私有采样ELF保留调试信息，为108,361,248字节；.text、.rodata、.data
及LOAD布局与正式94,087,824字节ELF一致。采样文件只作诊断，
生产入口和交付包保持exp335。两个完整1M输出的行数、端点顺序、
三字段、整数delay、精确EOF和完整SHA均通过，同exp335变化0行。
公开acc沿用99.01069721418632%，新增exact与评分CPU均为0。

Xeon Gold 6226R核3串行，两个正式采样前均使用冻结unique 20k预热。
U-output有88,754个样本，公开输入有103,579个样本，丢失均为0。
采样期间完整CPU分别为89.17秒和104.00秒，含perf开销；
峰值RSS均为1,669,664,768字节。这些时间用于诊断。

回查本次GCC 13.3的头文件，SearchQueue::push中的stl_pair.h:688
为pair构造成员写入，样本占8.44%和7.33%；stl_iterator.h:1077
为迭代器构造，样本占4.09%和3.54%。初稿把这两行解释为比较，
本次根据实际源码修正；函数占比和原始采样保持。
源码行归因包含优化、内联与采样偏移，
这些比例不能单独解释为某条指令的精确成本或可消除时间。
公开输入的UpperTree占比更高，后续候选要保留逐分布结果。
