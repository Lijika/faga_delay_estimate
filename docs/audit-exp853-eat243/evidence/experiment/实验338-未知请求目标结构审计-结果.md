## 结论

现有按目标端口分组的局部性仍有实际结构重复；把分组键直接替换为目标 cell
缺少保持目标端口 / rank-table 访问语义的证据，也没有可量化的未知请求 CPU
收益。本轮不创建目标 cell 分组候选，关闭该方向的直接实现。

本轮没有测量 100M 或 1B 估计器 CPU，阶段成绩继续以非重复 100M 和 1B
完整程序运行结果为准。
