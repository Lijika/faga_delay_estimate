# 实验440 二维距离程序的仿射归一化共享

2026-10-18预登记。exp439发现局部混合差非零约6%，每个商网格约10.5种
局部仿射面；多数完整网格同时具有正、负轴向二阶差分。
exp436只扣除子区域基值，相同分段形状加上不同线性斜率仍产生不同节点。
本轮主假设是进一步扣除两方向斜率可明显增加子程序共享。

固定exp436的两源、域、根目录和横纵二分规则。
每个子矩形取原点费用及首个横纵差形成仿射部分，剩余函数用于共享。
完全仿射子区共享零节点。左子区原点及首差保持，左边不需额外系数；
右子区保存相对于父仿射部分的常数、横斜率和纵斜率差。
单格宽/高对应坐标始终0，该方向差规范为0。节点固定16字节，
每根保存uint16基值、两个int16斜率和uint32节点号，共10字节。

自检要求原网格和任意加上线性函数的网格使用相同根节点，
全部原场值穷尽恢复，Zstd19压缩往返SHA一致。
源内可达节点数、跨源共享、访问数、静态容量、CPU及RSS分别记录。
候选两源静态<=exp415的50%、条件160源RAM<=1.5GB时扩大。
所有系数须在int16范围内，超过8M节点停止当前构造。
保留原窗口证书，Bellman末段掩码、全源静态100MB和完整程序CPU另验。

## 结果

仿射偏移不改变根节点的自检通过，两源107,091,200次恢复通过，
包括零轴重复；原场不同值共106,629,440个。
节点2,345,333个，相对exp436少19.659%；各源可达1,198,668和1,236,184。
平均访问5.398732个分支、最多9个，零叶不计访问，计数方式与exp436相差一叶。
节点16字节及更大的根记录使资产39,068,060 B，Zstd16,310,112 B，
条件160源RAM3,288,047,404 B，固定格式未过容量条件，停止扩大。
构造CPU11.161649秒、RSS622,657,536 B，压缩CPU50.351935秒。
分支共享增加已验证，静态容量收益未成立；不据此否定斜向区域条件。
