# 实验435 末段证书的非重复10M规模验证

2026-10-18预登记。exp434八源1M从同期1.615降至1.130秒，
名义查询7,493,361降至2,399,091，完整输出SHA保持。
本轮复用exp432的10M独特输入及40k新exact标签，验证等价优化的规模收益。

固定A为exp431原字段模型，B为exp434末段证书模型。
Xeon core3、20k预热、完整A/B/B/A，全部进程初始化、解析、输出计入CPU，
离线架构表生成成本另列。每次单线程、RSS<=2GB、运行<=3600秒。
输入、二进制及两套字段全部核对身份。
完整输出SHA须等于exp432，端点顺序、行数、字段数、整数和EOF检查通过。
相同输出直接复用原40k评分，新增exact与评分成本为0。

报告配对CPU差、名义查询数、证书覆盖、Block查询数和峰值RSS。
1M与10M拟合初始化及斜率作为诊断；小规模外推不计阶段成绩。
若10M<10秒且输出等价，保留100M规模诊断资格；全源容量继续独立解决。
本轮仍限8源到Z及当前架构，不更新正式入口或平台包。

## 结果

Xeon完整10M的A/B/B/A为13.64、8.61、8.60、13.68秒，均值13.660对8.605秒，
减少37.00586%。四份完整SHA为93ce9aae799436aaa51671c278ffaacd733ef6e71ee35149592bc28540506805，
与exp432保持，40k评分复用99.17564656%，95%区间[99.13991113,99.21243962]%。
候选单线程，最大RSS1,662,160,896 B。名义查询24,148,737次、witness命中6,831,506条，
Block调用339,316次及其认证查询15,976,091次保持。

两对CPU差为-5.03、-5.08秒，小样本t区间约[-5.372655,-4.737345]秒。
两对结果支持本机收益；跨机器稳定性仍需平台验证。
1M/10M两点诊断为初始化0.299444秒、每请求0.830556微秒，
条件外推100M83.355秒、1B830.855秒，外推不计阶段成绩。
已进入exp437新100M完整实测。

后置独立10M周期采样输出SHA保持，丢失样本0。main占37.78%、
Block429::query占19.88%、parsePin占7.89%、resolveOffset占7.81%、
