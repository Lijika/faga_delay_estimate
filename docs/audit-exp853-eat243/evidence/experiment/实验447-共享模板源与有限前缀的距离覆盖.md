# 实验447 共享模板源与有限前缀的距离覆盖

2026-10-18预登记。exp437八源非重复100M已测得83.81秒，抽样acc
99.191162%。下一项主要问题是全源距离表示的容量。当前八源原场约1.7GB，
完整160源直接扩张超出资源要求。exp391的单步费用矩阵下界仅约束该单步
表示，远位移的多步共享另行检验。

主假设是少量模板源可以通过有限短前缀覆盖其他源的名义最短路径。
固定八源为exp423的SOURCES；评估源s时排除其自身，模板H为其余七源。
前缀位移固定为[-12,12]^2，共4375条候选。对目标(d,t)计算

```text
Q_s(d,t) = min_{h,delta} D_s(delta,h) + D_h(d-delta,t).
```

每个距离来自既有已认证场，所有坐标均在已认证普通域中。拼接为名义
合法路径，所以Q>=D_s；取等需要至少一条名义最短路径经过相应模板状态。
这项关系只用于名义距离，真实Block/Line费用与真实acc独立验收。

每源按seed=20261018447+s，从x∈[-107,107]、y∈[-537,537]、
160目标端口的整数键空间均匀不放回抽4096键。前2048为开发集，
后2048为留出集。开发集按官方评分函数的平均值，确定性贪心选择
k=1、2、4、8个固定前缀；选择过程只读取开发列。结果按全部、
Manhattan距离<=32和>32分组，记录精确率、评分、绝对误差及分位数。
同时计算4375候选的oracle上限，保存反例的键、费用与所用前缀。

在查看结果前固定扩大依据。八个留出源的远区oracle名义分均>=99.97%，
且每源k=4的远区名义分均>=99.90%时，再研究可查询编码与真实完整1M。
门槛只筛选本固定模板及前缀方案；未通过时保存覆盖缺口，停止该固定
配置扩大。k=8用于诊断，目标或方向相关选择需要单独预登记。
名义评分不计为真实acc，oracle的4375次读取也不计为在线算法成绩。

原型复用Field、score、identity和write，修改范围仅为实验脚本与记录。
自检覆盖上近似组合、确定性前缀选择、无重复键和开发/留出隔离。
计入分析CPU及峰值RSS，原场生成成本复用既有证据。正式入口和发布基线
保持。理论推导记录在Obsidian的“共享模板源与有限前缀的名义距离因子化”。
