# 实验627 D64几何预取跨度的全端口消融

2026-10-23，在构建候选及查看计时前登记。近期完整程序基线为
exp622/T，保持D64、Q4、R8专门化、完整CSV批8和exp610的通用ISA/ABI。
exp625指出调用栈中预取约占T的8.87%，其中大部分来自近域rank512的
两条连续因子行；该占比是有限采样估计，不能单独推出预取指令可删减。
exp581曾在不同模型/背景实现下证明提前几何读取能降低完整程序CPU；
exp597排除了单纯增加批容量带来的当前证据。本轮保留预取时机及批量，
只检验每条近域因子行实际发出多少预取地址。

## 假设与候选

冻结几何实现按64维块预取，近域rank512每请求对左、右因子各发8次
`_mm_prefetch`，远域rank64每侧一次。完整点积后续按连续字节顺序读取
每一行。主假设H1：对近域仅预取每侧首个64字节cache line，其余依赖
需求读取及硬件流预取，可减少软件预取指令开销并保持完整输出；代价可能
是更多需求加载等待。A为当前全行预取，B为仅首行预取。C不预取向量行、
只保留尺度项预取，作为机理诊断，不作为选型后备。

A/B/C的点积地址、rank、局部索引、整数归约、double组序、舍入、中心值、
树推理、输出和预取相对树计算的位置均保持。仅变更near/far数据行的
软件预取条数。远域仍各预取一行，因此该部分类行为不变。

## 验收与停止条件

对每份数据，A/B/C各预热一次，然后执行六个平衡三臂区块：
`ABC, BCA, CAB, CBA, ACB, BAC`。每次都完整运行并写CSV，固定单核8、
同机串行。A/B/C各自输出SHA须等于对应冻结exp622/T输出，stderr计数须为
1,000,000行、不可达0、查询分配0；进程须单线程、RSS≤2GB，ELF<100MB。
输出哈希相同时复用准确率，delta Acc=0。

唯一主速度候选为B，分别在两份输入上相对A计算六个区块配对差及双侧
95% t区间。B须在两份输入都平均至少节省0.002秒/1M且区间下界大于0，
才进入新非重复10M。C为预登记诊断，只报告均值和区间，不据其挑选替代B。
10M前重新冻结输入/二进制/输出身份与成本，至少六对交错，节省门为
0.02秒且95%区间下界大于0；通过后再登记100M。

任一完整输出不等价或资源越界即停止候选。门失败时，仅否定本轮首line
与无行预取两种D64/Q4/R8布局；预取时机、cache hint、需求读取以及其他
模型/背景布局不作否定。本轮无标签生成。

T冻结SHA相同，`rows=1,000,000`、不可达0，故Acc差为0。计时固定在
Xeon Gold 6226R核8，无输出契约或资源失败。
