# 实验515 全端口短线拓扑深度与lane绕行

2026-10-19，在计算新统计前登记。基线提交`5f7951d3`，

## 假设与对象

exp514固定近域旧损失的86.623401%对应存在全短最优路径的查询。
本轮检验其中的短Net深度有多少由端口连通性直接决定，以及
最优路径是否需要比端点lane模差更多的一整圈lane前进。
这是共享短线模型的结构诊断，未定义新延时预测候选。

全短拓扑图保持208入口和288终端Output身份，仅允许128个非L Z
作为内部接续，忽略所有Net二维位移。分别以Arc数和原始Arc费用
求完整端口对最短值。Arc数减1为最少内部短Net数h0，最小费用记C0。
L终端在该家族为不可达；原始空路径按exp514单列。
用Floyd和反向Dijkstra/BFS独立计算，全部59,904槽逐值一致。

128个非L入口之间的lane增量为模8的0或1，静态原文已核对。
160个Z入口接128个非L输出也须逐边重新核对该条件。
对起始Z入口s、非L Z终端t的全短路径，所有Arc的+1次数K满足
`K == (lane(t)-lane(s)) mod 8`。若内部短Net数为h，
共有h+1条Arc，所以`h >= max(0, ((lane(t)-lane(s)) mod8)-1)`。
该式只是拓扑必要下界；保留二维位移和具体费用后可有更大深度。

## 完整数据与检查

全部208源、288目标、59,904端口对，复用exp514固定17位移及
1,018,368个不同名义查询。全部查询都参与完整根检查和分组；
适用lane同余的子集以路径身份筛选，其他端点继续有拓扑距离。
新增exact标签0，数据均为已查看开发机制域。
全部算法诊断、模型评价、评分只在r9执行。

对exp514全部紧边证书作后序递推，保留所有同费全短路径中的
K最小/最大值。logic入口的首Arc及logic终端的末Arc不计lane前进；
它们没有参与本轮同余命题。记录剩余内部Z转移的+1次数仅作描述。
L吸收分支在全短统计中不参与。

必须核对完整证书SHA、EOF、状态顺序、非空后继的严格费用下降、
全短分支存在性与exp514逐状态一致。所有全短根要求h_min>=h0、
D>=C0；适用同余根要求K_min/K_max均满足端点模差，
且K_max<=h_max+1。独立查询摘要逐值核对全部根身份、费用和旧四深度。

## 预定指标与研究顺序

主指标为旧缺口且存在全短最优路径者中，h_min==h0的比例，
按源、目标和17个位移分组，记录全短最优费用D-C0的直方图。
确定性完整开发域不作bootstrap；全部不变量为零容差。
若比例>=70%，后续优先研究保留lane拓扑的共享局部传播；
低于该阈值时优先研究拓扑与二维位移的联合表示。
该门只决定研究顺序，不构成生产准入或精度CPU收益。

适用lane命题的完整根另外记录最少额外整圈数、
全部tie中整圈数是否变化，以及h_min与lane必要下界的差。
保存至少一个实际需要额外整圈的根及完整合法紧路径，
若不存在则只记录已检查域。不得由单条规范路径判断整圈必要性。
检查失败保留原始失败证据并停止；不据结果修改阈值或筛掉端口。
