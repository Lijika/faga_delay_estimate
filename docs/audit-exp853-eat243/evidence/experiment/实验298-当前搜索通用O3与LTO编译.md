# 实验298 当前搜索通用 O3 与 LTO 编译

## 预注册

2026-10-16。exp295 的 highg384 公开acc为98.977714%，完整精度门
未过。当前完整验收通过的研究基线为exp292 fixed，独特1M均值
139.37 s，公开acc99.062696%。exp84/86 的通用O3仅检查了历史
模型及搜索实现，其原协议和不确定性保留。本轮检验当前实现的编译收益。
开工磁盘约409 GiB。

基线固定exp292 O2 ELF。两个候选逐文件复制同一源码，分别仅用
通用-O3替换-O2，以及在-O3上加-flto=1。模型、512预算、默认Both、
整数排序、图、真实费用、编译器及静态对象保持。无CPU专属编译选项，
浮点重排选项保持关闭。影响范围为私有构建产物、测试和本轮runner；
外部入口、结果字段及用户脚本继续沿用既有接口。

先检查当前GCC帮助及实际优化开关。三个编译配置对两个当前使用的
浮点模型核对输出位摘要，覆盖固定随机向量、NaN/Inf、零和每个分裂
阈值及相邻float。两候选各复用36,678条搜索、完整路径、768组cap、
80组weight、128条Arc费用变体及四组CLI检查；全部字段除cpu_s
保持，逐路径SHA保持。完整程序在三个既有exact开发样本上与exp292
输出SHA一致时复用评分，精度配对差与变化行数均为0。AMD计时仅记成本。

Xeon core3同机串行，在exp296/297结束后测量。输入完全复用exp297
原序独特20k/100k前缀，三臂分别预热，再ABC/CBA/ABC三轮。
主性能分布为100k，完整CPU含初始化和I/O。报告全部三组配对差、
df2 Student-t 95%区间，两端各加0.02 s舍入；0.5%仅记效应。
同次输出检查三臂和多次运行完整SHA一致、端点原序、恰好三字段、
整数delay、精确EOF、单线程、RSS<=2GB及CPU/wall<=3600 s。
任意输出或路径变化先保存证据并停止性能测量。

同精度下逐规模列CPU前沿，100k相对O2差区间下端<=0的候选保留
完整1M资格；明确变慢的固定配置结束本轮扩大。三个阶段指标保持。
新增100k前缀缺全量exact，已有精度证据限定于已测分布，正式接入仍需
完整1M。100M/1B、跨架构和官方平台性能另验。本轮记录构建、审计、
估计与评分成本，完整结果独占创建，复现另建目录保留当前证据。

单线程与资源检查通过。精度按已测相同输出证据复用，配对差和
变化行数为0。CPU为三对完整进程均值，区间包含两端0.02 s舍入。
