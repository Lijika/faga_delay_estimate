# 实验333 目标分组生产配置候选

## 条件预注册

2026-10-17。exp332的100k完整程序三对CPU下降6.740064%，输出保持，
其完整1M协议正在运行。本轮先在私有目录准备生产配置，正式迁入和打包
以exp332完整1M通过及本轮最终ELF验收为条件。当前生产入口保持exp323。
开工/dev/sdd约399GiB可用。

候选默认关闭完整请求结果缓存，`-cache-mb`继续允许显式设置。固定
65,536行、4MiB批次和目标端口分组，搜索、模型、权重与预算保持。
将原型批次头置于生产同构私有目录的`target_batch.h`，请求循环直接
放入main，去掉实验编译开关；只使用原型已核验的grouped路径。
显式其他算法配置沿用原序处理。

涉及调用者为main的普通构建、静态构建、默认及显式CLI、CSV错误处理
和默认cache预算。Router及ResidueEstimator的库级Options默认值保持，
测试直接构造对象继续使用原值。候选不新增依赖和公开参数。

## 验证与判定

私有最终静态ELF先核对四组已标记样本共48,184行、7行边界、特殊CSV、
显式cache64及其他CLI。逐行输出与exp332/exp323参考相同后复用评分。
批次容器仅有命名空间和文件名变化，原断言测试在最终头上普通运行。

AMD本机在最终ELF上串行运行unique和公开完整1M，各两次，默认参数
保持缓存关闭及目标分组。每次核对原行序、字段、整数、EOF、完整SHA、
单线程、RSS≤2,000,000,000字节、CPU和wall各≤3600秒。本机时间仅
记录参考；公开评分复用同输入、输出和标签的99.0106972142%，新增
exact与评分预算0，独特1M全量exact仍待验。

待exp332远端完整测量结束，Xeon核3比较exp332 grouped与此最终ELF。
20k两臂各预热一次，100k三对AB、BA、AB完整串行实测。原型臂使用
`-cache-mb 0`，最终臂使用默认。主指标为最终减原型CPU配对差，
t区间df=2另计0.02秒舍入。预定1%作为实际效应描述。区间跨零时
保留性能不确定性；若明确增加CPU，先检查编译地址、布局与默认分支，
结束固定生产配置的接入，原型资格保持。每次资源与输出要求相同。

通过后迁入两个差异文件，普通构建检查受影响入口，并以最终静态ELF
身份复用完整1M证据。新的打包检查器绑定本轮最终ELF及完整1M记录，
执行清洁目录和3107行holdout。按不可变版本、latest镜像、入口指针的
固定顺序打包，保留旧版本。打包规则已读subm/README.md和
subm/versions/README.md，后续涉及更新时再次核对当前内容。

两阶段成绩仍待非重复100M及1B完整算法实测。exp332及本轮1M仅用于
候选筛选和交付检查，输入事先未知的要求由动态处理保留。其他架构、
平台及隐藏精度另验。收尾记录实际成本、空间与清理清单。
