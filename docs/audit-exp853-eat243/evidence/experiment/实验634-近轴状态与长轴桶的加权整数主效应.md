# 实验634 近轴状态与长轴桶的加权整数主效应

2026-10-23，拟合前登记。正式exp610和研究基线exp622/T保持。
exp632精确背景干预支持近轴背景研究；exp633的共享单修正总体名义
L1改善，但方向1/2的x短轴退化。历史失败只限定于该共享配置。
本轮落实Gemini4的条件主效应启发，保留端口、方向和二维背景。

## 假设与表示

冻结D64+Q4及R8，定义远域近轴为qx+qy>3且(qx<2或qy<2)。
为避免exp633的横纵状态共用校准值，将其分为`qx=0,1`及`qy=0,1`
四个互斥状态；再按长轴商分四桶。qx短状态的qy桶为
`[4,8),[8,16),[16,32),[32,46)`；qy短状态的qx桶为
`[4,6),[6,8),[8,10),[10,12)`。保留完整pair与方向，桶内跨120种
余数phase拟合一项；D64/Q4继续提供原phase和二维响应。

每个`pair×direction×state×bucket`存一个有符号int8修正，
矩形上限3,833,856B。查询只在远域近轴启用；`forced=1`与近域及其他
远域保持原输出，复用exp632的补偿证据。新增ELF净表预算小于当前
8,952,808B余量，代码、对齐及最终ELF另核。

## 固定原型与停止条件

四方向使用完整208源、288目标、120 phase认证名义场。拟合网格为
qx短状态各取qy=`4,8,16,32,44`，qy短状态各取qx=`4,6,8,11`。
分离验证网格为qx短状态各取qy=`5,12,24,40`，qy短状态各取
qx=`5,7,9,10`；训练与验证商点无交集。认证场有历史使用，结论称为
网格分离验证，不称未见数据验证。

对每单元汇总训练商点与全部phase的当前整数背景残差，以
`1/(128+125qx+125qy)`加权整数L1中位数为拟合值，再限制至int8域。
中位数并列选`(损失,绝对值,数值)`最小者。记录支持数、饱和数、
各状态与桶内前后损失。先做单方向，再按固定方案完成其余方向。
每方向分离网格总L1至少下降2%，qx短、qy短两组均至少下降0.5%，
训练网格不增加，且无单桶损失上升超过1%；任一方向不通过则停止
该完整表，不更换桶边界、阈值或编码。

四方向过门后，对exp501完整1M使用冻结exp576折外R8和Q4/T背景，
仅在`forced=0`远域近轴应用表。主Acc增益至少+0.02pp，26源族
bootstrap9999次95%下界>0，distance/near_axis组下降不超过0.03pp，
方向和四状态各自下降不超过0.05pp；固定seed20261023634。
`forced=1`、近域、其他远域逐行保持。该开发集已多次使用；通过后
还须冻结候选并生成未参与选型的新全端口唯一1M验证，才评价完整CPU。
