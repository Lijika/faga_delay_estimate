# 实验309 状态解码倒数乘法与一次修正

## 预注册

2026-10-16。exp305的32位除法100k节省1.788491%，本轮在
该私有源码上只改状态解码，用初始化时的ceil(2^32/N)乘法和
一次比较修正计算商，再由原编号求余数。N来自实际Z端口数量，
全局编号、队列全序与局部标签保持，通用O2构建。新增两个标量
保存N和倒数；空端口初始化保留为零，合法解码仅接收N>0状态。

理论见vault《整数倒数乘法的一次修正解码》，已证明uint32域
商的初值至多高1，uint64乘法保持精确。夹具直接调用候选
stateCell，普通与ASan/UBSan覆盖官方全域、N=1、非二次幂、
INT_MAX、UINT32_MAX及100k随机值，并确认修正分支被触发。
97,200条搜索记录、895,251条路径边和八组完整样本输出须与
exp296相同；任一差异保存证据并停止性能测量。

固定两臂baseline为exp305 narrow、reciprocal为新增实现。
Xeon core3串行，exp297原序20k/100k，两臂预热后AB/BA/AB
三轮，共16次。100k完整user+sys为主指标，df2 Student-t
95%配对区间加两端0.02 s舍入；差区间下端<=0保留完整1M
资格，0.5%只记效应，AMD时间只作成本。精度与CPU关联同次
输出，按输入、标签、SHA复用精度，差0 pp、变化行0。

逐次检查输出契约、完整SHA、多次一致、单线程、RSS<=2GB、
CPU/wall<=3600 s。算术、构建、审计、估计分别记成本，新增
评分和exact为0。范围为私有legal_path_search两文件、测试和
实验记录；原型不增加依赖。原序前缀全量exact、完整1M、
100M/1B、跨架构与官方平台另验。开工磁盘405GiB，收尾复查。
