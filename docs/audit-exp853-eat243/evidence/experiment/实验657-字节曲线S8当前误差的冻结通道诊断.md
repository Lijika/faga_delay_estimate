## 主假设与接合点

Gemini4第2.2、3.4、5.1、6.1及6.3节提出误差分工。当前背景已由
Q4变为共享二维字节曲线，残差已由普通R8变为对称S8；报告中的旧
份额需要重新测量。复用exp632完整整数分解，优先判断剩余背景表示
与真实地图状态各自的研究空间及补偿关系，保持全部生产数值函数。

令N为首Net对齐名义值，B为exp654曲线背景，F为mandatory，D0为
无Line真实距离，y为真实标签，P为原exp640折外S8与B的整数预测。

```text
b = B-N
h = P-B-F-(D0-N)
l = D0+F-y
P-y = b+h+l
```
