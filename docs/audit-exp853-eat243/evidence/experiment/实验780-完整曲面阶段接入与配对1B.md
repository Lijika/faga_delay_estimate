# 实验780 完整曲面阶段接入与配对1B

任何本轮1B结果前固定。候选沿用exp779的静态ELF与全部模型，
基线固定为exp728。实现、模型与有效208源×288目标角色域保持。

## 阶段接入

exp779独立审核确认100M预登记联合门通过后，在r9清洁目录仅放
候选ELF，以空环境运行同一完整100M。核对静态链接、ELF<100MB、
单线程、RSS<=2000000000B、CPU及wall<=3600秒和完整输出SHA。
SHA相同复用已核验的完整输出契约和同次精度。
通过后立即写入不可变100M阶段目录，刷新根入口、latest和submission.zip，
再执行完整1B。99%和100秒为最终目标，阶段接入采用本轮联合收益。

## 1B确认条件与停止

在资源、契约和独立复算通过的前提下，要求1B观测CPU节省>0、
配对Acc差>0，实际综合分差至少0.02；
另报告给定本次CPU差时、仅考虑精度97.5%区间的条件下界，
并要求该下界>0。该条件下界不能解释为含计时不确定性的联合区间。
100M联合门仍是阶段选择的统计证据。

通过后写入新的不可变1B阶段目录并刷新指针。若1B与100M的联合
改善方向不一致，保留全部证据，恢复exp728指针并分析原因。
报告距离、方向、事件与源/目标族误差，最短距离退化完整披露；
本轮分组无新增接入阈值。当前精度不足99%继续研究恢复机制。
