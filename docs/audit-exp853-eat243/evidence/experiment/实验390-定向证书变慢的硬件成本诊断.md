# 实验390 定向证书变慢的硬件成本诊断

2026-10-17，在新硬件计数前登记。exp388固定10字节表示在公开唯一1M三轮
比exp354增加6.143333秒，初始化日志仅增加约0.2秒。exp389原值加8位阈值
已通过表示与覆盖先导；先诊断在线成本，再决定其完整计时投入。

按当前代码预先排序三项竞争假设。第一，原全域资格在同格后继间共享，
新定向资格随源Z变化，分支错误预测增加。第二，10字节行与更大工作集增加
cache miss。第三，差分恢复和寻址使instructions增加。计数仅用于解释整程序
变化，单个事件的变化不单独证明因果。当前只有一次配对诊断，无统计区间。

复用exp388冻结exp354控制与10字节候选ELF、公开非重复完整1M及输出参照。
Xeon核3串行，先各自20k预热，再control、candidate固定顺序各一次完整1M。
perf stat记录cycles:u、instructions:u、branches:u、branch-misses:u、
cache-misses:u，保留事件有效运行比例。输出契约及完整SHA继续核实，
time单列CPU、wall、RSS；单线程身份复用已通过的同ELF证据。
资源保持2GB和3600秒。本轮不产生新的正式性能资格或阶段成绩。

若权限或事件不可用，保留失败证据，换成现有cycles采样分析；
若采样亦不可用，记录该证据缺口。不得填零当作有效计数。
标签与评分复用同次输出SHA，新增exact及评分0。
原始证据validation/results/exp390，输出build/exp390。开始本机386GiB，
远端163GiB，结束记录空间和删除量。

candidate108.16秒；RSS分别1,669,664,768和1,837,821,952 B。

第一、第二假设得到关联证据；第三假设预测的指令总数增加没有出现。
减少四槽计算的收益与额外分支失败、cache miss同时发生，整程序更慢。
本轮单对计数无法分配各事件的因果耗时，也没有新的正式计时区间。
结合exp388三轮明确退化，定向证书类微调降为备选，暂停exp389完整计时扩大。
