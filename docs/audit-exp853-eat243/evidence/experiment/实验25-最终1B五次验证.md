# 实验25 最终入口的 1B 五次验证

本轮使用最终 `./estimate`，默认 mult2、source-short 150、冻结 xgb 和 64 MiB 缓存。五次 1B 均通过完整输出验证，平均 CPU 为 679.322 秒，输出完全一致。估计器与每次输出验证串行执行。

## 输入与制品

输入由公开 1M 请求按块重复 1000 次构成，表头只写一次，共 1,000,000,000 行、35,394,616,008 bytes。它含 1M 个不同 key，顺序为固定重复块。生成器只读取请求和架构，golden 只供最终离线评分。

最终 binary 的 SHA-256 为

```text
92a7631979c12976ad0fd94b9567de5b86f99aca4242385929a0abcda5d8b007
```

输入 SHA-256 为

```text
8174755d4094b9015b710fe5967a0a835c19b8c1160880e76ea1a050e571f409
```

1M 参考输出由同一个 binary 重新生成，SHA 与实验19C、24一致，为 `c5ba12aeb6c2c5d921f4515e91759b9c132679dbae70f73d68e5635535946e61`。本次重建 CPU 为 48.36 秒，峰值 RSS 为 903,608 KiB。输入、参考和当前输出保存在 `build/final-scale/`；逐轮资源及验证 JSON 保存在 `validation/results/exp25-1b/`。

## 五次运行

| 轮次 | user+system CPU | GNU time wall | 峰值 RSS | 观测线程数 | 一致块 |
|---|---|---|---|---|---|
| 1 | 672.85 s | 674.64 s | 903,596 KiB | 1 | 1000/1000 |
| 2 | 679.24 s | 685.98 s | 903,628 KiB | 1 | 1000/1000 |
| 3 | 674.57 s | 683.52 s | 903,636 KiB | 1 | 1000/1000 |
| 4 | 692.19 s | 695.75 s | 903,736 KiB | 1 | 1000/1000 |
| 5 | 677.76 s | 690.77 s | 903,740 KiB | 1 | 1000/1000 |

五次平均 CPU 为 679.322 秒，平均 GNU time wall 为 686.132 秒。峰值 RSS 为 903,740 KiB，即 925,429,760 bytes，低于 2 GB 预算。每次退出码为零。

每轮输出验证一次读取完整文件，同时统计行数、逐块比较、检查精确 EOF 并计算哈希。每块的 From、To、delay 逐字节等于 1M 参考；通过后才开始下一轮覆盖。五次完整输出 SHA-256 均为

```text
cb64ba261083ea345bd2a62d7de406f8651e6913ce14618015d6d838c00e2c3f
```

输出为 40,332,864,014 bytes。每轮缓存命中 999,000,000 次，unreachable、malformed、fallback 均为零。生成数据、输出验证和 runner 自身的 CPU 单列，估计器 CPU 采用 GNU time 的 user+system，并包含启动及建表。

公开 1M accuracy 为 96.116008，重复块保持该准确率。时间分为 62.259889，一致性分为 100，代入赛题公式得到本机重复输入综合分 91.231790。该分数采用本次 1B 的五次平均 CPU。完整汇总见 `validation/results/exp25-1b-summary.json`。

公开 1M 含一条 golden 为零的同 pin 请求，预测也为零，沿用本地约定给 1 分；该行在 1B 中重复 1000 次。题目公式的零分母处理尚未明确，MAPE 继续只使用正参考。

## 复现

完成构建后可按以下命令串行测量。生成 1B 输入和保留一个输出约需 76 GB 磁盘空间。

```sh
python3 scripts/run_consistency_runs.py \
  --binary ./estimate --arch doc/eda比赛文件/arch \
  --input build/final-scale/requests-1b.csv \
  --input-meta validation/results/exp25-input-1b.json \
  --output build/final-scale/output-1b.csv \
  --work-dir validation/results/exp25-1b --runs 5 \
  --mode repeated --reference-result build/final-scale/reference-1m.csv \
  --block-rows 1000000 --expect-rows 1000000000 \
  --json validation/results/exp25-1b-summary.json
```

运行前的 `reference-1m.csv` 必须对应同一 binary 和默认配置。每次运行的 JSON 记录 binary SHA、输入元数据引用、文件大小、开始结束时间及观测线程数。

## 评测范围

时间分按五次平均 CPU 与 1800 秒计算，内存预算为 2,000,000,000 bytes，单次运行失效时长为 3600 秒。这里报告本机与公开请求重复分布下的结果。100M mixed 的独特后缀成本另见实验23，全独特 1B 和赛方目标机尚未测量。

## 交付目录与入口

独立工作目录的首次两参数调用暴露了交付目录缺少 `arch/` 的问题，程序退出码为 3。根目录现已增加相对链接 `arch -> doc/eda比赛文件/arch`。从自身没有 `arch/` 的工作目录调用根 executable，仅提供 `-in` 和 `-out`，五条输出与最终参考逐字节一致。

`build/submission/` 包含最终 executable 和实际复制的五个 JSON，可整体搬移。包内 executable 与五次规模测试的 SHA 相同，架构目录逐文件比较通过。包内入口也从独立工作目录执行了五条请求，退出码为零，输出与参考逐字节一致。布局修复保留了生产 binary，详细入口记录见 `validation/results/exp25-cwd-check.txt`。

## 原始基线比较

原始 `build/estimate-baseline` 在同一输入上另跑一次，CPU 为 633.47 秒，wall 为 639.49 秒，峰值 RSS 为 417,908 KiB，观测线程数为 1。1000/1000 块等于原始 1M 输出，完整 1B 输出 SHA 为 `5123cd590d9db652371301a9d6bf956d3756943587c070796ca34845672e7e3e`。

| 指标 | 原始基线 | 最终默认 |
|---|---|---|
| accuracy | 91.621356 | 96.116008 |
| CPU | 633.47 s，单次 | 679.322 s，五次平均 |
| 时间分 | 64.807222，单次代入 | 62.259889，五次平均 |
| 综合分 | 88.018168，假定一致性100 | 91.231790，五次验证 |

最终 accuracy 提高 4.494652 个百分点，时间增加 45.852 秒。精度项增加 3.595722 分，时间项减少 0.382100 分，两项净增 3.213622 分。原始基线这次只测一轮，表中综合分是时间比较的筛选值；原始五次 1B 的一致性仍未验证。

原始 1M 参考已从根结果保存到 `build/final-scale/baseline-reference-1m.csv`，SHA 为 `3044018c4eb5818a411a66c178aa62394d4e72c7c6edb10e5a65789fefec762f`。根 `delay_estimate_result.csv` 已更新为最终 xgb 的 1M 输出。当前 `build/final-scale/output-1b.csv` 最后由 baseline 写入，最终五次的逐轮哈希与验证记录保留在 JSON 中。
