# 实验588 冻结方向背景候选的独立全端口1M

2026-10-22，生成请求和查看标签前登记。当前goal要求acc严格大于98.2%
并留余量，完整未知非重复全端口1B CPU100至300s。本轮验证精度泛化与
完整1M工程契约，1B目标继续等待对应规模实测。

## 冻结与假设

exp589两套已用全端口唯一1M均通过预登记联合门。固定D64，其两套数据
综合指标点值和95%下界均最高；D96与N768D64保留历史帕累托记录。
本轮只运行冻结D64和N512；新请求结果用于验证，后续选型将其归入已用域。

- D64静态ELF76,629,272B，SHA为
  9a62a79901bbd0d1c9b1256efd67359dc1872e0a467808199ef5a4a52375b667。
- N512静态ELF75,932,952B，SHA为
  35e7856e096bb2e44bfba15ab2660b6c3adfa785de195a99627f5383809b0f03。
- 五架构、R8、特征、近域背景与输出契约复用exp589冻结身份。
- 新请求生成seed20261022588，shuffle seed20261023588，规模1,000,000。

## 数据与执行

复用exp501的U-role生成、独立合法/可达/唯一性检查、全59904端口对检查、
四分片exact离线标签与合并核验。生成前排除历史exact集合，显式包含r9
research下的exp501、exp562、exp580标签及公开golden。记录各文件身份、
合并已知请求数及交集；完整1M输入唯一性与历史标签交集分别记录。

算法执行、评分、数值审计与计时只在r9指定工作目录。l7仅执行四份离线
exact标签任务；每份单线程，离线总资源另计。冻结校验在传输后再次执行。
候选输入始终为完整1M，标签分片用于离线计算。

## 指标与停止条件

完整最终整数输出官方acc点值及26源族2000次bootstrap95%下界均严格
大于98.2%。对N512的配对acc差至少+0.02pp且95%下界>0，距离、近轴
各组下降不超过0.03pp；同架构新请求支持同架构泛化，隐藏分布另待平台。

CPU预热一轮、六轮正反交错完整CLI，同机串行并避开重负载。综合指标
0.8*配对acc(pp)-1000*新增每1M CPU/120，点值至少0.01、95%下界>0。
倍乘1000仍为成本外推。使用exp586既有配对分组/计时bootstrap实现，
绝对acc区间采用seed20261022588的源族bootstrap。

逐项验证单线程、RSS<=2,000,000,000B、CPU<=3600s、核内分配0、
精确EOF、端点与行序、整数delay、3字段和完整行数。预热和六轮输出
完整SHA一致，ELF静态且严格小于100,000,000B。代码和资产未改时复用
exp589原生逐位审计；任何身份变化先停止。

全部门通过后保留D64进入10M，10M取得明确联合收益后再扩大100M。
失败固定候选停止扩大；本轮数据随后归入开发域，再验证需另生成新请求。
正式入口与提交包在工程验收和正式打包之前保持exp580身份。

## 完成结果

全部门通过。独立1M全部请求唯一，覆盖59,904端口对，每对3至34条；
与登记历史标签及开发请求交集为0。该结论未覆盖所有未标注1B输入。
D64完整输出acc为98.333506862%，26源族bootstrap的95%区间为
[98.278851385,98.386261458]%，相对N512提高0.174306495pp，
配对区间[0.165978638,0.182574409]pp。四距离组变化依次为
0、+0.239230145、+0.185898707、+0.116341291pp；近轴组提高
0.200539702pp，内部组提高0.159477239pp。

预热后六轮D64完整CPU为0.431260、0.430870、0.429714、0.428337、
0.431160、0.428590s，较N512增加0.0025125s/1M，95%区间
[-0.000050891,0.005075891]s。综合收益按1B外推为0.118507696，
95%区间[0.104896260,0.136921276]；这里的1B CPU属于外推。
完整输出契约、单线程、资源、查询内分配0及七轮完整SHA一致均通过。

四份l7离线标签CPU合计3880.29s，单份wall为962.98至975.51s，
与上述完整估计程序CPU分别计入。原始证据为evaluation.json、各份
labels-*.time与冻结输入/模型身份。r9结束空闲1,179,197,440B，
测试输出仅保留首份，同SHA副本已逐项记录重建命令后删除。

D64保留进入10M，正式提交版保持exp580。本实验只证明所测同架构新
请求的精度及1M工程行为；隐藏分布、100M和1B需各自实测。
