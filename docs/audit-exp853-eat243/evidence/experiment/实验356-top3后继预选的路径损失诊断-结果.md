# 实验356 top3后继预选的路径损失诊断结果

2026-10-17。历史12,150条请求中，baseline有10,346条有限结果。
policy3在其中235条费用更高或失败，这235条全部至少丢失一条原路径内部后继。
本样本支持先研究分支删除的影响。保留全部原边的10,005条有限路径均保持原费用，
该观察的适用范围限于这些开发请求。

## 路径与局部排序

探针检查baseline的126,462条边及policy3的128,325条边，
核对真实Net、Arc、I目标折叠、预选前三名编码、原四角数值及逐条身份。
policy3全部路径通过保留资格，384条跨头部、中部和尾部的ASan/UBSan结果与完整诊断相同。
对统计使用独立CSV汇总，并重新核对冻结输入、架构、源码、对象及正式产物。

因此单独修正舍入排名覆盖范围较小，保留低Slack后继更值得做下一项原型。
67条请求虽丢失原见证仍找到同费路径，另有39条得到更低费用，说明特定路径保留与最终质量应分别验证。

## 下一项与边界

先固定top3加25 ps Slack候选，与原top3单项及exp354工程基线比较。
保留预算480、权重1010、真实路径重放及原回退模型，只改变后继资格。
25 ps可恢复194/235条原路径的静态存在性，实际搜索精度、生成工作量和CPU待测。
当前数据没有全部展开的后继记录，以上比例只用于解释路径损失。

诊断样本含I目标，整体与U-output/U-role的合法端口分布分别解释。
没有新增exact标签、完整估计器计时或精度评分。100M测量继续由exp355串行运行，
本轮没有有效阶段成绩。正式入口和交付包保持exp354。
