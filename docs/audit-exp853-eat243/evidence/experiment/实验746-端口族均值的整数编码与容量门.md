# 实验746 端口族均值的整数编码与容量门

2026-10-27预登记。exp745的rank16/32/64名义评分分别提高
0.292614/0.508447/0.603052pp，Q6均值压缩投影120528240B。
本轮只把每个族均值按floor(mean+0.5)变成整数，复用全部已冻结因子，
检验均值的分数位在精度和压缩容量中的成本。

全部输入、两phase范围、整数点积与最终舍入规则沿用exp745。
每项均值偏差至多0.5ps；固定因子时，最终整数背景逐项改变至多1ps。
完整核对这一界，以及同一两个Zstd level9编码的回读。候选仍为
rank16/32/64，采用相同的0.20pp、加权L1至多0.70、双phase正收益、
双短轴下降至多0.03pp和静态投影严格小于100MB的门。

有通过项时选最小rank，直接进入全部方向和phase资产、匹配残差与
完整非重复100M验证。100M通过联合收益及交付门后及时接入阶段版，
运行完整1B并据同次CPU和Acc更新正式交付。若全部失败，只结束当前
整数均值、固定因子和编码组合。

算法计算在r9进行，复用research/exp745中的数组与因子，新增私有
build/exp746，离线CPU300秒、wall600秒、RSS8GB、磁盘100MB。
该轮是结构组件验证，全部结构点参与编码评价，新请求泛化另验。
原始证据保存validation/results/exp746，本地开工约273GiB，
r9约34.8GiB可用。无新增exact标签和完整estimate运行。
