# 实验812 互斥商域残量的单目录乘积编码

2026-10-29，预登记。exp810在l7构造，exp811在r9生成新exact；
本轮在本地做独立表示机制筛选，保持exp811候选与验证规则冻结。
最终目标仍为未知非重复全角色1B完整CPU约100秒，Acc严格大于99.1%。

## Altitude

exp803的轴加性式丢失qx与qy交互；exp802的两份目录容量超限。
本轮保留原A2048完整曲面，将B残量按互斥商域分别选码。
近轴qx<2为64码、远轴qx≥2为32码；同一uint32保存10位C、
11位A、6位近码及5位远码。每次查询仍读取一个A和一个B值。
这改变共享形状的组合方式，同时影响精度、静态熵和缓存工作集。

四方向B正文由1,130,496B变为164,864B，运行目录保持115,015,680B。
组合可表达64×32种形状，和旧256条完整B没有包含关系；
实际收益是待验假设。在线新增域判定和位提取成本在未来完整运行测量。

## 唯一候选与机制门

1. 原exp777方向0的26,624条构造曲面，A码与尾偏置保持。
   使用原整数几何权重，在两个域分别训练B，域外格和权重均置零；
   原中位数更新、零码和四轮重分配保持。种子20261029812。
2. 沿exp807方向0的8,320条非构造曲面，核对构造交集为0；
   该样本已被观察，结果仅作机制开发证据。
3. 两个域各自选B码后，按exp808同区间规则重估共同C。
   基线为原A2048/B256经过exp808偏置重估后的函数。
4. 原基线L1逐项复现；原生assign与独立重建一致，
   新uint32逐字段还原，候选全格整数值与分域解码相同。
   对候选偏置独立核对加权中位数两侧质量及边界最优性。
5. 全部加权L1至少下降5%，近轴和远轴各不恶化超过0.5%才扩大。
   失败停止此固定6加5位、四轮训练配置；同时保存共同偏置重估前后的损失。
6. CPU≤600秒、wall≤600秒、地址空间≤4GiB，不生成新exact，
   完整estimate运行0次。通过后再做四方向、匹配残差、全域容量和100M/1B。

## Tactical与Depth

互斥域只有一个B值参与当前查询，两个B码可以同时存于既有目录中。
固定偏置时，两域L1最小化可以独立选码；偏置变化后该最优性前提改变，
本轮固定一次选码再调偏置。目录多用三位信息，静态压缩率须单独验证。
结果保存validation/results/exp812/，理论见Obsidian对应笔记。

## 结果与停止范围

固定候选总加权L1由1,164,769,147,405降至1,126,626,185,788，
改善3.274722867%，低于预登记5%门。近轴改善3.495884705%，
远轴改善3.015122404%。保持此门，停止该6加5位、四轮配置扩大。
偏置重估前损失为1,153,640,240,394，表明形状选码与偏置各有贡献。

独立审核重算8,320条曲面的全部损失、字段恢复和偏置最优性；
对每31行的一条，共269条枚举两域全部码，选码最优性通过。
本地CPU11.145484658秒、wall7.572950578秒、
RSS2,028,048,384B，符合本轮离线4GiB资源门。
这些资源属于离线构造；完整estimate、新exact和最终Acc均未运行。
该结果限制当前码数分配和构造方法，其他互斥分域的精度、
压缩容量与查询成本仍属开放问题。
