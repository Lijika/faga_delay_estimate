## 假设与固定候选

exp92 冻结预测的剩余评分损失可由在线量预测，固定 exact 行预算下，损失排序优于相对修正量代理。
仅训练一个 XGBoost `reg:squarederror` 损失回归器，64 树、depth=4、eta=0.1、hist、max_bin=256、min_child_weight=1、gamma=0、lambda=1、alpha=0、subsample=colsample_bytree=1、seed=20260919、nthread=1。标签为 `1-point_of(exact,exp92)`；负 exact 的延时损失记0、可达性单列。每个训练窗口的样本权重为其距离带总体数/抽样数，两个窗口等权，归一化均值1。标签已含相对评分尺度。

排序特征固定为现有44维中的34个非 tag 量，以及 exp92、修正量、绝对相对修正量、7带 one-hot，共44维。所有 tag 槽均移除。在线原料只含 off、xgb、端点及端口元数据、位移、距离带、Line 交叉基础量。`off` 是未加残差和统一-3ps之前的 base 估计，即 `-residual off -bias-ps 0` 输出；`xgb` 是 exp92 最终输出。基线代理为 `abs(xgb-off)/max(abs(xgb),abs(off),1)`；off<=0 不触发。模型预测为负时夹0，并列按固定端点键。

## 指标、统计与阈值

预算固定 `k=5,000/20,000/40,000` 每1M。令可达行损失为 `l=1-point_of`，负 exact 损失为0；`C(k)=100*sum(selected*l)/N`，分母N为总请求数。另报以可达行数为分母的 accuracy 增益，两类可达性误判单列。效率按用户定义 `eta=C/C*`；附随机基线 `k*L/N` 及扣随机后的效率。

开发阶段采用七带语料权重，对已有样本做加权 top-k/N 捕获估计，边界样本按比例纳入。这是筛选估计；oracle `C*` 同样是加权样本估计。分别报告两个开发窗口和等权合并结果。开发进入新窗口要求 k20k 合并点增益>=+0.03pp、两个窗口点增益同为正、k5k合并点增益>=0。开发区间使用固定选择权重的七带配对 bootstrap，10,000次、seed20260925，仅作诊断。

通过后从开发数据冻结 k20k 的流式阈值和并列 hash 规则。新窗口先计算全部无标签分数，冻结候选/代理 top-k 集合及各预算边界上下20%的补标集合；选择并集全部 exact。另由固定七带随机样本估计总损失及 oracle，给10,000次分带配对 bootstrap 区间。所有 exact 输入及规则身份在标签前记录。条件于冻结选择的捕获区间与重新选择的不确定性分别注明；补标边界不足以完成重采样选择时停止正式判决。

新窗口主门槛为 k20k 相对同窗口代理合并增益>=+0.03pp、配对95%下界>0、两个1M方向一致，k5k点估计不退化。流式阈值另外报告实际触发率及捕获，触发率偏离2%超过相对20%则停止接入。可达性误判不得增加。conformal 仅监视阈值。

冻结流式规则为 score 大于阈值，或等于阈值且端点hash不大于边界。排序器阈值 `0.14064791798591614`、hash边界 `7757874365851515325`；代理阈值 `0.056155506521463394`、hash边界 `589040183458983557`。开发触发率分别为2.000012744%和2.000174585%。不依新窗口标签修改。

新窗口补充固定实现细节如下，均在标签前确定。

- 每个1M、每个选择器对前48,000行全标注，覆盖三个预算及各自20%边界；另加冻结流式触发行。七带随机样本各取 min(512,带总体数)，seed20260925，两片按顺序使用同一RNG。
