# 实验405 无跳格两阶段核心的真实DAG

2026-10-18，新结果前登记。正式exp354，CPU发布基准exp323。
主假设是固定桥后，同象限两核心的累计次数可确定实际位置，
把词序和次数分配放进两阶段DAG可改善exp404剩余的几何误差。
竞争解释是桥长或核心数量的费用限制仍占主要部分。
理论见Obsidian《无跳格双核心的累计次数分层DAG》。

控制为exp404真实候选选择的77条合法路径，54条费用≤exact的101%。
新增族保留同一批B4/B1桥与同象限方向，允许所有单调核心词及全部次数分配，
逐Net要求真实合法且实际位移等于名义位移；已有控制路径继续保留。
桥候选完全由架构产生，控制U由合法路径给出，exact只用于事后质量核对。
固定桥时，状态(stage,i,j,last)给出唯一实际位置，
第一阶段为S+bL+(signH*10i,signV*12j)，第二阶段再加bM。
普通转移消费一个L Net；阶段切换接内部桥并消费第二核心首Net。
两核心均非空，完整Arc、Net、Line费逐项支付，位置无跳格条件逐项核对。
以i+j为拓扑次序，固定桥时间与空间均为O((NX+1)(NY+1))。

名义最小Arc J加两实际端点强制Line L≥当前合法U时跳过DAG。
DAG状态已付实际费加固定后桥费≥U时停止该状态，等费保留控制。
前2条关闭两项筛选重算所有候选，最终费用与稳定见证须保持。
普通全77条、sanitizer前4条，费用、见证、计数逐项相同。
所有名义候选数与原费用继续与exp402比较。

小次数自检采用B1中id每15项取1项，并将零跳桥每4项取1项，合并去重。
四象限下保留桥首末方向均属于该象限的项；两核心首末余下方向全部2×2组合，
NX、NY各取2与3，实际起点(40,30)、(70,40)、(95,140)、(70,50)。
独立穷举所有二元方向词和每个非空内部切分，逐Net真实重放，与DAG费用比较；
普通与sanitizer均运行该自检。记录实际测试数与完整词数。
同分量零跳桥样本还核对单核心DAG与全部方向词枚举。
全量运行中至多前8个严格改善当前费用的DAG候选，用独立Python真实图Dijkstra核对其最小费用，
该对照保留实际坐标、端口和阶段，逐Net排除跳格，使用正权堆求最短。
最终77条见证独立Python重放，改进行核对无跳格与完整名义位移，
费用加1、实际目标横移1的负对照须拒绝。

主指标为全77条真实同端点且费用≤exact的101%的数量，
相对54条至少增加5条则保留该表示；90%作为恢复参考。
同时报告≤0.25%、≤0.5%、exact数、费用改善行、象限、候选量、
进入DAG、DAG状态与转移、resolver及跳格拒绝数量。
开发比较使用确定性配对描述，完整总体acc与新请求泛化另验。
初始化、输入准备、选择CPU、完整进程与checker成本分别记录。
本机计时仅作诊断，单进程CPU≤120秒、RSS≤2GB、单线程；
sanitizer放开虚拟空间并检查RSS。任一语义、见证或资源失败保存并停止扩大。

冻结协议、源码、私有生成源码、输入和控制见证后运行。
新增完整估计器CPU、全图exact和总体acc均为0。
