# 实验791 固定曲面码预算的近轴权重重分配

2026-10-28预登记。正式版为exp780；exp787的B1024候选在
100M相对正式版提高0.044353431pp，但综合门未过。exp788显示
`qx=0,1`只占30.2721%请求，却承担完整行教师与曲面码差距的
59.7733%；exp789共享均值、exp790单标量/单符号均未恢复该形状。

## Altitude 与主假设

当前瓶颈同时包含信息分配和访问预算。扩展主体码本使LLC miss
增加，新增在线修正又增加一次随机读取；本轮只重排已有B1024的
训练价值，不改变32bit目录、码本大小、查询次数或ISA路径。
假设当前几何权重对全552列的分配没有完全匹配最终请求损失，
对B级残量的`qx=0,1`列提高训练权重，能在相同热集预算内减少
主要短横轴形状误差，且远轴退化可由最终分组门约束。

## 固定对象与候选

保留exp787的A2048、四方向训练曲面、随机种子、四轮加权中位数、
零码、tie规则、目录布局和匹配模型参数。只重训B1024；A码、
偏置、输入、模型特征与整数解码不变。

exp777原权重在认证曲面的`qx=0,1`列占总权重38.1529%；
exp788中这两列对应的请求组承担59.7733%的可部署教师分差。
若将这两个不同测度的份额仅作预算启发，赔率比给出
`alpha=[.597733/(1-.597733)]/[.381529/(1-.381529)]≈2.4`。
该比值不证明最优评分权重，也不证明二者总体相同，故只冻结
`alpha=12/5`一个候选，不做倍数网格搜索。对B训练和B码重选时，
将`qx=0,1`的46点列权重乘alpha，其余列保持exp787权重；使用
整数四舍五入并检查无溢出。

## 信息门

先在每方向8192条未参与构造的名义曲面上比较exp787 B1024与
候选B1024：

- `qx=0,1`加权L1合计相对下降至少1%，任一方向不恶化超过0.5%；
- 全部552列的exp777原权重加权L1合计不恶化超过0.5%；
- 训练目标四轮单调，码号和int16范围合法，资源满足exp787离线门。

信息门通过后才重建百万背景并以相同source-pin折训练匹配
普通/H/V残差。开发评分相对exp787 `Q1024+匹配残差`提高至少
0.02pp，`qx=0,1`各组不下降，方向最低不低于-0.05pp，H/V
最低不低于-0.25pp；否则停止该固定倍数族，不做全域构造。

开发集只用于机制筛选和模型选择，不能作为未知请求保证。任一
通过候选仍须复用现成非重复100M，完整程序输出契约、SHA、单线程、
RSS与CPU配对门通过后才可进行1B和阶段接入。

## 证据边界

本轮不增加exact标签，不宣称qx条件权重等价于最终评分权重；
几何权重只是B码训练代理。若信息门改善而最终评分无改善，结论
归因于曲面码与残差失配或整数舍入；若最终评分改善但100M CPU
退化，保留为精度候选，不进入正式版。

脚本与结果保存于`validation/exp791_qx_weight.py`和
`validation/results/exp791-run3/`；r9私有构造目录复用exp787资产。
首轮远端启动误用`rm -rf`清理了`validation/results/exp791/`与
`build/exp791/`，因事前未检查目录状态，无法证明原目录为空；
脚本随后因协议文件未同步而在写冻结文件前退出。第二次运行使用
`rm -rf`清理`validation/results/exp791-run2/`与`build/exp791-run2/`
后，再次因协议文件位置错误在冻结前退出；这些路径原状态也未核验。
后续运行使用独立`exp791-run3`路径，不覆盖前两次目录或exp787资产。
