# 实验401 双单调核心次数分配的边界求值

2026-10-18，新语义、容量和性能结果前登记。正式exp354、CPU发布基准exp323。
exp400指出当前固定名义单核心族的费用限制，下一步先降低双核心的分配成本。
消费方仅为私有名义组件，不改生产、交付和默认配置。
理论见Obsidian《双单调核心分配的差坐标边界最小化》。

主假设是固定内部桥和完整首末端口后，两核心费用只在少量差坐标阈值处改变，
用矩形交与至多20点求值代替全部x,y分配枚举，可保持费用并减少CPU。
竞争解释为公式分支和参数读取占主导，或纯轴、小次数边界破坏推导。
不同矩阵、首末方向和象限的分支预先编译。候选与控制都消费相同预加载参数。
内部短桥费用和位移在本轮提出，桥选择、真实几何与完整请求质量另验。

普通及ASan/UBSan自检使用官方8矩阵和正、零、负C合成3矩阵的全部11×11对，
四象限、16种两核心首末方向组合、NX∈{0,1,2,3,4,6,12}、
NY∈{0,1,2,3,4,7,46}，共379,456项。
完整x=0..NX、y=0..NY枚举为对照。两核心均至少消费一个Net，以I为终端。
费用及稳定分配次序(费用,x,y)须保持，纯轴、两核心之一单Net和不可行单列。

固定种子202610180401，在8×8×4×16×13×47名义参数空间中
无放回选1M不同键。普通全量等价，sanitizer前4096项。
前128项有限查询用独立Python DAG枚举全部分配复核费用与获胜分配。
每个获胜分配恢复两个L词，独立核对次数、首末方向与Arc费；
费用加1及总NX加1负对照须拒绝。
任一语义或见证差异保留反例，停止扩大。

性能为同ELF双实现，各预热1遍，3块交错，每块遍历完整1M一遍并改变循环起点。
主指标为混合1M组件ns/次及配对CPU差的df2 95% t区间。
点估计省至少1%且差区间上界低于0称明确组件收益；其余保留待定。
本机AMD仅描述，Xeon核3、通用O2单线程串行为主要比较。
初始化、输入解析、编译与校验单列，计时不消费完整请求缓存。
1M输入为不同名义参数，完整估计器1M、10M、100M成绩继续分别测量。
单个普通组件进程CPU≤120秒、地址空间与RSS≤2GB；sanitizer放开虚拟空间并检查RSS。

本轮无新全图exact、总体acc或完整估计器CPU。语义及成本通过后再检查
多核心实际桥候选的费用覆盖、选择量与真实几何。完整算法固定后使用新请求，
最终总体acc严格大于99%，争取更大余量，再按1M、10M、100M推进。
开工/dev/sdd可用385G，收尾报告清理清单及空间。
