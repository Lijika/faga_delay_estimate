# 实验204 C1 映射路径固定缓冲与源费用复用

2026-10-11，承接exp203独立精度结果。本轮为纯等价工程优化，沿用已冻结模型和
全部输入输出定义，复用exp202/203 exact。私有目录`build/exp204`，磁盘445 GiB。

## 固定假设与四臂

生成器重复扫描相同source Arc并在每条候选链分配vector，去掉这两项重复工作
可降低CPU，保留所有路径合法性、费用、32跳与1200预算检查。

- reference为exp203生成器。
- array仅把长度上限32的路径vector改为32槽stack array，按已记录hops逆序访问。
- seeds仅预计算每个源端口到每个Z的seedFee，query读取同一最小值。
- combined同时采用上述两项。

所有臂输出相同摘要。固定格式为index等8列、26 cheap列和14 path列，
共48列；所有列、行序、U、C、valid_count和最终selector预测均要求逐字节等价。
种子表为496×160个int，启动构建成本计入完整进程。

## 测量与停止

remote r9r4900，cwd `/home/lhj/lhjwork/eda2026`，GCC11.4 C++17通用O2，
core3，四臂各一次预热，再10个块，每块四臂各一次，顺序按块循环左移。
固定新请求6176行，输入为exp203 feature-input，终端全部输出到CSV，
计时包含原始298,945,600 B parent加载、端点准备、源费用构建、链恢复、
重放、摘要与输出。串行运行，过程检查单线程、RSS≤2GB、wall≤600秒。

主比较combined-reference采用df9双侧95%配对t区间。array-reference和
seeds-reference作为归因描述，同时区间使用Bonferroni两比较临界值2.685010847。
实际收益门固定为combined平均CPU至少降低3%，且主比较95%上界<0。
未达门时保留原始证据与等价构造，整体生产CPU继续待验。
此前两机特征等价不能替代本轮四臂验证；本轮标签保持不变。
