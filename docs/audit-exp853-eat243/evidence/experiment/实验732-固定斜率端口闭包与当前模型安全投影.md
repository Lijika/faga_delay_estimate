# 实验732 固定斜率端口闭包与当前模型安全投影

2026-10-25，在读取新投影收益前登记。exp731已按固定门结束。
接续exp688报告3.3、3.4、5.5和10.4节，检验认证下界能否以小表
修复当前T2D6的低估损失。生产保持exp728。

## 假设、既有证据与边界

复用exp541的四个可行斜率及完整端口势。S使用原四势的最大端点差；
C在每个重加权真实图上只保留完整端口，求496状态商图的最短距离，
再把余距加回相应势差。消费后的208源端口到288目标各保存四项，
按实际值域计费，预算载荷1MB。在线只需四项读取和固定整数运算。
真实跳格的最小边费用必须参与认证；全部原Arc、有效Net都检查。

exp543已检验更强的端口加相对余类投影，否定的是八波前带来的额外
收益。本轮更换比较模型与容量配置，明确减少抽象状态，不声称新下界
比exp543强。四角斜率覆盖可行域的历史结论，也不等价于一个固定
端口势已经取得每个端口对的最大势差。

每个商图保留真实边的端口及最小重加权费用。真实路径逐边映射后，
商图最短余距不超过原路径余距；加回势差、已执行首Net实际费用及
剩余强制Line得到安全整数下界。整数值向上取整，负余段取0。
同pin单独输出0；无效首Net和不可达不混入普通投影。

## 固定数据与指标

复用exp719/726的一百万条历史折外缓存、已核验exact、原始完整请求
及当前T2D6加V8预测，属于离线组件评估。新增完整estimate测试、
新exact和训练均为0。先核对请求、特征、标签和预测身份。

比较原A、max(A,S)、max(A,C)，并记录S/C独立预测。全部行要求
S<=C<=exact、投影绝对误差不增。保留近轴、距离、源目标族、lane、
方向、事件及延迟分组，报告各群总体损失贡献。

唯一扩大候选为C，固定继续门为载荷<=1MB、总体Acc增益>=0.05pp、
26源族重采样95%区间下界>0。9999次重采样，seed20261025732。
通过才登记静态原型与新非重复100M，联合收益门通过后接完整1B。
失败则停止当前四斜率端口投影，不增加势数、模数或表项扫描。

## 实现与资源

只新增组件脚本、证据和理论记录。复用现有加载、评分、统计与架构
解析；商图用整数Floyd闭包，并以独立Dijkstra逐源核对全部保存表项。
原始四势安全性与逐条projection检查分别保留。

远端research/exp732串行，单线程、CPU<=600秒、RSS<=1.5GB，
新增资产<=100MB。本地/dev/sdd约275GiB，远端约43.77GB空闲。
停止前记录构造、评分成本和清理量；生产和历史大文件保持。

合法路径上界分别保留研究资格，本轮没有这些方向的新性能结论。

## 执行修复、成本与保留

首次导入训练脚本因解释器缺少CatBoost退出。第二次在输入身份检查时，
发现exp726清单路径需要按exp726目录解析。两次均在算法计算前停止。
修复复用已审核的T2D6整数预测和纯NumPy统计，并按原清单所属目录
解析路径；候选、输入字节、数据划分、门槛及随机种子保持。
原始失败记录分别保存在`validation/results/exp732-startup-failure.json`
和`validation/results/exp732-precheck-failure/`。

构造、输入核对与评分记录CPU10.283309秒，其中构造阶段6.114218秒；
该进程计时从模块导入后开始，导入和两次早期失败的CPU未单列。
独立审核进程CPU3.627363秒，wall3.628652秒。两次成功任务单线程，
最大RSS1,027,579,904B，符合离线1.5GB预算。线上成本保持未测。

新增构建资产24,351,744B，主任务结束远端空闲43,748,851,712B，
本地/dev/sdd仍约275GiB空闲。本轮删除0B，小型资产与原始结果保留。
新增exact标签、训练及完整estimate运行均为0。
主构造脚本为`validation/exp732_port_bounds.py`，独立审核入口为
`validation/exp732_audit.py`。远端使用exp491的NumPy解释器，
`OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1`；主入口拒绝覆盖已有结果，
重建需按`protocol-original.md`恢复独立实验目录及冻结输入。
