# 实验820 全角色对覆盖的曲面码本构造数据

2026-10-29，查看新候选结果前登记。最终目标保持全有效角色、未知
非重复1B约100秒，Acc严格大于99.1%并留余量。当前阶段为exp811。

## Altitude

exp818、819分别检验逐键代码序列与码本内完整行的精确共享，
两者未达到固定容量门。exp817同容量联合训练在构造集改善6.1774%，
判别集改善2.9607%。这些结果使构造数据覆盖成为一个具体的待验因素。
现有每方向26,624条构造数据按208源各128条抽取，实际分别覆盖
21,495、21,554、21,519、21,590个角色对，约占全部59,904对的36%。
源端覆盖与源—目标组合覆盖分别成立，训练数据可改变而保持在线结构。

本轮仅替换exp817的构造样本方案。保留方向0的A2048/B256、
原始中心初始化、四轮联合更新、加权L1、严格改善与偏置范围。
码本正文、32位目录和两次码本读取保持其格式；全域压缩字节仍需实测。
数据同时改变样本数和分布，结果只解释这项整体数据方案，单独的
样本量效应与分层效应暂不拆分。

复读深化报告6.2至6.9、整数曲面解答13.1至14，以及测试集补充、
qa和生成规则。模型构造使用固定架构认证名义场；主测试继续采用
非I、可达、非自查询、全角色对、非重复、乱序的100M→1B阶梯。

## 唯一数据方案

对208×288的每一个角色对，在方向0的120个rx×ry上下文中
无放回抽两个，固定种子20261029820，合计119,808个完整552点曲面。
排除exp807/817的8,320个判别键，其余上下文等概率选择；
各对的两个上下文排序后按pair顺序保存。每源576条，每对恰好两条。
保存键、上下文、源目标覆盖、与判别集交集及全部资产SHA。

l7已核实保存完整exp499字段。每源解压前后核对原SHA、认证计数、
文件头、source/target映射；抽取新曲面的同时，逐项核对该源40条
判别曲面与既有缓存一致，合计4,592,640个整数。
使用相同原字段再次以展平地址核对所抽曲面，保存每源选取摘要。
输入构造完全不读取真实图exact或最终预测误差。

新数据的初码沿exp777计算，即尾偏置下顺序选择A、B，再求exp808
加权偏置。选码以32768行分块，仅改变离线调用大小；每行整数成本、
最小编号平局和完整枚举保持。四轮依次更新A中心、B中心、A码、
B码和偏置，复用exp817全部函数与训练单调检查。

## 比较、门与扩大

判别集继续固定8,320个已观察开发曲面，全部208源参与。
B为exp811背景表示，R为原中心两轮重编码，C为新数据训练的中心
及两轮重编码。R须逐字节复现exp817保存结果，C另与exp817旧数据
联合训练结果比较。固定报告原构造集见过和未见过的角色对两组，
以及qx<2、qx>=2和各源的损失变化。这些组仅作机制解释。

沿用exp817门，C相对B的判别加权L1至少下降5%，相对R至少下降2%，
近远两组各退化不超过0.5%。两个主门和全部数值检查通过后，
立即扩大其余方向和真实请求最终评分，再验完整静态目录与CPU。
失败停止本双上下文全角色对、原权重及四轮配置，不扫描样本量或轮数。
主张泛化和接入仍需冻结候选后的新100M及完整1B联合证据。

全部判别损失、零码和字段独立重算；固定32行对两臂逐项枚举码号
和偏置，复用exp817审核。源—目标覆盖可直接由保存的整数键复算。
构造与判别共享固定架构，名义L1和最终Acc分别判断。
