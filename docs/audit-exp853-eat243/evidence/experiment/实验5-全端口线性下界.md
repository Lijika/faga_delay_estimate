# 实验5 全端口线性下界

日期 2026-09-17，基线提交 ff9940d。范围限于 tests/linear_bound_probe.cpp、
validation/results/linear-bound-audit.json、validation/results/linear-bound-samples.csv 与本日志。
src、estimate 与旧 bound_audit 未改。

## 方法与依据

在全部 496 个 port 节点上建约束图。所有 8192 条 Arc 各给一条权重为 S 乘 arcDelay 的边，
每条真实 Net hop 类型给一条权重为 S 乘 blockDelay 减 a 乘 dx 减 b 乘 dy 的边，其中 dx 与 dy
取 resolveNet 的真实位移，blockDelay 是 gapDelay 扣除必过 Line 费用后的部分。
hop 类型按 (net, dx, dy, blockDelay) 归并。

每个象限用全零超级源做 Bellman-Ford，得到 h 满足 h[to] 不大于 h[from] 加 w。
随后逐边检查 reduced cost 非负，任何负环或负值立即非零退出，不缩放斜率也不继续认证。

查询下界为

```
L(s,t) = max(0, ceil(max_q(a_q*dx + b_q*dy + h_q[t] - h_q[s]) / S)) + mandatoryLine(s,t)
```

全部使用 int64。同一物理 pin 返回 0。非法 pin 在 identity 判断之前拒绝，另加坐标存在性与
端口范围检查，因为 Architecture::parsePin 只解析文本。

有效性来自 Goldberg SODA 2005 第 2 节。对任一象限，路径各边 reduced cost 之和等于
S 乘路径费用减 a 乘总位移减 b 乘总位移，再加 h 起点减 h 终点，望远镜求和后非负，
因此路径费用不小于线性项除以 S，取上整后仍成立。Line 部分单独相加：两轴位于端点之间的
Gap Line 站点，任何合法路径至少穿过一次，而 resolveNet 对每次穿越收费，所以该和是必过费用；
该和在同一轴上满足区间三角不等式。线性项不含 Line 费用，因此不存在双计。
只有当前固定架构的全部 Arc 与全部归并 Net 类型都通过逐边检验，才写 certified lower bound。

## 限制

1. L 是下界而不是估计值，本轮不改变任何预测，也不做百万行评分。
2. 认证范围仅限当前架构、当前斜率与本次建表；更换架构、斜率或表后需重跑逐边检验。
3. residue value 只作对照，不在证书内；实验4 已记录 residue 在真实图上的反例。
4. 探针为读取 scale 与 slopeA/B 仍构建完整 estimator，耗时 15.5s、RSS 约 393MB；
   生产化需要单独暴露斜率而不建表。
5. exact 样本只覆盖 Manhattan 70 以内的局部对，且只做 plain Dijkstra，未做大规模精确验证。
6. self-check 覆盖 identity、非法 pin、ceil 算术、BF 可行性、故意破坏 h 的拒绝，
   以及 witness path 重放对移动末步坐标与错配 To 的拒绝；不替代逐边检验本身，
   逐边检验覆盖全部 Arc 与全部归并 Net 类型。
