# 实验713 端口兼容的首尾局部支持与同预算残差

2026-10-25，在查看新增特征或评分前登记。exp710/711完整词函数目录
容量不足，exp712三种平局代表的支持增量未达门。接合新报告第4.1、
4.2和10.4节，直接测量从请求可算的局部支持对最终评分的贡献。

## 主假设与特征

固定16个已认证Net几何类。源端在真实首Net落点a，取当前完整端口
的合法后继Arc所允许motion，与a处的合法forward motion求交。
目标端取能够经末端Arc接入完整目标端口的motion，与真实Net逆关系
在目标位置的存在性求交。逆关系由全位置forward枚举构造，保持真实
跳格和缺格规则。每端16个二值支持位，共32列。

该状态保留完整端口兼容性与一跳几何支持，不能证明全路径可达或费用界。
来源为固定架构，特征构造与训练标签无关。与exp614的坐标、周期和
障碍计数特征分别判断，当前53列保持对照。

## 四臂及隔离

复用原百万开发缓存、exact D0、完整truth及source-pin三折。它是离线
训练与评分缓存，完整估计程序运行次数为0。V事件继续使用冻结V8。
A为当前原S8/V8；C为exp656已完成的曲线匹配S8，叠加相同冻结V8。
两者都使用当前D64加字节曲线背景，身份与整数预测先完整核对。

P使用原53列加32支持位。R保留原0至25、50至52列，换入32支持位，
合计61列，直接代替原24个端点坐标、余量、side和带号列。
P/R沿用exp640的16路、16轮训练、固定前8棵depth4和全部超参数，
训练目标、权重与exp656相同。每折源pin无重叠，特征取值、模型叶编号、
独立JSON解码、最终整数预测全部核对；没有新增模型预算。

## 验收与停止

C++全域构造16类forward及真实inverse支持，Python独立按原图枚举
验证66,000位置的32位及全部496端口兼容掩码。百万缓存的首落点和
逐条支持位再作双实现核验。记录表字节和使用率，部署成本保持待验。

P/R分别比较A及C。进入静态实现须同时对A、C提高至少0.05pp，
四比较同时95%源族敏感性区间下界均为正；distance、near_axis、
direction各组下降不超过0.03pp，V事件整数预测保持原值。
两臂通过时选择对A总体增益较高者，完全相等选R。
未达门时停止当前局部支持、固定S8预算配置，保留局部语义与其他
路径片段支持的研究资格。该缓存多次参与开发，不声明新请求泛化。

通过后才接静态部署、新非重复100M扩大exact及配对CPU；100M联合
收益通过后及时形成阶段版并跑全端口非重复1B。

## 资源与范围

只新增私有组件、训练驱动、证据与理论笔记。单进程离线CPU≤1800秒、
wall≤1800秒、RSS≤2GB，AS≤8GiB，新增文件≤100MB。
沿用原训练线程，在线程序继续单线程。exp712 exact结束后在r9串行执行。
本轮无新exact、无完整估计器运行、无发布。开工/dev/sdd可用279GiB。

## 结果与独立核验

C++构造与Python独立枚举的66000位置、496端口掩码及百万缓存
全部相同，合法motion边937812条。格点两向支持各有82种，
表共266048B。96个折外模型的叶编号、原生预测、JSON独立解码
及最终整数预测通过。再次独立重建当前曲线背景、96模型全部
折外输出和四项配对统计，结果与报告相同。
