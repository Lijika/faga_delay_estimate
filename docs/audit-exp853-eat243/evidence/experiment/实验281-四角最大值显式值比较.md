# 实验281 四角最大值显式值比较

2026-10-16。性能基线为 exp277 冻结私有 ELF，精度基准为 exp258。
本轮针对 exp280 的生成代码退化做单因素复核，生产入口和正式版本保持不变。

## 预注册

主假设是 exp280 的两层 `std::max` 返回 `const` 引用，导致编译器生成
临时值、指针选择和额外分支；将四个有限值保存为 `int64_t` 局部变量，
再用顺序 `if` 比较，可能消除这部分成本。四角、缺席哨兵
`INT64_MIN`、单槽证书、宽表、fallback、舍入、Line、截断、队列和搜索
顺序均保持。

算术自检覆盖全部 6^4 槽组合、8 组线性边界和 100,000 组固定种子请求，
另运行 ASan 与 UBSan。局部检查复用 128 条搜索、六个边界、768 组 cap
和 80 组 weight，要求字段及完整路径保持；随后比较 12,320 条 exact，
总体和七组 acc、平均相对误差以及逐条整数输出必须相同，
`changed_rows`、`improved_rows`、`worsened_rows` 必须为 0。

通过后在 Xeon core3 同机串行测试两类原序 20k，每臂预热一次，
AB/BA/AB 三对，CPU 为 user+sys。统计采用 df2 配对 95% t 区间并加入
±0.02 秒舍入界。两类均至少节省 1%，且加入舍入后的区间上界小于 0
才扩大；任一明确变慢或 acc 变化均停止。扩大阶段包含搜索审计、七组
CLI、Arc 变体、AMD 20k 和完整 1M，具体范围沿用 exp280 预注册协议。

候选只进入私有 `build/exp281/`；通过验收后才考虑正式实现。完整独特
100M/1B、官方隐藏集和其他 FPGA 架构不在本轮先导门内。

## 结果与新规则复评

候选 ELF 为 `build/exp281/combined/estimate`，94,083,728 B，SHA-256
`dd8d0d8f901d5051f04010d8a3644acb87157a06e6cab625586cffabf35d1d34`。
源码、编译参数、架构、输入与父版本身份见 `validation/results/exp281/freeze.json`。
正式 `src/`、`./estimate` 和交付包保持原状。

算术普通版与 ASan/UBSan 各通过 110,368 组合。扩大审计核对 35,702 条搜索、
109,505,958 次 q、完整路径、七组 CLI、128 条 Arc 变体、768 组 cap、80 组 weight。
12,320 条 exact 开发样本的 acc 均为 99.30225286909072%，总体和七组平均相对
误差保持，变化、改善及变差行数均为 0。公开 golden 完整 1M 的配对 acc 均为
99.27638014510116%；官方格式评分脚本求和为 99.27638014510366%。两种求和
方法在各自的基线与候选之间完全相同，逐行变化为 0。

Xeon core3，两类原序 20k 各预热一次、AB/BA/AB 三对，完整进程 user+sys。
差值为候选减基线，区间含时间舍入界，单位为秒。

| 分布 | exp277 CPU | exp281 CPU | 配对差 95% 区间 | 节省 |

| U-output | 6.953333 | 6.700000 | [-0.287676,-0.218991] | 3.6433% |
| U-role | 7.203333 | 6.953333 | [-0.294841,-0.205159] | 3.4706% |

完整独特 U-output 1M 两次 CPU 为 192.84 / 193.22 s，均值 193.03 s；最大
RSS 为 1,713,045,504 B，最大 wall 193.26 s，单线程。两次输出 SHA 均为
`86dca80df1fa1ce5ccf78aca15e3e96177238a8362040aa22392213f41a5612c`，
与 exp277 相同。exp277 的历史两次 CPU 为 205.88 / 206.31 s，跨批对照只作描述；
严格配对效应来自本轮 20k。完整独特 1M 尚无全量 exact，输出等价复用原精度证据。

公开 1M 的同次运行同时提供评分输出与 CPU 209.44 s，RSS 1,713,090,560 B。
repeated 1M 含 1000 个独特请求，八次计时输出相同，cache hits=999000。
基线/候选 CPU 均值为 3.370000 / 3.366667 s，含舍入的配对区间为
[-0.037676,+0.031009] s；最大 RSS 1,692,069,888 B。此分布性能差保持待定。

AMD 同一 ELF 的 output 为 12.51→13.183333 s，role 为 14.533333→16.37 s，
两项区间跨零。按用户 2026-10-16 新规则，AMD 计时仅作参考，exp281 保留为 Xeon
方向的等价加速基线。候选采用 acc >99% 的 CPU–acc 前沿规则；本项的等价主张
继续要求逐行相同。三个阶段指标保持，第一阶段 1M <100 s 尚待达到。
