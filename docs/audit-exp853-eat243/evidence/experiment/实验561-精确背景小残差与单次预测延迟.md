# 实验561 精确背景小残差与单次预测延迟

2026-10-21，结果查看前登记。exp557离线训练同时推进；本实验回答残差
组件能否在100ns预算内保留必要精度。全部算法验证、评分及计时在r9执行。
精确名义背景Q的在线获取成本单列，当前组件实验不构成完整程序成绩。

## 固定模型与数据

沿用exp554/556经认证的非重复完整1M、53项特征、source pin隔离三折、
每折及训练补集59,904端口对。追加已计算的整数背景Q-F作为第54项特征。
固定两个模型O8与O16，分别8棵depth4/eta.3和16棵depth4/eta.2；CPU hist、
max_bin256、加权MAE、base_score0、全样本全特征、seed沿用exp556，训练
权重1000/max(D0+F,128)。参考O32沿用exp554小Q的32棵depth4/eta.1原模型，
特征继续53项。开发域重复使用已声明，不作新请求泛化结论。

三模型均保留解析背景、真实首Net与物理Line分解。原生保存回读、独立
C++通用解码的完整1M float32逐位相同后才测推理。质量门为acc≥99.10%、
相对exp354提高≥0.05pp且按源族2000次配对bootstrap的95%下界>0。
任一新小模型通过即可保留其容量；两项均失败则结束本固定小模型配置。

## 固定实现与计时

N为生成的原生C++分支，L为四层紧凑布局、各树交错遍历，Q为每树一个
uint16候选叶掩码的QuickScorer。全部使用同一原始树序与float32加法，
不增加拟合容量。整数特征与阈值均完整核对，模型保存回读和完整退出叶
序列一致。单线程、静态、通用x86-64、O3、无异常/RTTI、禁fast-math及
浮点收缩、推理区间无动态分配。计时包含模型调用、行定位和结果写入，
特征准备及Q背景获取另计；输入维度仍为完整54项。

每个模型、每臂check一次、warm一次，再按N/L/Q、Q/L/N、N/L/Q计三轮。
主计时为有前后依赖的串行调用。离线编码chain[i]=i XOR bits(expected[i-1])，
运行时用上次预测bits与chain[i]恢复下一行号；首行使用0。计时内保存每次
实际行号，计时后完整检查其等于原行号，保持完整1M原顺序及端口覆盖。
行号等式检查放在计时后，避免编译器利用该等式将特征地址改写成循环下标。
另检查生成汇编中预测结果至下一特征地址的依赖。普通顺序调用另列为描述性
吞吐量对照，不能代替串行结果。全部预测原始float32与退出叶完整核对。

100ns门要求三次串行完整1M平均纯核CPU<0.1s，且95%t区间上界<0.1s；
报告计时区间与每臂变化行数。性能与质量门分别判断。离线CPU预算1800s、
AS8GiB、新增1GB。尚无完整程序、exp323生产CPU、独立新请求或最终ELF验证。
