# 实验747 整数族均值的无损编码与完整背景

2026-10-27预登记。exp746的整数均值保留rank16名义增益0.290593pp，
固定Zstd9容量投影102609045B。继续同一预测表示，先测试Zstd19与
XZ6两个固定无损编码；优先采用能通过容量门的Zstd19，其次XZ6。
输入采用exp746保存的整数均值，比较原小端字节与逐曲线int32差分
字节平面。解压及逆变换逐字节相同，全部预测和评分复用exp746证据。

如rank16仍无法投影至100MB以内，本轮停止。通过后立即提取全部
四方向、120phase、542个远域商点的936族对均值，实测全量编码长度，
连同N512近域、原中心、完整因子、scale、现有非资产部分及1MB代码
余量重新核算。全量均值的Q6原值用于余量拟合，整数均值用于查询。

完整余量拟合固定rank16/32，共用width48的随机子空间，seed20261027747，
一次幂迭代。右基正交，左因子为完整矩阵在右基上的投影；所有端口和
几何点参与。INT8方式与exp745相同。先完成方向0，再判断其余方向。
方向0在原两phase全点和固定均匀抽取的4096个全phase几何列上分别
比较当前整数D64加曲线，要求相对加权L1不高于0.75且名义至少提高
0.15pp，双短轴下降至多0.03pp。实际静态容量可行的通过rank才扩大。
这两个筛选域均为结构开发域，完整真实请求Acc另验。

完整通过项直接进入匹配残差和完整非重复100M联合实测。小模型先复用
T2D6预算，强教师只用于判别表示是否仍缺少质量。以满足质量的较短
点积为优先；100M收益门通过后及时接入阶段版，完成全端口非重复1B。
最终交付必须满足Acc严格大于99%、静态100MB、单线程及2GB等全部要求。

算法计算在r9，单次只保存一个方向的约7.8GB结构矩阵，固定输入来自
exp499已验证的208个完整名义场。每个场核对压缩、展开SHA和端口顺序。
本轮离线CPU7200秒、wall3600秒、RSS24GB、新增磁盘12GB；这些是离线
预算。生产资源、初始化和随机访存仍由完整程序验证。
可重建结构矩阵在该方向结果与因子验证后按名清理，保留生成命令与身份。
理论沿用Obsidian族均值投影及整数化两篇笔记。

## 结果与停止范围

两phase的Zstd19差分为149434B，所有压缩回读保持同一预测。
扩大全部208个源端口、四方向和120phase后，整数均值实际压缩
41890923B，rank16/32静态容量投影为93291168/101287584B。
全部场的压缩及展开SHA、端口顺序、标量地址和原两phase均值通过。

每个固定抽样列覆盖全部59904 pair，全phase评分项为245366784个。
原两phase的64935936个旧背景逐项复现exp689；右基正交及64行独立
投影重算通过，最大投影差3.17524e-14；整数点积标量检查通过。
两个rank均未通过质量门，停止其余方向训练及完整CLI构建。
该结论限定全phase共享rank16/32、width48、一次幂迭代、本均值与
INT8方式。两phase结果继续作为其局部证据，其他条件表示另验。
