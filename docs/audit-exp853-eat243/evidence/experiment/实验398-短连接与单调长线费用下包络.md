# 实验398 短连接与单调长线费用下包络

2026-10-18，在新容量、胜者和性能结果前登记。正式入口exp354，
CPU固定发布基准exp323。本轮消费方仅为私有组件验证与计时，
不改生产src、正式入口和交付包。理论见Obsidian
《短连接与单调长线费用的一维下包络》。

主假设是有限短连接B后接单调长线F时，固定分量、象限和余数的费用共享主项，
其下包络可以消除逐个短连接求值。竞争解释包括分桶后的候选已经很少、
新增主表访问增加延迟、真实几何使表内胜者失去资格。
本轮仅处理名义内部域，|Dx|在36至119、|Dy|在40至549。
每个残余轴至少两次Net。真实Block、Line与多个内部短桥为后续独立问题。

对照采用按源L、目标L分量、10×12位移余数分桶的B逐项调用已验F。
候选按末方向分别保存11点费用下包络，两侧作仿射延伸，
末Arc在线接入。费用与见证用分列int32数组，稠密主表预算21,626,880 B，
另计核记录、桶、映射、初始化CPU、完整索引与峰值RSS。
全部核3,895项扫描只用于512个预定查询的资格检查。
各桶候选数、有效分支数、各行不同获胜核数在验证后记录。

使用固定种子202610180398生成1,000,000个不同名义查询键，
键含源L、目标L、Dx、Dy；从完整有限域无放回抽样。
该输入是预加载组件输入，既有核及F用于开发等价验证，
不得记为比赛完整非重复1M成绩。普通C++全量逐项比较；
sanitizer前4096行。对官方8矩阵及正、零、负C合成矩阵，
固定种子测试四象限、两个末方向、11点边界及两侧尾部。
全量费用与稳定等费胜者须保持；512个固定查询核对全扫描。
前128个有限查询用独立Python单调DAG DP检查桶内全部候选最小值，
并恢复B词和L词，独立核对名义位移、端口、费用。
费用加1与Dx加1负对照须拒绝。任一语义差异保留证据，停止扩大。

计时为同ELF内两实现，预加载相同1M不同查询，先各预热1遍，
3块交错配对，每块完整1遍并改变循环起点，次次重新计算。
主指标为全部1M组件条件ns/次及配对CPU差，采用df2的95% t区间；
点估计节省至少1%且差区间上界低于0称为明确组件收益。
本机AMD仅描述，Xeon核3、通用O2、单线程串行为主要比较。
预热、输入读取、校验、初始化、输出分别记录，完整估计器成本仍待验。
普通组件每进程CPU≤120s、地址空间及峰值RSS≤2GB。
ASan虚拟地址空间按运行时需求放开，实测RSS保持检查。
未达明确收益条件保留为待定，资源或语义失败保留反例。

本轮不产生总体acc、全图新exact或完整1M/10M/100M成绩。
完整路径选择规则固定后，先用未参与选型的新请求检查精度，
再按完整1M、10M、100M推进，最终总体acc严格大于99%并争取更大余量。
开工df可用385G。收尾记录空间、删除清单和可复现证据。
