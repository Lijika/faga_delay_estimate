## 故障、恢复与证据

首次构建的生产fold没有使用b0，触发`-Werror=unused-variable`。
在完整测试前改为`[[maybe_unused]] const int b0`；原脚本、
编译日志及失败构建保留于exp833-build-failure。
十四次计时结束后，历史audit导入将共享execution.ROOT重设为
exp720，非H检查在创建日志前退出。恢复器重新配置共享路径，
并以完整输出SHA复用已通过的非H证据，完整程序新增运行0次。

首次评分恢复又发现符号链接路径与原抽样freeze记录中的路径
字符串不同。保留失败score-freeze、脚本及日志于
exp833-analysis-failure；后续直接使用exp830原抽样路径，
评分结果写exp833独立目录。模型、输入、原冻结脚本、门槛及计时
均保持；失败期间没有生成精度或联合判断。恢复器为
validation/exp833_finish.py，成功日志为exp833-analysis-recovery.log。

原始证据在validation/results/exp833/。最终审核为
independent-audit.json，完整等价为equivalence.json。
两份4GB输出先逐份核对SHA，再与exp830已通过完整恢复的归档
核对内容身份和归档SHA；共享持久归档继续保留，重建命令逐项
记录于retention-plan.json，随后按名删除当前重复输出。
tmpfs净释放8,027,127,808B，磁盘因新日志增加20,480B。
本地/dev/sdd开工及收尾均约260GiB可用，当前显示697GiB已用。
