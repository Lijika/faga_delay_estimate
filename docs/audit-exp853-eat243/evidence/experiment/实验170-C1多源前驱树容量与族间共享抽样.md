# 实验170 多源前驱树容量与族间共享抽样

2026-10-10，分支`research/exp169-nominal-parent-tree`，起点`e94865a`。
正式exp131保持，exp169单源树与证据可复用。

## 固定对象

从20个Z端口族各选lane0和lane4，共40个源；每个源在同一
C1200完整二维名义盒[-97,97]×[-116,116]上独立Dijkstra。
每个有限状态选最小索引Bellman前驱，按目标优先[z,y,x]写7,269,600字节流。
先逐源Zstandard19，再把40条原流串联压缩，比较独立文件与共享上下文的容量。
统计同族lane0/lane4的parent字节差异，判断是否存在可直接共享的端口自动机。

## 门与停止

每个流的单帧、checksum、内容长度、EOF和往返由exp129工具核验；
40源完整证书、搜索计数、边界和单线程由C++探针核验。
样本总容量仅作全源外推；若40源独立和串联流均显示明显低于
正式剩余31,798,896 B按源线性预算，继续exp171全160源；
若同族parent差异高、共享流仍超过预算，转做按端口位移的delta/字典共享。

容量参考：单源exp169目标优先流309,243 B，40源线性估计12.37 MB，
加正式68.20 MB和1 MB代码余量约81.57 MB。串联压缩若低于线性值，
可保留共享上下文；全160源仍须实测。
