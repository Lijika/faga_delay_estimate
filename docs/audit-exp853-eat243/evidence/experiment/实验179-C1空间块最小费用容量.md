# 实验179 空间块最小费用容量

2026-10-10，使用exp177完整认证D，旧40源parent保持。正式exp131保持。

## 固定候选

按每源xmin/ymin对齐的[z,y,x]费用盒，划分B=2、4两种B×B空间块，
每块存floor(min有限D/5)，全unknown块0，边界补INF65535。
任一有限键满足5Q_tile≤D(v)，因此可在恢复前安全跳过无法降低best的固定路径。
有限/unknown由旧parent判断，完整真实重放仍产生U。理论见Obsidian
《空间块最小费用的恢复前安全剪枝》。

固定plain/dx两种表示，dx以uint8相邻差、恢复prefix mod256。
每B实际测完40源和两表示后按最终字节小者选表示；不根据精度选参数，
完整旧U精度保持是硬条件。量化参数5、Zstandard19及单线程设置沿用exp177。

## 门、范围与成本

块下界逐有限槽核对，独立checker用分相位取min重新复算所有块；
root0、全unknown0、边界、dx逆变换与完整EOF分别验证。
每B完整40源frame+40×64B元数据≤18,228,271 B才可进入在线CPU实验，
预计加exp175和1MB代码后<100MB；实际ELF/RAM/恢复/查询CPU另验。
两种B都通过时，下一轮均作为固定CPU候选比较原始/块2/块4及必要终端复用组合。

候选与代码先提交，再固定输入与构建身份，CPU3串行压缩，每frame≤900s/RSS≤2GB。
不重求Dijkstra/exact，完整D/Q和旧parent输入身份保持。容量未过则该固定B停止；
安全块下界推导及其他表示继续保留。受影响路径仅离线block_values、压缩与checker，
当前生产及交付、标签与模型保持。
