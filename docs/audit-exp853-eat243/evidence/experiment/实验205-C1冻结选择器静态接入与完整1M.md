# 实验205 C1 冻结选择器静态接入与完整1M

2026-10-11。承接exp203新请求精度门和exp204纯等价CPU门。
分支`research/exp202-candidate-selector`，私有目录`build/exp205`，开工445 GiB。

## 固定目标与实现

将exp203冻结cheap选择器、40棵C1200 parent和cycle0–7真实重放接入完整静态程序。
P为正式exp131最终整数，all=min(P,U0)，C=min(all,U7)，有效集C>0且U7>C时，
冻结模型预测评分增量>0.005则选U7，其余保留C。32树和26维输入保持；
模型SHA与exp203一致。精度选型沿用exp203新标签，当前改动是等价部署。

复用exp175无损Zstandard树恢复与生产配置判断、exp204固定32跳缓冲和source费用复用。
初始化按mode与source port建立有有限seed的tree列表，来自同一seedFee；
所有有效路径仍真实重放和计数。path摘要14列供研究使用，冻结cheap模型输入
只保留原26列。节点compact C++推理保持float32逐树升序累加、严格小于阈值分裂。

在cache miss路径的校准后整数上调用选择器，结果变化时返回selected+3，
随后main执行既有-3；首次与缓存命中均保持最终selected。0/负值、不同core
graph和其他显式诊断配置继承原分派。正式src和入口保持，候选在private构建。

## 验收与预注册

1. 使用exp202与exp203的12352请求，核对26维float32、all/C/U/valid_count、
   冻结模型raw增量及最终整数。cheap模型在全部请求离线重新推理，避免拿exp202
   五个折外模型当作最终模型。额外覆盖同pin、零delay、负值、边界和解析输出。
2. direct estimate、estimateText及cache hit保持，CLI与探针结果保持；
   两套静态control/candidate均为通用C++17/O2，候选ELF严格小于100,000,000 B。
   private control须保持exp131在已冻结三种1M上的完整SHA。
3. remote r9r4900仅在`/home/lhj/lhjwork/eda2026`内运行，core3、串行。
   public/unique/repeated各先control与candidate预热一次，再5对AB/BA交错。
   public对应公开1M，unique沿用exp57，repeated沿用exp120的1000 distinct×1000。
   baseline为正式exp131静态bin，candidate为本轮私有静态bin。记录每行顺序、
   完整SHA、初始化/CPU/wall/RSS、线程、cache hits与misses。
4. 全部1M的输出契约须通过，恰好三字段、原端点、整数delay、精确EOF、多次SHA；
   每次线程1、RSS≤2,000,000,000 B、CPU和wall≤3600秒。
5. 新请求accuracy相对P的配对95%区间在计时前补算并冻结，七带10000次bootstrap
   seed=20261013。全套对P的主收益按该新请求增量和完整public1M的CPU差估计。
   CPU五对采用df4双侧95%t区间；综合点≥0.01，精度下界与CPU上界合成下界>0。
   unique/repeated分别报告相同预算换算及实际cache miss。该换算假设目标1B
   的新增工作仍集中在约1M miss，逐行公共路径的额外代价需单列，平台实测为准。

公开golden只在候选冻结后评分，结果不用于本轮模型调参。计时失败或综合门未过，
按阶段成本继续优化已通过精度门的候选，并保留本次可复现证据。
满足完整1M门和综合门后才进入正式接入/打包；平台1B和跨硬件速度仍需实测。

## 结论与限制

冻结选择器通过本地完整1M输出契约、资源门和预注册条件综合门，候选具备
进入后续正式接入评估的证据。新增CPU主要出现在1,000,000次miss路径，
repeated输入只有1,000次miss；按约1M miss外推到1B仍属于假设。平台1B、
跨硬件速度和逐行公共开销尚未验证，正式入口与交付包继续保持exp131身份。
