## 小修正器边界

预登记的有限类只覆盖**固定 direction×forced 分组、每桶 0–15 ps 的非负修正**。在暴露 1M 上，8 个桶中只有 4 个 ordinary 桶非空，4 个 forced 桶全空；非空桶的 1–15 ps 修正都降低分数，oracle 全选 0 ps，净变化 `0.0 pp`。ordinary 当前残差为正 454,419 行、负 241,528 行、零 283,376 行。

因此“零收益”只排除这个固定 direction/forced、0–15 ps 的非负有限类，不覆盖 event 1、其他动作集合、带符号修正、训练得到的条件选择器或未知输入。
