# 实验105 距离选模独立窗口验证

日期2026-09-27。开工 `/dev/sdd` 可用约479G，承接实验104预先固定的独立验证方案。

## 固定方案

候选在 `dist >= 101` 使用实验93的47维depth 10、128树、gamma 1模型，其余行使用实验92正式depth 8模型，两侧统一减3 ps。规则在读取新窗口结果前已冻结。正式模型SHA-256为 `92a3c09217e7881fc07704159f4ba7d123f233bcb21dab5f78a2a8fc61c015cc`，depth 10模型为 `9e0989b5b0f38e272a3e481498ea7042b69fd9b2d8d87bbf78adb04e21ea58cf`。

独立窗口固定为affine unique `[40M,42M)`，2,000,000行，每带至多1024条exact；排除公开输入、训练池和历史已登记端点，命中即停止且保持原抽样。主指标为语料带份额加权accuracy，七带配对bootstrap 10,000次、seed20260925；点增益至少 `+0.03 pp`、95%下界大于0、两类可达性误判均不增加才继续私有C++接入和最多三对1M CPU测量。

## 验证结果

请求文件的四项历史前缀零差异，生成器身份一致。探针保留6,179行，其中0带35行，其余六带各1024行；完整端点唯一，历史排除集命中0，距离与带交叉检查零差异。评分前样本、特征二进制、exact探针和两个模型的冻结SHA均通过。特征矩阵为6,179×47，fast/base输出端点、字段和行数检查通过。

| 指标 | 正式depth 8 | 全量depth 10 | 距离选模 |
| --- | ---: | ---: | ---: |
| 加权accuracy/% | 96.384261 | 96.408329 | 96.411344 |
| 加权MAPE/% | 0.921248 | 0.914682 | 0.914023 |
| false finite | 0 | 0 | 0 |
| reachable false unreachable | 0 | 0 | 0 |

距离选模相对正式depth 8增加 `+0.027083 pp`，95%区间 `[-0.012479,+0.066354] pp`。两个精度门槛均未通过，关闭这条规则。两个触发距离带的accuracy差分别为 `101–300 +0.009202 pp`、`301+ +0.083573 pp`，其余带逐行沿用正式输出。正式实现继续采用depth 8，本轮止于独立精度验证。

结论范围为同一架构和本次新请求分布。C++部署、CPU、跨架构及隐藏集收益未验证。固定特征上的扩容、增标签、平均及距离选模已出现连续弱收益；新的在线路径信号仍属于待检验假设，goal保持active。
