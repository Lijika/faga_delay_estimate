# 实验756 冻结曲线的相位奇偶条件短点积

2026-10-27预登记。exp755的完整lane剩余在全相位共享小秩下质量不足，
本轮用已有条件空间思路，让相位选择一套较短的端口因子。保留当前
全部曲线、中心、趋势和近域；每个请求仍执行一次点积与一次曲线读取。

固定四个候选为rx奇偶×rank32/48、ry奇偶×rank32/48。每方向两套左
因子，几何右因子保持每列一份。增加一个全相位rank64重拟合控制，
区分离线重拟合与条件化作用；控制项只作诊断。

复用exp755已使用的59904pairs、方向0、120phase、2880训练列和960
留出列，数据全部视为开发集。拟合目标扣去冻结曲线；旧D64左空间
与32个随机方向初始化，两遍幂迭代后再次纳入旧左空间，再做有限SVD。
训练列决定左空间，各列右系数用自身认证标签投影构造。
种子20261027756，左右按行INT8量化。报告浮点和整数预测、各距离组、
核心/逻辑组及120phase。与exp755数据身份相同时复用认证与地址证据。

rank32整数留出总体名义分须不下降，rank48须提高至少0.03pp；
相对L1比例至多1.0/0.97，所有距离和端口组退化至多0.03pp。
rank48至少100/120phase提高。全方向容量投影低于100MB才继续。
通过多项时优先较短点积，同rank取留出总体差较高者；这只选择后续
全量构造候选，独立请求与完整CPU仍须新100M、1B验证。

预算使用既有近域32771541B、非资产7585312B、exp728差额43776B、
1MB代码与4096B头部。冻结曲线复用exp661的无损21281730B记录。
左因子测本方向全部行的Zstd9实字节并乘4，右因子按全方向未压缩
字节计入；该投影的跨方向压缩假设明确保留，下一阶段须测真实全资产。
同时列出全因子未压缩上限，实际ELF与启动另验。

所有计算在r9，CPU1800秒、wall900秒、RSS12GB、离线BLAS8线程。
完整程序为0次，新exact为0；任何合格候选接续全方向与背景/残差四格，
随后及时运行新100M和1B。全部失败按本固定配置停止扩大。
结果在`validation/results/exp756/`，构建在`build/exp756/`，复用当前
research/exp745私有工作目录。本地开始273GiB，远端约23.39GB可用。

结构值，所有完整角色pair与120phase均覆盖。

旧基线名义分99.384575591%，属于所选结构列；真实请求Acc另列。
rank48的全因子未压缩预算101,134,839B，表中的投影复用当前曲线
无损压缩，并假设其余方向的左表压缩大小相同，尚未构造完整ELF。
rx48仅1个phase的整数评分提高，其他条件候选均为0。

控制项的训练平方误差从1480.626931降至1217.835562，留出浮点
最终评分仍下降0.011333pp；量化后退化进一步增加。这个现象同时
保留了训练列数量、平方目标与量化配置的限制，不能单凭它排除全部
条件空间。当前相位奇偶×32/48及固定曲线组合停止。

原生求值过程对五项整数配置的全部287,539,200个留出点积用INT32
独立重算，逐项相同。保存后的十项浮点/整数预测共575,078,400个，
独立脚本重新评分；分组、phase、容量算式与选择结果一致。
exp661被复用的曲线原始SHA与当前资产相同，其无损恢复证据通过。
