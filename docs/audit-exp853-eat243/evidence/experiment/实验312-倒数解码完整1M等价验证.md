# 实验312 倒数解码完整1M等价验证

## 预注册

2026-10-16。exp309固定整数倒数加一次修正，算术、路径与完整
样本输出已通过等价检查。其100k证据允许扩大后，在本轮复用
同ELF，与exp305 narrow交错比较完整1M；当前窄除法完整
均值100.585 s。主假设为精度保持，解码CPU减少。

直接沿用exp308的16次schedule与checker，只更换两臂冻结身份。
Xeon core3串行，20k各预热、独特1M AB/BA两对、候选公开1M
两次、repeated预热后AB/BA/AB三对。unique用df1、repeated
用df2 Student-t 95%配对区间，两端加0.02 s舍入。区间跨零
保留待定，0.5%仅记效应，两次独特1M均<100 s时记录阶段达到。

同次完整输出须匹配exp299相同分布SHA，复用公开99.028029%
与新请求精度，精度差0 pp、变化行0。缓存行为按等价路径和
完整输出复用1,000 miss/999,000 hit记录。每次核验行数、
端点顺序、三字段、整数delay、精确EOF、SHA、多次一致、
单线程、RSS<=2GB及CPU/wall<=3600 s。估计成本单列，评分
和exact新增0，AMD只作参考，通用O2参数保持。

当前公开acc与独特1M CPU分别解释。独特全量exact、100M/1B、
跨架构与官方平台另验。开工磁盘405GiB，收尾复查。

候选100.64/100.77s；均值100.715/100.705s，点节省0.009929%，

两次候选均超过100s，第一阶段继续推进。

99.0280294290%；相对本轮基线精度差0pp、变化0行。

差区间[-0.087676,-0.018991]s。缓存行为复用相同路径及输出
对应的1,000 miss证据；独特与repeated分别判断。

完整契约、端点顺序、EOF、SHA、多次一致与单线程通过。
