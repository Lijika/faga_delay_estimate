# 实验497 全端口条件查询组的块状低秩分解

2026-10-19，查看新分解和评分前登记。exp496的自然切口矩阵为
6656×39744；右侧前五个数位 `(b1,b2,b3,dy,h)` 共有72组，
每组留下552个几何列。本轮把同一矩阵按这72组拆成72个
6656×552小矩阵，查询时只访问所属组的因子。

## 假设与对象

完整208合法非I源、288 Output目标、四方向、两认证余类、552几何全部保留，
共264,536,064值，评分域257,647,104值，新增exact标签0。沿用exp496自然
键序和输入标签。对每个组 `q=(b1,b2,b3,dy,h)` 独立做float64经济型SVD，
一次训练保留rank64，评价固定rank16/32/64。每个查询按目标和方向确定q，
只计算该组的r项点积；输出顺序、整数舍入、同端口空路径和趋势保持。

块状分解的全矩阵等价形式是对右列置换后得到块对角的左因子选择。
它不假设72组共享子空间；质量由每组实际谱尾和完整评分判断。
rank32的A8条件int16因子主体为
`2*72*(6656+552)*32=33,214,464`字节，float32双表为66,428,928字节。
A480若每个全余类组独立保存，容量另行计算，不能由A8结果外推。

## 计算、评价与停止

SVD训练固定在l7claude，8个BLAS线程，峰值RSS<=64GB、wall<=3600秒。
因子恢复、量化编表、完整解码、评分和独立verify全部固定在r9r4900。
每个rank执行float、逐组逐分量int16、float32表和只读verify，
每阶段完整264,536,064值，另作479,232次独立标量查询。
评分与对照使用exp494原切口rank1024最终表，并报告源族bootstrap；
该对照的完整输出与配对数组在r9保留，便于逐源族重采样。

主门为rank32最终总体>=99.97%、近轴>=99.9%、量化损失<=0.01pp，
并且相对exp494原切口rank1024最终表的配对收益bootstrap下界>0。
rank16/64固定执行用于谱尾和容量诊断；rank32未过时结束当前组状布局。
通过时保留rank32作为完整非重复1M接入候选，之后按1M→10M→100M
顺序测完整程序CPU。全余类、真实acc、官方平台和A480容量仍须另验。

开工前r9远端`df -h .`可用约8.0GiB，l7离线重建可独立进行。
大矩阵、因子和输出逐成员SHA核对后按可重建条件清理，compact证据保留。
