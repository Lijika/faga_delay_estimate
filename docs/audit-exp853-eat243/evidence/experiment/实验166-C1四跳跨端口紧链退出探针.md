# 实验166 四跳跨端口紧链退出探针

2026-10-10，分支`research/exp166-tight-chain-exits`，正式exp131保持。
控制为exp161，复用其6176行冻结开发输入及262行exact/轨迹；本轮观察结构。

## 假设与固定候选

首跳跨端口、每跳恰有一个最终tight successor的短链，
在完整保留侧退出与终端时，可通过同真实终点取最小费用和一跳真实连接支配减少退出。
按262行原请求顺序及exp161 radix展开顺序取最先256条链，重叠链照原顺序保留，
每条≤4跳。后续hop允许同端口，遇goal、无效Net或非单tight即停止。

记录全部链状态、h、safe_h、chosen_c、prefix费、原始侧退出、末端和终端，
以及出口间一跳真实resolver连接。按入口费用递增，在最终保留集合中寻找支配证书；
同终点合并具有相同真实(x,y,port)，费用取min。
仅使用一跳连接，更长连接需要另立候选。

## 主指标与停止

- 原始退出数为每个链内节点的所有侧退出，加最终节点和可达终端；
  内部tight继续边单独计入原扫描数。连接支配后的总数/原始退出数为保留率。
- 所有链重放、退出prefix与一跳连接零违约；262行exact和原expanded/relaxed保持。
- 至少25%链有≥3跳，即有两个可消去内部节点；这是机会数量，真实节省另测。
- 总保留退出≤原始80%，两项结构门同时通过才扩大到真实宏。
- 原扫描上限`256*4*19=19,456`，诊断额外记录内存≤8 MiB。
  max≤4跳只界定本候选；理论上更长链与更长支配路径保持开放。

诊断不改frontier与dist；额外h调用会预热缓存，CPU仅报告资源。
后续宏须独立处理外部进入链中间、dist/stale、终端、uint32累计容量。
结构门失败转195位移显式路径目录，初版预算128 KiB。
