# 实验789 近横轴共享残量与目录空位的信息门

2026-10-28，查看本轮新结果前冻结。正式版为exp780，exp787
100M联合收益未过0.02门；exp788百万历史开发集上，qx=0,1
占30.2721%请求并贡献完整行教师相对exp787差距的59.7733%。
报告第5、6.7、8.5、9、11章要求同时核对信息、容量与访存。
现有记录低10位为偏置，10至20位为主体2048码，22至31位为
剩余1024码；位21尚未分配。本轮先测试完全不增加目录字段的
表示，不把该空位当作已经获得的压缩容量。

## 假设与固定判别

exp787完整552点码本在`qx=0,1`的92点剩余误差，可能在
`direction×原剩余码号×qx×qy`条件下共享。用exp777保存的
982671条认证名义曲面及exp787原目录。对每个唯一
`pair×context`使用首次请求的source-pin折号，在另外两折
的名义曲面上对每个条件求加权整数均值，零支持格为零；
同键的重复请求随该代表折评估并单列跨折数量。
权重与exp777形状目标一致，采用合法位置数的乘积除以名义
响应，禁止真实延时标签进入拟合。只修复qx0/1，其他qx、
首Net、cycle、mandatory和现有残差均保持；用旧残差的折外
连续值直接计算新整数输出，不将失配对照当匹配重训收益。

无新索引的uint16修正表正文为`4×1024×2×46×2=753664B`。
位21的可选条件码若日后使用，整个域每context一位在运行目录
已有32bit字中；静态压缩载荷与查询分支仍需独立测量。
本轮不使用位21，查询仅在qx0/1多取一次短表，不能推定
单机6242R、6226R或一般CPU上的速度。

固定四个输出：exp787原预测、在qx0/1替换为exact名义且
保留旧残差的上界诊断、折外共享表修正且保留旧残差、
修正后仅qx0/1及各source/方向的配对分数。
上界是旧残差下的干预量，并非所有残差函数的理论上界。
精确名义与当前背景用同一个已保存曲面逐条校验；
禁用cycle行的修正。记录表的最大幅度、无支持比例、
zstd9压缩字节、训练/测试身份及脚本SHA。

## 停止与扩大

本轮仅有已反复使用的百万开发样本。若exact名义干预在
qx0/1总体贡献不超过0.08pp，停止此域单改名义的配置；
若共享表折外总体改进小于0.04pp、qx0/1任一组下降、
方向组任一低于-0.05pp或H/V组任一低于-0.25pp，停止
固定剩余码号×92格、加权均值、旧残差的组合。这个门
只筛选候选，不把未匹配残差或已观察样本当新请求确认。
离线CPU≤600s，wall≤900s，RSS≤4GiB，静态表正文≤1MB。

只有上述门通过，才使用完整208源认证名义重新拟合/核对
全域静态资产，匹配训练普通/H/V残差并检查实际ELF<
100000000B与RSS≤2000000000B。之后直接复用现成非重复
100M和exact，按预登记配对CPU/Acc综合分95%保守下界>0、
点估计≥0.02确定是否做完整非重复1B与阶段发布。
若此表未过门，仅排除当前无新索引均值配置，后续可评估
按物理事件条件编码或替换旧资产，但须重新冻结证据与成本。

代码在`validation/exp789_near_axis.py`，原始结果存
`validation/results/exp789-retry/`。首次运行在任何模型拟合
与评分之前触发了错误的`folds[inverse]==data["folds"]`断言；
`validation/results/exp789/freeze.json`和原脚本提交055e67c7
保留失败证据。修订后的唯一键折划分不使用真值训练。
r9私有目录`research/exp787`，
本地开工`df -h /dev/sdd`可用266G；新增产物小于5MB，
收尾核对本地空间，不删除已有输入或原始结果。

## 结果与边界

重试完整运行通过脚本与资产SHA、输出身份、单线程离线计算
检查。真实预测baseline 98.877428464%，`qx=0,1`精确名义
仅替换干预为99.166049981%，增加0.288621517pp；旧残差
未重新训练，且开发集已被反复使用。共享均值表折外结果为
98.875209244%，下降0.002219220pp，`qx=0`/`qx=1`均下降。
三折每折总体都下降，预登记门失败；不构造正式ELF，也不运行
该表示的100M或1B。独立表正文753664B，zstd9后128063B，
仍须多一次在线查表；离线CPU34.1265s、RSS1818484736B。
11570条请求的source-pin折号不同于同键代表折，已按代表折
统一以避免名义键泄漏；拟合仅使用认证名义曲面、没有真实标签。
完整结果及身份在`validation/results/exp789/retry-{report,freeze}.json`。
失败限定固定`direction×B码×qx×qy`均值及旧残差的组合，
不能否定每键有信息、单个位选择或训练匹配残差后的其他结构。
本地收尾`df -h /dev/sdd`仍可用266G，本轮没有删除文件。
