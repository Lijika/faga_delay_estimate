# 实验851 低成本几何主趋势与直接预测教师

2026-10-29，查看新评分前预登记。exp850同一批历史非重复请求上，
直接预测强教师Acc89.683994469%，修正exp825的强教师
Acc98.888569380%，相对正式预测只增加0.006940662pp。
正式exp825的历史1B同次抽样Acc98.881628718%、CPU160.776248秒。
两个教师均未过exp850门，正式ELF保持原样。

## 假设与范围

exp850的直接臂把绝对延迟交给128棵深度7的树；整数大尺度距离
随商格近似线性增长，有限树叶需要重复表示该主趋势。这个失败
限定其固定目标表达式和当前输入特征，不能推断“廉价端点状态
无法直接预测”。只改变学习目标，在原始端点位移上显式计算
`H=125*(abs(tx-sx)//10)+(dy<0?125:127)*(abs(ty-sy)//12)`，
让同样的教师拟合`truth-H`，推理时按原顺序加回H再整数化。
H只使用请求字段及固定整数运算；它不是准确的首Net对齐名义值。

输入、源目标mapping、pair-population权重、train/test拆分、
32维原始特征的前31维、CatBoost1.2.8的全部超参数、
训练权重、整数化和源族抽样方法完全复用exp850。原始请求/标签/
估计逐行核对、输入SHA和1B基线Acc复算。exp850直接臂的
89.683994469%作为历史同定义对照，不重训原臂。

机制门固定为历史1B验证总体至少98.95%、近轴至少98.20%，且
对exp825配对整体提高、26源族重采样95%下界大于0。
通过才研究短模型/无旧背景表示的静态和CPU成本；失败则结束
固定主趋势与这组特征、模型的组合，不外推到精确首Net趋势、
有向路径信息或其他函数族。无论结果如何，这个128棵树的教师
不直接作为提交候选，且测试请求曾被历史研究观察。

脚本只写新的exp851结果与一个离线教师模型；不改生产源码、
已有输出或结果。r9执行，离线CPU≤1800秒、RSS≤16GiB、
wall≤1800秒。没有部署候选就停止100M/1B；出现明确可交付
联合收益时再按非重复100M→1B测试并接入。
本地`/dev/sdd`开工259GiB可用；不删除历史文件。

## 结果

远端r9完成，原始结果、协议和模型已取回
`validation/results/exp851/`。输入身份与exp850逐项一致，
exp850结果文件SHA、脚本、预登记协议和新模型SHA均写入结果；
基线Acc重新复算为98.881628718%，原直接臂Acc复用
89.683994469%。全部59,904端口对各32/64条的核对继续使用
相同加载器。固定趋势后的直接教师Acc为91.866248225%，
相对原直接臂增加2.182253756pp，但比exp825低7.015380494pp。
近轴1,384,174条的条件Acc为88.022608460%，其余
2,449,682条为94.037516967%；26源族重采样配对95%区间
[-8.087108482,-6.139064044]pp，改变3,802,812行。
预登记的总体98.95%及近轴98.20%均未过。

离线CPU155.564874秒、wall77.410073秒、RSS2,020,216,832B，
模型282,096B；以上不是完整提交程序资源测量。固定原坐标趋势
加这组特征与128棵depth7教师停止扩大，正式exp825未改变。
此次趋势只使用原坐标，而正式程序先执行首Net消元，再依据
对齐位移、首段费用及Line费用计算。原趋势相对上一臂的
2.182pp进展提示主趋势分离有作用，但不足以证明更精确的
首Net趋势可行；需要单独判别首段状态提供的条件信息。
本地`/dev/sdd`收尾仍259GiB可用，未删文件，释放0B。
