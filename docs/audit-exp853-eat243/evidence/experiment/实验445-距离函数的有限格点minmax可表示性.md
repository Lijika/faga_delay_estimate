# 实验445 距离函数的有限格点minmax可表示性

2026-10-18预登记。exp439的局部仿射候选平均约10.5个，
全局max仿射和min仿射受到双向曲率反例限制。本轮检查多层min/max能否
利用同一批局部平面精确表达二维距离，而减少区域切分树的节点。

对象固定为SEA、LE两份原始名义场，每源4个符号方向、10×12余数、
160目标，共76,800张商网格。复用exp439的2×2仿射格生成所有不同平面，
不新增任意拟合面、不读取真实请求exact或调整已冻结估计器。

对格点i定义U_i为所有在i处大于等于真值的平面集合。
候选表达式为F(x)=max_i min_{j属于U_i} l_j(x)，合并相同集合并删除
包含另一个集合的冗余项。每点有至少一个取等面时，F(i)>=f(i)；
若每一对(i,k)都有U_i与{j:l_j(k)<=f(k)}相交，则F在全格点等于f。
这个有限域判据自行推导，记录于Obsidian理论笔记；连续函数文献只提供动机。
空集合或缺少取等面分别记录，不将其算作恢复成功。

先用仿射、凸、凹、混合min/max和不可表示负对照做自检，
再逐格恢复两源全窗口，报告可表示网格、覆盖值、项数、平面数、
工作量和首个可复算反例。无源内或源间泛化结论。
若至少95%网格由原平面精确表达，继续研究共享编码及随机查询；
低于95%则当前固定平面集停止扩大，保留不相容见证指导区域或核表示。
容量与真实请求精度均独立待验；本轮无完整算法性能宣称。
