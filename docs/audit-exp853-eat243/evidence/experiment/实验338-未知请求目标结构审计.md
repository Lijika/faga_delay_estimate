# 实验338 未知请求目标结构审计

2026-10-17。起点23c8a63，分支research/exp337-lazy-bucket-repair。
本轮只审计非重复请求中的目标端口、目标cell和完整目标pin重用，
不修改估计器、不生成预测输出，也不把重复目标结构当作结果缓存命中。

## 预注册

最终1B请求对全部唯一且事先未知。目标请求本身不能通过完整请求键
复用结果；目标端口、目标cell和目标pin仍可能在不同请求间重复。
当前262144行批次按目标端口分组，假设更细的目标cell分组可能减少
目标相关准备或改善局部访问。先量化实际频次与批次内重复度，再决定
是否创建候选。

固定输入：

- 本地U-output：`build/exp262/output-1m.csv`
- 本地公开：`delay_estimate_request.csv`
- 远端U-output 1B：`build/hidden-suite-v1/output-1b/requests.csv`
- 远端U-role 1B：`build/hidden-suite-v1/role-1b/requests.csv`

输入只流式读取，不保存副本，不重排请求，不执行估计器。解析目标
`SRB_x_y/Port`，记录全局目标端口、目标cell和目标pin计数；每个
262144行批次记录三种键的distinct数、重复行数和最大端口组大小。
同一目标pin的计数只说明准备共享机会，不属于结果缓存命中。

停止条件是输入身份变化、解析失败、计数溢出或磁盘异常。输出为
小型JSON统计与原始身份；结果只支持结构判断，不支持CPU收益或精度
结论。需要新增理论时沿用已有[[有界目标分组与请求换序等价]]，
本轮不引入新的路径假设。
