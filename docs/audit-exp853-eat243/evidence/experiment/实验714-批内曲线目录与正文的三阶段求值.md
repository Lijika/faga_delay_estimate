# 实验714 批内曲线目录与正文的三阶段求值

2026-10-25，在新增候选计时前登记。基线为exp708已经完成1B的
exp707/M，56B状态、批8、SSE2及全部资产保持冻结。
接合报告第7.3、8.1、8.2节和exp709完整处理骨架结果。

## 假设与改动范围

当前prepare发出曲线code目录预取，finish在背景求值后才依次读取
code和曲线正文。候选C在整批prepare后加入一次stageCurve循环，
取得code、计算正文偏移并发出正文预取，再按原行序finish。
复用ready远域状态中不再用于返回值的answer字段保存正文偏移。
状态保持56B，raw仍是double；近域、提前返回及cycle覆盖保持原链。
正文值、两次舍入、每块尺度乘法与树累加顺序全部保持。

只改私有worker、组件检查和驱动，不改生产源、解析器、reader、
writer、模型或构建参数。逐请求predict和审计入口也必须经过stage。
相对exp628/629，当前背景从Q4变为距离曲线，且exp707已减少准备
工作；本轮只重开这条目录依赖，保持稳定行视图，不增加文本复制。

## 验收与预登记

先验证239616条路径见证的四折逐字段、浮点位模式和最终整数结果，
补充496端口及坐标边界的提前返回组件；检查正文偏移实际范围及
sizeof。上述均为组件检查，完整程序测试从非重复100M开始。

复用exp685的全端口非重复100M及完整输出、契约和1916928条exact
身份，因为函数与输出相同。r9实际为6226R，6242R性能另待实测。
固定CPU8，同机串行，A/C各一次预热；随后六轮成对运行，
顺序为AC、CA、AC、CA、AC、CA。主指标为完整CPU，逐对计算
A-C的均值及t(5)双侧95%区间。实际收益门为均值至少0.5秒/100M，
且区间下界大于0；逐行输出SHA相同，查询分配为0。
资源门为单线程、RSS不超过300000000B、wall不超过3600秒，
静态单ELF严格小于100000000B。

通过后及时接入阶段版并完成全端口非重复1B；同次输出相同时复用
3833856条exact评分。未通过时停止固定三阶段与answer复用配置，
保留其他调度、树等待窗口和更大结构削减的研究资格。
性能收益只对当前硬件和输入作结论。

## 执行与资源

远端目录为`research/exp714`，exp713审计结束后串行构建和计时。
驱动使用`python3 validation/exp714_curve_pipeline.py build`及`run`。
每个重复输出在完整SHA与保留参考相同后逐文件删除，并记录重建命令。
本地开工`/dev/sdd`可用279GiB；远端空间另记在freeze和report。

## 完整结果

组件检查通过239616条见证的四折字段与浮点位模式比较，以及99200个
边界案例，状态仍为56B。两次组件设置失败分别来自留出模型宏和审计
dump目录，原始证据保留；生产计时使用原生产宏。

14次完整100M全部输出SHA与冻结参考相同，查询分配0、单线程、
RSS与时长均通过资源门。六对正式计时的A均值为21.773397秒，
C均值为21.652559秒，节省0.120838秒，配对95%区间为
[0.030032,0.211644]秒。点估计低于预登记0.5秒门，选择A，
停止当前固定三阶段与answer复用配置的扩大。

输出保持，复用1916928条exact评分与契约证据；新增exact为0。
独立审计从逐次run、完整SHA记录和清理记录重新计算均值、区间与门，
结果通过。已删除14份与保留参考同SHA的重复输出，共56189906710B；
逐项身份与重建命令在cleanup记录。本轮核验复用这些SHA记录，
原始输出在删除后没有再次逐字节读取。

正式阶段版继续为exp708/M，1B仍为226.157413秒及抽样Acc98.658061657%。
本轮没有新增1B或交付包。收益结论限r9实际6226R和既有100M分布，
6242R及其他调度布局继续待验。本机收尾`/dev/sdd`可用278GiB。
