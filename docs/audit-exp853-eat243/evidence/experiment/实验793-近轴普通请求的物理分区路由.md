# 实验793 近轴普通请求的物理分区路由

2026-10-28预登记。exp792用exp791固定alpha=12/5背景并匹配残差，
相对exp787开发Acc下降0.001718pp。分组差为qx0 +0.187966pp、
qx1 +0.092799pp、qx≥2 -0.064036pp；H/V分别下降0.025381/
0.007967pp。该结果显示同一共享普通残差函数同时面对相反分组变化。

## Altitude 与主假设

近轴与其余距离的残差响应可能不同，使用统一普通T2D6模型会把
纠正近轴的自由度与保护qx≥2的自由度耦合。本轮只对ordinary
按`qx<=1`显式分区，为近轴请求训练独立的相同规模16路T2D6；
qx≥2保留exp792普通预测，H/V全部保持exp792预测。单个请求仍只
执行原有16路之一的16棵depth6树，新增的是静态模型资产和分支，
不增加每行树数。静态体积、缓存压力与CPU仍待实测。

## 固定训练和验收

数据、source-pin三折、训练器版本、普通参数、输入特征、B1024
背景、匹配目标与exp792完全相同。每折×原16路仅在ordinary且
`qx=0,1`训练并验证新模型；保证同一source-pin cluster不跨训练
和验证。验证只替换exp792普通预测中的qx0/1行；qx≥2及H/V逐行
保持exp792整数预测。禁止超参数搜索和额外exact标签。

开发门要求相对exp787匹配预测总体增加至少0.02pp，qx0/1各组
不下降，方向最低不低于-0.05pp，H/V最低不低于-0.25pp。若未过
则停止这个固定二分路由；若通过仍需独立测模型静态资产、完整
输出和现成非重复100M CPU/Acc，达到项目联合收益门后才做1B。

## 证据边界

这组百万标签是反复使用的开发数据，exp788/792也已参与假设形成，
因此只作路由机制筛选，不能作未知1B泛化结论。路由同时改变模型
集合与分组函数，不能把差值解释为纯背景收益。
