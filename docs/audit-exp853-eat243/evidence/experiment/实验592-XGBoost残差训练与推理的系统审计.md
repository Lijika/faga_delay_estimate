# 实验592 XGBoost残差训练与推理的系统审计

2026-10-22，查看本轮数值结果前登记。接续exp590，主问题为当前R8
是否存在残差泄漏、原精确行污染、特征职责偏移、切分泄漏、树叶支持
不足，以及训练标签、权重、背景迁移、导出和选型等异常。

## 冻结范围

复用exp554完整唯一开发1M，全部59,904端口对，三折及各训练补集均
全端口。复用N192背景、R8真实OOF预测、冻结D64背景与最终R8 trace。
最终全数据训练模型的开发预测只用于实现审计，泛化结论使用OOF与
exp588新请求证据。所有数值审计在r9指定目录，模型和生产路径保持。

核查源pin分组是否一一对应，三折源pin交集为0；追踪R8与教师蒸馏
源码的训练/预测掩码。Design/Circuit不在请求字段中，其分组适用性
依据赛题请求语义说明；内部路径共享需要额外path_id证据。

## 固定诊断

- 状态为精确、(0,0.1%)、[0.1%,0.5%)、[0.5%,1%)、[1%,5%)、>=5%。
  输出完整转移计数和官方分贡献；对近域、近轴与D0标签差异分组。
- dead-zone固定为0.5/1/2/4ps，诊断全1M损益。全部作为开发集描述，
  本轮不据这些阈值发布候选。
- 分别量化D0+mandatory与truth差异、128ps分母下限、真实分母权重、
  N192到D64的残差目标迁移。权重scale与min_child_weight的关系回查
  安装版本3.0.5官方源码。
- 遍历16路×8树，统计使用特征、分裂收益、叶子实际行数、加权支持和
  有效样本量；逐位重建最终native输出，核对保存sum_hessian。
- 复用完整1M JSON/C++等价、零核内分配、静态ELF及资源证据，核查
  缺失值、常量特征、阈值范围、基准背景和评价数据身份。

诊断通过条件为数据身份与全端口成立、状态矩阵覆盖全部请求、逐行
分数贡献恒等式成立、重建native逐位一致、训练节点权重在浮点容差
内一致。实证问题、已通过检查、待验证假设分别记录。发现收益方向
后另行冻结候选与门槛，不把描述性诊断当独立泛化结果。

## 完成结果与问题归因

全部诊断断言通过。当前数据为完整唯一1M、59,904端口对，source pin
共960,505个且与cluster一一对应。三折训练/验证均全端口，各折source
pin交集为0。R8采用真实OOF；exp585教师采用嵌套crossfit，teacher门
失败后未训练学生。final全数据模型预测只用于导出核对和支持量审计。
请求字段不含Design/Circuit，因此当前分组单位依据source pin定义；
共享内部路径、空间外推和跨架构泛化仍需要各自证据。

N192上R8 OOF将acc从97.649828648%提高到98.060711882%；冻结D64上
从97.918425765%提高到98.327666547%，增益0.409240782pp。
D64改善325,789行、变差237,546行。43,609条原精确行中23,167条
变差，贡献-0.010897594pp；最终精确44,268行。当前小修正有精确行
损失，整体收益清楚，污染程度与exp590旧E32分别记录。

固定dead-zone 0.5/1/2/4ps在D64上变化为0、+0.000916392、
+0.000853836、-0.006762441pp。收益不足0.02pp实际门，保持原R8。
0.5ps阈值对最终整数输出没有收益也符合舍入行为。

1,802个叶子中22个仅1行、192个少于10行、669个少于100行，实际
支持中位数281.5行。保存sum_hessian与训练权重和的最大相对误差
1.0678e-7。按固定3.0.5源码，L1分裂使用g=w*sign(e)、h=w；
min_child_weight限制权重和，当前默认1可容纳单行叶，适合另做容量
消融。叶值按加权中位数刷新并已乘eta；lambda主要通过结构增益起
作用，不能把通用二阶叶权重公式直接解释为这里的最终叶值。

53特征均有限且无常量。前26相对/端口特征占38.8292%分裂数、
8.5503%分裂收益，后27真实位置/几何特征占91.4497%收益。
forced_detour、ax、tx、arrival_band、target_band位列收益前五。
特征没有直接使用背景预测；当前树主要关注几何。gain统计不能证明
删除相对特征有益，下一轮需保留全部特征与几何特征做配对消融。

D0+mandatory与truth在27,188行不同，差值0至354ps。即使D0精确，
该分解的oracle acc仍为99.909873713%。当前final在不匹配组为
95.864323769%、匹配组98.413409789%；总延迟残差是可检验方向。
128ps分母下限只影响5行，近域降分的主要解释应另找。N192到D64
背景改变943,498行，差值-73至72ps；现R8仍使用旧N192残差标签。
exp587已证明仅更换N512/N768目标的收益很小，D64需另行冻结消融。

## 标签来源与实现核查

名义矩阵来自exp499的完整场和exp500-preparation的全量核验记录，
exp510.materialize只做坐标置换并逐源核对压缩/原始SHA与逆变换；
exp589继续核对矩阵SHA c3aaeca23271dbea1ff4badc8b65b4f60f6723291dc5da4a524ba8df25dd8f86。
该背景不以本批请求truth拟合，反复选型使用的请求仍按开发数据处理。
独立请求精度证据来自exp588。

tests/exp203_exact_labels.cpp经冻结scaffold调用terminalQuery(...,true,...)，
关闭请求cache，并对标记请求比较无bound、binary heap参考求解；
tests/exp553_no_line_paths.cpp复用该入口并逐路径重算费用。
Router使用确定性的整数A*/Dijkstra，相关入口没有随机采样或时间截断。
因此当前没有依据把小叶拟合描述为随机绕线噪声；全量未知图语义的
正确性仍以既有exact证据及其架构边界为准。

最终原生float32树值逐位重建相同；路由选择、所有53特征、严格阈值
边界、raw有限、最终整数输出、base_score=0及eta均通过核查。
无类别分裂。未发现重复学习率、自动截距遗漏或当前有限特征域的
缺失值分支错误。全部过程的数值审计在r9，CPU8.107021441s、wall
8.258279388s、RSS586,829,824B。磁盘从1,170,579,456B变为
1,170,227,200B，新增证据352,256B；没有新增大trace。
