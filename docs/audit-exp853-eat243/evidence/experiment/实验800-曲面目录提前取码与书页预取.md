顺序、路由、解析、输出与 ISA 保持一致，适用于 x86-64/SSE2

## Tactical：冻结验收门

现成输入为 r9 的
`/dev/shm/eda2026-exp781-scale/u-role/requests.csv`，大小
3,519,796,063B，SHA-256
`b26b7e7942dadcc21f58251758fd60da3d0222f8a80bcefd9d86703ddbad7bea`；
完整 100M 输出必须为 4,013,572,706B，SHA-256
`d69146449c13321f6acc1ae665e169b54be75aa41214f3783fd31a95771dbe75`。
先用该文件前 1M 做完整输出契约、端点次序、整数、精确 EOF、
单线程及 RSS 检查；构建需静态 ELF<100,000,000B。
在任何计时前冻结二进制、输入、顺序与本节门槛。

r9 Xeon Gold 6226R CPU8 绑核仅用于可比计时，预热两臂，
四对交错顺序为 FC/CF/FC/CF，F 为原 ELF，C 为候选。
单次输出核验完整 SHA 后按名删除。主门为 F-C 平均至少
0.25s/100M，四对双侧 95% t 区间下界>0，单线程、
RSS<=2,000,000,000B、CPU/wall<=3600s，Acc 逐行不变。
不通过即停止本布局，不为触发 1B 改门槛。

通过才对现成、非重复、全角色 1B 输入作 F/C 完整配对，
两臂输出经 40GB memfd 核验完整 SHA，与 exp780 同身份时
复用 3,833,856 条 exact 样本。阶段门要求 C CPU 比同对 F
至少减少 2.4 秒，即综合分增益至少 0.02；单对只作观测，
不宣称 CPU 置信区间。仍须检查单线程、ELF、RSS、精确 EOF，
正式接入前独立复算并阅读两份 subm 打包规则。正式入口在
所有门槛之前保持不变。

## Depth：依赖和条件

目录提前读取可能把串行等待从 `finish596` 搬到
`prepare596`，增加栈状态和书页预取量；完整程序与原版
配对决定收益。exp785 的末尾预取结果只代表其 AVX2 gather
结构，不能推断此处标量流水。该优化不改善当前 Acc 距
严格大于 99% 的缺口，后续仍要在静态容量与热集预算内
研究背景条件信息，保持路线 B 的系统级目标。

原始证据放 `validation/results/exp800/`，程序与资产在 r9
私有目录。开工本地 `/dev/sdd` 可用约 266GiB；保存现成
100M/1B 输入，输出核验后删除或关闭 memfd，收尾记录空间。
