# 实验407 后桥分组的架构次数费用下界

2026-10-18，新结果前登记。正式exp354，CPU发布基准exp323。
控制为exp406的架构表选择器。主假设是固定左桥、内桥和分支后，
后桥桶的最低桥费与次数函数的后缀最小值可跳过整桶，减少候选扫描。
竞争解释是下界太松、后桥桶太小或准备开销抵消收益。
理论见Obsidian《后桥分组的架构次数后缀下界》。

预计算Q(b,a,c)=min{F(b,x,y):x≥a,y≥c}，次数域与exp406相同。
Q共5,246,976项，每项uint16，新增10,493,952字节，
65535表示无限；构建时验证所有有限F<65535。
每个目标端口及位移余数桶统计后桥最小费、dx/dy极值。
固定前缀后由极值取得NX、NY各自的最小值，
Q与最小后桥费之和给出整个后桥桶的名义费用下界LB。
只在LB严格大于当前名义双核心胜者费用，且LB+强制Line≥当前合法实际费用时跳桶，
保证费用、稳定见证与全部进入DAG的候选次序保持。
第一个条件保持严格不等号，稳定同费候选继续检查。
前128个有限样本采集完成后才允许跳桶，既有样本记录同时保持。

普通及ASan/UBSan核对全部Q项的下界和邻接单调性。
4096分支各6×6个矩形独立全枚举，共147,456项，与Q逐项相同。
77条沿用开发中段，核对名义结果、真实费用、稳定见证、全部DAG工作计数；
实际访问候选、费用界过滤计数按新工作量分别记录。
sanitizer前4条，费用、词和对应新计数与普通保持。
新增只读audit-group运行逐一检查每个被跳过候选的真实名义费用≥LB，
以及两个跳过条件；该运行不参加计时。复用既有标签，不生成新exact。

Xeon Gold6226R核3、通用O2、同ELF、单线程串行。
控制及候选先各预热1次，再按A/B、B/A、A/B交错3块完整选择器进程。
主性能指标为77条选择CPU配对差，最小实际收益预定5%；
三块t区间95%上界小于0且点估计达到5%则判选择收益明确。
同时报告初始化、完整进程CPU差及区间、峰值RSS、后桥桶数与实际查表数。
候选减少比例预定至少20%用于保留该组表示；CPU和工作量结果分别报告。
本机AMD只作语义与资源诊断，不据其时间弃用候选。
每进程CPU≤120秒、RSS≤2GB、单线程；sanitizer放开虚拟空间限制并核对RSS。
任何语义或资源失败保存并停止扩大。

完整估计器CPU、总体acc和新全图exact本轮均为0。
完整候选形成后仍须新请求及完整1M、10M、100M阶梯验证。
开工/dev/sdd可用385G，收尾记录清理清单。
