# 实验790 近轴目录单比特与信息密度

2026-10-28预登记。exp789认证名义精确替换在历史百万开发集
提高0.288621517pp，而按direction×剩余码号的均值表下降
0.002219220pp。主假设是共享码号内的剩余误差有方向相反的
两类形状，exp787每context 32bit字的bit21尚未使用。
路线B需要同时证明精度信息、静态预算和随机查询成本。

## 固定两级判别

复用exp789百万条历史数据、认证552点名义曲面、exp787完整
目录及已有折外残差。对每个唯一pair×context，提取qx0/1
全部92列，用exp777原非负权重；旧背景与精确名义的差记为
残差。按每行92点加权平均并四舍五入到有符号int8，得到
“每键一个标量”信息上界诊断，仅评估该标量能保住的官方
整数评分增益；它需要每context额外一个字节，不能直接部署。
保持其他qx及cycle不变。

在不读取任何真实图延时标签的前提下，另用全部百万认证
曲面拟合每个direction×旧B码×92列的非负残差幅值，选码
保持原状。每键用全部92列加权L1，在`+幅值`与`-幅值`
之间确定性选择，tie固定负号；将该选择作为bit21写入
原uint32目录字。高精度一位方案在历史百万上使用原折外
连续残差解码预测，额外码本为`4×1024×92×int16`，
并统计原始bit比例和与原目录合编码后的实际字节增量。
对全源静态容量须另验；这里只允许先用已保存开发键，
不从开发键压缩率宣称全源可交付。

第一门要求标量干预总体提高≥0.08pp，位选择总体提高
≥0.04pp，qx0/1每组不退化，四方向最低≥-0.05pp，
H/V最低≥-0.25pp。若未过，只停止固定旧B码幅值、
单比特符号与旧残差的配置；记录上界和失败层级。
主流程单线程CPU≤600s、wall≤900s、RSS≤4GiB，
本轮无新的真实图标签。

第一门通过时才在固定源号`[0,19,48,75,104,133,170,207]`
对完整认证名义字段和exp787原uint32记录重新计算92列符号。
每源独立用原exp787字段字节平面和同一zstd9参数压缩旧/新
目录，逐源核验旧目录SHA、位以外全部32bit不变、解压恢复
完整字节。以实际旧目录文件字节作基线，记录8源各自
增量与bit比例；这是容量先行证据，不把8源平均直接
外推208源。若8源任一增加超过30KB，停止固定一位编码
的完整构造；否则继续全部208源并以真实静态ELF验收。

完整质量、静态与RSS都通过时才重训匹配残差并做100M
完整程序配对；复用现成非重复100M和exact，按既有
联合门判断1B与阶段发布。缺少实测100M不得报接入收益。
纯诊断证据在`validation/results/exp790/`；r9私有目录
`research/exp787`。开工本地`df -h /dev/sdd`可用266G；
不删除任何保留输入、静态资产或原始日志。
