  3,833,856 个 exact 抽样行。r9 same-arm 已有七组完整输出 SHA-256 一致性检查

  与 rawzero 两个完整 1M replay，覆盖 6,032 个有向 pair、population mass
  100,707,454（全总体 10.0707454%），使用固定图成对区间。EAT131 的独立检查
  54/54 通过，Main 的 full-row analysis 对两个 current 点独立一致。
- EAT129 对完整 development 1M 的 parent097 做全行、全 pair 加权会计：59,904

  event、route/source-family、target-family 分区。这些 oracle 只定位丢失信息，
  不构造生产预测器。
- EAT132 回到 current117 实现检查候选前提；EAT133 仍在执行，尚无最终结果。
