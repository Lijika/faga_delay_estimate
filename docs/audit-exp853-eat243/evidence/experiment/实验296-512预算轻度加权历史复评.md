# 实验296 512 预算轻度加权历史复评

## 预注册

2026-10-16。当前 exp292 已通过完整 1M，exp294 的 highg384 正在
exp295 独立新窗口验证。本轮在读取 exp295 新标签和预测前固定另一个
历史方向，exp295 窗口全部排除于本轮选型。开工磁盘约 409 GiB。

exp257 的 256 预算、权重1.005/1.01/1.02 直接替换 acc 分别为
98.844724%、98.810437%、98.557538%，旧负证据保持。本轮主假设为
当前 512 预算和默认 Both 回退下，较轻的前两个权重有可能满足
总体 acc>99%，并减少完整查询 CPU。三个主臂为 exp292 fixed
baseline、weight1005、weight1010；均512展开，同 f 原 id/g 排序。
源码复制到私有目录，模型、bias、终端消元、真实边与 P 回退保持。

私有接口的权重单位统一为千分位，键为 g+floor(q*w/1000)，两个
候选的默认 w 分别1005和1010。全部已知调用者为 residue 默认调用
和本轮探针，探针显式传入千分位权重。按非负 int32 q、正 int32 w
和 uint32 g 的范围证明 uint64 乘加无溢出，推导见 Obsidian
`agent-theory/定点轻度加权排序的路径合法性与精度边界.md`。
通用 O2/C++17 静态编译，无新依赖或架构专属指令。

先用实际候选源码对 exp257 的12,150条开发请求检查八臂
raw256/raw512/raw1024、light005/light01/light02（256预算）、
light005-512/light01-512。前六臂逐字段与路径重现 exp257，
全部有限结果经原始 JSON 独立重放，U>=exact；同权重小预算完成时
较大预算字段与路径保持。六条内置边界在各权重下检查，完整程序
七行边界另验。探针 CPU 只计成本。

Xeon core3 同机串行，在 U-output、U-role、exp258 三个已查看
exact 样本上，各组三臂预热，再正序/逆序/正序三轮。同次完整输出
记录 acc、配对差、分组误差、变化行、CPU、RSS、单线程、字段及
完整 SHA；baseline 须匹配 exp287 search512-both。同臂多次一致，
标签复用，评分单列。acc 分层 bootstrap 10,000 次，seed
20261016296；CPU 三对 df2 Student-t 95% 区间，两端加0.02s舍入，
0.5%只作效应描述。区间按单比较报告，探索后需另用新请求。

总体 acc>99% 且处于逐分布点前沿或比较仍不确定的候选保留；选择
三个分布都满足精度门的最快新候选继续另行冻结的新请求与完整1M。
若均不满足，保存证据结束这两个固定权重的扩大。路径或历史复现失败
先停止性能测量。AMD 时间只作参考，独特完整1M、100M/1B、跨架构
及官方平台均待相应验证。exp295与本轮远端计时严格串行。
