# 实验290 历史短预算双端点新请求复评

## 预注册

2026-10-16，exp288 的 pin 隔离窗口已经用于 search768 的选型，
本轮明确将其 12,315 条 exact 样本作为开发集使用。
本轮固定已在 exp287 同批旧开发样本满足总体 acc >99% 的
`search512-both`，与通过 exp288 完整 1M 验证的 `search768`
在同一新近开发样本上直接比较。基线 ELF SHA 为
`153f6ead6b661e4fd120e4200c55ca95f397c71abb26512c37710a49b4e1e1d5`，
候选 ELF SHA 为
`af6bee05009fcc1595213538ffc0bfa051635783ecf84d5f44c06004d04662ed`。
均复用现有静态构建；正式入口、版本包和其他用户改动保持现状。

主假设为 512 次搜索配合双端点能在排除后窗口总体 acc
严格大于 99%，同时比 search768 减少同批 Xeon CPU。
最低实际收益预设 0.5%，仅作效应描述；以同一输入、硬件、
计时协议下 CPU-acc 帕累托前沿及其不确定性保留候选。
若候选 acc 未过 99%，仍保留 exp287 旧分布上的原始通过结论；
若本次 CPU 区间下端 >0 且被 search768 精度支配，则保留本次
负证据并结束该固定组合在本分布的扩大测试。

复用 exp288 已核验的样本、权重和 exact 标签，
检查其完整 SHA、行序、零与不可达行，不重跑 exact；
重复评分使用同次运行的输出。Xeon `r9r4900` 在现有远端工作目录内
绑定 core 3 串行，预热 AB 后固定 AB/BA/AB 三对，
A=search768、B=search512-both。两臂每次执行完整程序，
计时 user+sys 包含初始化与 I/O，输出逐行验证端点原序、
整数 delay、恰好三字段、精确 EOF、完整 SHA 和重复一致。
线程数为 1，RSS≤2,000,000,000 B，CPU/wall≤3600 s。

报告排除后七带加权总体 acc、组内误差、配对差、
变化/改善/恶化行数，七带 10,000 次配对 bootstrap
使用 seed=20261016290。三对 CPU 差使用 df2 Student-t
95% 区间，两端各加 0.02 s 表示计时舍入。
两种区间均逐项解释，三对运行不检验正态性，
同家族请求相关性限制请求重采样解释。
阶段指标仍为独特 1M <100 s、100M <100 s、1B 100-300 s。

本轮只检验同一批已用于开发的样本。若样本 acc >99%
且性能仍有改进可能，后续需另行冻结未参与选型的新请求验证，
并在完整独特 1M 上核验资源和 CPU，之后才考虑正式接入。
结果、原始输出与计时存 `validation/results/exp290/`，
本轮新增标签 CPU 为 0；评分、bootstrap、估计与诊断成本分列。
开工 `df -h /dev/sdd` 约 411 GiB；收尾按项目规则核查清理。

## 结果

两臂 8 次联合运行通过完整输出契约、重复 SHA、单线程和
2 GB/3600 s 约束。既有 exact 的 204 条不可达在两臂保持；
零距离组 27 条标签均为正值。候选总体加权 acc 99.1401970034%，
search768 为 99.2269216136%，配对差 -0.0867246102 pp，
七带 bootstrap 95% 区间 [-0.1189480744,-0.0521194193] pp。
候选绝对 acc 区间 [99.0827133304,99.1948103492]%，
总体 acc 条件通过。546 行变化，改善 76 行、恶化 470 行，
各组误差在 `sample-report.json`，301+ 组 acc 为 98.865782%。

同批 Xeon 样本基线三轮 CPU 4.21/4.22/4.22 s，
候选 4.14/4.14/4.16 s，三对差 -0.07/-0.08/-0.06 s，
均值 -0.07 s，节省 1.6601%。含计时舍入的 95% 区间
[-0.1148413771,-0.0251586229] s。此样本点前沿保留
search768 与 search512-both，区间不足以把配对 acc/CPU
的交换推广到其他输入分布。最低 0.5% 描述门达到。

8 次估计 CPU 合计 33.46 s，最大 RSS 1,694,957,568 B，
最大 wall 4.23 s。新评分 CPU 0.061363318 s、
bootstrap CPU 4.392360475 s，新增 exact CPU 0。
原始完整报告 SHA 为
`b9e0f179ecefef6c2b43a0b44860647d16afc12c60619c24a202ba6efce939ce`。
本轮结果代表已经查看的 exp288 保留人口 1,521,323，
不能宣称独立新请求验证。历史 exp287 四套分布原始前沿继续保留；
搜索 512 在 exp255 未过 99% 的记录也保持。

冻结时可用 440,312,958,976 B，收尾约 440,311,328,768 B；
`df -h /dev/sdd` 仍约 411 GiB。新增文件均小于 10 GB，
删除 0 个文件，主动释放 0 B。下一步冻结新窗口并生成独立 exact，
随后再决定是否扩大完整 1M。正式入口和包身份不变。
