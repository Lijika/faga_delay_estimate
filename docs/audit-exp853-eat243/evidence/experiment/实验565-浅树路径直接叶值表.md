# 实验565 浅树路径直接叶值表

2026-10-21，结果前登记。复用exp561冻结O8三折模型和完整非重复1M，
全部59,904端口对，每折及训练补集全部端口覆盖。模型、分裂条件、特征、

该质量依赖预生成精确背景Q，完整候选背景仍由exp564研究。

## 主假设与实现

L为exp561的按层交错遍历，末端依次查询路径到叶编号和叶编号到叶值。
D在导出时按完整四层路径直接复制原float32叶值，运行时一次查表。
浅叶填充的每条路径均独立核对编号和浮点位模式。Trace保留原叶编号，
计时路径保持零查询分配、通用x86-64静态构建和原浮点运算顺序。
该表保存现有非对称树的路径值，分裂特征仍由前缀路径决定。

PSHUFB、对称树重训和INT8-MLP本轮保留为后续候选，本轮只验证直接
表能否以更少的依赖查询获得收益。精确背景、特征计算及完整CSV程序
成本另计，当前100ns组件证据沿用exp561并在相同硬件重测。

## 验证与停止

仅在r9测试。核对exp561原始导出资产、输入和独立保存审计；完整1M
L/D原始float32逐位一致，与既有独立预测一致；全部退出叶、预测依赖链、
端口覆盖、线程1和核内分配0分别核验。任一失败停止并保留现场。

先完整check各一次、预热各一次，再固定交错LD/DL/LD/DL/LD/DL，
每臂六次完整1M有依赖单次调用。主效应为六对L-D的CPU均值与双侧
95% t区间，df5系数2.5705818366。均值节省至少5%且差值区间下界
大于0时保留；100ns另以D均值及其95%上界判断。禁止与exp564评分
或其他重负载并行计时。预算CPU240s、新增逻辑资产400MB。

完整程序、精度新分布、完整ELF和10M/100M/1B继续分别验证。冻结
独立exp562数据继续隔离。本实验结束前不改变上述选型条件。
