# 实验795 近轴专家的支持域回退

2026-10-28预登记。exp794以`ordinary && qx<=1`选择exp793整列预测，
相对exp787开发分增加0.044661990pp。但exp793实际只生成了24个
折外模型：8个route各3折；其余route没有可训练样本，预测数组在这些
格仍沿用exp792。直接把整段qx01输出称作近轴专家会把背景回退混入
专家效果。

## Altitude 与主假设

exp794支持“把B1024近轴专家和exp787其余人口分开”的组合思路；
部署条件还需服从模型支持范围。用三个fold都存在的route作为专家支持域，
仅在ordinary、qx<=1且route有完整折外模型时选exp793预测，其他行恢复
exp787。这样将近轴专家实际贡献与未建模route及全域背景变化分离。

## 固定判别与停止条件

- supported route集合从exp793-run4模型清单机械求交集，禁止看新评分后改集合。
- 对照和输入沿用exp787、exp793已冻结的同一百万历史开发数据；
  不训练、不新增exact标签、不改路由边界或模型。
- 非路由行逐行必须等于exp787；H/V保持逐行不变。
- 主要门：总体相对exp787至少+0.02pp；qx0/1分组均不退化；
  四方向最低不低于-0.05pp。
- 通过后再构建静态单线程候选，在项目保留的非重复100M上测完整程序
  CPU、RSS、输出契约与同次exact评分。该100M固定数据已有历史用途，
  结果按本次请求、二进制及标签身份报告。
- 该评分仍属于开发复核，不作为未知输入的独立泛化结论；若此门失败，
 停止当前route支持子集，不扩大模型家族。
