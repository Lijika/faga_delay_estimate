# 实验399 双端短连接单核心的开发路径质量

2026-10-18，新结果前登记。exp398在1M不同名义查询上费用保持且Xeon组件
187.17降至74.88 ns/次，但族内有限值仅55.43%。本轮先查路径质量，
消费方为离线开发分析，保留正式exp354和CPU发布基准exp323。
理论见Obsidian《双端短连接包围单调核心的费用族》。

主假设是允许两端各一个≤4非L Net短连接，并从8个L分量选择单一单调核心，
足以保留大部分长距离中段的真实费用。竞争解释是内部短桥、多核心、
非单调或真实Block事件决定了剩余误差。与B+F单项比较，再决定扩大索引。
暂不写完整预计算、工程压缩或生产快路。

复用exp207已核验256条定向开发exact路径。每条取第一个L Net的落点I_p
到最后一个L Net的起点Z_q，保存原中段词、费用、实际端点和名义位移。
合资格条件固定为|名义Dx|≥52、|名义Dy|≥56，物理总位移不额外限制；
这些条件保证任意双短桥后两轴剩余次数≥2。
全部合资格路径用于枚举和真实重放，前8条有限查询独立DAG逐候选求最小值。
原中段真实重放必须保持；固定末Net方向F不得重复终端Arc。
任一合法同真实端点候选低于已验exact须停止并查证。

对照为B+F，候选为B1+F(I_t终端)+B2。使用exp393全部最小名义核，
枚举完整B1和按末端口、目标q、余数分桶的B2，首末方向逐分支求费。
两轴单调核心只允许H、V，保持lane及分量。名义族最小值应不高于对照。
保存稳定获胜双桥、核心run数和完整词，独立核对名义位移、Arc费、
费用加1及Dx加1负对照。真实重放报告有效、目标匹配、Gap费用、
与原exact费用的配对差。名义最小胜者无效时本轮不替换第二名。

预先固定的扩大条件为全部合资格中段中，真实匹配且费用至多原exact的101%
的比例至少90%。该阈值仅为定向开发原型质量筛选，不等同总体acc。
未达到时保留结果与单桥组件收益，先研究多个核心或真实几何表示。
报告单项和组合的有限率、真实匹配率、费用差分布与枚举量。
不生成新全图exact、不运行完整估计器或评分、不报告新总体acc。
Python离线分析单次CPU≤120秒、RSS≤2GB，超时保留证据。
资源、格式和索引构建成本在决定完整预计算后再测，本轮无查询性能结论。
开工df可用385G，收尾记录清理与空间。证据位于validation/results/exp399。

## 结果

冻结提交87dd67a。256条定向开发路径中77条满足内部域条件。
77条原中段真实路径独立重放保持，双桥全部给出名义有限值。
42,900个候选的固定末方向费用与独立DAG等费，
1,066个不同DAG键，266个费用/位移负对照通过。
原始证据与冻结身份检查`python3 validation/exp399_two_bridge_quality.py check`通过。

| 77条合资格中段 | 单桥B+F | 双桥B+F+B |
| --- | ---: | ---: |
| 名义有限 | 56 | 77 |
| 选中词真实有效 | 37 | 54 |
| 真实目标匹配 | 23 | 32 |
| 同端点且与exact等费 | 2 | 4 |
| 同端点且费用≤exact的101% | 10 | 23 |

双桥主质量比例23/77=29.8701%，未达到预登记90%扩大条件，
当前不建立完整单核心索引。这个判定限制当前名义最小胜者与规范词恢复，
其他等费词、真实几何选择和多个核心仍分别研究。
单桥有限的56项中，双桥22项等费，其余改善，平均名义Arc费下降37.4821 ps，
最大下降214 ps。合法同真实端点费用均不低于已有exact。

描述性分析见`analysis.json`。77条原中段的净实际位移均等于名义位移，
选中双桥词的22个有效错端点均相差水平14格，其中-14有9条、+14有13条。
这支持继续检查真实Block事件与转向位置；净位移相同不代表原路径没有穿越。
匹配的32条中，费用超exact比例中位数0.651084%、最大5.912596%。
77条原词有67条含内部非L Net，60条发生长线分量变化。
这些结构说明多核心表示有研究价值，尚不证明单核心的所有替代词都失败。
