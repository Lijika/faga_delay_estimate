# 实验530 完整查询Gram驱动的混合位宽双表

2026-10-20，查看新候选结果前登记。正式入口exp354、CPU基准exp323
保持冻结身份，当前新增实现使用私有实验目录。算法执行、合成数值
检查、恢复与评分全部在r9r4900。离线训练也放在r9，复用其已经完整
保存的exp500因子，减少远端大文件传输。

## 主假设与对象

H530为完整查询加权失真能够指导有限码域、混合位宽与相关误差补偿，
使已有短点积模型保留质量并进入静态预算。第一表量化后，用当前
第一表的正规方程将第二表拟合到冻结原预测，单独核对这一系统耦合。
线上接口为启动恢复float32双表，查询保持两个行索引和128项点积。

冻结对象为exp500已通过完整恢复的int16反量化float32表。
18组各有66560×128和13248×128因子，完整开发域含208源、
288目标、59,904端口对和15,872,163,840个矩形槽。
合法物理槽为208×288×239×1099，基线名义99.3767265477589%、
近轴98.87167258980675%，静态323,950,212B。
该域已经用于历史选型，真实新请求资格继续独立验证。

## 冻结编码与三个比较项

每侧每latent列可选2、3、4、5、6、8bit，每张128列的表总位数
不超过448bit/行。每列每种位宽以完整行的查询权重训练一个有限
标量码本，按加权分位数初始化，进行12轮Lloyd更新，中心保存
float32。码本选择和列位宽使用原始因子，全部候选共用。
有限动态规划精确最小化独立列的对角失真代理；自然latent顺序固定。
真正联合平方误差、整数评分与实际压缩分别测量。

最近码字为比较基线；feedback使用当前对侧Gram的连续相关反馈，
第二侧仍围绕原R；joint复用feedback的第一表，并将第二侧连续目标
改为冻结P在该表上的最小二乘投影。feedback和joint的第二侧共用
同一有限码本与位宽。码域外按最近端码字处理，所有有限码域误差
保留实测。正定系统使用固定相对对角正则1e-10，原始二次目标
继续用于报告。保存条件数、正规方程残差和正则化大小。

加权域按既有Gram笔记分为两个矩形，尺度d=128+125i+125j。
左侧rx=0且dx=1的行仅使用i>0列，其他行使用全部合法列；
右侧i=0使用剔除这些行的Gram，i>0使用全部行。
有限码域训练代理包含同端口零位移的原始实数预测项。
完整联合扰动及评分按原强制零路径规则扣除这些项。

每组每候选保存独立XZ preset3资产，包含头、位宽、所有float32
码本及精确bit流。列数据以低位先行连续压位；本模型行数均为32倍数，
压位列与码本保持4B对齐。恢复时显式检查位宽、码字、有限性、EOF
及全部padding。完整静态计入18份归档和mapping；正式ELF另验。
恢复主体735,510,528B，码本、压缩流、图及初始化工作区另计。

## 核验、指标与停止

先在r9使用208×288全端口合成数值矩阵核对六Gram与完整直接展开，
以及全部行的连续约束更新、第二侧正规方程、位宽预算和bit恢复。
这一步验证实现，真实数据仍要求18组全域完成。

全部18组的构造完成后才形成完整候选。复用exp500全部exact标签，
逐矩形槽使用原C++累计顺序和输出规则评分。基线完整输出SHA
须与exp500已有结果一致；每项保存完整输出SHA、逐源/目标、
余类、方向、近轴、内部指标和变化行数。保存表回读与训练表
逐元素相等，并以全部端口对的独立Python标量地址核对。

C++在完整合法物理域同时累加相对冻结基线的连续ps平方扰动，
与六Gram结果比较，容差为5e-8×max(1,直接平方和)。
合成Gram容差1e-9×max(1,直接平方和)。
完整物理域为确定性普查，源族bootstrap仅描述成组精度变化。

唯一拟扩大候选为joint。机制要求联合平方扰动较nearest至少下降20%，
另记其对feedback的单项差。候选静态资产≤80,000,000B，恢复主体
≤1,500,000,000B，完整名义评分≥99.25%，相对基线损失≤0.1pp。
达到这些门后再接真实Block、Line、Gap和未知非重复全端口1M；
随后按1M→10M→100M推进。真实acc严格>99%、完整程序CPU及
单文件静态ELF<100,000,000B分别实测。

任何身份、EOF、索引、预算、Gram、保存回读或基线SHA失败立即
保留失败记录。每阶段离线CPU≤28,800s、AS≤96GB、实验新增主体
≤8GB；门失败结束本固定位宽预算、码本与自然顺序配置扩大。
本轮不追加秩、旋转、码本轮数或结果后的位宽候选。

## 影响范围与磁盘

仅新增exp530 driver、保存证据检查和实验记录。复用exp500供数、
元数据、int16基线反量化和完整评分器；由固定源码生成私有评分器，
