# 实验136 C1/C4竞争端口与容量新请求验证

2026-10-09，Asia/Shanghai。分支`research/exp136-p1-competitor-fields`，起点`5b83a41`。正式基线exp131为68,201,104 B，SHA `aed8b929957a14cd5a2ae73bf94fedfd0cfaa86732ff79a7ee08a9e7afca064c`。exp132十个p1场压缩流为24,377,085 B，按该容量估算尚余7,421,811 B。开工`/dev/sdd`可用463G。

## 假设与固定候选

exp135在已反复查看的开发窗口中发现Arc源模板命中行主要受十端口源集合遗漏影响。后续只读开发筛选把当前集合外的`ZSEA[4]`与`ZDW[2]`排在边际候选前两位；该排序属于选型依据，不是收益证据。本轮固定增加这两个端口，不再根据新样本换端口或调阈值。

场位固定为exp132/135的p1锚点`(60,284)`，候选场分别从`ZSEA[4]`与`ZDW[2]`出发，保留全部160个Z/lane目标状态。复用`Router::distanceField`、exp115已验证的`dy`模差分与exp131同身份的静态Zstandard19打包器。每场源点、最远有限状态和八个固定stride目标须与Router A*一致，clipping为0；解压及逆变换须逐字节恢复uint16场。

容量门固定为：exp131基线 + exp132十场 + 本轮两帧 + 1,000,000 B代码/索引预算，不超过100,000,000 B。等价地，本轮新增帧合计须≤6,421,811 B。通过此门只代表数据容量有余，不代表实际ELF合格。

质量验证固定使用affine unique序号`[46M,48M)`。既有`[44M,46M)`曾由其他未启动候选预留，但没有生成请求或exact标签；本轮选择更晚且未检索到既有使用的窗口。以规范生成器生成48M前缀，核对前44M与已记录输入一致，再切出本窗口。对2M行按七个距离带分别以固定seed `20261009`作无标签蓄水池抽样，每带最多1,024行；先写出样本端点与各带总体数并冻结SHA，再查询exact。完整端点键须与公开输入、历史exact训练/开发样本及exp127开发样本不相交；命中即停止，不替换样本。标签使用冻结的`build/query_profile_exp18b`，不以任何候选预测选样。

## 候选、指标与停止

对冻结样本分别计算exp131当前预测、当前预测与既有十个p1模板的竞争值、当前预测与十二个p1模板的竞争值。模板沿用exp127真实端点解析与Line平移算法；当当前预测和模板均为非负且当前预测大于0时取较小值，其余情况保留当前预测，复用exp132已固定的竞争规则。模板近似值只作预测，不作为精确界或剪枝条件。

唯一部署候选为十二场方案。主指标为其相对exp131的七带总体加权accuracy百分点差，带权重取本窗口2M行各带总体数除以该带样本数；采用分带配对bootstrap 10,000次、seed `20260925`。报告相对exp131及十场方案的配对差、95%区间、逐带结果、场覆盖、改变行数、可达性和零延迟错配。

只有三项同时通过才进入单独预注册的生产实现阶段：新增场容量门通过；十二场方案相对exp131点收益至少`+0.03 pp`且配对95%下界大于0；false-finite、false-unreachable及zero-mismatch均不高于exp131。任一项失败即停止本候选，保留容量/评分证据，正式版本保持exp131。旧开发窗口只用于固定选择，不作本轮效果证据。

## 实现与证据

新增范围仅包括两场生成、压缩和核验工具，新窗口端点抽样/冻结、模板候选评分工具、`validation/results/exp136-*`及本记录、路线图。生产源码、根入口、正式版本、模型和交付指针保持exp131。私有构建位于`build/exp136/`；所有结果拒绝覆盖。协议先提交，工具/冻结身份提交后才生成新请求、抽样并取exact标签，最后独立复核结果。

编译及运行资源限单线程、CPU≤600秒、wall≤600秒、RSS≤2,000,000,000 B；exact查询使用既有probe记录资源。场压缩调用exp131已审计的packer，逐场记录CPU、压缩大小、SHA及恢复SHA。完整生产ELF、1M验收和平台1B不属于本轮门槛，若三项通过再登记后续实验。

收尾前重新运行`df -h /dev/sdd`。生成文件依实验规则逐项审查可重建性、哈希及引用后再决定清理，并把释放量和超10GB文件的身份/重建命令写入结果记录。
