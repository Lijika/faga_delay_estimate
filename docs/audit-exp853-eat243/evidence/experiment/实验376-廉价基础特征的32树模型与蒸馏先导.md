# 实验376 廉价基础特征的32树模型与蒸馏先导

2026-10-17，训练和查看本轮结果前登记。尝试exp258外部建议中的32树depth6
小模型与搜索输出蒸馏。主假设为一次基础residue查询配几何和端口特征，可以
在微秒量级成本上恢复有用精度。exp375说明当前低预算U/P凸融合上限低于99%，
本轮学习区间外的有符号残差。

只修改本轮私有build、tests和validation文件。正式入口与源码保留exp354，
CPU比较基准继续exp323发布版。复用现有ResidueEstimator及xgbBase47Features，
endpoint=Off、residual=Off、cache=0、residueMultiplier=2，编译关闭UpperTree
与LegalPath。47维中fast和base相同，既有掩蔽列保持0。本轮没有查询结果缓存。

固定两臂各32树、最大深度6，目标分别为exact-base与quality512输出-base。
教师来自exp368的成功U及失败P，训练目标标为伪标签；评估使用经核验的exact。
XGBoost使用reg:absoluteerror、eta=0.1、min_child_weight=10、lambda=10、
hist、max_bin=64、subsample=1、colsample_bytree=1、base_score=0、
nthread=1、seed=20261017376，不调参数、不做后验缩放。
正base且exact、教师均可达的训练行参与拟合；base<=0保持原值，所有行参与评分。
最终整数值使用max(0, floor(base+raw+0.5))。

训练池为exp368的output、role、exp258三开发集35,872条。各分布先将人口权重
归一化，再等权混合，同请求对合并权重并检查标签与教师一致；训练权重再除以
max(exact,1)，最后缩放到均值1。公开golden保持评分用途。
旧外部开发验证使用exp370的output 9,113条与role 13,615条，核对与训练请求及
端点均无交集。本集已有多轮可见结果，本轮不将其称为新独立验证。

主指标为两验证分布exact评分、相对exp323配对差、相对base改善、分带误差和
变化行数。按原分层等权bootstrap 10,000次、seed=20261017376，报告固定模型
条件下95%区间；模型训练不确定性及跨架构泛化另验。
最小有用精度改善固定为相对base至少0.10个百分点；最终交付要求仍为acc>99%，
偏好>=99.1%。若两分布点估计均>99%，后续用新请求验选型，再开展完整1M；
低于99时保留速度和误差机制证据，记录恢复所需信息。

计时分开初始化、批量解析、基础查询、47维特征生成和C++模型推理。
AMD固定三个批次，推理顺序AB、BA、AB；每次重新执行算术与树遍历，重复批次
仅用于局部成本诊断。数据集小、热内存、未含完整I/O的计时不作为阶段成绩。
验证模型JSON保存载回、C++与XGBoost逐位float32相同及整数舍入相同，
检查特征形状、有限性、端点顺序、零值与不可达行为。新exact成本为0。

先导报告完成后再决定后续实验。所有扩大遵守完整非重复1M→10M→100M，
100M<100秒与1B 100至300秒目标保持。
