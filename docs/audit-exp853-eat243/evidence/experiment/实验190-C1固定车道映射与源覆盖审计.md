# 实验190 固定车道映射与源覆盖审计

2026-10-10。分支`research/exp190-lane-automorphism`，上游`7746f02`。
开工`/dev/sdd`可用446G，正式exp131及全部已有冻结材料保持。

## 主假设与范围

40源parent可通过保持Net位移的Z端口车道置换服务额外source；
每条mapped Arc存在时，真实几何相同，按mapped Arc费用重算得到合法U。
完整费用等价提供更强的距离复用前提。原block4费用下界需要独立重定价证明。
理论及边界在Obsidian`端口置换的合法路径与重定价`。

固定映射为全20类共同的cycle1至7与xor1至7，共14项。
cycle将lane映为(lane+k) mod 8；xor将lane映为lane xor k。
本轮逐160端口及2752条finite折叠Arc检查置换、Net位移、mapped边存在与费用相等。
记录全部边、首个缺边/费用反例、finite mapped费用的精确最小/最大比值及见证。
Arc重复边沿用原商图的min语义，官方五个JSON与40源名单固定。

## 覆盖和推进规则

开发集复用exp174的6176条已查看请求、exact及冻结人口权重。
对每种映射的40个source，逐行以实际sourceArc或直接Z身份计算seed存在数。
分别记录原source、mapped source、额外source，以及14映射去重并集。
源匹配忽略terminal、parent unknown、mapped缺边及真实几何，属于覆盖上限。

可向下修正的完美oracle上限只包含当前all预测大于非负exact的源匹配行，
按官方point函数和原权重计算。该值保留当前40源已验证收益，说明额外改进的最大空间；
实际候选仍需逐链证明并量化收益。
完整unweighted映射存在且其并集oracle上限至少0.03 pp时进入完整映射原型。
全部映射并集oracle上限至少0.03 pp时保留逐链合法映射探针，即使完整映射门失败。
本轮固定一次审计，全部结果保留；未做候选调参、重标注、acc或CPU收益结论。
