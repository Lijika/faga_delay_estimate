# 实验470 评分预算提前结束的覆盖诊断

2026-10-18预登记，先于探针结果。用户提出按赛题tanh评分放宽取等停止。
当前t算法已直接计算首尾混合模型并执行Block修正，本轮只测模型下界C已知、
取等见证未通过时的末段枚举。最终输出保持，正式入口保持exp354。

主假设为候选最小值B接近C时，中点输出能以可证明的少量评分预算省去后续读取。
模型C与真实下界R分别记录。R采用强制首Net费用、首Net落点到目标的Line及
目标最小入Arc费用之和；先核对所有Z没有outgoing Arc、目标具有入Arc、
所有费用非负，再用既有40k exact开发标签审计R<=G。
理论见vault两篇短笔记《真实延迟区间的tanh最坏评分》
与《混合模型区间提前结束的评分损失界》。

固定四档单行分数损失预算0.001/0.005/0.01/0.02。
中点q=floor((C+B)/2)，delta=ceil((B-C)/2)，以整数判据
4000/800/400/200乘delta<=R识别最早触发。每档保持同一Block项H，
核对最终输出变化<=delta，并按全输入触发率计算总体确定损失界。
探针继续完整原枚举，只记录假想停止时可省的后续名义查询及候选数，
完整1M输出SHA和非时间计数须与t相同。

先做小整数区间的minimax自检、评分差界数值自检，再用私有源码运行
exp442完整非重复1M。旧40k标签只作为开发诊断，按同次输出记录配对差、
分组、变化行数；选型后用新请求验证。探针计时单列，其附加记录开销
用于诊断，性能候选另测。

任一预算档至少节省0.5%总模型读取且总体确定损失界<=0.03个百分点，
才实现该档完整CPU消融。未通过时保留计数和边界，停止当前固定R与中点配置
的性能扩大。预取已在start中执行，可省读取数只给工作量证据，
完整CPU决定实际收益。全端点与其他架构仍待验。
