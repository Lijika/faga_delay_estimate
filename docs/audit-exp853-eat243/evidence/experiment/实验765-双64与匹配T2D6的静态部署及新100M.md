# 实验765 双64与匹配T2D6的静态部署及新100M

2026-10-27预登记，exp764选择D且独立审核通过后执行。冻结正式exp728
源码及ELF，以exp701的双64/256曲线资产和exp764相同预算的匹配模型
替换对应组件，测量真实新请求上的精度与完整CPU收益。

## 构建与数值

保持exp728的融合CSV、批8、预取、SSE2通用构建、端口准备、近域、
中心、解析趋势、第一次舍入、首次Net费用与特殊循环。远域按
2*direction+(qsum>15)选左行，右表恢复原260160几何地址，每次64项点积。
无损恢复直接复用exp701，完整几何及曲线SHA须与已审核布局相同。

按exp764参数在全部旧开发数据各训练一次16路T2D6和V模型，
V沿原64轮训练并仅取固定前8棵。保持原特征、D0-B1目标、权重和种子。
普通模型复用exp720生成器和exp727坐标掩码编译，V保持noinline函数边界。
final与OOF缓存逐行核对特征、背景、mandatory、double raw位模式和
最终整数输出；OOF须复现exp764的D。坐标表逐项、叶组合及随机输入
组件继续复用既有检查。

候选需静态自包含、严格小于100,000,000B，缓存路径单线程且RSS<=2GB。
完整程序输出使用原From,To,delay契约。源码候选、模型及构建证据写入
r9的私有research/exp765，当前阶段入口保持exp728，接入由100M门决定。

## 新100M及收益门

全部208非I源、288目标角色覆盖，保证可达、非自查询、请求唯一。
复用已审核生成与抽样程序，proposal_seed20261028765、
shuffle_seed20261029765、sample_seed20261027765。
候选与基线冻结后生成新100M，剔除训练源pin及已用exact请求。
每角色对抽32个位置，共1,916,928个exact，保持source/history隔离。
输入、输出、标签和二进制保存完整身份；Acc使用完整计时运行的同次输出。

双方各预热一次，固定AC/CA交错六对，同机core8串行，并避开标签生成
等重负载。计入初始化、CSV、求值和输出；所有运行单线程、RSS<=2GB、
CPU与wall<=3600秒。完整契约核验一次，后续重复输出完整SHA保持。
时间与精度分别用97.5%区间合成保守95%综合下界。

沿exp764预登记，综合点估计至少0.002分且95%下界大于0。
100M筛选使用10倍完整CPU差估计1B成本；这项外推单列为筛选，
1B成绩另做完整实测。精度总体差至少0，保守区间下界至少-0.01pp；
距离、方向、近轴组下降至多0.03pp，V事件下降至多0.10pp。
通过后及时接入阶段版并完成有效角色全覆盖的非重复1B，最终目标保持
CPU约100秒且越快越好、Acc严格大于99%并有余量。

## 资源与停止

本轮先执行静态与缓存审核，再进入完整规模。final训练CPU600秒、
wall900秒、RSS2GB；构建与缓存资产1.2GB以内。新100M使用tmpfs普通
文件承载输入和输出以适应r9当前约2.37GB磁盘空间，双方存储条件相同；
主程序RSS与tmpfs用量分别记录，磁盘和官方平台表现待后续核验。
大文件存储位置在冻结生成配置中固定。exact计算预算CPU10000秒，
费用单列；超预算保留已完成证据，先定位成本。
完整100M任一数值、资源或联合收益门失败则停止当前部署，保留算法
收益及其适用范围；本轮不追加模型配置或调整阈值。

本地开工/dev/sdd约272GiB。清理仅针对完整身份已比对、可重建且有
保留副本的输出；原输入、模型和不可变正式包保持。
