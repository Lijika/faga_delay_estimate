# 实验207 C1 中长距离高低损失精确路径诊断

2026-10-11。沿用exp206在查看新路径前固定的256条开发请求和128个同组配对。
每对拥有相同距离带、目标y区、source class与target class。
本轮导出已核验exact Router的一条最优路径，用于解释剩余信息缺口。
私有目录`build/exp207`，开工可用445 GiB。

## 固定方案与假设

复用exp158/159的safe residue、radix和terminal-fold求解器。
私有Router只在已有relax更新时记录parent state，在最终最优终端记录目标state，
退出前导出坐标、端口和距离。距离、启发式、队列、终端选择和tie规则保持。
每条输出都须等于exp174保存的exact，逐Arc/Net真实重放，逐前缀Bellman费用、
终端端点及总费用必须一致。

主假设为中长距离真实最优路径的内部Arc费用常超过当前1200预算。
内部费用剔除source seed与terminal Arc，内部跳数对应两个Z状态之间的转移；
总Arc与总Net跳数另列。预先报告内部/总Arc费用>1200的样本比例、
内部/总Net跳数>25比例、Block/Line费用及skip、方向变化、路径外接盒。
高低损失组报告匹配差值与10/50/90%分位数，
结果仅描述所选样本；该批按已知损失选取，总体accuracy收益需新实验。
指标用于判断较大预算、真实几何候选和路径信号的下一轮优先级。

远程r9r4900按exp205、exp206之后的顺序运行，core3、单线程，
进程CPU与wall上限600秒、RSS≤2,000,000,000 B。已知exact不符、
任意前缀或终端重放失败时保留证据并停止解释路径统计。
本轮不改正式入口、基础模型或冻结选择器。

```bash
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp207_exact_paths.py freeze
# 冻结提交后，经herdr运行静态probe，保存summary和逐步路径
PYTHONDONTWRITEBYTECODE=1 build/venv-ml/bin/python validation/exp207_exact_paths.py report
```

## 实际结果

256条路径、128个高低损失配对的label、逐前缀Bellman、终端和exact重放
检查全部通过。四组样本的费用和跳数统计如下。

| 101-300/high | 64 | 64 | 63 | 8 | 11 | 2156.59 | 18.88 |
| 101-300/control | 64 | 64 | 63 | 15 | 16 | 2309.03 | 20.09 |
| 301+/high | 64 | 64 | 64 | 64 | 64 | 4294.39 | 36.20 |
| 301+/control | 64 | 64 | 64 | 64 | 64 | 4401.66 | 36.91 |

101-300的128条样本中有126条内部Arc费用超过1200，301+的128条样本
全部超过1200；301+的内部跳数也全部超过25。高低损失配对的
high-control均值差为内部Arc`-129.85`、内部hop`-0.96`、总Arc`-131.28`、
总hop`-0.96`。预算阈值对候选覆盖缺口有直接解释力，单独的内部Arc费用
尚不足以区分同组高低损失。

## 结论与限制

当前1200预算确实排除了中长距离最优路径中的大量内部费用，32跳限制也
与301+样本的真实路径长度形成一致解释。费用阈值提供了较大预算原型的
机制依据，样本中的高低损失差异仍需要新的廉价路径信号或更完整几何特征
来区分。该批样本按已知损失选择，只支持机制解释，不支持总体accuracy
外推，也没有改动正式入口、基础模型或冻结选择器。

本轮结束时`/dev/sdd`可用空间约`444 GiB`，开工记录为`445 GiB`，
释放量为0。没有删除实验输入、输出或其他大文件。
