# 实验357 top3加低Slack后继

2026-10-17，读取候选运行结果前固定本轮规则。
exp356显示235条退化请求全部丢失原路径，top3加25 ps范围可保留其中194条原路径。
本轮主假设为补入低Slack后继能恢复精度，同时保留部分q求值和入队节省。

候选固定为top3加最低预选键25 ps内所有后继。三个比较对象为exp354完整工程基线、
相同三字节位图表示的top3单项、top3加25 ps候选。预算480、权重1010、主导条件、
真实路径重放和失败回退保持；CPU最终固定参照exp323发布默认配置。

## 先导与判据

先使用exp325同一U-output、U-role、exp258开发集，三臂各一次完整程序运行，
计时输出直接评分，完整契约与资源一起记录。本机AMD时间只记录成本。
预选位图只依赖架构和目标列、residue、落地端口、主导角，不保存请求结果。
每项24位掩码使用3字节，当前规模预计265,420,800 B；度数超过24沿用完整后继。
正式预计算表原样复用，私有构建目录为build/exp357。

主指标为各分布总体acc、相对exp323配对差、分带误差、变化行数，
以及同样本搜索的evaluations、relaxed和expanded。
原top3输出须重现exp325各分布SHA，baseline须重现exp353已核验输出。
候选全部有限路径用原官方JSON解释器重放；零、不可达和边界继续检查。

有明确工作量下降的候选保留探索资格，最终交付要求总体acc严格大于99%。
无插桩Xeon计时在exp355两臂100M结束后串行执行，预热一次，100k三对AB/BA/AB，
报告点差与95%区间。固定0.5%作为效应描述参照，明确正收益继续保留。
新请求精度验证与完整1M、100M验收在候选选型后另行冻结。
本轮先导结果不计作100M或1B阶段成绩。

## 停止与成本

每条臂只改后继资格及其表示，模型和缓存容量保持当前cache0。
若自检、路径或资源失败，修复表示或保留负证据；性能测量用无插桩静态ELF。
新exact标签预算0，三套已有标签只用于开发。编译、估计、评分、bootstrap成本分别记录。
开始与结束核对磁盘，按逐文件三条件清理；正式入口和交付版本保持exp354。
