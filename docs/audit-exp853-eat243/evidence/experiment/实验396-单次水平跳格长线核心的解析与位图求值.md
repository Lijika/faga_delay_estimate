# 实验396 单次水平跳格长线核心的解析与位图求值

2026-10-18，在读取新比较结果前登记。exp395已验证单调L核心的转向次数
解析式，本轮将C++费用求值和真实Block事件联合验证。正式入口保持exp354，
CPU比较基准保持exp323。前一轮有新实现、提交和原始证据，分类为progress。

路径族限定为同一个四方向L分量、水平正向、竖向单调、恰好一次水平跳格。
源x在16至75、目标x在90至119，避开Block0。
跳格宽14、费用292、可跨行域由官方架构加载并核对。
设水平Net总数nX=(tx-sx-14)/10、竖直Net总数nY=abs(ty-sy)/12，
首个进入跨带的水平Net序号a=ceil((76-sx)/10)。
固定跳格前竖直Net数j后，Arc费为
`F(p,E;a-1,j)+F(E,q;nX-a+1,nY-j)`，
再加292与实际端点Line前缀差。

候选A枚举全部合法j。候选B使用允许j位图与转向次数解析式。
当两段均使用两个方向时，固定各段末Net方向后，j相关项只有
`kA+kB=min(mA,j-eA)+min(mB,nY-j)`；同一分量的系数相同。
系数非负时取任一可行j；系数负时取最大值区间内的可行j，
区间外只需比较其最近左、右可行位。j=0、j=nY及首段水平次数为0单独处理。
位图由实际可跨行域生成，保留全部有效端点和完整端口角色。
证明与边界见Obsidian理论笔记，两候选均为当前限定路径族的精确求值假设。

数据固定为exp394中满足限定几何域的已查看开发核心、4096条新生成的唯一
限定族请求、以及16条域外/端口/位移控制输入。新生成请求只检查受限L族，
不作为全图accuracy样本。竖直距离四档按请求交错分配，次数分别为0、
1至4、5至12、13至45；固定种子20261018，8分量与首末端口均衡轮转。
生成过程不读取新标签。固定输入后才运行求解与比较。

普通及ASan/UBSan先将C++名义F与独立单调DAG逐项比较，
再比较枚举j、位图候选和使用原resolveNet的受限真实Dijkstra。
普通版跑全部请求，sanitizer跑前256条。
所有有限切分均展开真实路径核对端点、Arc、Gap与费用，
每个普通版有限最优路径保留见证，Python ReferenceArchitecture独立重放。
费用修改与端点修改负对照应被拒绝，域外输入应返回unsupported。
任一费用/端点差异先修复并保留失败证据，再决定扩大。

主指标为有限/不可达/域外数量、三者逐项等费、可行j数与实际求值次数、
真实路径见证及资源。两候选完全通过才保留完整请求组合资格。
成本测量固定为1次预热、3个交错配对块，每项128轮请求，
逐轮打乱起始次序、每次重新计算。该重复遍历只用于组件计时，
没有完整请求结果缓存，不作为1M、100M或1B成绩。
本机CPU描述性报告；通过后在远端Xeon核3复核组件成本与输出，
远端重负载串行，初始化、解析、求参考距离与重放成本另列。
配对差采用三块的df2 t区间；仅在95%上界低于0且点估计节省至少1%时，
记为当前组件的明确CPU收益。其余结果保留待定，完整算法候选资格由语义检查决定。

实现范围为私有Core、独立受限Dijkstra、见证重放器与实验driver。
消费方均位于本轮tests与validation，无生产调用、配置或导出变更。
新请求按四条一组遍历端口组合，每组交错四个距离档；普通版覆盖全部分量，
sanitizer前256条另由完整矩阵及位图self-check补充分量覆盖。

单次普通原型CPU<=120秒、地址空间<=2GB；sanitizer单独限制CPU。
不运行估计程序1M，不生成全图exact标签或总体评分。
源码为tests/exp396_long_core.h、tests/exp396_geometry.cpp与
validation/exp396_geometry.py，私有产物build/exp396，证据validation/results/exp396。
完整算法仍需首尾接入、内部短桥、其他几何与非单调族；固定后用新请求验证
acc严格大于99并检查余量，再按1M、10M、100M阶梯。
开工`df -h /dev/sdd`可用385G，收尾记录释放量。

## 结果

实现与输入冻结提交be4e2f8。首次编译因`{E,v}`混合enum与int被拒绝，
c7ba76f补充显式转换后重新冻结。失败编译、原协议和输入保存在
`validation/results/exp396-build-type-failure-01/`，当时未读取查询比较结果。
Xeon复核runner与输入冻结于fcc140b；本机混合计时后，c79fee2单独登记
有限/不可达条件计时，补充结果按事后提出的诊断解释。

普通与ASan/UBSan的34,496项单调DAG/词恢复、45,056项位图选择自检通过。
普通版完整4,113行包括4,096条新唯一请求、1条开发核心和16条域外控制。
枚举j、位图选择、真实受限Dijkstra逐行等费，有限1,397、族内不可达2,700，
域外16。9,021个有限切分按真实resolver展开并等费，所有有限最优路径通过
独立Python区间展开重放，2,794个费用/端点负对照均被拒绝。
sanitizer前256行与普通版对应行完全相同，有限84、重放切分504。
唯一开发核心的限定族费用与原exact子路径相同。

全部普通输入的费用求值从23,164次降至5,435次，减少76.54%，本批每条最多4次。
