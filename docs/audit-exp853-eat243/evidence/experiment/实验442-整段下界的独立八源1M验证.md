# 实验442 整段下界的独立八源1M验证

2026-10-18预登记。exp441开发20k的新整段下界全部<=exact，
候选acc99.195040%，相对旧组合-0.018065pp，下界查询减少93.9791%。
本轮冻结该模型后验证新请求，不再调节算法或阈值。

输入取exp437新生成100M的第1,000,000至1,999,999行（零基编号），
继承其输入内唯一性与旧开发数据排除证据。当前exp437尚未回传评分，
本轮候选未使用该批请求选型；两项验收输入存在预先声明的包含关系。
独立抽40k生成exact，种子20261018442，四个距离带各2条扩大窗口核验。

A为exp434，B为exp441整段下界。Xeon core3、20k预热、完整A/B/B/A；
全部初始化、解析、输出计入CPU，标签和评分单列。每个候选的两次SHA相同，
全部输出行数、端点顺序、字段、整数、EOF、单线程、2GB及3600秒检查通过。
同次完整输出抽样配对评分，按源端点成组bootstrap2000次。
完整CPU明确减少且候选acc>99%时保留；总体点估计>=99.1%作为余量参考。
CPU节省至少10%时优先扩大10M。报告精度差、改善/恶化行数、源端口分组。
exp323同分布1M成绩继续用exp429，当前同步对照为exp434。
全160源、其他端点、静态资产容量及1B目标继续独立验证。

## 结果

完整A/B/B/A的CPU为1.12、0.92、0.91、1.12秒，均值1.120降至0.915秒，
减少18.303571%。候选峰值RSS1,627,553,792字节，单线程；
完整输出契约和每臂两次SHA一致性通过。exact标签生成CPU138.15秒单列。

同次完整输出的40k新exact抽样中，旧组合acc99.1766214072%，
整段下界99.1617735414%，候选95%区间[99.1249889788,99.1974752644]%。
配对差为-0.0148478658个百分点，95%区间[-0.0183717320,-0.0113504142]。
147条预测变化，147条评分下降；最弱源ZLS[7]为99.0955039521%。
总体点估计与区间下界均超过99.1%，逐源余量另行保留。
