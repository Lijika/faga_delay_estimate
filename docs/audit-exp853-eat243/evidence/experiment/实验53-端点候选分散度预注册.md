## 候选语义和字段

先按生产解析、根级可达性分派。有效请求在距离不超过150时采用Both，其余采用Source，
Source的I*目标真实前驱校验继续生效。端点经真实几何校验后，按 `(x,y,port)` 去重保留最低费用。
`S` 是合法至多一条Net路径最小值，`V` 是全部有限residue endpoint leaf费用多重集。
Source每项为 `exit.cost+middle`，Both为 `exit.cost+middle+entrance.cost`。
`middle` 沿用 `estimateBase()` 的fallback和零值行为，同费用保留重数。

生产答案 `E=min(S,min(V))` 只合并存在的有限项，空集沿用-1。根级拒绝行跳过端点枚举。
`S` 有真实路径依据，`V` 含近似中段，其次小值描述估计候选顺序。

| 字段 | 定义 |
| --- | --- |
| `from,to,parse_ok,root_unreachable` | 完整键与入口状态 |
| `mode_effective,dist` | 有效分派及Manhattan距离 |
| `exits_total,entrances_total` | 去重后端点数，Source入口记NA |
| `pairs_possible,pairs_evaluated` | 语义允许的候选数、原循环实际调用中段次数 |
| `finite_count,finite_count_pruned` | 完整、原剪枝枚举中的有限项数 |
| `short_present,short_value` | `S` 的存在性及费用 |
| `endpoint_best,endpoint_best_no_prune` | 生产端点答案及完整枚举重建的 `E` |
| `best_full,second_full` | 完整 `V` 的最小值及带重数次小值，缺项记NA |
| `gap_abs,gap_rel` | `second_full-best_full` 及其除以 `max(best_full,1)`；少于两项记NA |
| `ties_at_best` | 完整 `V` 的最小值重数，空集为0 |
| `pruned_early` | 原循环因incumbent跳过至少一项允许候选 |
| `pruned_best_full,pruned_second_full` | 被评估前缀中的顺序统计量 |
| `no_prune_second_full` | `second_full` 的明确别名 |

仅 `E` 的值可复用生产结果。原剪枝下 `V` 自身的first/second/ties都可能删失，尤其在 `S`
先赢时。因此 `best_full` 固定指完整 `V`，与 `E` 分列。统计根级拒绝、Source目标拒绝、空集、
单候选、并列、fallback及同pin的行数。

## 第一检查点

1. 私有源码构建与冻结入口在99条、已见1,000条、公开10k的默认输出逐行相同。
2. 探针与生产 `estimateEndpoint()` 的 `E` 相同，完整枚举与剪枝版的 `E` 相同，并与关闭
   残差的CLI输出核对。根级无效行按生产入口处理。
3. 同输入两次dump字节相同。检查排序、非负gap、重数、缺失值及150/151分派，覆盖无效
   端点、网格外、空输入和同pin。
4. 人工小集合覆盖短路径先赢导致所有residue项被剪、并列值及单候选。报告剪枝与完整second
   的数值差异和单侧缺失，分别以交集和全部有效行为分母。
5. 分Both/Source报告实际候选数、有限比例、gap定义域、剪枝比例、额外查表数、CPU和RSS。
   局部测量用于成本筛选，1B综合收益仍待实测。

等价或不变量失败时先修探针，重复受影响检查。无有效定义域或特征全常数时记录该候选负结果。

## 与四象限信号的重复程度

按完整键连接 `build/exp51/dump-seen-pool.csv` 和 `build/exp51/dump-public-10k.csv`，
键与重数均核验。双方定义域交集上算tie-aware Spearman及Kendall tau-b。主对为 `gap_rel`
与 `span_max_second`，另报 `gap_abs/gap_rel` 对 `span_max_second/span_max_min` 全部组合、
`finite/dominant` 分组及 `gap_rel × span_max_second` 四分位表，记录并列造成的实际箱数。

固定决策量为训练池和公开10k主对的最大绝对rho。主对无定义时先解释定义域或常数原因，
暂缓消融。rho至少0.9时按高排序重复停止本候选；0.5至0.9时须在含实验51象限列的控制之上
再验证；小于0.5时进入44维控制消融。阈值服务资源分配，低相关只支持继续检验。
统计定义依据SciPy官方 `spearmanr` 与 `kendalltau(variant="b")` 说明，常数输入记NA。

## 第二检查点结果

2026-09-25，使用当前生产端点 E 作为 fast，在完整键连接下完成 44 维控制与增加
`gap_abs,gap_rel` 的 46 维候选消融。训练池 10,024 行，开发来源为实验24/43/46 的
3,107/6,180/6,177 行；六个生产未计算槽按实验40约定置零。三份开发集的探针 E 与
`./estimate -residual off` 逐行一致，三次历史 fast 差异分别为 6/23/11 行，均为
exact<0，正 exact 行无差异。44/46 维矩阵、NaN 缺失规则、完整端点键的子集/乱序不变量、
单线程固定训练参数和确定性重训均通过；未生成新 exact、未运行 1M 或更大计时。

候选相对冻结模型的来源加权 accuracy 差为：exp24 `-0.006952 pp`、exp43
`-0.045909 pp`、exp46 `+0.000608 pp`，只有 1/3 来源为正。合并 15,231 条正 exact
评分行，冻结/44维控制/候选 accuracy 分别为 `95.608713%`、`95.594154%`、
`95.589272%`；候选−冻结为 `-0.019431 pp`，配对 bootstrap 10,000 次、seed
20260925 的 95% CI 为 `[-0.040641,+0.001743] pp`。候选−控制为 `-0.004967 pp`，
CI 为 `[-0.024731,+0.014980] pp`；控制−冻结为 `-0.014464 pp`，CI 为
`[-0.025487,-0.003385] pp`。候选和冻结的 false finite 均为 0。

按预注册门槛，候选不满足至少两来源为正、合并增益至少 `+0.03 pp`、候选−冻结及
候选−控制置信下界为正的要求，关闭 `gap_abs,gap_rel` 特征候选，不生成独立新请求。
原始证据为 `validation/results/exp53-stage-ablation.json`、同名 txt、预测 CSV、
`build/exp53/ablation/` 下的三份探针与 CLI 输出；脚本为
`validation/exp53_endpoint_ablation.py`。该负结果只关闭本候选，研究 goal 继续转向
路径位移匹配或中段 Block/边界信号；新 1B 或更大规模运行仍需用户明确确认。
