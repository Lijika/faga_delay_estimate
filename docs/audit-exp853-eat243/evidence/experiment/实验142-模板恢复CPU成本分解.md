## 主假设与边界

exp141 已保留 exp138 的同架构 accuracy 增益 `+0.0487506934 pp`；完整 unique/public/repeated 1M 输出与资源均通过。repeated 的 CPU 差为 `+0.476667 s`，95% 区间 `[+0.143076,+0.810257] s`，预登记诊断门失败。候选一次初始化恢复全部 12 个模板字段，展开 253,440,000 B。假设 repeated 回退的主要正成本项来自模板恢复；现有初始化 wall 与全进程 CPU 只能提示这一方向，尚未量化阶段 CPU。

Herdr Codex Astra 的静态核对给出了字段惰性加载的反例。repeated/public 第635、30、558行分别由 `A_AY`、`A_EQ0`、`S_CY` 展开到原十场及新增两场；unique 第2371、286、282行有相应见证。预测三个固定负载都触达12/12字段，故字段级惰性加载在这些输入上只能改变恢复时机。本轮先记录 repeated 的实际字段读取 mask；public/unique 的覆盖仍为静态推断。Astra 本轮提问属于工程成本诊断，后续每十个实验的提问按用户新增要求从第一性原理及实际反例提炼算法突破难题。

## 测量协议

主指标为两版 repeated 全进程 CPU 差及相应阶段差。使用 `getrusage(RUSAGE_SELF)` 的 user+system 分段统计整个初始化、模板恢复、query miss、selector、整个行处理；模板恢复再拆分 vector 分配、Zstandard 解压、字节平面合成、dy 前缀恢复。阶段有包含关系，汇总使用差值避免重复计入。模板读取位置另记录12位 mask。

先做6,176行冻结样本逐行等价检查，再在CPU 0同机串行运行，各版一次预热、固定10对 AB/BA 交错。所有观察保留，按df=9、双侧t临界值2.262157163计算95%区间，轮次固定后停止。逐轮核对完整1M契约、完整SHA、单线程、2GB RSS、3600s wall。baseline/candidate 输出分别固定为 `69c98e486abde3c5d3be56655aeed6c5339a70fc3b924fb4ec623fbd9da2af67`、`f4cf3af68e4e5471ba008fe142ce82033d191b70b0a5bed83825b23d700953ec`。

插桩会在每个 miss/selector 读进程CPU，仅用于成本定位；新阶段差不能替代 exp141 未插桩验收。以每轮 `Δ总CPU = Δ模板恢复 + Δ其他初始化 + Δmiss + Δhit/I/O + Δ其他进程CPU` 恒等式复核。accuracy沿用已通过的固定输出，任何输出/资源/身份检查失败即停止。此阶段没有模型/阈值选型和新标签。

若 candidate 的字节合成与前缀恢复合计均值至少 `0.03 s`，再登记单遍融合的组件原型；收益门和实际部署效果另行固定并测试。低于该值则记录成本并停止此工程方向。12/12 mask成立即停止“减少未触达整场”的方案。

本实验测得的全进程插桩 CPU 差 `+1.554 s` 与 exp141 未插桩 repeated 差 `+0.476667 s` 不能直接合并解释。插桩构建只用于阶段定位；其中“模板恢复以外”差值的派生均值为 `+0.776853 s`，95% `[+0.056952,+1.496754] s`，且行处理分量也变化明显。可靠结论是恢复本身稳定耗费约 `0.777 s`，其中融合最多直接作用于约 `0.205 s` 的两个阶段；其能否改善正式全进程CPU及恢复能否解释 exp141 回退，仍需未插桩候选配对验证。

因此下一轮保留 C4 的 accuracy 选择规则，仅对恢复循环做语义等价的单遍融合原型。实验门槛在看新计时前另行固定，必须同时检查完整1M输出 SHA 和端到端CPU；组件门通过只准许原型，不构成接入或收益结论。模型、模板选择阈值与精度均不改变，不关闭 C4 或其他未被路线图明确排除的方向。
