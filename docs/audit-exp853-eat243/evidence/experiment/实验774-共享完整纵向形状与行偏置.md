# 实验774 共享完整纵向形状与行偏置

2026-10-27预登记。exp773保留中间曲线后提高0.15至0.22pp，
四个独立节点已接近2GB预算。当前主问题是完整背景的质量、静态
信息与访问成本。复读深化报告6.7、6.8、8.6、9.1、9.2后，
本轮检验跨行共享完整形状，保持准备和完整CPU的后续验证要求。

## 假设与历史边界

固定pair、direction、rx、ry、qx得到46点残差R，定义C=R(45)、
S(q)=R(q)-C。N用C+A[a,q]；Q用C+A[a,q]+B[b,q]。
A有4096条完整曲线，B有256条，二者第0条恒零。
两级按顺序加权L1选择最小编号；第二级包含N的整行损失。
该包含关系适用于选码目标，实际请求单点与最终Acc分别检验。

exp689的256+128码作用于完整二维542点；exp738为二维1024/
2048单码；本轮固定qx、分离尾偏置并共享46点完整纵向函数。
exp650及666支持共享形状的机制，但各自的背景、函数长度和
预算边界保持。本轮不继承它们的质量或速度结论。

每行使用一个对齐uint32，低10bit存C+67，后12bit存a，
再8bit存b，最高2bit为0。N的b也为0。完整345047040行目录
1380188160B，加完整码本400384B和256MB预留为1636588544B。
这一布局避免变长查址和在线插值；查询为目录读取、一个或两个
小曲线元素读取及整数加法。预计可删除N512/D64及原曲线资产，
真实RSS、随机访问和初始化成本仍需完整候选验证。
完整静态目录须实际压缩并恢复；本轮不从样本压缩率外推ELF。

## 构造、数据与模型

复用exp773的92MB认证完整行缓存，按名义行键去重，核对同键
曲线完全一致。208个源各固定随机抽256个唯一行，共53248行，
种子20261027774。只使用固定架构名义值，真实图exact不参与码本。
构造测度是历史请求中的唯一行样本；全域适用与新请求质量另验。
所有源参与共享码本，有限源诊断不会成为交付算法。

权重沿用exp773的max(550-|dy|,0)/max(D_nom,1)，负向零轴为0，
乘2^20并就近取整数。整数权重支持确定性并列与独立枚举；
该矩形位置代理仍未计Block、端口可达性或官方未知分布。
固定行偏置后，从不同的非零构造形状无放回随机初始化A，
不足时补零；4轮加权整数中位数更新与精确重选码。B用A剩余
残量同样初始化及4轮更新。零中心固定，空簇保持。整数中位数
取满足累计权重达到一半的最小值，整列零权重时取0。
冻结两码本后对缓存全部唯一行重新顺序选码，保存当前请求的
uint32记录及整数背景。原fee、mandatory、cycle和非负裁剪保持。

普通残差与V匹配训练复用exp772，N/Q各比较53列16路T2D6
与T32D6，source-pin三折，V为71列V8，合计198模型。
所有真实标签、模型参数、基线B2/E2、分组和统计复用冻结身份。
当前数据已经用于研究选型，结果属于开发证据。

质量门沿用exp772/773，S需Acc>=99.1%、源族95%下界>99%、
三折均>99%，方向/距离/近轴最低差>=-0.05pp，
H/V最低差>=-0.25pp。通过S时才构造完整静态目录和启动恢复。
若仅T通过，记录信息与小残差函数容量问题；S/T都失败则停止
当前码长、构造样本、权重及顺序训练配置。正的精度信号保留，
其他容量及联合训练不由此被否定。通过交付资源门后立即新100M，
联合收益通过后阶段接入并完成全有效端口非重复1B。

## 验证与成本

本轮仅新增私有验证脚本、分配器、协议及证据，不改变生产接口。
分配器从exp650整数行加权L1模式改为可变码本、逐行整数权重，
所有乘积累加使用uint64；按块早停保持最低编号并列。
自检覆盖有符号极值、全零权重、重复中心、最大码数、权重中位数
与32bit字段边界。每次分配核对被选中心精确损失和训练单调。
独立审核重读记录重建全部200万背景，并对每源一行穷举全部
4096/256中心；198模型与400万输出由原独立JSON解释器复核。

全部算法计算在r9r4900私有research/exp774，构造最多8线程，
总CPU<=3600秒、wall<=1500秒、RSS<=8GB、新资产<=100MB；
审核CPU<=300秒。部署继续单线程、RSS<=2GB、ELF<100MB。
该轮不新增exact及完整100M/1B程序测试。目录、背景和训练成本
分别记录，任何实现错误先修复，质量门保持。
开工本地/dev/sdd约269GiB可用，远端约599MB可用。
