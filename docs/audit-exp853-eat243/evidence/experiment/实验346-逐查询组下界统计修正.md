# 实验346 逐查询组下界统计修正

2026-10-17。复用exp344的固定下界构造和输入，修正其观察统计。
正式入口保持exp335，本轮只改变私有插桩与统计。

## 主假设与固定方法

exp344统计函数把所有查询的生成组保存到同一个数组，最后统一使用
全样本最大出队键。它还用出发状态的g计算落点组下界，少计Net费用。
两者保持较弱界的安全性，但与预登记的逐查询观察量不同。

本轮每条查询单独保存生成组与最大物理pop键K，包含stale pop。
查询离开时立即累计 `bound>K` 和 `actualMin>K` 的候选数，覆盖全部
提前返回。下界使用 `g+Net费用` 作为落点基础费用，另外记录少计Net
费用的逐查询比例，以区分两项修正。启动边界检查单列，主样本前清零
统计。原搜索的排序、relax、标签、父链、路径与预算480/权重1010保持。

固定使用原12,150条标签审计请求与非重复20k前缀，均为开发数据。
主指标仍为非重复20k的保守可省q/push候选比例，至少10%且包含关系、
原字段和路径全部通过，才创建在线调度候选；低于10%结束本固定构造
扩大。两项修正只观察工作量，插桩CPU用于研究成本。

## 检查与停止条件

先用两条具有不同K的微型查询检验统计隔离，再跑原整数下界自检。
实际样本逐组核对 `H<=Arc+h` 与 `bound<=actualMin`，核对输出
逐字段（CPU除外）、完整路径SHA、单线程及2GB/3600秒约束。
汇总重复读取应保持结果。普通探针和ASan/UBSan微型检查完成后，
两套样本及原始身份复核通过即结束；正式程序CPU、100M、1B另验。

证据位于 `validation/results/exp346/`，私有探针位于 `build/exp346/`。
