# 实验792 exp791候选的匹配残差评分诊断

2026-10-28预登记。实验791固定alpha=12/5后，四方向留出曲面
qx0/1加权L1合计下降13.94%，但按原全曲面几何权重计总L1
恶化2.73%，未过其预登记信息门。exp788的分组归因显示近轴
名义替换可能对应较高官方分数价值；几何L1不能替代最终评分。

## 目的与边界

本轮不改变exp791训练所得B1024码本，不搜索权重或重训曲线；
仅作为新诊断，在固定的历史百万请求、source-pin三折、相同
T2D6/H8/V8参数下评估该码本与匹配残差的官方整数分。exp791的
全曲面L1门失败仍保留，结果不能改写成exp791通过。

全部million标签与背景人口均为已反复使用开发数据。alpha的动机
也参考了同一历史开发集的exp788分组，因此本诊断只回答“几何
残差重加权能否转成当前开发集分数”，不提供未见请求的独立
泛化区间、100M/1B结果或正式接入依据。

## 固定对照与执行

- 基线：exp787 B1024背景与其匹配残差、原完整预测。
- 候选：exp791 alpha=12/5 B1024背景、完全相同的首级A2048、
  目录格式、特征、折分、训练器和树参数，重新训练匹配残差。
- 额外输出：新背景配旧残差失配格，仅作诊断；不得作为候选收益。
- 精度：配对总体分及qx、方向、event、fold、source组分；分数
  差对exp787至少+0.02pp、qx0/1各组不降、方向最低≥-0.05pp、
  H/V最低≥-0.25pp，才通过开发诊断门。
- 资源：离线CPU≤2000s、wall≤1200s、RSS≤8GiB；无新exact标签、
  无完整估计程序、无静态ELF和完整CPU结论。

本轮为了测量候选官方分，明确绕过exp787评分器中的“名义L1
信息门必须通过”前置断言，仅在内存中向该诊断的背景构造步骤
提供一次允许标志；磁盘上的exp791失败证据保持不变。任何候选
即使通过本门，也必须另做现成非重复100M完整程序与同次exact
配对，再按项目阶段规则决定是否运行1B。
