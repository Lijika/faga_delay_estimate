# 实验797 近轴专家的背景与残差交互分解

2026-10-28预登记。exp795的支持域近轴候选使用B1背景与匹配专家残差，
开发集提高0.044661990pp；exp796将同一固定路由专家改为exp787的B0
背景后提高0.001537047pp且qx1轻微退化。需要在相同请求、路由和折外
预测上分离背景主效应、条件残差主效应及二者交互。

## Altitude：把背景与纠错器作为一个系统对照

报告路线B明确要求B0/R0、B1/R0、B0/R1、B1/R1四格，且不能由失配
格单独决定是否保留新背景。本轮复用exp787匹配残差R0、exp792导出的
B1背景、exp796的B0近轴专家R1及exp795所用的B1近轴专家R1。它们覆盖
同一支持人口：ordinary、qx≤1、支持route `[0,1,4,5,8,9,12,13]`；
四格外的所有请求都保持exp787预测。

## 固定四格和分析量

- B0/R0：exp787 Q1024背景及匹配残差，作为基线。
- B1/R0：在相同选中请求上，将exp787原始残差输出作用到exp792 Q1024
  背景；只作冻结残差失配诊断。
- B0/R1：exp796按exp787背景训练的支持域专家预测。
- B1/R1：exp795所用的exp793折外专家输出，背景为exp792 Q1024。
- 四个预测均按exp787最终整数解码和tanh评分；严格复用相同样本与标签。
  不新训练模型、不调参、不新生成exact标签、不创建提交二进制。
- 逐行评分差计算背景在R0与R1下的效果、残差在B0与B1下的效果，以及
  交互差：`(B1R1-B1R0)-(B0R1-B0R0)`。同时报告全样本及qx0/qx1组。

## 验证与范围

先核验exp787、exp792、exp795、exp796冻结文件和预测SHA；核验四格外
逐行保持exp787、H/V逐行不变、qx≥2逐行不变，且四格分解恒等式误差
不超过1e-12。以独立脚本重算四格和统计量。

本轮仅用于解释同一历史开发集上的机制，不提供未见请求泛化区间，也不
构成完整程序CPU收益。任一背景或残差对照的统计点差不能提升为新请求
因果结论。后续只有形成可部署的精度—CPU联合候选，才进入非重复100M。

证据预期：`validation/exp797_background_residual_factorial.py`、
`validation/results/exp797-run1/`。仅保存冻结身份和小型JSON报告，不
复制百万行预测文件。
