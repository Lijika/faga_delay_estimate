# 实验766 精确背景的小残差容量与误差预算

## 证据与待判断问题

exp744的精确名义背景加64树教师达到99.402233%，普通人口贡献主要
收益。exp734增加普通几何条件与教师容量只提高约0.046pp。
exp747、755、756、763的固定短点积表示在浮点阶段已有明显损失。
exp733保留公共准备的等输出回放为10.684370秒/100M，说明背景替换
需要与公共准备简化共同推进。当前exp765完整100M计时已结束，
新exact与联合评分仍按原冻结协议完成。

尚待判断的是精确背景是否必须配合64树才能超过99%。若现有T2D6
预算已足够，背景研究可以用明确的最终输出误差预算筛选表示；
若小模型仍不足，需继续研究背景与地图信息的共同表达。

## 固定实验

复用exp744已核验的百万历史请求、完整truth、精确名义N、首段fee、
mandatory、source-pin三折及全部59,904角色对。端口范围排除I*。
两臂仅改变训练背景，输入均为当前53列，保持16路、2棵depth6、
eta0.7599及exp734其余参数。目标为truth-background-mandatory，
权重1000/truth。B2用当前背景，E2用N+fee，各训练一次三折。
V输出保持当前冻结V8，完整四格分别用两个背景与两个raw合成。
冻结T2D6和exp744/E64作为已有参考，E64的输入与容量差异单列。
B2须重现exp734/A的历史分数，否则先定位实验条件。

原生模型、JSON叶号、double累加和最终整数逐行检查。主诊断门为
E2总体Acc至少99.2%、源族95%区间下界大于99.1%、三折均大于99.1%，
距离/方向/近轴组相对B2保持。通过仅支持低成本残差的背景研究，
交付资格仍需可实现表示、完整100M联合门及1B实测。

固定E2残差后，对非V名义背景施加逐行任意整数误差[-e,e]，
e从0到8ps，计算两端输出中较差的逐行得分并汇总。
解码关于背景单调，固定truth的绝对误差在输出区间端点取最大，
因此该值是在此数据和误差界前提下的保守评分。
用小数组穷举及保存预测独立核对；不把该条件界外推为隐藏分布保证。
按名义近域、商距离、ordinary/H/V和实际距离报告损失与背景差分，
用于判断下一个表示应压缩哪些信息。
