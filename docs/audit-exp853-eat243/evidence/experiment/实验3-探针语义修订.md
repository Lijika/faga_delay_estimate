# 实验3 plan_probe 探针语义修订

日期 2026-09-17，基线提交 baf5139。本轮只修 tests/plan_probe.cpp 的诊断语义并补最小回归，
src、scripts 与 estimate 均未改动。文中的输出证据来自未改动的基线生产代码，百万行本轮未复测。

## 方法与命令

把探针计算抽成共享函数，self-check 与 crp、tnr、labels 调用同一份实现，回归不另写公式。
新增 tnr 入口，labels 保留 ALT、窗口图、relay、label 空间投影的原有结构。探针在下列情况
返回非零。crp 遇到同约束样本量为零、同约束不一致、跨 cell 计数不守恒、cell 局部值低于全图、
局部值有限而全图不可达时失败。labels 遇到 relay 低于精确距离时失败。self-check 任一断言失败
即失败。

```sh
g++ -std=c++17 -O2 -Wall -Wextra -Wno-unused-parameter -o build/plan_probe \
    tests/plan_probe.cpp src/architecture.cpp src/router.cpp src/residue_estimator.cpp
timeout 60s stdbuf -oL ./build/plan_probe --arch doc/eda比赛文件/arch --self-check
./build/plan_probe --arch doc/eda比赛文件/arch --crp
./build/plan_probe --arch doc/eda比赛文件/arch --tnr --width 8 --height 8
./build/plan_probe --arch doc/eda比赛文件/arch --labels --width 8 --height 8
```

## 旧语义下的失败回归

早期版本的自测把 5760x5760 全矩阵建了出来，未能在合理时间内结束。现改为采样 3 entries 与
6 exits，自测约 0.6s。旧语义下的关键输出如下，行内是程序断言名与统计值。

```
FAIL via-hub relay uses d(s,h)+d(h,t)
FAIL same-way hub
FAIL correct relay verdict is equal, not under
info real out=3275840 in=3275840 conserved=yes | nominal out=3275840 in=3189440 conserved=NO
info cell matrix same-constraint matches=0/18 (sampled 3x6 of 5760x5760)
FAIL matrix equals the explicit port-graph Dijkstra under the cell restriction
info cell(76,100) real entries=0 nominal entries=0 missed-by-nominal=0
FAIL nominal-origin enumeration misses concrete Block-band cell entries
SELF-CHECK FAILED 5 check(s)
```

名义原点计数使 incoming 少 86400 条跨 cell 边。矩阵在相同约束下与显式 pin 图 Dijkstra 0/18
一致，差额来自重复计入的 I 到 Z Arc。前 4 项失败来自旧矩阵与 relay 语义；第 5 项是当时夹具把
测试 cell 选在 Block 空洞，(76,100) 的 real entries 与 nominal entries 都为 0，属夹具选择问题，
换成 (90,100) 后才具备判别力。5 项失败不能全部归因于算法。

## 修正内容

cellExitMatrix 离开 cell 的 Net 落点只计 hop 的 gap 费用并记到 exit I，I 到 Z Arc 只在落点
位于 cell 内时展开。AccessRelay 的 best 改为 reverseToHub 的 d(s,h) 加 forwardFromHub 的 d(h,t)，
reverse 邻接由反向 Dijkstra 生成。countCrossCellInterfaces 枚举真实 resolveNet 边，origin cell
与 landing cell 不同时出、入各计一次，名义原点版本保留为历史证据。enumerateCellInterfaces 的
entry 改为全图真实枚举。auditCellEntries 复算历史判定并给出具体漏计 entry。
restrictedPortDijkstra 的出口松弛改成取最小值并在队首距离达到答案时结束，避免把未出队的
虚拟终点当成精确值。删除无用的 PortState 与不再使用的名义 entry 枚举，补齐 tuple、set、
numeric 头文件。

self-check 第 4 段新增 membership 断言。该段先用 auditCellEntries 找出会被名义规则漏掉的
Block skip entry，再调用 enumerateCellInterfaces 并二分查找断言真实枚举确实返回该 landing。
若把 enumerateCellInterfaces 改回名义原点规则，这条断言会失败。


## 原因与限制

三处错误都来自用名义量代替真实图语义。出口费用把下一格 entry 的 I 到 Z Arc 记进本格，relay
用两次正向搜索拼有向路径，incoming 计数用 dx 与 dy 反推原点。修正后这些探针只描述各自的小
原型。完整两级 CRP 与 MLD overlay、TNR 的 access mapping 与 transit matrix、locality filter、
hub label 的 cover 与查询正确性、标准 CCH 的 nested dissection、customization、层次查询与更大
区域实验都尚未实现。单 hub relay 的 hub 选择只按出度取前 12，equal 与 strict 只对该样本与
hub 集合成立。restrictedPortDijkstra 与全图 Router 的比较是同约束与跨约束之比，两者不等属于
预期。本轮不产生任何比赛分数或增益结论。
