# 实验311 默认轻度权重键的整数分解

## 预注册

2026-10-16。在exp305窄除法基线上，将默认weight1010的
floor(h*1010/1000)改为h+h/100。其他weight参数保持原表达式，
通用O2、原编号、512预算、Both与模型均保持。新增分支服务
当前默认权重，h为非负int32；g与h先升为uint64后相加。
理论见vault《百分之一加权键的整数分解》。

候选只改私有legal_path_search.cpp的一条key表达式。
算术夹具从修改后的真实源码抽取表达式，核对连续h、100的
整除边界、INT_MAX与UINT32_MAX的g、历史权重及随机值。
普通及ASan/UBSan各运行一次；八臂97,200条搜索字段、
895,251条路径边、四套exact样本与四组CLI SHA须全部保持。
任一差异保留证据并停止性能测量。

两臂baseline exp305、split候选，Xeon core3串行，原序
20k/100k，两臂预热后AB/BA/AB三轮，共16次。主指标100k
完整user+sys，df2 Student-t 95%区间两端加0.02 s舍入。
差区间下端<=0保留完整1M资格，明确变慢则结束固定实现扩大。
0.5%只记效应，AMD只作参考；精度由同次输出身份复用，
差0 pp、变化行0，新增exact和评分0。

逐次验输出契约、SHA、多次一致、单线程、RSS<=2GB、
CPU/wall<=3600 s。构建、算术、审计、计时成本分别记。
20k/100k全量exact、完整1M、100M/1B、跨架构和平台另验。
开工磁盘405GiB，收尾复查。
