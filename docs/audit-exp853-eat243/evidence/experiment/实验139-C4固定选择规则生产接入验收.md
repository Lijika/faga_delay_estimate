## 假设与固定行为

exp138在独立同架构请求上验证了`all-lower-only-500`，增益+0.0487506934 pp，配对bootstrap 95%区间[+0.0291140843,+0.0703144572] pp。假设将这一固定选择接入生产缓存未命中路径，可逐行保持exp138选择器的最终整数输出，且实际静态文件低于100,000,000 B、完整1M输出契约与2GB/3600秒/单线程资源约束通过。

固定12场集合为exp136的十场`p1`和新增`ZSEA[4]`、`ZDW[2]`，坐标均使用记录的(60,284)源场。raw采用exp136模板端点展开和Line修正语义；仅当最终base已应用生产模型与统一-3 bias、base>0、raw非负且严格小于base，并满足下式时选择raw：

```text
(base - raw) * 10000 <= 500 * base
```

候选仅在原有正式默认配置激活，模板表在初始化时恢复，查询计算只在估算缓存miss执行，缓存保存可经现有bias路径还原为选择后输出的值。其他CLI配置、`estimate()`直接调用、非候选构建及exp131正式包保持原行为。相同端点重复命中缓存时，输出须与miss相同。
