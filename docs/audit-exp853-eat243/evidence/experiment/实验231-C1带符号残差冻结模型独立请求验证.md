## 预注册

仅用 exp215 的 6180 行重新训练一个模型，P>0 行参与训练，沿用 exp230 的
19 个 upper 特征、32 棵 depth3、L1 目标、`weight/max(exact,1)` 权重及全部参数。
输出规则与 exp230 一致，alpha 固定为 1。该数值是 exp230 五折中四折采用的
缩放值，本轮在新标签生成前固定，不再校准。模型 JSON 与离线特征实现一起提交。

基线为固定 selector+C4800 截断 P；候选用 `exact-P` 的带符号残差模型，
取整后限制为正整数，并以合法 U 作高侧截断；P<=0 保持原值。
exp226 的固定 `(8,64)` 作为单独描述性对照。模型输入只读取端点、P 与 U。

新请求窗口固定为 `[60M,62M)`，先生成 2,000,000 行，再排除与
exp174/203/215/226/228 任一请求共享完整 pin 的行。七带各取至多 2048 行，
抽样 seed2026101209，样本及权重先提交，随后运行经核验 exact 求解器。
重新检查基础模型训练请求零重叠，四个中短距离带各取两行 plain/span 交叉核验。

使用与 exp228 相同的 selector、20 棵 C4800 树和八种 cycle 生成合法上界。
逐行核对端点、exact、权重、U>=exact、缺失资格、零/负值及整数输出。
旧 exp215 训练数据只检验模型 JSON 预测、独立树遍历与重复加载的位级一致，
不以训练分数作为推进证据。

主指标为总体权重恢复后的 accuracy 配对增量，七带 bootstrap 10000 次，
seed2026101210。推进门为相对 P 点增益至少 +0.10 pp 且 95% 区间下界高于零。
报告七带贡献、改善/恶化行数与相对 `(8,64)` 的描述性差值。
未过则停止此固定模型，不使用新标签调深度、树数、特征或缩放值。
通过后才做 C++ 导出、完整 1M 与整程序 CPU 验收。

## 实测结果

单一冻结模型通过独立精度门。七带实际抽取 12,322 条请求，其中零距离 34 条，
其余六带各 2,048 条；排除 3,958 条已查看 pin 相关请求后，恢复总体权重为
1,996,042。提交 `e607577` 的标题把样本量误写为 12,324，冻结文件、执行
输入和评分记录均为 12,322。
