# 实验712 真实最优词的平局选择与跨位置支持

2026-10-25，在新增词生成和统计前登记。exp710/711已界定固定词函数
表示的容量边界。新报告第4.5和11.2节提醒，保存词的复杂度和移植失败
可能部分来自平局代表。先测代表选择对该机制的影响，再决定是否继续
扩大支持编译。正式算法及exp708阶段制品保持。

## 数据与三种选词

固定seed20261025712，在exp705的26源族×4方向各抽10个完整pair，
共1040组，每组原四位置全部保留，合计4160条。选样只读端口、坐标、
方向，随后加载原exact D0。它是原四位置总体的开发组件样本，完整程序
测试继续只用100M和1B。记录各层人口数与抽样概率，检查源目标族及lane。

O为原严格下降和原后继序，重新运行后词须逐字节等于旧词。
R只反转每个节点的有序后继和源Arc种子顺序，保持原exact费用目标。
H在原费用最小的路径中最小化Net跳数。H按费用及跳数的字典序更新，
继续处理f等于已知最优费用的队列项，直到f严格大于最优费用。
启发式仍只对原费用提供已认证下界，所有Net及Arc费用保持。
相同费用与跳数继续按原确定顺序保留首次父链。

复用exp552求解器与exp705无Line架构及终端折叠。新增hop标签只在
私有H构建使用。源Z初始hop为0，每次Net+Arc转移加1；末端Net加1，
被折叠的固定末Net统一补1。同格空路径与终端Arc分别保持原语义。

## 检查、指标与门

三臂D0逐条等于原标签，完整词Arc接续、真实落点和逐步累计费全部核对。
H的跳数不得高于O/R，保存的最优跳数须等于父链重放计数。
构造小图自检覆盖同费用长短路径、延迟更小但跳数更多、相同费用晚发现
短路及零费用边；H采用有限状态字典序松弛，hop严格递增防止等费环。

各词移植到同pair的另三个位置，分别记录越界、缺格、错误落点、
合法同终点费用、恢复目标D0比例。目标位置自身的词全部排除。
比较O、R、H及三臂并集；报告词长、motion RLE及去重计数。
各层先取每pair四位置均值，再按原pair人口权重汇总，配对差用设计方差。
这是固定名义键四位置总体的支持诊断，指标不称为最终Acc。

扩大门固定为并集较O恢复D0的比例至少提高3个百分点，或H平均词长
至少下降20%且其支持覆盖比O下降不超过0.5个百分点。全部语义门必须通过。
若两项均未达，结束当前三种代表的扩大，保留其他路径族与参数化研究。
此门只决定支持机制研究，不能触发模型接入或100M成绩声明。

## 执行范围

私有构建、路径与结果放build/exp712及validation/results/exp712，
远端research/exp712。exp709完成后才运行exact，三臂串行。每臂CPU
上限1800秒、RSS上限1.5GB，遇到预算或语义失败保留证据。
无训练、新完整估计器运行和发布；离线成本与部署成本分别记载。
开工本地/dev/sdd可用约278GiB，远端约41GB；本轮仅新增小型数据。

## 结果与边界

三臂各4160行全部恢复原D0，O词逐字节相同。H的保存hop标签与完整
父链重放相同，每行跳数均不高于O/R。全部交叉重放、对角原位置核验、
目标自身词排除和独立分层配对统计通过。

| 代表池 | 跨位置合法到达比例 | 恢复目标D0比例 |
| --- | ---: | ---: |
| O | 79.965570% | 74.600402% |
| R | 80.067024% | 74.673478% |
| H | 79.910315% | 74.571022% |
| 三臂并集 | 81.155849% | 75.795189% |

并集恢复率增加1.194787个百分点，设计95%区间为[0.839647,1.549927]，
低于3pp扩大门。H/O平均词长比0.999710546，下降约0.029%，低于20%门。
平均Net数O/R/H分别22.996712/22.996936/22.990055；平均motion RLE
分别10.221164/10.173432/10.204547。R改变1207条词，H改变27条。

原队列次序会改变代表及少量支持覆盖，但本轮三策略增加的支持和长度
改善均未达到固定门。停止该三代表池扩大，保留其他次优路径族、按支持
稳定性选词和参数化片段的研究资格。这里没有未知请求Acc结论。

三臂离线CPU为22.485389/22.386925/23.292005秒。启动首次误用没有
NumPy的系统解释器，随后复用exp491虚拟环境；exact尚未启动。
最终导出遇到NumPy布尔值，改为Python bool后仅重做汇总，三臂路径
保持SHA。两次失败证据分别保留，independent-audit.json通过。
小型证据与路径保留，删除0B。
