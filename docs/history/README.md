`fed41553d0f85b963612ed9fc783d8d96598d918`。其中路径和验证范围对应当时快照。

`publication-verification.json` 和 `PUBLICATION-SHA256SUMS`。

`accuracy/exp688-replacement-check.json`。旧来源文件保留用于审计数据的取得过程，
