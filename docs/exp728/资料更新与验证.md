`publication-verification.json` 汇总机器可读结果。

1. 59 份冻结源码、模型和原始资产逐文件核验；同工具链独立构建，五份对象与最终 ELF 相同，静态链接与容量通过。
2. 3,833,856 条记录的 SHA、实际坐标、完整端口、角色 pair、唯一性、原行序、分层覆盖、人口权重和训练 pin 标记均通过。
3. 两版完整样本的 Acc 重新计算，与原报告一致；CSV 与全量 NPZ 逐行核对，旧子集所有字段保持。
4. T2D6 route 0 最终参数与冻结模型相同；fold 0 源 pin 隔离、叶编号和原生 raw 预测通过。历史 S8 route 0 从移动后的参数路径重训通过。
5. exp720 新增的 1,916,928 个排除 pair 与旧排除集合、训练源 pin 完整互斥；三份历史抽样计划全部重建为相同 SHA，过滤和 sampler 机制检查通过。
6. 提问书进行措辞、数值、路径和约束复核，Obsidian 与仓库副本按字节核对。

Git 全范围空白检查提示七份历史原始文件的 CRLF 或行尾空白，均已与原文件核对相同。保留这些原始字节，对其余新增代码和文档执行的空白检查通过，清单见 `publication-file-checks.json`。

精度导出仅读取已有 exact 和预测。本轮没有新增完整 estimate、精确标签生成、
新的性能对比或比赛平台运行。SSH 传输中出现的超时已通过重新连接和 SHA
检查解决，成功的独立构建记录单独保存。

## 仍未验证的范围

当前 Acc 是既有 1B 的分层估计，整套输入已有研究历史。当前完整 1B 只有
一次候选运行；官方隐藏集、全量 1B exact、五次 1B 平均、6242R 和其他 CPU
性能仍未验证。exp703 perf 属于旧 exp688，本轮没有采集 exp728 新 perf。

本轮只重训 T2D6 route 0 和其 fold 0，其他 route 的参数按冻结身份提供。
完整名义场和曲线没有重新拟合；历史研究运行器仍依赖当时工作目录及大型
中间资产。官方合法请求域是否仅限 208×288 仍开放，提问书已经要求专家处理
这一问题。
